# 会話（会話の仕組み・シナリオのセリフを触るとき）

セリフを足す・直すときは **`dialogue-csv` スキル**（CSV の書き方・取り込み・点検・ユーザーの好み）。

## 仕組み（`Assets/Script/Talk/`）
- `DialogueData`（文の配列 `lines`：`character`・`expression`・`speakerName`・`text`）、`CharacterProfile`（名前・色・左右・立ち絵の表情ごとの絵。`Data/Characters/Noah.asset`・`Sigle.asset`）、`Expression`（enum。**末尾にだけ追加**＝番号でセーブ・CSV に使う）。
- `DialogueManager`（シーンごとのシングルトン）。`Assets/Prefab/UI/DialogueSystem.prefab` を置けば使える（Stage1_1 / SampleScene / Stage_1_Boss）。Stage1_2 はシーンの Canvas に直接組んだもの（**両方直す**：枠 1600×260・立ち絵 820×1040）。
  - **シネマ演出（11-25 kura_study）**：「シネマ演出で出す」`useCinema`（初期値オン＝全部の会話）で、枠を出さずに `Camera/CinemaMode` の上下の帯と下の帯の字幕に出す（名前はキャラの色で文の前・1文字ずつ・▼・カメラが少し寄る）。イベントが続いている間は帯を出したまま。立ち絵は `cinemaShowPortraits`（**11-25 にユーザーの指示でオン**。シネマのときは 0.75 倍・下の帯の上に持ち上げ・0.2 秒のフェードイン〔`LayoutPortraits`・`FadePortrait`〕。11-25 時点で立ち絵が出ていた会話の一覧は `Docs/シネマ演出で隠した立ち絵.md`。Stage1_2 はシーンの Canvas の並び順しだいで立ち絵の下が帯に隠れるので確かめる）。
  - **見た目（11-26 チームの指摘）**：細い上下の帯（0.07）＋下の黒いぼかし（高さ 0.22・濃さ 0.8）＋**今までの会話の枠を小さく（1240×200）、ぼかしにかからないようにその上に**（`cinemaTextStyle` = 会話の枠。`LayoutPanel`）。「字幕」を選ぶと枠なしでぼかしの中に白い文字（並び順 102）。帯は 97。
  - **テーマは「儚い」**（ユーザー、11-25）：演出は「現れて、溶けるように消える」でそろえる（▼ は明滅・文の切り替えと終わりはフェードアウト・立ち絵は透ける・文字は生成りの白・帯の縁はぼかす）。新しい演出も、元気な動き（はねる・揺れる）より静かなフェードを選ぶ。
  - 送りは E・Space・Enter（`extraAdvanceKeys`）。枠の右下の下にキーの説明（`showKeyHint`・`keyHintText`）。話していない方の立ち絵は暗くなる。
- `Dialogue`：会話の中身を持つ部品（Intaractable。**作者は成田さん**）。DialogueManager がないシーンでは旧方式で表示。
- イベントから会話を出すのは `DialogueEventAction`（会話）：**「会話データ」に DialogueData を直接入れる**（11-13〜。子の「会話」オブジェクトは要らない）。空なら前の作り方（子の「会話」に置いた Dialogue）を使う。OP・Stage1_2・Stage_1_Boss の今のイベントは前の作り方のまま。
- `DialogueCsv`（エディタ）：CSV（会話ID, キャラ, 表情, 名前, 本文）⇄ DialogueData。UTF-8 / Shift-JIS、同名は上書き（GUID 維持）。`DialogueCsv.Import(path, showDialog:false)`。Parse などは internal にして `BarkCsv`（相棒の一言）が使い回す。

## シナリオ
- 元は `Assets/Data/Dialogue/Scenario_OP.csv`（OP）・`Scenario_F1.csv`（一層）・`Scenario_F2.csv`（二層）・`Scenario_Landing.csv`（上陸 OP_02a〜OP_02k。2026-11-20 の指示書から。OP_01 の手紙の行はこちらの OP_02a へ移した。`OP_02_Desert` は今は使っていない＝-Lint で UNUSED に出る）。台本 `セリフ.xlsx`（ユーザーのダウンロード）から変換し、演出は「#」のメモ行に残した。
- 会話ID は `F<層>_<番号>_<場面>`。**直すときは CSV を直して取り込み直す**（DialogueData を直接直さない）。
- ノア・シグル以外は CharacterProfile がなく「名前」の列だけ（ティンパニ・ヴェルツィー・カイロス・？？？）。正体を隠すシグルは キャラ=Sigle・名前=？？？。
- 表情は台本から推測して入れてある。立ち絵は今「通常」だけ（ノア `Images/UI/UI_Noah`・シグル `Images/UI/UI_siguru`）なので、ほかの表情も通常の絵になる（コンソールに「表情 X の立ち絵がありません」が出るのはそのため）。
- **シグルとノアの関係（ユーザーの指示 11-20。書斎・T字通路から）**：シグルは表向きノアに興味がなくぶっきらぼう（話を聞かない・カイロスのことに答えない・一方的・一人で先へ行く・「お前がやれ」）。ノアを助けたことで力を使い、実は調子が悪いのを隠している（息が荒い・壁にもたれる・顔色。少しだけ匂わせる）。ノアは助けてもらったので最初は好意的だが、態度にムッとしたり不審に思ったりする。**嫌な奴にしすぎない**：どちらにも裏のやさしさ（ヒントをくれる・「くたばるなよ」「気をつけろよ」・ノアが体調を気にする）。
  - **バディものの最初の段階**（ユーザーの指示）：まだ仲良くないが、これからお互いを知り、認め合っていく流れ。いきなり仲良くしない。「認める」セリフを足すときは先にユーザーに確かめる（11-20 に足した3つ〔扉を壊すほどの力でも・ちょっとは見直した？・去ったあとの独り言〕は「いらない」と言われて消した。シグルの「、、で、なんで太鼓が分かった。」は残す）。
  - **シグルはお面をかぶっている**ので顔色・表情は分からない。調子の悪さは、息が荒い・肩で息をする・壁にもたれる・ふらつく、で見せる。
  - カイロス＝ノアの師匠（街一番の調律師）。何年も前にいなくなった。ノアが探している人。シグルはカイロスの質問にいつも答えない。
- まだ置いていない会話：`F1_13_Stairs`（二層への階段。部屋がない）と二層（F2）。`dialogue-csv` の `-Lint` の UNUSED で確かめられる。
