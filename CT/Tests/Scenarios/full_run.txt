# 通し：タイトル → はじめから → Stage1_0（船の上で OP → 奥の出口）→ Stage1_1（塔の入口）→ Stage1_2（ランタン → 追跡 → 助けられる → シグルが扉A を壊す）→ 扉A → Stage1_3（書斎。着いたとき）→ ロード
# シーンをまたぐつながり（遷移・出現位置・フラグの引き継ぎ・2人で着くか）を確かめる。1本 5〜6 分
scene Title
eval UnityEngine.Object.FindAnyObjectByType<TitleMenu>().OpenNewGame(); return "open";
button SlotAuto                 # オートセーブの枠
button YesButton                # 前のデータがあるときの「上書きしますか？」
wait scene Stage1_0
wait 2
advance all                     # OP（砂浜・船の上）
expect flag Flag_OP_Done on
expect eval !PlayerSwitchManager.Instance.Sigle.activeSelf   # まだノア1人
warp -115.1,37.5                # 奥の出口のすぐ手前
key UpArrow 400                 # 歩いて出口にぶつかる → Stage1_1
wait scene Stage1_1
wait 2
expect idle                     # Stage1_1 の OP は流れない
warp -115.5,25.6                # 塔の入口（F1_01）
wait 1
advance all
warp -115.3,29.0                # 上の扉 → Stage1_2
wait scene Stage1_2
expect scene Stage1_2
wait 2
advance all                     # 着いたとき
expect idle
warp -107.25,14.9               # ランタンの前
wait 1
key E
advance battle                  # 追跡が始まったらすぐ止まる
warp -128.6,13.0                # 追跡のゴールへすぐ
wait 2
advance all                     # 助けられる → 帰れ → シグルが扉A を壊して先へ（合流しない）
expect flag Flag_Sigle_Joined off
expect flag Flag_Shosai_DoorABroken on
warp -128.3,16.1                # 扉A に入る → 書斎（Stage1_3）へ
wait scene Stage1_3
expect scene Stage1_3
expect eval !PlayerSwitchManager.Instance.Sigle.activeSelf   # ノア1人で着く（シグルは部屋の NPC）
wait 1
advance all                     # 着いたとき：シグルが扉を殴る → ロック
expect flag Flag_Shosai_DoorsLocked on
expect no-error
reload                          # タイトルへ → つづきから（書斎の着いたときのオートセーブ）
expect scene Stage1_3
expect idle                     # 着いたときの演出が繰り返さない
expect no-error
