#       → Stage1_2（扉を閉める → 頭痛 → ランタン → 追跡 → 助けられる → シグルが扉A を壊す）→ 扉A → Stage1_3（書斎。着いたとき）→ ロード

expect talk あれが、塔          # 着いたら塔の全景スチル
