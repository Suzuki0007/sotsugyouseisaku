## 0. 背景（なぜ作るか）

11/20 のプレイ確認会を受けて、ゲームは「体験型ドラマ」（参考：風ノ旅ビト・GRIS）の方向に変わった。言葉で説明するより、**色・光・天気・画面の見た目で、場面の気持ちや時間の流れを伝える**作りにしたい。

そのための**演出の基盤**を作る。今回の範囲は次の5つ。

| 記号 | 名前 | 一言で |
|---|---|---|
| S1 | 世界の色調（ムード） | 場面の「気持ち」を、画面全体の色で決める |
| S14 | 光 | 場面の「時間帯」を、2D の光で決める |
| W | 天候 | 雨・雪・砂ぼこり・霧・光の粒などを、パーティクルで出す |
| S3 | 回想の見た目 | 過去の場面を、現在と違う見た目にする。暗転せずに切り替える |
| S15 | 1枚絵 | イラストを1枚、画面に出す（フェード・ゆっくり寄る・流す） |

**今回は作らない物**：エンドロール、音の聞こえ方の切り替え（Audio Mixer のスナップショット）、カメラのショット・黒帯、時代・季節の切り替え（S4）。ただし S4 は次に作る予定なので、**あとで「色調＋光＋天候」をまとめて1つの時代プリセットから呼べる**作りにしておいてほしい（6章）。

## 1. 全体の考え方

### 1-1. 役割を分ける

| 仕組み | 表すもの | 決まりごと |
|---|---|---|
| 色調（S1） | 気持ち | ポストプロセス（画面全体の色の加工）。光の色は変えない |
| 光（S14） | 時間帯・場所の明るさ | 2D の光（Light 2D）。画面全体の色の加工はしない |
| 天候（W） | 天気・空気 | パーティクルなど。色調・光とは独立して ON／OFF できる |
| 回想（S3） | 時代（過去か現在か） | 回想用の色調＋回想中だけ出す物＋（あれば）コマ落ち |
| 1枚絵（S15） | 区切り・余韻 | UI の上に出す。色調・光・天候の影響を受けない |

「色は気持ち、光は時間帯」を守る。色調と光の両方で同じことをしない。

### 1-2. プランナーがコードを書かずに使えること

今の開発目標（Inspector だけで制作を進められる）に合わせる。

- 色調・光・天候・回想は、それぞれ **Inspector で作れるプリセット（データ）** にする。
- 切り替えは、**イベントの流れの部品**（日本語名・分類メニューから追加）にする。
- **シーンに入ったときの既定**（このシーンはどの色調・光・天候で始まるか）を、シーンに1つ置く設定で決められるようにする。フラグの条件で既定を変えられるとよい（今の SceneBgm の条件や、フラグで見た目を切り替える仕組みと同じ考え方）。
- 項目には日本語の Tooltip を付ける（早見表の自動作成に載るように）。

### 1-3. 切り替えは「ゆっくり」が基本

どの部品も「かける秒数」を指定でき、0 秒なら即座に切り替わる。途中でもう一度切り替えが来たら、**今の見た目から次へ**なめらかにつなぐ（飛ばない）。

## 2. S1 世界の色調（ムード）

### 2-1. 作るもの

| 物 | 中身 |
|---|---|
| 色調のプリセット（データ） | 画面全体の色の加工の設定一式。名前・説明・中身 |
| 部品「色調を変える」 | プリセット・かける秒数・変わり方（直線／ゆっくり始まりゆっくり終わる）・終わるまで待つか |
| 部品「色調を戻す」 | シーンの既定の色調へ戻す。かける秒数・終わるまで待つか |

### 2-2. プリセットで調整したい項目

URP のポストプロセスのうち、次を使う想定（使える物・使い方は Claude Code が判断）。

| 項目 | ねらい |
|---|---|
| 彩度 | 喪失・回想で色を抜く（GRIS の考え方） |
| 明るさ・コントラスト | 重さ・軽さ |
| 色かぶり（暖色・寒色） | 温かい日常／寒い夜 |
| 暗い所と明るい所の色分け（Split Toning） | 映画らしい色味 |
| 周辺を暗くする（Vignette） | 孤独・集中 |
| 粒子（Film Grain） | 回想・古い記録の感じ |
| にじみ（Bloom） | 回想・夜明けの柔らかさ（光る物があるとき） |

### 2-3. 最初に用意してほしいプリセット（値は目安。調整してよい）

| プリセット名 | 使う場面 | 目安 |
|---|---|---|
| 通常 | 既定 | 何も加工しない |
| 夜・一人 | 砂浜に上陸 | 彩度 -30、寒色寄り、周辺を暗く（弱〜中） |
| 温かい日常 | 第一層の日常・カイロスとの再会 | 彩度 +5、暖色寄り、周辺を暗く（弱） |
| 喪失 | カイロスの死のあと・ヴェルツィーと同行 | 彩度 -70、コントラストを少し下げる、周辺を暗く（中） |
| 回想 | 地下の記憶・中庭の回想・埋葬 | 暖色（セピア寄り）、彩度 -20、粒子（中）、周辺を暗く（中）、にじみ（弱） |
| 夜明け | ヴェルツィーの墓・エピローグの手前 | 淡い桃色〜青、彩度 -10、にじみ（弱） |

### 2-4. 条件

- UI（会話・立ち絵・メニュー）は色調の影響を**受けない**こと。
- マップは中央 4:3（`MapCameraAspect`）なので、周辺を暗くする効果が**マップの表示範囲に対して**自然に見えること（16:9 の UI 全体の端ではなく）。見え方を確認して報告してほしい。
- 品質レベル「軽い」では、粒子・にじみなど重い項目を外せること。

## 3. S14 光

### 3-1. 作るもの

| 物 | 中身 |
|---|---|
| 光のプリセット（データ） | 全体の光（Global Light 2D）の色と強さ＋（任意）シーンの中の追加の光の ON／OFF と強さ |
| 部品「光を変える」 | プリセット・かける秒数・変わり方・終わるまで待つか |
| 部品「光を戻す」 | シーンの既定の光へ戻す |

### 3-2. 追加の光（場面ごとの光）

月明かり、ランタン、窓から差す光の筋、夕日、塔の頂上の小さな光など、**シーンに置いた Light 2D を名前（またはグループ）で指定**して、プリセットから強さを変えられるとよい。シーンに置く光は、プランナーが Hierarchy から追加できる形（右クリックのメニューなど）だと助かる。

### 3-3. 最初に用意してほしいプリセット（値は目安）

| プリセット名 | 目安 |
|---|---|
| 昼 | 白、強さ 1（今の昼の値） |
| 夜 | 色 (0.5, 0.6, 0.9)・強さ 0.45（**今の Stage1_0・Stage1_1 の夜の値**。レシピ `night_stage1_0_1`） |
| 月明かり | 夜より少し青く暗い。月の方向の追加の光を使う |
| 夕日 | 橙、強さ 0.8 |
| 夜明け | 淡い桃色〜水色、強さ 0.7 |
| 塔の中の暗がり | 暗い灰青、強さ 0.3 |

### 3-4. 条件

- **今の夜の設定（Stage1_0・Stage1_1）を壊さない**こと。プリセットに移すか、今のまま残すかは判断してほしい（7章）。
- 今の SpriteFrameBlend の「シーンの明るさに合わせる」（明かりなしのシェーダーの波も同じ色に暗くする）が、光を変えたときにも**ついてくる**こと。
- 今の部品「暗さ・視界を変える」（Stage1_2 のランタン・暗闇）と役割が重なる可能性がある。重ねるか、まとめるかを判断してほしい（7章）。

## 4. W 天候（パーティクル）

### 4-1. 作るもの

| 物 | 中身 |
|---|---|
| 天候のプリセット（データ） | 種類・量・風向きと風の強さ・落ちる速さ・色・大きさ・（任意）ループする環境音 |
| 部品「天候を変える」 | プリセット（「なし」も選べる）・かける秒数（量を増やす・減らす時間）・終わるまで待つか |
| 範囲で天候を変える（任意） | 範囲に入ると天候を変える／止める（室内に入ると雨が止む、など）。今の足音の設定（SceneFootstep）の「範囲の中だけ」と同じ考え方 |

### 4-2. 最初に用意してほしい種類

| 種類 | 見た目 | 主な場面 |
|---|---|---|
| 雨（弱・強） | 斜めに落ちる線。強いときは地面に小さなはね | 埋葬の記憶（季節）、中庭（任意） |
| 雪 | ゆっくり揺れながら落ちる粒 | 埋葬の記憶（冬） |
| 砂ぼこり | 横に流れる細かい粒。強いと少し画面がかすむ | 砂浜・砂漠 |
| 霧 | ゆっくり流れる半透明の層（パーティクルか、流れる絵） | 塔の中、夜明け |
| 光の粒 | ゆっくり漂う小さな光（ほこり・蛍のような） | 回想、地下、夜明け |
| 舞うもの（任意） | 花びら・葉など | 回想（三人の頃）、エピローグ |

### 4-3. 条件

- 天候は**画面（カメラ）の範囲にいつも降る**のが基本。マップの端でも途切れないこと。見下ろし 2D なので「上から降る」より「画面の上から下へ斜めに流れる」見え方でよい。
- 夜は粒が暗くなる（光の影響を受ける）か、受けないかを選べるとよい。既定をどちらにするかは判断してほしい。
- 描く順番：マップより上、UI より下。キャラの前後は、プリセットで「キャラの後ろ」「キャラの前」を選べると助かる（霧はキャラの前、雨は前、など）。
- 量を急に変えず、増やす・減らすときは「かける秒数」でなめらかに。
- 性能：粒の上限を決め、品質レベル「軽い」では量を減らす。毎フレームのメモリの確保をしない（今の性能のルールに合わせる）。

## 5. S3 回想の見た目

### 5-1. 作るもの

| 物 | 中身 |
|---|---|
| 回想のプリセット（データ） | 使う色調のプリセット・使う天候（任意。光の粒など）・回想中に立てるフラグ・入り方・（任意）コマ落ち |
| 部品「回想に入る」 | プリセット・かける秒数・入り方 |
| 部品「回想から戻る」 | かける秒数・戻り方（入る前の色調・光・天候へ戻す） |

### 5-2. 入り方（暗転しない）

| 入り方 | 見え方 |
|---|---|
| 色が抜けてから差す（おすすめ） | 今の画面の色がいったん抜けて灰色に → 回想の色がにじむように差す。その間に回想中だけの物が現れる |
| ゆっくり溶ける | 今の色調から回想の色調へ、そのまま移る |
| すぐ | 0 秒で切り替える |

### 5-3. 回想中だけ出す物

- 回想中フラグ（名前は今の決まりに合わせて決めてほしい。例：`Flag_Flashback_Active`）を立て、**今の「フラグで見た目を切り替える」仕組みで**、三人の頃の家具・人影・飾りなどを出し入れする。
- 出し入れは、パッと消えずに**透明度でなめらかに**変わるとよい（入り方の秒数に合わせる）。

### 5-4. コマ落ち（余裕があれば）

回想中だけ、キャラや物のアニメのコマ数を落として（少しカクつかせて）、古い記録の感じを出す。今の SpriteAnimator・Animator でできるか、どの範囲に効かせるかを判断してほしい。難しければ今回は見送ってよい。

### 5-5. 条件

- 回想から戻ると、**入る前の色調・光・天候**に戻ること（シーンの既定ではなく、直前の状態）。
- 回想中にセーブ・ロードが起きた場合の扱いを決めておくこと（7章）。

## 6. S15 1枚絵

### 6-1. 作るもの

| 物 | 中身 |
|---|---|
| 部品「1枚絵を出す」 | 絵（スプライト）・出すまでの秒数（フェード）・動き・動きの秒数・閉じ方 |
| 部品「1枚絵を閉じる」 | 閉じるまでの秒数（フェード） |

### 6-2. 動き

| 動き | 見え方 |
|---|---|
| なし | 止まったまま |
| ゆっくり寄る | 少しずつ拡大する（開始と終わりの大きさを指定） |
| ゆっくり引く | 少しずつ縮小する |
| 横に流す・縦に流す | 絵の一部を映したまま、ゆっくり動かす（開始と終わりの位置を指定） |

### 6-3. 閉じ方

| 閉じ方 | 中身 |
|---|---|
| キーで閉じる | 会話の送りと同じキー（Space・Enter）で閉じる。キーの案内を小さく出す |
| 時間で閉じる | 指定の秒数がたったら閉じる |
| 部品で閉じる | 「1枚絵を閉じる」が来るまで出したまま（その間に会話を出せる） |

### 6-4. 条件

- 1枚絵は**色調・光・天候の影響を受けない**こと。
- 出す範囲は、マップの 4:3 の範囲か、16:9 の画面全体かを選べるとよい。既定は判断してほしい（7章）。
- 1枚絵を出したまま会話を出せること（会話の UI・立ち絵が絵の上に出る）。
- 背景の色（絵の外側）を指定できること（黒・白・透明）。

## 8. 進め方（段階）

報告の合意のあと、次の段階で進めてほしい。各段階の終わりに、動作の確認と短い報告をする。

| 段階 | 中身 | 確認 |
|---|---|---|
| 1 | **色調**（プリセット・部品2つ・シーンの既定）と**光**（プリセット・部品2つ・追加の光） | 6つの色調・6つの光を、試し用の場所で切り替えて、なめらかに変わる・UI が影響を受けない・今の夜の見た目が変わらない |

| 3 | **回想**（プリセット・部品2つ・回想中フラグ・入り方） | 入る → 戻るで直前の状態に戻る・回想中だけの物がなめらかに出入りする |
| 4 | **1枚絵**（部品2つ・動き・閉じ方） | 動き4種・閉じ方3種・会話との重なり |
| 5 | 仕上げ | デバッグウィンドウで「その場で試す」、シーンチェックの点検（プリセットの入れ忘れなど）、テストシナリオ1本、プランナー向け作業手順書と早見表の更新、変更履歴 |

### 試す場所

今の Stage1_0（砂浜）の流れは変えずに、**試し用のシーン**（Build Settings に入れない。砂浜の絵を使う）で確かめるのがよいと考えている。試し用のシーンを作るか、別の方法にするかは判断してよい。

### デバッグウィンドウ（あると助かる）

色調・光・天候・回想のプリセットを一覧から選んで、その場で切り替えられる。プランナーが値を調整しながら見比べるのに使う。

## 9. 次の段階との関係（作り方の注意）

次は **S4 時間の層**（砂浜の時代・季節の切り替え）を作る予定。S4 では「時代プリセット」に、**色調・光・天候のプリセットと、出し入れする物（墓標の数など）をまとめて**指定し、部品「時間を進める」で一度に切り替える想定。

そのため、今回の色調・光・天候は、**部品からだけでなく、ほかの仕組みからも同じように呼べる**作りにしておいてほしい（同時に呼ばれたときに、どちらが優先かも決めておく）。

## 10. 使い方の例（プランナーが組むイメージ）

**埋葬の記憶に入る**（砂浜・過去）

1. 回想に入る（回想プリセット「埋葬」：色調＝回想、天候＝光の粒、入り方＝色が抜けてから差す、3秒）
2. 光を変える（夜明け、2秒）
3. 会話（シグルの独り言）
4. 天候を変える（雨・弱、4秒）
5. ……
6. 回想から戻る（3秒）

**エピローグの1枚絵**

1. 色調を変える（夜明け、3秒・待つ）
2. 1枚絵を出す（再会のイラスト、フェード2秒、ゆっくり寄る 10秒、閉じ方＝キー）
