# プランナー用ツールの使い方

制作・確認を速くするためのエディタ機能のまとめです。

| ツール | 開き方 | 何に使う |
|---|---|---|
| シーン・出現位置の選択 | SceneChange の Inspector | 遷移先の打ち間違いを防ぐ |
| シーンチェック | **Tools > シーンチェック** | 設定ミスを一覧で見つける |
| デバッグ | **Tools > デバッグ** | 再生中にアイテム・フラグ・ワープ・回復を操作する |
| 会話CSV | **Tools > 会話** ／ CSV を右クリック | Excel・スプレッドシートで書いた台本を会話データにする |
| フラグ一覧 | **Tools > フラグ > フラグ一覧** | `フラグの使い方.md` 参照 |

---

## 1. シーン・出現位置を選択式にする（SceneChange）

SceneChange の **Scene Name** と **Spawn Point Id** がドロップダウンになりました。

- **Scene Name**：Build Settings に入っているシーンから選びます
- **Spawn Point Id**：選んだシーンにある **PlayerSpawnPoint** の ID から選びます
  （「デフォルトの位置」を選ぶと、遷移先の初期位置に出ます）
- 候補にない値が入っていると、**オレンジ色で「⚠ 値（理由）」**と表示されます
  - 「Build Settings に入っていません」→ File > Build Profiles（Build Settings）にシーンを追加
  - 「○○ にありません」→ 遷移先のシーンに、その ID の PlayerSpawnPoint を置く
- 一覧の一番下の「**手入力に切り替え**」で、文字を直接打つこともできます

> 遷移先のシーンを開いていなくても、保存済みのシーンファイルから ID を読み取ります。
> プレハブの中に置いた PlayerSpawnPoint は候補に出ません（シーンに直接置いてください）。

## 2. シーンチェック

**Tools > シーンチェック** を開くと、すぐに今開いているシーンをチェックします。

| ボタン | 内容 |
|---|---|
| 開いているシーンをチェック | 今開いているシーン＋プロジェクト全体 |
| Build Settings の全シーンをチェック | ゲームに入る全シーン（閉じているシーンも一時的に開いて調べる） |
| エラー／注意／参考 | 表示する種類の切り替え |

各行の **選択** ボタンで、問題のあるオブジェクトを選択します（閉じているシーンなら開きます）。

### 見つけられる主なミス

| 種類 | 内容 |
|---|---|
| エラー | 遷移先シーンが Build Settings にない／出現位置 ID がない・重なっている |
| エラー | 宝箱の Id が空・重なっている／ItemPickup・ItemInteraction の名前が重なっている（セーブが混ざる） |
| エラー | 調べるオブジェクトに Is Trigger の Collider2D がない |
| エラー | EventZone の Event Sequence が空／DialogueEventAction の Dialogue が空 |
| エラー | EventSequence が自分（か親）を非表示にして、後ろの部品が動かない |
| エラー | Missing Script／ItemData が `Resources/Items` の外にある／アイテム・フラグの ID が重なっている |
| 注意 | EventSequence に登録し忘れた部品がある／ルールの Sequence が空／条件の Item・Flag が空 |
| 注意 | FlagSwitch・ItemPossessionSwitch に切り替える対象がない |
| 参考 | 遷移先が空の SceneChange（ボタンから呼ぶなら問題なし）／DialogueManager がないシーン |

**シーンを作り終えたら、一度チェックする**習慣をつけるのがおすすめです。

> 「Build Settings の全シーンをチェック」では、他のシーンを一時的に重ねて開くため、Console に
> 「More than one global light …」や「Creating missing … component」が出ることがあります。
> チェックのために一時的に開いたことによるもので、シーンは保存されないので気にしなくて大丈夫です。

## 3. デバッグウィンドウ

**Tools > デバッグ**

### 再生中にできること
| 項目 | 内容 |
|---|---|
| アイテム | ＋／− で所持数を増減する |
| フラグ | チェックで ON / OFF |
| ワープ | このシーンの出現位置へ瞬間移動／シーンビューの中心へ移動／別のシーンの出現位置へ移動 |
| プレイヤー | 全回復・1ダメージ・**無敵**（シーンが変わっても続く。再生を止めると元に戻る） |
| セーブ | 今の状態をセーブ（チェックポイントと同じ） |
| マップの範囲（歩ける範囲・届くか） | **歩ける範囲を表示**（ゲーム画面に線：緑＝歩ける範囲・赤＝歩けない形・水色＝マップの範囲）・**敵と相棒の道を表示**・**届くかの確認**（今いる場所から、調べる物・出口・出現位置まで歩いて行けるか。行けない物が上に赤で出て、理由・選ぶ・ワープ。閉じた扉やまだ開いていない通路の先は「行けない」と出るのが正しい） |
| イベント（その場で試す） | シーンのイベント（EventSequence）の一覧。名前で絞り込み、**実行**（操作中のキャラで、きっかけなしに）・**止める**。名前を押すとそのオブジェクトを選ぶ |

### 再生開始時の状態（自分の PC だけ）
「**再生開始時に、下のアイテムとフラグを与える**」をオンにして、個数とフラグを決めておくと、
再生するたびに自動でその状態から始まります。後半のイベントを、毎回最初から遊ばずに確認できます。

- この設定は**自分の PC にだけ**保存されます（他の人やビルドには影響しません）
- 使い終わったらオフにしてください（オンのままだと、普通に遊んだときの確認と食い違います）

### セーブ
セーブは3つのスロットに分かれています（詳しくは `タイトル画面とセーブの仕組み.md`）。

- **使っているスロット／プレイ時間**：再生中の状態
- **ステージから再生するとき**：Title 以外のシーンから再生したときに読み込むスロット（初期値「使わない（保存もしない）」。自分の PC だけの設定）
- **今の状態をセーブ**：チェックポイントと同じ（スロットを使っているときだけ）
- **スロット**：各スロットの場所・プレイ時間・保存日時と、**消す**ボタン
- **セーブファイルの場所を開く**：中身（save_1.json 〜 save_3.json）を確認したいとき

## 4. 新しいシーンで会話を使えるようにする

`Assets/Prefab/UI/DialogueSystem.prefab` をシーンに1つ置くだけで、会話（名前・立ち絵・送り）が使えます。
（中に専用の Canvas と DialogueManager が入っているので、シーンの Canvas に何かを足す必要はありません）

置き忘れると、会話が旧方式（1文だけ・立ち絵なし）になり、「会話を閉じるまで待つ」も効きません。
シーンチェックで「DialogueManager がない」と出たら、このプレハブを置いてください。

---

## 5. 会話を CSV から作る

### 書き方
1. **Tools > 会話 > CSVのひな形を作成** で、例の入った CSV を作る
2. Excel かスプレッドシートで編集する

| 会話ID | キャラ | 表情 | 名前 | 本文 |
|---|---|---|---|---|
| Elder_First | Elder | 通常 | | よく来たな、旅の者よ。 |
| | Elder | 笑顔 | | 北の森へ行ってみるといい。 |
| | Noah | 驚き | | 森……ですか？ |
| Sign_Village | | | | ここは はじまりの村 |

| 列 | 説明 |
|---|---|
| **会話ID** | 会話データのファイル名。**空なら上の行の続き**（1つの会話に複数の文） |
| **キャラ** | CharacterProfile のファイル名か表示名。空なら立ち絵なし（看板・ナレーション） |
| **表情** | 通常・笑顔・怒り・悲しみ・驚き・困り（Normal などの英語名でも可）。空なら通常 |
| **名前** | 名前欄の上書き（例：？？？）。空ならキャラの名前 |
| **本文** | 表示する文。セルの中で改行してもよい |

- `#` で始まる行はメモとして無視されます
- 保存形式は「**CSV UTF-8**」がおすすめです（普通の「CSV」でも読めます）

### 取り込み
1. CSV を `Assets` の中（例：`Assets/Data/Dialogues/`）に置く
2. CSV を右クリック → **会話CSVを取り込む**（または **Tools > 会話 > CSVから会話データを作成**）
3. CSV と同じ場所の「CSV名」フォルダに、会話IDごとの会話データ（DialogueData）ができる

- **同じ会話IDの会話データは上書き**されます。シーンに設定済みの参照は切れないので、
  台本を直したら**もう一度取り込むだけ**で反映されます
- キャラや表情が見つからない行があると、ダイアログと Console に何行目かが出ます

### 書き出し
既存の会話データを Project ウィンドウで選び、**Tools > 会話 > 選んだ会話データをCSVに書き出す**。
Inspector で作った会話を、CSV での管理に移したいときに使います。

> 取り込むと、Inspector で直接直した内容は CSV の内容で上書きされます。
> CSV で管理する会話は、**CSV だけを編集する**ようにしてください。
