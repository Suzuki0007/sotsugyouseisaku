# 素材の渡し方（作る人・集める人へ）

音や絵を Unity に入れる人（Claude・プログラマー）に渡すときの決まりです。
この形で渡してもらえると、**どこに入れるかが素材チェックリストから自動で決まり**、入れる作業がほぼ自動になります（`Docs/素材の取り込み.md`）。
守れていなくても入れられますが、確認の質問が増えます。

## 1. フォルダの分け方（いちばん大事）
**1つの素材（チェックリストの1行）を1つのフォルダに入れ、フォルダ名をチェックリストの ID で始める。**

```
渡すフォルダ/
  SE-16_Peg/              ← チェックリストの SE-16（ペグの音）
    SE-16_peg_start.wav
    SE-16_peg_success_1.wav
  POR-01_NoahFace/        ← POR-01（ノアの表情差分）
    UI_Noah_Surprise.png
  BGM-02_TimpaniBattle/
    BGM-02_timpani_battle_loop.ogg
```

- ID の後ろの名前（`_Peg`）は自由（英数字がおすすめ）。
- チェックリストにない素材は、チェックリストに行を足して ID を付けてから（一番下に足す。区分の頭文字＋番号）。
- 試聴用にいくつかをつないだ音は名前に `_image_` を入れる（入れずに残します）。古い版は `_old` フォルダへ（入れません）。

| ID の頭 | 区分 | Unity の置き場所 |
|---|---|---|
| `SE` | 効果音 | `Assets/SE/` |
| `BGM` | BGM | `Assets/BGM/` |
| `POR` | 立ち絵 | `Assets/Images/UI/` |
| `CHR` | キャラの絵・モーション | `Assets/Images/Player/` |
| `ENM` | 敵 | `Assets/Images/Enemy/` |
| `FX` | エフェクト | `Assets/Images/Effect/` |
| `UI` | UI（アイコン・HP・画面） | `Assets/Images/UI/` |
| `MAP` | 背景・マップ | `Assets/Images/Map/` |
| `EVT` | 一枚絵・演出 | `Assets/Images/Event/` |
| `ETC` | その他 | `Assets/Images/Other/` |

## 2. ファイル名の決まり
英数字と `_`（全角・空白は使わない）。

| 種類 | 決まり | 例 |
|---|---|---|
| 同じ音の何パターン（足音・打撃など。ランダムで鳴らす） | 最後に `_01`〜 | `footstep_noah_01.wav`〜`_04` |
| 順番に変わる音（1回目・2回目…） | 最後に `_1`・`_2`… と書き、チェックリストの備考に「順番」と書く | `peg_success_1.wav` |
| ループする音・曲 | 名前に `_loop` | `guard_loop.wav`、`BGM-03_tower1_explore_loop.ogg` |
| 立ち絵の表情 | 最後に表情の名前（下の表）。キャラ名（`Noah`・`Sigle`）も入れる | `UI_Noah_Surprise.png` |
| アイテムのアイコン | `Item_` ＋ アイテムの名前（Unity のアイテムのデータと同じ名前） | `Item_Lantern.png` |
| 連番の絵（エフェクト・アニメ） | `_00` から | `Fx_Hit_00.png`〜`Fx_Hit_07.png` |
| 何コマかを横に並べた1枚の絵 | 名前に `_sheet`（チェックリストの備考に「何コマ・1コマの大きさ」） | `Fx_Hit_sheet.png`（8 コマ・256×256） |
| キャラ・敵の動き | `Chara_名前_動き_向き_番号`／`Enemy_名前_動き_番号`（動き：Idle・Walk・Attack・Windup・Stun・Dead） | `Enemy_Creature_Idle_00.png` |
| 直した版（差し替え） | **前と同じファイル名**で、同じ ID のフォルダに | `SE-16_peg_miss.wav`（2回目） |

| 表情の名前 | 意味 |
|---|---|
| `Normal` | 通常 |
| `Smile` | 笑顔 |
| `Angry` | 怒り |
| `Sad` | 悲しみ |
| `Surprise` | 驚き |
| `Troubled` | 困り |

## 3. 形式
| 種類 | 形式 | 気をつけること |
|---|---|---|
| 効果音 | wav（44.1kHz・16bit）。モノラルで十分 | **頭の無音を切る**（鳴るのが遅れる）。大きさはほかの音とそろえる（目安：RMS -20dB 前後。最大は -1dB くらいまで。0dB に張り付くと割れる） |
| BGM | **ogg**（mp3 はループのつなぎ目に隙間が出やすい） | ループする曲は、終わりと頭が自然につながるように。長さの目安はチェックリストの「形式・仕様の目安」 |
| 立ち絵 | PNG（透過） | **1920×1080 のキャンバス**に、ノアの通常（`UI_Noah.png`）と同じ位置・大きさで描く。表情差分は顔だけ変える |
| アイコン | PNG（透過）128×128 の正方形 | |
| キャラ・敵 | PNG（透過）。1コマ 64×128 前後（キャラ） | 1 マス＝100 ピクセル |
| エフェクト | PNG（透過）の連番。6〜12 コマ・128〜256 ピクセル | |
| マップ | PNG。部屋ごとに1枚（2048 ピクセル以内推奨）＋同じ大きさの「歩ける所を白く塗ったマスク画像」（`_mask`） | |

くわしい大きさは素材チェックリストの「仕様の目安」シート。

## 4. 渡すときに一言そえてほしいこと
- どの場面の音か・絵か（チェックリストの行と違う使い方をしてほしいとき）。
- フリー素材なら、サイト名・URL・作者・ライセンス（チェックリストの備考に）。
- 「仮」の素材なら名前に `_kari`。

## 5. 入れたあと
入れた人が素材チェックリストの「進み具合」を「確認待ち」にします。**Unity で鳴らして・見て、よければ「完了」に。**
音量のばらつきは **Tools > 素材 > 音の一覧（試聴・音量）** で聞き比べて直せます（Ctrl+Z で戻せる）。
