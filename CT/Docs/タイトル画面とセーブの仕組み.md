# タイトル画面とセーブの仕組み（プランナー向け）

ゲームは **タイトル画面（`Assets/Scenes/Title.unity`）** から始まります。

| メニュー | 内容 |
|---|---|
| **はじめから** | 「オートセーブ」の枠を選ぶ → 最初のステージから始まる。オートセーブにデータがあると「上書きしますか？」と確認が出る（手動でセーブしたスロット 1〜3 は残る） |
| **つづきから** | 「オートセーブ」かスロット 1〜3 を選ぶ → その記録の場所から再開する（セーブがひとつもないときは押せない） |

**セーブの枠は4つ**：一番上の **オートセーブ**（ゲームが自動で書く）と、**スロット 1〜3**（セーブポイントで手動でセーブしたときだけ書く）。
自動のセーブが手動のスロットを上書きすることはありません。手動のスロットからロードして遊んでも、自動のセーブはオートセーブの枠に書かれます。
| **ゲーム終了** | ゲームを終わる（エディタでは再生が止まる） |

操作（タイトル・メニュー・セーブ／ロード画面・確認ダイアログで共通）：マウス、または 矢印キー（WASD）で選んで **Space / Enter で決定**、Esc / Backspace で戻る。
確認ダイアログでは ←→ で「はい」「いいえ」を切り替える（最初は「いいえ」が選ばれている）。

## 効果音（UI の SE）

タイトル・メニュー・セーブ／ロード画面・確認ダイアログ・アイテム画面・ゲームオーバー画面で、共通の効果音が鳴ります。
音は **`Assets/Resources/UISounds.asset`** の各欄（SeData）で決めます。

| 欄 | いつ鳴るか |
|---|---|
| **Select** | ↑↓←→ で選択を動かしたとき |
| **Decide** | 決定したとき・「はい」 |
| **Cancel** | もどる・「いいえ」・Esc・アイテム画面からメニューに戻ったとき |
| **Menu Open / Menu Close** | Tab でメニューを開いた・閉じたとき |
| **Save** | セーブが終わったとき |
| **Cannot** | 選べない・できないとき（今は使っていない。今後用） |

- 今入っているのは **仮の電子音**（`Assets/SE/UI/`）。本番の音にするときは、欄に別の SeData を入れるか、`Se_UI_〇〇` の SeData の音声ファイルを差し替える。
  音量・ピッチ・連打対策は各 SeData で調整できる。
- 画面ごとに別の音にしたいときは、TitleMenu・SaveSlotPanel・GameMenu・SavePoint の SE 欄に入れる（空なら共通の音）。
- ほかの画面のボタンで鳴らしたいときは、ボタンに **UIButtonSound** を付ける（ゲームオーバー画面のボタンには付け済み）。
- 仮の音がなくなったときは **Tools > UI効果音 > 仮の効果音を作成** で作り直せる（設定済みの欄は変えない）。

## メニュー画面（ゲーム中に Tab）

| 項目 | 内容 |
|---|---|
| **アイテム** | アイテム画面を開く。Tab / Esc で閉じるとメニューに戻る |
| **ロード** | セーブデータを選ぶ →「ロードしますか？」→ そのデータで再開 |
| **タイトルに戻る** | 「タイトルに戻りますか？」→ タイトル画面へ |
| **とじる** | ゲームに戻る（Tab / Esc でも閉じる） |

- メニューを開いている間はゲームが止まります。会話中・イベント中・暗転中は開きません。
- メニュー画面の見た目は `Assets/Resources/UI/GameMenu.prefab`（**Tools > メニュー画面 > メニューのプレハブを作成** で作り直せる）。

## セーブポイント

マップに置いて、**調べる（E）** と「セーブしますか？」→ セーブデータ選択（スロット 1〜3。オートセーブの枠は出ない）→ 選んだスロットにセーブ →「スロット N にセーブしました」。

- 使用中のスロットを選ぶと確認が出ます（最後にロード・セーブしたスロットは「セーブしますか？」、別のデータなら「上書きしてセーブしますか？」）。
- 「つづきから」では、セーブポイントの **Resume Offset** の位置から再開します（シーンビューで水色の丸と線が出る）。セーブポイントに重ならず、歩ける場所にしてください。

### 置き方
1. Hierarchy で右クリック → **セーブポイント**（仮の青い丸・調べる範囲・SavePoint がまとめてできる）
2. 置きたい場所に動かす
3. 見た目を変えるときは **SpriteRenderer** の Sprite を差し替える（大きさは Transform の Scale。調べる範囲は BoxCollider2D）

| 項目 | 説明 |
|---|---|
| **Question** | 最初に出す確認の文 |
| **Resume Offset** | つづきからで再開する位置（セーブポイントからのずれ） |
| **Save Se** | セーブしたときの SE（任意） |

今は Stage1_1・Stage1_2 の入口の近くに1つずつ置いてあります（位置は仮）。

## セーブされるタイミングと、再開する場所

| いつ | 書く枠 | 再開する場所 |
|---|---|---|
| **セーブポイントでセーブしたとき** | 選んだスロット（1〜3） | セーブポイントの再開位置 |
| **シーンに着いたとき**（扉などで移動した・はじめから・つづきから・リトライ） | オートセーブ | そのシーンの、着いた出現位置 |
| **イベントの部品「オートセーブ」を実行したとき** | オートセーブ | その時の操作キャラの位置（か、部品で指定した場所） |
| **チェックポイント（`CheckPoint`）に触れたとき** | オートセーブ | そのチェックポイントの位置 |

- オートセーブしたときは、画面の右上に「オートセーブしました」と少しだけ出ます。
- **ゲームを終了したとき・タイトルに戻ったときは保存しません**。所持品・フラグ・拾ったもの・開けた扉などは、**最後にセーブした時点**の状態に戻ります（セーブしてから次のセーブまでに手に入れたものは失われます）。

### 部品「オートセーブ」を置くところ（大事）
シーンに着いたときの自動セーブは「着いた出現位置」から再開します。そのため、**イベントで入口がふさがる・通り道が変わる**と、ロードしたときに入口側（もう通れない所）から始まって進めなくなります。
そういうイベントの **最後**（会話のあと、プレイヤーが動けるようになる直前）に、イベントの部品 **オートセーブ** を付けてください。

| 項目 | 説明 |
|---|---|
| **再開する位置** | 「操作しているキャラの今の位置」か「指定した場所（下の欄）」 |
| **指定した場所** | 「指定した場所」のとき。空のオブジェクトを置いて入れる |

今置いてあるところ：Stage1_2 のシグルと合流した場面の最後・Stage1_1 の OP の最後・Stage_1_3 で全部調律できたときの会話の最後。
話の区切り（仲間になった・ボスを倒した など）に置くと、戻される距離が短くなります。
置いたら、イベントの前と後で「タイトルへ → つづきから（オートセーブ）」を試して、出た場所から進めるか・イベントが繰り返さないかを確かめてください。

セーブデータの一覧には **場所・プレイ時間・保存日時** が出ます（場所の名前は `Assets/Resources/PlaceNames.asset` で変える）。

## タイトル画面の設定（`Title.unity` の `TitleCanvas` の **TitleMenu**）

| 項目 | 説明 |
|---|---|
| **First Scene** | 「はじめから」で最初に入るシーン（今は `Stage1_1`） |
| **First Spawn Point Id** | 最初のシーンでの出現位置（空ならシーンの既定の位置） |
| **Decide Se** | 決定するときの SE（任意） |

- **場所の表示名**：`Assets/Resources/PlaceNames.asset` で、シーンごとに「ステージ1-1」→「地下水路」のように変える（タイトル・メニュー・セーブポイントで共通）。
- セーブデータ選択画面は、タイトル・メニュー・セーブポイントで同じ部品（**SaveSlotPanel**）を使っています。

- **背景**：`TitleCanvas/Background` の画像を差し替える（今は `Assets/Images/UI/UI_TitleImage.PNG`）。**Aspect Ratio Fitter**（Envelope Parent）で、縦横比を保ったまま画面いっぱいに出す（画面と比率が違う分、上下か左右が少し切れる）。画像を替えたら Aspect Ratio を「横 ÷ 縦」に直す。
- **ボタンの色・文字・位置**：各ボタンを選んで Inspector で変える。
- **BGM**：`System` の **SceneBgm** の Default Clip に曲を入れる（空なら無音。ステージの曲はタイトルで止まる）。
- 見た目を最初の状態に戻したいときは **Tools > タイトル画面 > タイトルシーンを作成**（作り直すので、手で変えた見た目は消えます）。

## ゲームオーバー画面

**リトライ**（倒れたステージの入口からやり直す）と **タイトルへ** があります。
キーボードでも選べます（最初はリトライが選ばれている。↑↓ で選び、Space / Enter で決定）。Canvas に付けた **MenuKeyboardNav**（キーボードで選ぶ）で、ボタンの順番・選ばれたときの色を変えられます。ほかの画面のボタンの並びにも付けられます。
別の画面に「タイトルへ」ボタンを作りたいときは、ボタンと同じオブジェクトに **ReturnToTitleButton** を付けて、
OnClick に `ReturnToTitleButton.ReturnToTitle` を登録してください。

## Build Settings

ゲームに入るシーンは **Title → Stage1_1 → Stage1_2 → Stage_1_3 → SceneGameOver** の5つです（先頭の Title から始まる）。
シーンを増やすときは Build Settings に追加してください（③のドロップダウンにも出るようになります）。

## エディタで確認するとき

- **Title から再生**：本番と同じ。自動のセーブはオートセーブの枠に保存されます。
- **ステージのシーンから直接再生**：**Tools > デバッグ > セーブ > ステージから再生するとき** で選んだスロットを読み込みます。
  - 初期値は「**使わない（保存もしない）**」。この間に拾ったものなどは、ファイルに保存されません。
  - 続きの状態で確認したいときはスロットを選んでください（そのスロットのデータに保存されます）。
  - 「オートセーブ」を選ぶと、オートセーブの記録から始まり、自動のセーブもそこに書かれます。手動のスロットを選んでも、自動のセーブはオートセーブの枠に書かれます。
- デバッグウィンドウの **スロット** の一覧で、各枠（オート・1〜3）の中身の確認と削除ができます。**今の場所でオートセーブ** のボタンで、その場でオートセーブできます。
- セーブファイルは `save_auto.json`（オートセーブ）と `save_1.json` 〜 `save_3.json`（「セーブファイルの場所を開く」で開ける）。
  以前の `save.json` は、初めて起動したときにスロット1へ引き継がれます（場所の記録がないので「場所不明」と表示され、「つづきから」では最初のステージから始まります）。
