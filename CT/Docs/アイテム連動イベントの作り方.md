# アイテム連動イベントの作り方（プランナー向け）

「このアイテムを持っていたら○○できる」「持っている状態で○○すると○○になる」を、
コードを書かずに Inspector だけで作るための手順です。

考え方は **きっかけ × 条件 × 結果** です。

| | 内容 | 例 |
|---|---|---|
| きっかけ | 何をしたとき | 調べた（E キー）／エリアに入った |
| 条件 | 何を持っているとき | 鍵を1個以上／宝石と地図の両方／ランタンを持っていない |
| 結果 | 何が起きるか | 会話・SE・表示切り替え・スプライト変更・アイテムをもらう／消費する |

---

## 1. アイテムを用意する

1. Project ウィンドウで `Assets/Resources/Items/` を開く（**必ずこのフォルダに置く**）
2. 右クリック → **Create > Item > ItemData**
3. Inspector で設定する
   - **Id**：セーブ用の名前（英数字。カンマ「,」とコロン「:」は使わない。空ならファイル名）
   - **Display Name**：アイテム画面に出る名前
   - **Description**：アイテム画面に出る説明
   - **Icon**：アイコン画像（任意）
   - **Is Key**：鍵として扱う（鍵付きの宝箱 `Treasure` で使える）

## 2. アイテムを拾えるようにする

1. 置きたいオブジェクトに **Collider2D（Is Trigger をオン）** と **ItemPickup** を付ける
2. **Item** に 1 で作った ItemData を入れる
3. 同じシーンに同じ名前のオブジェクトを複数置くときは **Pickup Id** に別々の名前を入れる

一度拾ったものは、シーンに戻っても出てきません。

---

## 3. 「持っていたら○○できる」オブジェクトを作る（ItemInteraction）

### ひな形を作る
Hierarchy で右クリック → **アイテム連動 > 調べるオブジェクト**

次のものが自動で作られます。

```
ItemInteraction        … 調べる範囲（BoxCollider2D）と ItemInteraction
├─ 成功時              … 条件を満たしたときに実行する（表示切り替え＋会話）
└─ それ以外            … 条件を満たさないときに実行する（会話）
```

### ItemInteraction の設定

| 項目 | 説明 |
|---|---|
| **Trigger** | 「調べたとき（E キー）」か「エリアに入ったとき」 |
| **Rules** | 上から順に調べて、**最初に条件を満たしたルールだけ**を実行する |
| └ Label | メモ（動作には関係なし） |
| └ Conditions | 条件の一覧。**すべて**満たすと実行（空なら常に実行） |
| 　└ Item / Count | このアイテムを Count 個以上持っている |
| 　└ Not Have | チェックすると「持っていないとき」 |
| └ Consume Items | 実行するときに条件のアイテムを消費する |
| └ Sequence | 実行する内容（EventSequence） |
| └ Mark Completed | 実行したら「完了」にする（以後このルールは実行されない） |
| **Otherwise** | どのルールも満たさないときに実行する（任意） |
| **After Completed** | 完了後にもう一度調べたときに実行する（例：「もう開いている」）（任意） |
| **Save Id** | 完了を記録する名前。同じシーンで同名のオブジェクトがあるときだけ入れる |
| **Save Completed** | 完了状態を保存する。シーンに戻っても完了後の見た目のままになる |

- 「A **か** B を持っていたら」は、ルールを 2 つ並べて作ります。
- 完了状態の復元では、会話や SE は鳴らず、**表示切り替えとスプライト変更だけ**が反映されます。

### 結果に使える部品（EventSequence の Actions に追加する）

| 部品 | できること |
|---|---|
| **DialogueEventAction** | 会話を出す（同じオブジェクトの Dialogue に文章を入れる） |
| **SeEventAction** | SE を鳴らす |
| **SetActiveEventAction** | オブジェクトを表示／非表示にする（扉が消える、通路が出る） |
| **SpriteChangeEventAction** | スプライトを差し替える（像が光る、スイッチが切り替わる） |
| **ItemGiveEventAction** | アイテムを渡す |
| **ItemTakeEventAction** | アイテムを取り上げる（条件にないアイテムを消費したいとき） |
| **BgmFlagEventAction** など | BGM の切り替え（既存） |

部品は EventSequence と同じオブジェクトに追加し、EventSequence の **Actions** リストに登録してください。

## 4. 「持っている間だけ○○になる」を作る（ItemPossessionSwitch）

Hierarchy で右クリック → **アイテム連動 > 持っている間だけ切り替え**

| 項目 | 説明 |
|---|---|
| **Conditions** | 条件（すべて満たしたとき） |
| **Active When Met** | 条件を満たしている間だけ表示する |
| **Active When Not Met** | 条件を満たしていない間だけ表示する |

所持品が変わった瞬間に切り替わります。
ItemPossessionSwitch を付けたオブジェクト自身は、切り替え対象に入れないでください。

---

## 例

### 鍵で扉を開ける
- Trigger：調べたとき
- ルール1：Conditions = 鍵 ×1、Consume Items = オン、Mark Completed = オン
  - 成功時：SetActiveEventAction の **Hide** に扉を入れる＋SE＋会話「扉が開いた」
- Otherwise：会話「鍵がかかっている」
- After Completed：（なし）

### 宝石を像にはめると隠し通路が出る
- ルール1：宝石 ×1、Consume Items = オン
  - 成功時：SpriteChangeEventAction（像を光った画像に）＋SetActiveEventAction の **Show** に通路
- Otherwise：会話「何かをはめ込めそうだ」

### 手紙を持って NPC に話すと、お礼の品をもらえる
- ルール1：手紙 ×1、Consume Items = オン
  - 成功時：会話「ありがとう！」＋ItemGiveEventAction（お礼の品）
- Otherwise：普段の会話（Mark Completed は付けない）
- After Completed：会話「手紙、届けてくれてありがとう」

### 持ち物で会話を変える（消費しない）
- ルール1：地図 ×1、Consume Items = オフ、Mark Completed = オフ → 会話「その地図、北に何かあるらしい」
- ルール2：（条件なし）、Mark Completed = オフ → 普段の会話

### ランタンを持っていると暗い部屋が明るい
- ItemPossessionSwitch：Conditions = ランタン ×1、Active When Met = 明かりのオブジェクト

---

## 注意

- セーブの確定はチェックポイントとシーン遷移のときです（宝箱と同じ）。
- エディタで再生を止めると、所持品と完了状態はリセットされます。
