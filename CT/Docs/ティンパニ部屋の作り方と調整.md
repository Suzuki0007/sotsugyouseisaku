# ティンパニ部屋の作り方と調整（プランナー向け）

Stage_1_3（ティンパニの部屋）の仕組みと、値の変え方をまとめます。
ほかの部屋で同じような「ペグを締めて調律する戦闘」を作るときも、この手順で作れます。

---

## 1. 遊び方（できあがりの流れ）

1. Stage1_2 でシグルと合流したあと、正面の扉を調べる → シグルがこじ開けて Stage_1_3 の中央に出る
2. 戦闘前の会話（F1_09 → カメラが音楽生物を映す → F1_10 → 調律のしかた F1_10b）→ 戦闘が始まる
3. ノアでペグに近づいて **E** → リズムゲーム（縮む輪が中心の輪に重なるときに **E**）→ 3回成功でペグが締まる
   - ペグが締まると、周りの敵の弾が消え、敵が少し止まる
   - 1台のティンパニのペグが全部締まると、真ん中の音楽生物がおとなしくなる（絵が変わる・♪・回復アイテム）
   - 残りの音楽生物は激しくなる（攻撃が増える）
4. 敵の弾の輪は **Q**（シグルの守り＝弾消し）で消せる。守りのゲージには限りがあり、時間でたまる
5. 落石と一緒に、守りのアイテム（青い菱形）が落ちてくることがある。拾うとゲージが速くたまる
6. 全部のティンパニを調律するとクリア → ティンパニとの会話（F1_11）→ 左の出口への通路が開く
7. 体力がなくなるとゲームオーバー → リトライで部屋に着いた直後から（短い会話 F1_10c のあと戦闘）

## 2. 部屋の中身（Hierarchy の `ティンパニ部屋`）

| オブジェクト | 部品 | 役割 |

## 3. よく変える値

### 3-1. ペグの数・位置
- ペグを足す：`Assets/Prefab/Gimmicks/Timpani/Peg` を、そのティンパニ（`ティンパニ_○`）の**子**にドラッグする（または今のペグを複製 Ctrl+D）。
- 位置はシーンビューで動かすだけ。**歩ける範囲の中**に置く（外だとシーンチェックで「注意」）。
- 減らす：ペグを消す。ティンパニのペグは子から自動で数えるので、ほかに直す所はない。

### 3-2. リズムゲームの難しさ（各ペグの TimpaniPeg）
| 項目 | 初期値 | 意味 |
|---|---|---|
| 使えるキャラ | ノアだけ | シグルで近づくと「ノア」の目印が出る |
| 成功する回数 | 3 | この回数タイミングよく押すと締まる |
| 輪が縮む時間（秒） | 1.3 | 短いほど難しい |
| 成功するたびに速くなる割合 | 0.1 | 成功のたびに 10% 速くなる |
| 判定の甘さ（マス） | 0.16 | 大きいほど簡単 |
| 失敗で戻る回数 | 0 | 外したとき成功の回数を減らすか |
| 失敗のあと押せない時間（秒） | 0.35 | 連打で成功しないように |

全部のペグを同じにしたいときは、Hierarchy でペグをまとめて選んで変えるか、**プレハブ**（`Peg`）を開いて変える（シーンで個別に変えた値はそのまま残る）。

### 3-3. 敵の攻撃（`Assets/Data/Enemies/Timpani/`）
| ファイル | 内容 | よく変える値 |
|---|---|---|
| `EnemyData_Timpani_Creature` | 音楽生物 | 体当たりのダメージ・絵・行動パターン |
| `Pattern_Timpani_Creature` | 行動（3段階） | 各段階の「待つ」の秒数（短いほど激しい）・使う攻撃・落石の回数 |
| `Attack_Timpani_Ring` | 弾の輪（通常） | 予告の時間（1 秒）・弾の数（12）・速さ（3） |
| `Attack_Timpani_Ring_Hard` | 弾の輪（激しい） | 弾の数（12）・回数（2）・間隔（0.8）・速さ（3.3） |
| `Attack_Timpani_Spiral` | うず巻き（もっと激しい） | 本数（3）・回数（14） |
| `Attack_Timpani_Rock` | 落石（部屋のあちこちに次々に落ちる） | 予告（影）の時間（1.3）・画面の揺れ（0.15）・**落とす数（5）・次を落とすまで（0.3 秒）・ばらまく場所（歩ける範囲全体）・プレイヤーを狙う割合（0.15）・影どうしの最低の間（1.8）**・一緒に落ちる物と確率（守りのアイテム 1 個ごとに 8%） |

**激しさの目安**（敵全体で、10 秒あたりのおおよその弾の数）：通常（3体）約 32 発、激しい（残り2体）約 40 発、もっと激しい（残り1体）約 41 発。おとなしくなった数が増えても、全体の量はあまり増えないようにしてある。きついときは、`Pattern_Timpani_Creature` の「待つ」を長くするのが一番簡単。

段階が進む条件：`Flag_Timpani_Calmed1`（1体おとなしくなった）・`Flag_Timpani_Calmed2`（2体）。TimpaniRoom が自動で立てる。

### 3-4. 守りのゲージ（`守りのゲージ` の GuardGauge）
| 項目 | 初期値 | 意味 |
|---|---|---|
| 出していられる時間（秒） | 2 | 満タンから弾消しを出し続けられる時間 |
| 空から満タンまでの時間（秒） | 6 | リチャージの時間 |
| たまり始めるまでの間（秒） | 0.4 | 弾消しをやめてから |
| 空になったら出せるようになる量 | 0.5 | 空になったら、この割合までたまるまで出せない |
| 名前・色・画面の位置 | 「シグルの守り（Q）」 | |

このゲージを置いたシーンだけ制限がかかる（ほかのシーンは今までどおり、いつでも弾消しを出せる）。

### 3-5. アイテム（`Assets/Prefab/Gimmicks/Timpani/`）
| プレハブ | 効き目 | 値 |
|---|---|---|
| `Item_Heal`（ハート） | 体力を回復 | 回復する量（1） |
| `Item_GuardBoost`（青い菱形） | 守りのゲージ | すぐためる量（0.3）・速くたまる倍率（2）・時間（10 秒） |

共通：消えるまでの時間（12 秒）・点滅を始める残り時間（3 秒）・拾えるまでの時間（0.3 秒）。
- 回復アイテムは、ティンパニを1台調律するたびに1つ出る（各 TimpaniUnit の「出す回復アイテム」。空にすると出ない）。
- 守りのアイテムは落石と一緒に落ちる（`Attack_Timpani_Rock` の「発動したときに出す物・出す確率」）。

### 3-6. ペグが締まったとき・調律できたとき（各 TimpaniUnit）
| 項目 | 初期値 | 意味 |
|---|---|---|
| 攻撃を消す範囲（マス） | 9 | 締まったペグからこの距離の弾を消し、敵の攻撃をやめさせる |
| 敵を止める時間（秒） | 1 | 攻撃をやめさせた敵が動き出すまで |
| 調律できたあとの絵 | 水色の笑顔（仮） | おとなしくなった敵の絵 |
| エフェクト・音・イベント | | 調律できたときに出す |

### 3-7. 戦闘中の一言（`戦闘中の一言` の TimpaniBarks）
- できごと（ペグの成功・失敗・締まった／調律できた／守りが切れた・戻った／アイテムが落ちてきた・拾った／ダメージ／体力が少ない／しばらくペグが進まない／戦闘が始まった）ごとに、**候補の一言**（話すキャラ・文）・**出す確率**・**次に出せるまで（秒）**。
- 一言どうしの間（3 秒）・体力が少ないとき（2 以下）・ヒントを出すまでの時間（25 秒）。
- 戦闘エリアが動いている間だけ出る。吹き出しなのでゲームは止まらない。

### 3-8. 会話（`Assets/Data/Dialogue/Scenario_F1.csv`）
| 会話 ID | 場面 |
|---|---|
| F1_08・F1_08b_ForceDoor | Stage1_2 の扉（シグルがこじ開ける） |
| F1_09_BigRoom・F1_10_Timpani | 部屋に着いて、ティンパニが現れる |
| F1_10b_HowTo | 調律のしかた（ペグはノア、守りはシグル） |
| F1_10c_Retry | ゲームオーバーからのやり直し |
| F1_11_TimpaniCalm | クリア後（ティンパニとの会話） |
| F1_12_Continue | 左の出口 |

直すときは CSV を直して、CSV を右クリック → **会話CSVを取り込む**。

## 4. フラグ（`Assets/Data/Flags/`）

| フラグ | セーブ | 意味 |
|---|---|---|
| `Flag_Sigle_Joined` | する | シグルが仲間（Stage1_2 で立つ）。立っていないとノア1人 |
| `Flag_Timpani_IntroSeen` | する | 戦闘前の会話を見た（リトライで短い会話になる） |
| `Flag_Timpani_Calmed1`・`Calmed2` | しない | 調律できた数（敵の段階が進む）。シーンが始まるたびに OFF |
| `Flag_Timpani_Cleared` | する | クリア。戦闘の勝ち方・戻ってきたときの姿 |

## 5. 確かめ方

- **Tools > デバッグ** の「ティンパニ」（再生中、ティンパニの部屋にいるときだけ出る）
  - 進み具合（ペグ ○/9・調律 ○/3）
  - **近くのペグを締める**・**1台調律する**・**全部調律する**（リズムゲームを飛ばす。攻撃が消える・調律・一言は遊んだときと同じに起きる）
  - 守りのゲージ（満タン・空にする）
- **Tools > フラグ > フラグ一覧** で、`Flag_Sigle_Joined` を ON にしてから Stage_1_3 を再生すると2人で始まる。戦闘前の会話をもう一度見るときは `Flag_Timpani_IntroSeen` と `Flag_Timpani_Cleared` を OFF に。
- **Tools > シーンチェック** で、次の設定ミスを見つけられる：歩ける範囲に形がない・出現位置が歩ける範囲の外・ペグが歩ける範囲の外・ティンパニに敵やペグがない・部屋のクリアのフラグが空。

## 6. 仮のもの
- 絵：音楽生物（紫）・調律後（水色）・ペグ（丸）・弾（丸）・アイテム（ハート・菱形）。絵ができたら、敵のデータの「絵」、TimpaniUnit の「調律できたあとの絵」、各プレハブの `見た目（仮）` を差し替える。
- 音：ペグ・調律・ゲージ・アイテム・ティンパニ登場の揺れの音は空欄。
- 左の出口の先（台本 F1_13 の階段・二層）のシーンはまだない。
