# マップチップの置き方（見え方をよくするコツ）

タイルパレット「Mapchip」でマップを作るときのコツと、そのためのタイルの使い方です（2026-11-25 に調べてまとめた）。
これからの向上の計画は `Docs/マップの見た目の向上プラン.md`（2026-11-27）。
見本：`Assets/Scenes/Test_Mapchip.unity` の東側「浜辺と遺跡」（再生して右の壁の通り道から東へ。ゲームビューは 1920×1080 で見る）。

## 1. コツ

| コツ | なぜ | このプロジェクトでのやり方 |
|---|---|---|
| **層を分ける** | キャラが壁の縁の下を通れる・物を消しても下の地面が見える | 海と砂 → 床 → 床の上の砂 → 影 → 壁の面 → 平らな小物 →（キャラ）→ 壁の縁。下の「層の決まり」 |
| **同じ絵の繰り返しを崩す** | 同じタイルが並ぶと格子が目立つ | 砂・海・床は「ランダム反転」のタイルで塗る（場所ごとに上下左右の反転が変わる。毎回同じ見た目） |
| **四角い形を避ける** | 四角だけだと作り物に見える | 海岸線を段々に・入り江を作る、部屋の壁を崩して砂を入り込ませる、石畳をところどころ途切れさせる |
| **奥行きをつける** | 平らに見えない | 海は沖ほど暗く（影のタイルを重ねる）、壁の面の下の床に薄い影、立っている物の右下に影 |
| **物には影** | 影がないと浮いて見える | 物と同じ形を黒く半透明にして右下に少しずらす（見本の歯車） |
| **ドット絵は斜めに回さない** | 斜めに回すと画素がゆがむ | 回すのは 90 度ごと＋左右・上下の反転だけ |
| **見せ場は 1 つ・小物は濃い所と薄い所** | どこを見ればよいかわかる・散らかって見えない | 奥の部屋に大きな歯車を重ねて 1 か所、ほかは小さな歯車をまとめて置く所と、まばらな所を作る |
| **配置を先に・飾りはあと** | 飾りから始めると迷路のようになる | 通り道・部屋・見せ場を先に決め、廊下で部屋をつなぐ（一目でわかる形） |
| **何もない所は小さくするか目印を置く** | 意味のない広さは退屈 | 広い砂浜に崩れた壁のかけらを置く |
| **継ぎ目の対策** | タイルの間に細い線が出る | `Tools > Mapchip > Fix Seams`（`Docs/素材の取り込み.md`） |

## 2. タイル（パレット Mapchip の下の段）

| タイル | 使う所 |
|---|---|
| `Kabe.1` | 壁の面（2 段重ねると壁らしい） |
| `Kabe.2`（縁が下）・`Kabe.2_縁が上`・`_縁が左`・`_縁が右` | **壁の上を上から見た縁**。部屋の外側の辺に、縁が外側に来る向きで置く（上の辺は「縁が下」を壁の面の 1 つ上のマスに）。白い所は透明（2026-11-25 に透過。元の絵は `Docs/素材の元/Mapchip/Kabe.2.png`） |
| `Umi.2`（海が下）・`Umi.2_海が上`・`_海が左`・`_海が右` | 波打ち際（砂のマスの、海のある側に泡）。角のチップはないので、角は「海が下」で代用 |
| `Suna_ランダム反転`・`Umi_ランダム反転`・`Yuka_ランダム反転` | 広い砂・海・床（繰り返しが目立たない） |
| `影_薄い`・`影_濃い` | 半透明の黒。海の深さ・壁の面の下・崩れた壁の下に重ねる（影の層に塗る） |

## 3. 層の決まり（Tilemap Renderer の Order in Layer）

| 層 | 並び順 | 中身 |
|---|---|---|
| 海と砂 | 0 | 海・砂・波打ち際 |
| 床 | 1 | 石畳・部屋の床 |
| 床の上の砂 | 2 | 部屋に入り込んだ砂 |
| 影 | 3 | 影のタイル、物の影（4） |
| 壁の面 | 4 | Kabe.1 |
| 平らな小物 | 5 | 床に転がる歯車など |
| キャラ・立っている物 | 100 | 同じ 100 にすると、上下の位置で前後が決まる（立っている物は「奥行きのある物」にする） |
| 壁の縁 A・B | 110・111 | Kabe.2。角は A と B に 1 枚ずつ重ねて L 字にする |

### 明かりの置き方（2026-11-27）
- **強い明かりは部屋に 1〜2 か所**（見せ場のそば）。ほかのたいまつは弱く小さく（明るさ 0.7〜0.8・大きさ 3.5〜4）。全部同じ強さだと、どこを見ればよいかわからない。
- 見せ場には**光だまり**を重ねる。窓のある部屋は**窓の光**で床に形を落とす。
- 暗い部屋に**地面の色むら**を強くかけると、明るい所が白いもやに見える。暗い場所では強さを下げる。

### 崩れた所・がれき・道（2026-11-27）
- **崩れた所**は、開いた所の両脇の壁を 1 段低くする（上の段の面と縁を外し、1 段目の上に縁）。四角く切った穴に見えなくなる。
- **がれき**は壁の色に近い小さなかけらを、崩れた所（外へこぼれる）・壁ぎわ・壁の足もとに 2〜5 個ずつ。1 か所に固めない・線や四角に並べない。平らな小物（並び順 5）にして影を付ける。
- **砂が入り込んだ床**は、砂の層を少し暗く暖かい色に（Tilemap の Color）。明るいままだと暗い部屋の中で床の穴に見える。崩れていない部屋の隅には入れない（理由のない砂は穴に見える）。
- **道**は幅をそろえて目的の所（扉）まで通し、外側の辺だけを少し欠けさせる。道の中のマスを抜いたり、1 枚だけ離して置いたりすると、意味のない四角に見える。
- **見せ場**は部屋ごとに 1 つ（立てた大きな物＋明かり）。

### 壁の形の決まり（見下ろし＝3/4 の見え方。2026-11-27）
見下ろしの絵では、壁は「上の面」と「こちらを向いた面」が見える。部屋の 4 つの辺は次のように塗る。

| 辺 | 塗る物 |
|---|---|
| 奥（上） | 壁の面 `Kabe.1` を 2 段＋そのすぐ上に上面の縁 `Kabe.2`（縁が下） |
| 左右 | 上面の縁だけ（`Kabe.2_縁が左`／`_縁が右`）。奥の壁の面の横まで伸ばす |
| 手前（下） | 上面の縁（`Kabe.2`、床の一番下の段）＋**その真下に外側の面 `Kabe.1` を 2 段**＋面の下の砂に `影_薄い` |
| 廊下 | 部屋と同じ（奥は面 2 段＋縁、手前は縁＋面 2 段） |
| 壁のかけら（1 本だけ立つ壁） | 面 1 段＋上面の縁。**面の段の左右に縁を描かない**（上面ではない所に縁を描くと、線で囲んだように見える） |

- 上面の縁の太さ（約 0.33 マス）は、どの辺も同じにする。手前の壁の面は、奥の壁と同じ高さ（2 段）にする。
- 手前の壁の縁はキャラより手前（並び順 110）に描くので、部屋の中で壁ぎわに立つと足が少し隠れる（壁の後ろにいる見え方）。
- 手前の壁の外の歩ける範囲：面の下の端から 0.61 上までを歩けるようにする（足が面の下の端に来る。面に乗らない）。

- 歩ける範囲（WalkArea）は、マップを塗ったあとで決める（海・壁の面・縁・大きな物を抜く。`Docs/謎解きと2人の仕掛けの作り方.md`・room-build）。
- **キャラが後ろを通れる物（歯車・柱・木・像など）は「奥行きのある物」にする**：物を選んで（重なっている物はまとめて選んで）Hierarchy 右クリック > **マップの見た目 > 奥行きのある物にする**。
  - 約束は 2 つ：**赤い四角（足元の当たり判定）には入れない**、**青い線（前後の境目）より上にいるキャラは物の後ろ、下にいるキャラは前**。シーンビューに赤い四角と青い線が出る。
  - 当たり判定は四角でざっくり（見た目どおりの円や細かい形にしない：キャラが引っかかる・押し続けるとぶるぶるするもと）。初めは見た目の幅の 7 割 × 下半分。
  - 青い線は赤い四角の上の端より 0.25 マス下（同じ高さだと、キャラがちょうど境目の上に立って、向きなどで前後が入れ替わる）。
  - 部品「奥行きのある物」の Inspector で幅・高さ・境目を変えたら「当たり判定と境目を作り直す」を押す（黄色い線が出ていたら作り直しが要る。シーンチェックも知らせる）。
  - 前後を上下の位置で決めるのは、2D レンダラー（`Assets/Settings/Renderer2D.asset`）の Transparency Sort Mode＝Custom Axis（0, 1, 0）のおかげ（11-25 に Default から変えた）。同じ並び順（キャラは 100）の物どうしだけが上下の位置で比べられる。
- **上下の壁は「足の分」だけ離して抜く**：歩ける範囲はキャラの位置（体の真ん中）で決まり、絵は真ん中から下へ約 0.6 マス出る。壁の上側（外）を歩く所は、縁の下の端から **0.7 マス上**まで、部屋の下の壁は、縁から **0.7 マス内側**まで歩けないようにする（ぴったりだと足が壁の面にはみ出る）。左右の壁は体の幅が細いので、縁の太さ（0.33）＋少しでよい。
- 見本の作り方は Claude のレシピ `mapchip_tiles` → `mapchip_test` → `mapchip_beach` に残っている（作り直せる）。

## 4. 見え方をよくする部品（2026-11-25）

| 部品 | 作り方 | 使い方 |
|---|---|---|
| **明かり（ゆらぐ）** | Hierarchy 右クリック > **マップの見た目 > 明かり（ゆらぐ）** | たいまつ・窓の光・水面のきらめき。暖かい色の明かりは、暗い場所（下の「場所の色味」を暗く）で映える。Light 2D の Color・Intensity・Radius で色・明るさ・大きさ、「明かりのゆらぎ」でゆれの強さ・速さ（たいまつ 0.15・3、水面 0.4・0.7）。明かりの「Shadows」をオンにすると、下の「壁の影」で影が落ちる |
| **壁の影**（明かりをさえぎる） | 壁の Tilemap を選び、Inspector の Tilemap の **⋮ > 壁の影（Shadow Caster 2D）を作り直す** | 塗ってあるマスから、明かりをさえぎる形を作る。壁を塗り直したら、もう一度押す |
| **影を付ける** | 絵の付いた物に **Add Component > マップの見た目 > 影を付ける** | 同じ形の影が右下に出る（物が浮いて見えなくなる）。濃さ・ずらす量・縦の長さ（小さくすると落ち影らしくなる）・並び順 |
| **隅の影** | 影用の Tilemap を作り（並び順 2）、**Add Component > マップの見た目 > 隅の影**。床・壁の Tilemap と「影_薄い」「影_濃い」を入れて **影を塗り直す** | 壁ぎわを薄く、角を濃く自動で塗る。マップを塗り直したら、もう一度押す（この Tilemap の中身は消える） |
| **地面の色むら**（11-27） | Hierarchy 右クリック > **マップの見た目 > 地面の色むら** | マップ全体に大きなもやもや（暗い所・暖かい明るい所）を薄く重ねる。同じタイルが並んでも格子が目立たない。「強さ」0.3〜0.5。床より上・壁の面より下（並び順 2）なので、壁・キャラには掛からない。新しいチップは要らない |
| **流れる雲の影**（11-27） | Hierarchy 右クリック > **マップの見た目 > 流れる雲の影** | 薄い影がゆっくり地面を流れる（外の場所だけ。屋根のある室内には置かない）。「濃さ」0.2〜0.25・「流れる向き」・「速さ」0.3〜0.6。キャラ・壁の上にも落ちる（並び順 120）。再生中だけ動く |
| **光だまり（絵の明かり）**（11-27） | Hierarchy 右クリック > **マップの見た目 > 光だまり（絵の明かり）** | やわらかい丸い光。影を作らないので軽い。見せ場の真上に置いて目を引く（Transform の Scale で大きさ、Light 2D の Color・Intensity で色・明るさ） |
| **窓の光（型抜き）**（11-27） | Hierarchy 右クリック > **マップの見た目 > 窓の光（型抜き）** | 窓枠の形の光が斜めに床へ落ちる（格子の影つき）。窓のある壁の下の床に置く。少し青白い色・明るさ 0.6〜0.8 くらい |
| **床をはう霧**（11-27） | Hierarchy 右クリック > **マップの見た目 > 床をはう霧** | ふちのぼけた霧がゆっくり行ったり来たりし、濃さも少しずつ変わる。2〜4 枚を少しずつずらして重ねる（濃さ 0.2〜0.3）。床より上・キャラより下（並び順 6）。遺跡・洞窟・水辺に |
| **光の中のちり**（11-27） | Hierarchy 右クリック > **マップの見た目 > 光の中のちり** | 小さな光の粒がゆっくり舞う（Particle System）。光だまり・窓の光の中に置く。舞う範囲は Shape の Scale、粒の色は Start Color |
| **場所の色味** | Hierarchy 右クリック > **マップの見た目 > 場所の色味** | 四角に入ると、画面全体（マップ・キャラ）の色と明るさがなめらかに変わる。浜辺は夕方の暖かい色、遺跡の中は暗く冷たい色、など。重なる所は「優先度」の大きいほう。出ると元に戻る。UI は変わらない。暗いステージ（StageDarkness）のシーンでは働かない |

- 見本は Test_Mapchip の「浜辺と遺跡」：遺跡に入ると暗く青っぽくなり、たいまつが映える。浜辺は夕方の色、海に弱いきらめき。
- 場所の色味・明かりのゆらぎは**再生中だけ**動く（エディタでは Global Light 2D の元の色のまま）。

## 5. あると質が上がるチップ（作る人へのお願いの候補）
- 波打ち際の**角**（外側・内側）、壁の縁の**内側の角**。今は 1 方向の絵を回して使っているので、角がつながらない。
- **砂の色をそろえる**：`Umi.2` の砂の部分は `Suna.1` より明るく、波打ち際の上に色の境目が帯のように見える。
- 砂・床の**違う柄の 2〜3 枚**（ひび・小石・欠けたタイル）：ランダムに混ぜると繰り返しがさらに消える。
- 草・岩・貝殻・流木などの**小物**、壁の面の**下の端**（床とつながる影つきの絵）。
- 海の**動き**（2〜4 コマ）：Rule Tile／Animated Tile で波を動かせる。
