# 演出の作り方（色調・光・天候・回想・1枚絵・手の動作・波紋）

2026-11-26 作成（指示書 `CT_presentation_mood_light_weather_still_claudecode_instruction_2026-11-25`）。
言葉で説明する代わりに、**色・光・天気・画面の見た目**で場面の気持ちや時間の流れを伝えるための道具です。コードは書かずに、Inspector とイベントの部品だけで使えます。

| 道具 | 表すもの | 何を変えるか |
|---|---|---|
| 色調 | 気持ち | 画面全体の色（彩度・色かぶり・周辺を暗く・粒子・にじみ・画面の縁・光漏れ） |
| 光 | 時間帯・場所の明るさ | 全体の光（Global Light 2D）と、シーンに置いた「場面の光」 |
| 天候 | 天気・空気 | 雨・雪・砂ぼこり・霧・光の粒・花びら |
| 回想 | 過去か今か | 回想用の色調・天候・光 ＋ 回想中だけ出す物 ＋ コマ落ち |
| 1枚絵 | 区切り・余韻 | イラストを1枚、画面に出す |

**決まりごと：「色は気持ち、光は時間帯」**。同じことを色調と光の両方でしないようにします（夜にしたいときは光を「夜」にする。色調で暗くしない）。
会話・メニュー・HUD（ハートなど）は、色調・光・天候の影響を受けません（色調のプリセットで「会話画面にもかける」をオンにしたときだけ、会話画面にも色がかかります。1 章）。

---

## 1. プリセット（データ）

プリセットは `Assets/Resources/Presentation/` の中にあります。**ここ以外に置かないでください**（セーブから名前で探すため）。
増やすときは、今ある物を **Ctrl+D で複製**して名前を変え、値を変えるのがかんたんです（Project ウィンドウの右クリック > 作成 > CT > 演出 からも作れます）。

| 種類 | フォルダ | 最初からある物 |
|---|---|---|
| 色調 | `Mood/` | 通常・夜・一人・温かい日常・喪失・回想・夜明け |
| 光 | `Light/` | 昼・夜（Stage1_0・Stage1_1 の夜と同じ値）・月明かり・夕日・夜明け・塔の中の暗がり |
| 天候 | `Weather/` | 雨・弱・雨・強・雪・砂ぼこり・霧・光の粒・花びら |
| 回想 | `Flashback/` | 回想（基本）・埋葬 |

- 最初の値に戻したいときは **Tools > 演出 > 最初のプリセットを作り直す**（調整した値は消えます）。消してしまった物だけ作り直すときは **Tools > 演出 > 最初のプリセットを作る（ある物はそのまま）**。
- 値の意味は、Inspector の項目にマウスを乗せると出る説明（Tooltip）を見てください。
- **品質「軽い」**では、色調の「粒子」「にじみ」が外れ、天候の粒の量が半分になります。

### 光のプリセットの「場面の光」
月明かり・ランタン・窓の光・夕日のような、シーンに置いた光を、グループ名で点けたり消したり、強さを変えたりできます。

1. Hierarchy 右クリック > **演出 > 場面の光（点の光）**（窓から差す筋なら「四角い光」）で光を置く。
2. 「場面の光」の **グループ名** に名前を入れる（例：`月`、`ランタン`、`夕日`）。
3. 光のプリセットの「場面の光」に、そのグループ名と「点ける」「強さ（元の何倍）」を書く。
- プリセットに**書いていないグループは、置いたときのまま**です。ふだんは消しておきたい光（夕日など）は、Light 2D のチェックを外して置き、使うプリセットにだけ「点ける」を書きます。
- 明かりのゆらぎ（LightFlicker）と一緒に付けても大丈夫です。

### 色調のプリセットの「会話画面にもかける」（11-26）
- **オン**にすると、その色調の間は会話画面も同じ考え方の見た目になります。立ち絵は色が抜けて色がかかり、粒子が乗ります。名前・本文・キーの案内には色がかかります。会話を出している間は、会話画面の上に粒子と周辺の暗さが薄く重なります。
- **会話画面の強さ**（0〜1）：1 でマップと同じ。0.8 くらいが読みやすいです。
- 会話画面の粒子は、色調の「粒子」と「会話画面の強さ」を下げるほど**点がまばらに**なります（1 つの点の濃さは変わりません）。
- 最初は「回想」だけがオン（0.8）です。喪失などでも使いたいときは、その色調でオンにします。
- メニュー・HUD・セーブの画面は変わりません。色調の切り替えと同じ秒数でなめらかに変わります（回想の「色が抜けてから差す」では、会話画面もいったん灰色になります）。

### 色調のプリセットの「画面の縁」（11-27）
マップの映る範囲（画面の中央 4:3）の端を整える項目です。「画面が真四角に見える」「空を暗く落としたい」ときに使います。
- **縁をぼかす幅**（0〜0.25）：4:3 の端を、左右の帯の色（ふつうは黒）へなめらかに消します。画面の高さに対する割合で、0.04 で少し、0.08 でしっかり、0.15 で大きく。0 でくっきり切れたままです。
- **角の丸み**（0〜1）：0 で四角、1 で丸く（古い写真・ブラウン管のような角）。
- **上のグラデーション**（強さ・色・高さ）：画面の上から色をかぶせます。黒・紺で空を暗く落とし、重たい感じに。白で上を白くかすませます。
- **下のグラデーション**（強さ・色・高さ）：画面の下から色をかぶせます。白・薄い黄色で地面が明るくかすみ（ダリの絵の地平線のような感じ）、黒で足元を暗くします。
- どれも 0 なら何も出ません。ほかの色調の項目と同じように、切り替えの秒数でなめらかに変わります。
- 周辺を暗くする（ビネット）は四隅を丸く暗くし、こちらは端と上下を整えます。一緒に使えます。
- 会話・1枚絵・暗転の幕・シネマの帯・HUD（体力など）には、かかりません。

### 色調のプリセットの「光漏れ」（11-27）
古いフィルムの光漏れのように、画面の端から光が差し込みます。思い出・回想・儚い場面に。
- **光漏れの強さ**（0〜1）：全体の強さ。0 でなし。ふだんの場面は 0.2〜0.3、回想・思い出は 0.6〜1 が目安です（いつも強くすると効果が薄れます）。
- **右の帯・左の帯**（強さ・色）：左右の端から差し込む光の帯。右は橙、左は青緑が最初の値です（古い写真の色）。片方だけにするときは、もう片方の強さを 0 に。
- **帯の幅**：帯が内側へ伸びる幅（画面の横幅に対する割合）。
- **角の焼け**（強さ・色・焼ける角）：角が白く焼けたようになります。
- **縦の筋**：細い光の筋（品質「軽い」では出ません）。
- **揺れ**：光がゆっくり揺れ、強くなったり弱くなったりします。0 で止まったまま。
- **一瞬光る回数（1 分に）**：ときどき一瞬だけ強く光ります（ピッと入る）。0 で光りません。2〜4 くらいがさりげないです。
- 光は「足す」重ね方です。**明るい場面（白い砂など）では目立たず、暗い場面ほどはっきり見えます**。明るい場面で見せたいときは強さを上げてください。
- 会話・1枚絵・暗転の幕・HUD にはかかりません。

### 太陽（レンズフレア）（11-27）
カメラのレンズ越しに太陽を見たときの光です（太陽のまわりが白く飛び、画面の中心を通る線の上に六角形・玉・虹の輪が並び、全体が白っぽくかぶる）。
- Hierarchy 右クリック > **演出 > 太陽（レンズフレア）**。置いた場所が太陽です（シーンビューに黄色の二重の円）。空の上など、画面の端の近くに置くと自然です。
- **強さ**・**太陽の色**・**太陽の光の大きさ**・**ゴーストの強さ**（六角形・玉・虹の輪。0 で出さない）・**白いかぶり**（太陽が画面の真ん中に近いほど全体が白っぽく）・**かぶりの色**・**画面の外でも出る距離**（太陽が画面の外でも、この距離までは少し出る）。
- 色調のプリセットの **レンズフレアの強さ**（最初は 1）を掛けて出します。夜・室内・回想の色調で 0 にすると、太陽を置いたままでも消えます。
- 表示・非表示で出す・消す（イベントの「表示を切り替える」で）。1 つの場面に 1 つだけ置いてください（複数あるときは強い方）。
- **使いすぎると安っぽくなります**。太陽が見える場面だけに置いてください。品質「軽い」ではゴーストを出しません。

### 映画の字幕（11-27）
飾らず、文字だけを画面の中央より少し下に大きな太字で出す字幕です（映画の字幕のように）。語り（「彼女は〜」「男は〜」）に向いています。
- 部品「字幕」の **字幕の形** を「映画」にします（**新しく足した字幕は最初から「映画」**。前からある字幕は「帯」のままです）。
- 名前・帯・後ろの黒いぼかしは出ません。シネマ演出の帯がなくても出せます。会話データ（CSV）を入れると、文だけを順に出します。
- 1行は 16 字くらいで折り返します。**2行まで**に収めてください（3行以上は読みにくくなります）。
- 見た目は `Assets/Resources/Presentation/SubtitleStyle` で変えられます（フォント・字の大きさ・字と行の間隔・色・高さ・1行の幅・縁取り・影）。**白い画面でも読めるように影と縁取りを付けています。白ベースの場面では外さないでください。**字の大きさは 46 より小さくしないでください。
- 会話の「シネマ演出で出す」は、これまでどおり帯の字幕です。

### 色調の「塗り替え」（明るさ → 色。青と黄色の哀愁、11-26）
画面の明るさに合わせて色を塗り替えます（画像編集のグラデーションマップ）。**暗い所＝紺、普通＝青、明かりの中＝黄色**のように、光で明るくなった所がそのまま黄色になります。「色調はどの色に塗り替えるか、光はどこを明るくするか」を決めます。

| 項目 | 中身 |
|---|---|
| 明るさで塗り替える | オンで塗り替える |
| 境目 | 段階（硬い境目）／なめらか |
| 色の段 | 「明るさ（から）」0〜1 と「色」の一覧（暗い → 明るい）。明るさは画像編集と同じ見方（sRGB の値）なので、依頼書の「明るさ％」をそのまま入れてよい |
| 元の色を残す | 塗り替えた色に元の色を混ぜる割合（0.15 で物の色がわずかに残る） |
| 塗り替えの強さ | 1 で全部塗り替える |

- 最初からある物：**P1 ファミレス型・P2 夏のうちに型・P3 月夜の砂浜・P4 回想・ぬくもり・P5 喪失・P6 夜明け**（`Mood_P1_〜` 〜 `Mood_P6_〜`）。今までの色調（夜・一人など）も残っています。
- 再生中に今使っている色調の「塗り替え」の値をいじると、**その場で画面が変わります**（作り直すボタンは要りません）。
- 塗り替えの色調から別の色調へも、なめらかに変わります。回想の「色が抜けてから差す」では、いったん塗り替えが外れて灰色になってから、次の色が差します。
- 会話・メニュー・HUD は塗り替えません（「会話画面にもかける」は P1〜P6 ではオフ）。

### 青と黄色の光（11-26。**光が主役**）
方針（ユーザーの指示）：**元の絵に、光で色味と雰囲気を足す**。絵の色を塗り替えすぎないように、青と黄色は主に光で出し、色調の塗り替えは控えめな仕上げ（強さ 0.25・元の色を半分残す）にしています。
- 案ごとの光のプリセット **「Light_P1_ファミレス型」〜「Light_P6_夜明け」**：全体の光＝案の青（藍・青・紺）、窓・ランプ・月・頂上・時計の光＝案の黄色（レモン色・杏色・淡い黄色・クリーム色。P5 喪失は青白く弱い）。光のプリセットの「場面の光」に **「色を変える」と「色」** を足しました。
- 色調 P1〜P6 と、同じ番号の光をセットで使います（試し用マップの台座「青と黄色」は、調べるとセットで変わります）。
塗り替えの色調では、**光の形と明るさがそのまま構図**になります。
- 光のプリセット **「青い夜（塗り替え用）」**：全体の光は白で暗め（0.25。白い物でも黄色にならない）、窓・ランプ・月・頂上・時計のグループの光を点ける、キャラの周りを少し明るく（0.35）。
- Hierarchy 右クリック > 演出 > **青と黄色の光** > 窓の光（床に落ちる台形・硬い境目・影あり）／ランプ・ランタン（硬い円＋外の弱い縁の光・影あり）／月明かり／塔の頂上の光／懐中時計の光。置いた時点では消えていて、「青い夜」などグループを書いた光のプリセットのときだけ点きます。
- **光の強さは、場所の絵の明るさで変わります**。砂浜（明るい絵）はそのまま、一層の通路（暗い絵）は光 9・縁 3.5 にしています。合わせるときは、デバッグウィンドウの「演出」の **「塗り替えの境目を表示」**（または試し用マップの台座）で、色の段ごとに 紺・青・水色・黄… の色で塗って見ます。光の中が黄の段、外が紺〜青の段になるように、場面の光の Light 2D の強さを変えます。
- 光の中の影：窓とランプの光は影を落とします（Shadow Caster 2D の付いた物だけ。試し用マップでは残骸 2）。キャラの影はまだ付けていません。
- 光の強さの決まり（依頼書 4-1）：光の外は白い物でも黄色の段に届かない／光の中は暗い物でも黄色の段を超える／縁は少し大きい弱い光を重ねると 1 段出る。

## 2. シーンの既定（このシーンはどの見た目で始まるか）

Hierarchy 右クリック > **演出 > シーンの演出の既定（色調・光・天候）** をシーンに1つ置きます。

| 項目 | 空のとき |
|---|---|
| 色調 | 通常（何も加工しない） |
| 光 | シーンの Global Light 2D の値のまま |
| 天候 | なし |

- **条件で変える**：フラグの条件と、変える物（色調・光・天候）を書いておくと、条件を満たしている間はそちらになります（優先度の大きいほうが勝つ）。ゲームの途中でフラグが変わると、「切り替える秒数」でなめらかに変わります。
- 例：Stage1_0・Stage1_1 は光＝「夜」。

## 3. イベントの部品（分類「会話・演出」）

| 部品 | すること |
|---|---|
| 色調を変える | 色調のプリセットへ、秒数をかけて変える |
| 色調を戻す | 「色調を変える」をやめて、シーンの既定へ戻す |
| 光を変える | 光のプリセットへ、秒数をかけて変える |
| 光を戻す | シーンの既定の光へ戻す |
| 天候を変える | 指定した天候にする／止める（なし）／シーンの既定に戻す。量は秒数をかけて増える・減る |
| 回想に入る | 回想のプリセットの見た目にする（暗転しない） |
| 回想から戻る | 回想に入る直前の見た目に戻す |
| 1枚絵を出す | イラストを出す（動き・閉じ方を選ぶ） |
| 1枚絵を閉じる | 「1枚絵を出す」（部品で閉じる）の絵を閉じる |

- どの部品も「かける時間（秒）」を指定でき、**0 ならすぐ**です。途中でもう一度切り替えても、**今の見た目から次へ**なめらかにつながります。
- 「終わるまで待つ」をオンにすると、変わり終わってから次の部品へ進みます。
- **ロードしたとき**は、セーブしたときの色調・光・天候に戻ります（部品を置き直す必要はありません）。

### 強さの順番（同時に指定されたとき）
| | 弱い → 強い |
|---|---|
| 色調・光 | シーンの既定 ＜ 範囲（場所の色味）＜ 部品 ＜ 回想 |
| 天候 | シーンの既定 ＜ 部品 ＜ 天候の範囲（室内など）＜ 回想 |

## 4. 天候

- 天候は**画面の範囲にいつも降ります**（マップの端でも途切れません）。
- 天候のプリセットの「描く順番」で、キャラの前か後ろかを選べます。「光の影響を受ける」をオンにすると夜は粒も暗くなります（光の粒はオフ＝光って見える）。
- 「環境音（ループ）」にループの SeData を入れると、その天候の間ずっと鳴ります（今は空）。
- **天候の範囲**：Hierarchy 右クリック > **演出 > 天候の範囲**。四角の中に入ると天候が変わる（空なら止む）。室内に入ると雨が止む、などに使います。出ると元の天候に戻ります。

## 5. 回想

1. 回想中だけ出す物（三人の頃の家具・人影など）を置き、最初は非表示にしておく。
2. Hierarchy 右クリック > **演出 > フラグでなめらかに出す** を置く（条件に回想中フラグ `Flag_Flashback_Active` が最初から入っている）。「満たしているとき」に 1. の物を入れる。今の時代にだけある物は「満たしていないとき」に入れる。
3. イベントで「回想に入る」→ 会話など →「回想から戻る」。

- 入り方：**色が抜けてから差す**（おすすめ。今の色がいったん抜けて灰色 → 回想の色がにじむ）／ゆっくり溶ける／すぐ。
- 回想の間の「色調を変える」「光を変える」「天候を変える」は、**戻ると取り消されます**（回想に入る前の見た目に戻る）。
- 回想の間は、キャラ・物のアニメのコマ数が落ちます（プリセットの「コマ落ち」。0 で落とさない）。
- **回想の中にオートセーブを置かないでください**。回想の途中でセーブされたときは、回想に入る前の状態で記録されます（ロードすると回想の外から始まる）。シーンチェックで知らせます。
- 「回想に入る」には「回想から戻る」を対で置きます（シーンチェックで確かめます）。

### 使い方の例（埋葬の記憶）
1. 回想に入る（回想＝埋葬、3秒）
2. 光を変える（夜明け、2秒）
3. 会話（シグルの独り言）
4. 天候を変える（雨・弱、4秒）
5. ……
6. 回想から戻る（3秒）

## 6. 1枚絵

| 項目 | 中身 |
|---|---|
| 絵 | イラスト（スプライト）。置き場所は `Assets/Images/UI/Still/` |
| 出すまでの秒数 | フェードの時間 |
| 動き | なし／ゆっくり寄る／ゆっくり引く（大きさの始めと終わり）／横に流す・縦に流す（位置の始めと終わり：-1＝左端・下端、1＝右端・上端） |
| 閉じ方 | キーで閉じる（会話の送りと同じ E・Space・Enter。右下に案内が出る）／時間で閉じる／部品「1枚絵を閉じる」で閉じる（その間に会話を出せる） |
| 出す範囲 | マップの範囲（中央 4:3。既定）／画面全体（16:9） |
| 絵の合わせ方 | 範囲を埋める（はみ出た所は切る。流すときはこちら）／全部見せる |
| 背景の色 | 黒・白・透明 |
| 上下の帯を出しておく | シネマ演出の帯を最初から出しておく（会話が始まっても帯が動かない） |

- 「流す」は、絵が範囲より大きいときだけ動きます（16:9 の絵を 4:3 の範囲に「範囲を埋める」で出すと、横に流せる）。
- 会話の枠・立ち絵は、1枚絵の上に出ます。
- 使い方の例（エピローグ）：色調を変える（夜明け、3秒・待つ）→ 1枚絵を出す（再会のイラスト、フェード 2秒、ゆっくり寄る 10秒、閉じ方＝キー）。

## 8. 注意
- 色調は**マップの範囲（中央 4:3）だけ**にかかります。周辺を暗くする効果も 4:3 の四隅に付きます。
- 世界の中に出している物（調べる案内「[E] 調べる」・敵の攻撃の予告・相棒の目印など）には色調がかかります。
- 明かりに反応しない絵（Sprites-Default などの Unlit のマテリアル）は、光を変えても明るさが変わりません。マップ・物は **Sprite-Lit-Default** にしてください（波の SpriteFrameBlend は「シーンの明るさに合わせる」で光についてきます）。
- 暗いステージ（StageDarkness、Stage1_2）の暗さは、光のプリセットの上に掛かります。

## 9. 手の動作（11-27。指示書 `CT_presentation_ripple_subtitle_gesture` の S13）

「時計を巻く」「墓を掘る」「手を伸ばす」のような**手で何かをする瞬間**を、キーの押し方で感じさせる道具です。イベントの部品 **「手の動作を待つ」** を流れに置くと、終わるまで次の部品へ進みません（その間、プレイヤーの移動・攻撃・メニューは止まります）。

### プリセット（`Assets/Resources/Presentation/Gesture/`）
| 項目 | 意味 |
|---|---|
| 型 | **ゆっくり回す**（押したまま。進むほど見た目が回る）／**長押し**／**繰り返し（1 回ずつ押す）** |
| 使うキー | E（調べると同じ）／Space／どれでも |
| 終わるまでの秒数 | 回す・長押し：重さ 1 で押し続けたときの秒数 |
| 重さ（カーブ） | 横＝進み具合 0〜1、縦＝進む速さ。最後だけ低くすると「最後の 1 割が重い」 |
| 離したとき | 止まる（戻らない）／ゆっくり戻る（戻る速さ） |
| 回数・次を押せるまでの間 | 繰り返しの回数と、1 回ごとの間（すぐ次を押しても数えない） |
| **押すたびに進む**・1 回で進む量 | **長押しが苦手な人向け**。オンにすると、回す・長押しも「押すたびに少し進む」になる（プリセットごと） |
| 進み具合の見た目 | なし（画面の中の物で見せる）／輪（画面下に丸いゲージ） |
| 案内の文 | 空なら型に合わせた文（「E を押したまま」など）。最初の 3 秒と、止まって 2.5 秒たったときだけ出る |
| 震えの強さ | 押している間、手元（下の「震わせる物」）が小さく震える |
| 押している間、まわりを止める | 「最後の一音」用。押し始めるとゲームの時間と音が止まる（終わると戻る） |

最初からある物：カイロスと調律（長押し・軽い）、手を伸ばす（長押し・最初は重く近づくほど軽い）、墓を掘る（繰り返し 5 回）、二人で墓を掘る、最後の一音（長押し・まわりが止まる）、最後のひと巻き（回す・最後の 10% が重い）。
作り直しは Tools > 演出 > 手触りと波紋のプリセットを作る（ある物はそのまま）。

### 部品「手の動作を待つ」
| 項目 | 意味 |
|---|---|
| 手触りのプリセット | 上のプリセット |
| 案内の文（上書き） | この場面だけ文を変える |
| 途中の出来事 | 「進み具合（0〜1）」を超えたときに 1 回だけ流すイベント・合図（半分で字幕、9 割で揺れ など。繰り返しは回数の割合） |
| 1 回ごとに動かすイベント・合図 | 繰り返し：1 回押すごとに |
| 進み具合を書く数値・回数を書く数値 | 下の「演出の数値」の名前。ここに書いた数値で、画面の中の物（時計の針・墓標）を動かす |
| 震わせる物 | 押している間に震える物 |

### 画面の中の物を動かす：演出の数値
- **「演出の数値で動かす」**（Add Component > 演出）：数値の名前・値の範囲と、動かし方（回す〔角度〕／大きさ／位置をずらす／絵を段ごとに替える／子を順に出す）。時計の針なら「回す・0〜1 で 0 → -360 度」、墓標なら「子を順に出す・0〜5」。
- 部品 **「演出の数値を変える」**（分類「進行」）：数値をこの値にする／足す。「セーブする」をオンにするとロードしても残る（オフはシーンを移ると 0 に戻る）。場面の最初に 0 に戻すのに使う。

## 10. 波紋と色の戻り具合（11-27。S2）

### 波紋（`Assets/Resources/Presentation/Ripple/`）
直した場所から色や光が**輪になって広がる**演出です（光で作っているので、マップの絵はそのまま）。
| 項目 | 意味 |
|---|---|
| 見せ方 | **色が戻る**（その場所だけ、今の暗さ・色かぶりを打ち消す光）／**光が灯る**（光の色で照らす） |
| 光の色・強さ・最後の半径・広がる秒数・縦の割合 | 輪の中の光 |
| 縁の明るさ・色・太さ・縁が消える秒数 | 広がっていく輪の縁（広がり終わると消える。画質「低」では縁なし） |
| 戻り方 | ずっと残る／ゆっくり消える（消える秒数） |

最初からある物：色が戻る、光が灯る（黄色）、小さな光（手元から小さく広がって消える）。

- 部品 **「波紋を広げる」**：中心（物・ノア・シグル・操作中のキャラ）＋ずらす、広がる秒数（0 ならプリセット）、**残す ID**（空でなければセーブに残り、ロードしたときは広がった状態で出る）、広がるまで待つ。
- 部品 **「波紋を消す」**：残す ID（空ならすべて）を秒数をかけて消す。セーブからも消える。
- **「残る波紋（フラグで）」**（Add Component > 演出）：フラグの条件を満たしている間、その場所に波紋を出す（シーンに入ったときに満たしていれば広がった状態）。「直した → フラグ → 波紋が残る」に。

### 色の戻り具合（層全体の色が少しずつ戻る）
- シーンの **「シーンの演出（既定）」** の「色の戻り具合」に、**色が戻りきったときの色調・光**を入れておく。
- 部品 **「色の戻り具合を変える」**：割合を足す／この割合にする（1 で戻りきる）、かける時間。音楽生物を 1 体直すたびに 0.25 足す、など。**セーブに残る**。
- 部品「色調を変える」「光を変える」で変えている間は、そちらが勝ちます（戻すと、戻り具合のついた既定の見た目に戻る）。

## 11. 試す：動作と波紋の広場（試し用マップの東）

見本の広場から**右（東）へ歩く**と、砂浜の床をもう 1 枚並べた広場に入れます。
```
 [回す（時計）]  [長押し（手を伸ばす）]  [繰り返し（墓を掘る）]   ← 上に時計・伸びる手・墓標
 [波紋 色が戻る] [波紋 光が灯る]          [波紋を全部消す]
 [色の戻り +0.25] [色の戻り 0 に戻す] [場面 埋葬の記憶] [場面 最後のひと巻き]
```
| 台座 | 調べると |
|---|---|
| 回す | E を押したまま。時計の針が回り、最後の 1 割だけ重い。画面下に輪 |
| 長押し | E を押したまま。手が伸びて向こうの手に届く（最初が重い） |
| 繰り返し | E を 5 回（間を空けて）。墓標が 1 つずつ立つ |
| 波紋 色が戻る／光が灯る | その場所から輪が広がって残る（ロードしても残る）。全部消すで消える |
| 色の戻り +0.25／0 に戻す | 砂浜全体が「温かい日常・夜明け」へ少しずつ近づく（ロードしても残る） |
| 場面 埋葬の記憶 | 回想に入る → 5 回掘る（墓標が立つ）→ 字幕 → 戻る。回想の間だけ、左に光の波紋（残る波紋〔フラグで〕） |
| 場面 最後のひと巻き | 回す → 半分・9 割で字幕 → 巻き終わると時計から光が灯る |
