# 素材の取り込み（音・画像を入れる）

素材（BGM・効果音・立ち絵・アイコン・エフェクト・キャラや敵の絵）を Unity に入れて、使う場所に設定するための道具です。
Claude に頼むときは「このフォルダの素材を入れて」と渡せば、下の流れで進めます（`asset-intake` スキル）。自分で使うこともできます。

## 1. 取り込みの設定は自動（置いたフォルダで決まる）
`Assets/Data/AssetTools/取り込み設定.tsv` に、フォルダごとの取り込みの設定が書いてあります。新しく入れたファイルには自動でかかります（今ある素材は変わりません）。

| フォルダ | 設定 |
|---|---|
| `Assets/BGM/` | Streaming・Vorbis 70%（長い曲でもメモリをほとんど使わない） |
| `Assets/SE/` | 読み込み時に展開（短い効果音） |
| `Assets/Images/Map/` | Sprite・1 マス 100 ピクセル・四角のまま描く（大きいマップの絵） |
| `Assets/Images/Effect/` | Sprite・圧縮しない（色がにじまない） |
| `Assets/Images/`（ほか） | Sprite・1 マス 100 ピクセル・圧縮・Max Size は絵の大きさに合わせる（絵が縮まない） |

- 画像は**1枚の絵（Sprite Mode = Single）**で入ります（勝手に分割されない。2026-11-19〜）。何コマも並べた連番の絵は、ファイル名に `_sheet`（または `_animetion`・`_animation`・`_anim`）を入れると分割できる形（Multiple）で入るので、Sprite Editor の Slice（Grid By Cell Count など）で切ってください。
- すでに入っている画像が勝手に分割されていたら：Inspector の Sprite Mode を Single にして Apply（置いてある物は Sprite を入れ直すか、Tools > 素材 > 仮素材を差し替える）。
- 表を直すと、その後に入れた素材から変わります。今ある素材に新しい設定をかけるときは、Project で素材かフォルダを選んで右クリック → **素材 > 取り込み設定をかけ直す**。
- 設定の書き方（「設定」の列）：画像＝`ppu=100;mesh=tight|full;filter=bilinear|point;compress=on|off|hq;mip=on|off;maxsize=auto|2048;mode=single|multiple;sheet=_sheet,_anim`（sheet＝名前にこの言葉が入っていたら連番として分割できる形にする）、音＝`load=streaming|decompress|compressed;format=vorbis|pcm|adpcm;quality=70;mono=on|off;background=on|off`。

## 2. 割り当て表（どの素材をどこに入れるか）
`Docs/素材の割り当て/` に、タブ区切りの表（.tsv。Excel・メモ帳で開ける。保存は UTF-8）を置きます。1行＝1つの素材。

| ファイル | 入れる先 | 設定 | メモ |
|---|---|---|---|
| `SE-16_peg_miss.wav` | `slot:TimpaniPeg.missSe@Peg.prefab` | | ペグを外した音 |
| `BGM-02_timpani_battle_loop.ogg` | `bgm-rule:Stage_1_Boss/ティンパニ戦=Flag_Timpani_InBattle` | `vol=0.8` | 戦闘中だけ |
| `UI_Noah_Surprise.png` | `chara:Noah:Surprise` | | 驚いた顔 |
| `Enemy_Creature.png` | `replace:Assets/Images/Enemy/Enemy_Timpani_Creature_kari.png` | | 仮の絵を付け替え |

- 入れる先の書き方は、素材チェックリストの「確認キー」と同じです（`slot:部品.欄@場所`）。くわしくは `.claude/skills/asset-intake/SKILL.md`。
- 効果音の欄に音のファイルを書くと、同じフォルダに SeData（`Se_〇〇`）を自動で作ります（音量は「自動」でそろえる）。
- **Tools > 素材 > 割り当て表を試す（変えない）** で、何がどう変わるかを先に見られます。よければ **割り当て表を流す**（プレハブ・データ・シーンを保存します。シーンに保存していない変更があると止まります）。
- 何度流しても同じ結果です（もう入っている所は「同じ」と出て、何もしません）。手本は `2026-11-14_BGM_SE.tsv`（11-14 に入れた音の全部）。

## 3. 仮素材の差し替え
**Tools > 素材 > 仮素材を差し替える**：「古い素材（仮）」と「新しい素材」を入れて「探す」→「付け替える」。
プレハブ・データ・ゲームのシーンのどこで使っていても、全部付け替えます（画像どうしなら、中の絵を名前 → 並びの順で対応させます）。仮の絵を消すのは、付け替えたあと「探す」で 0 か所になってから。

## 4. 音の一覧（試聴・音量）
**Tools > 素材 > 音の一覧（試聴・音量）**：効果音（SeData）と BGM を並べます。
- ▶ で試聴（効果音は SeData の音量・ピッチで鳴る）、■ 止める。
- 音量はその場で直せます（Ctrl+Z で戻せる）。「自動」で聞こえ方を -20dB くらいにそろえます（大きい音だけ下げる）。
- 「聞こえ方」は大きさの目安：赤＝大きい（-14dB より上）・青＝小さい（-28dB より下。音量 1 でも小さいので素材を直してもらう）。
- 「使っている所」：どのシーン・プレハブ・データが使っているか（「選ぶ」でそこへ）。「使っていない物だけ」で、入れたのにどこにも使っていない音がわかります。

## 5. 素材を渡すときのお願い（作る人へ）
`Docs/素材の渡し方.md`（フォルダ名＝チェックリストの ID、ファイル名の決まり、形式）。直した版は同じファイル名で渡してもらえば、参照が切れずに差し替わります。
