## 2. イベントの部品

EventSequence の「＋ 部品を追加」で選ぶ（分類 > 名前）。上から順に実行される。

### 仕掛け・敵

#### ダメージエリアを出す
イベントの部品「ダメージエリアを出す」
- 攻撃のデータ（AttackData）を、指定した場所から出す。予告・形・発動のしかたはデータのとおり
- 「当たる相手：敵」にすると、ギミックで敵を攻撃するエリアになる（例：仕掛けを動かすと床に電気が流れる）
- 向きの「プレイヤーの方向」は、プレイヤーを狙う（敵を狙いたいときは「決まった角度」か、円の形を使う）
- ずっと出しておきたいときは、攻撃の発生源（AttackEmitter）を置いて「敵に命令」で動かす・止めるほうがよい

- **攻撃**：出す攻撃（AttackData）。攻撃の種類を「ギミック」にしておくと、敵の効き方で区別できる
- **出す場所**：ここを「敵の位置」として攻撃を出す（右向きが「敵の向いている方向」）。空ならこのオブジェクトの位置
- **回数**
- **間隔（秒）**：続けて出すときの間隔（攻撃の後隙のあと）
- **終わるまで次の部品を待たせる**：オン：攻撃が全部終わってから、イベントの次の部品へ進む（順番に実行のとき）

#### 仕掛けを操作
イベント（EventSequence）で仕掛けを操作する
- 例：会話で「レバーを引いた」→ 仕掛けを ON ／ アイテムをはめたら（ItemInteraction）→ 仕掛けを ON 「決定」のレバーで答え合わせ ／ ギミックのリセットボタン
- 固定されていても変える（イベントからの操作は強制）
- セーブから戻ったときは何もしない（仕掛けの状態は、仕掛け自身がセーブから戻す）

- **仕掛け**：シーンに置いた「仕掛けの状態」（GimmickState）。答え合わせの操作なら答え合わせ（PuzzleCheck）の付いた物
- **操作**
- **値**：「値にする」のときの値

#### 戦闘エリアを操作
イベントの部品「戦闘エリアを操作」
- 会話のあとで追跡を始める（戦闘エリアの始まり方を「イベントの部品から」にしておく）
- ギミックを解いたら勝ちにする、など

- **戦闘エリア**
- **命令**

#### 押せる箱を戻す
押せる箱を元に戻す
- 例：箱が角に詰まって動かせなくなったときの「リセットのレバー」／ 部屋を出たら戻す
- 穴に落ちた箱はそのまま（穴は埋まったまま）

- **Blocks**：戻す箱。空ならシーンの全部の押せる箱

#### 敵にダメージ
イベントの部品「敵にダメージ」
- ギミックを作動させたら敵にダメージ（天井を落とす・電気を流す など）
- 攻撃の種類は既定で「ギミック」。敵のデータの効き方で「ギミックでしか倒せない」敵も作れる
- 攻撃を受ける部品（DamageReceiver）を指定すると、弱点などその部分に当てる（部位のダメージの倍率が効く）

- **Enemies**：ダメージを与える敵
- **Parts**：ダメージを与える部分（敵の弱点など、攻撃を受ける部品）。敵に直接当てるなら空でよい
- **ダメージ**
- **攻撃の種類**
- **エフェクト**：当たった敵の位置に出す
- **SE**

#### 敵に命令
イベントの部品「敵に命令」
- ギミックを解いたら敵が止まる、攻撃の発生源（見えない敵）が弱くなる・止まる、などに使う
- ItemInteraction・EventZone などの EventSequence に、ほかの部品と同じように付ける
- セーブから戻ったとき（ItemInteraction の完了の復元）は、ずっと続く命令（止める・動かす・段階・倒す・消す）だけをやり直す

- **Enemies**：命令する敵（シーンに置いた敵）
- **Emitters**：命令する攻撃の発生源（見えない敵）
- **命令**
- **秒数**：「○秒だけ止める」のときの秒数
- **段階の番号**：「段階を変える」のとき。行動パターンの段階の番号（1 から）
- **止まっている間の色を変える**
- **止まっている間の色**：止まっていることが見て分かるように、敵の絵にかける色
- **エフェクト**：命令したときに、それぞれの敵の位置に出す
- **SE**

### 会話・演出

#### BGM のフラグ
イベント (EventZone → EventSequence) でBGMフラグを切り替えるアクション
- BgmConditionFlag と組み合わせて使う
- Flag（GameFlag アセット）を入れたらそれを使う。空なら Flag Name を使う（旧方式）
- 新しく作るときは SetFlagEventAction を使ってもよい（同じことができる）

- **Flag**：切り替えるフラグ（GameFlag アセット）。入れたら下の Flag Name は使わない
- **Flag Name**：旧方式のフラグ名 (例: Boss)
- **Value On Enter**：イベント発動時に設定する値
- **Revert On Exit**：エリアから出たときに元に戻す

#### BGM の進み具合
イベント (EventZone → EventSequence) で BgmProgress を変えるアクション

- **Value**：Set / SetAtLeast では進行度、Add では加算量

#### アニメ
イベント (EventZone → EventSequence) でアニメーションを流すアクション
- (扉が開く、スイッチが切り替わる、像が光り出す、など)
- EventSequence の actions リストに追加して使う セーブから復元するときは、音やエフェクトを出さずに「流し終わった見た目」にする

- **Target**：アニメーションを流す SpriteAnimator (空ならこのオブジェクトのもの)
- **Clip On Enter**：イベント発動時に流す動きの名前
- **Clip On Exit**：エリアから出たときに流す動きの名前 (任意)。設定した場合、セーブからは復元しない (一時的な変化とみなす)
- **Wait Until Finished**：順番に実行するとき、アニメが終わるまで次の部品を待たせる（ループするアニメは1周で次へ進む）

#### エフェクト
イベント (EventZone → EventSequence) でエフェクトを出すアクション
- EventSequence の actions リストに追加して使う

- **Effect On Enter**：イベント発動時に出すエフェクト
- **Effect On Exit**：エリアから出たときに出すエフェクト (任意)
- **Spawn At**：どこに出すか
- **Custom Point**：「指定した場所」のときに使う位置
- **Offset**：位置のずらし
- **Follow**：出した後も対象にくっついて動く
- **Stop Loop On Exit**：エリアから出たとき、ループエフェクトを止める

#### カメラを向ける
カメラを向ける
- 例：スイッチを入れたら、離れた場所（相棒のエリア）の扉が開くところを見せる ／ ボスの登場を見せる
- 「順番に実行」の EventSequence では、見せ終わる（戻す）まで次の部品を待つ
- 見せている間、プレイヤーを止めたいときは EventSequence の Lock Player をオン

- **見せる場所**：カメラを向ける場所（扉など。空のオブジェクトでもよい）
- **動く時間（秒）**：カメラがなめらかに移る時間。0 なら一瞬
- **見せる時間（秒）**：着いてから、この秒数見せる
- **戻す**：オン：見せたあと、操作しているキャラにカメラを戻す／オフ：向けたまま（あとで別の「カメラを向ける」で戻す）

#### 一言（吹き出し）
イベント（EventSequence）で一言を出す
- 例：扉が開いたあとに「開いたな」／ 謎を解いたあとの掛け合い ／ 敵が出てくる前の「来るぞ」
- 一言のデータ（BarkData）を選ぶか、ここに直接文を書く
- 会話（DialogueManager）と違って、ゲームを止めない

- **一言のデータ**：Resources/Barks/ のデータ（候補からランダムに選ぶ）。空なら下の「文」を出す
- **データの条件・回数を見る**：オン：データの条件・何回出すか・待ち時間を満たさなければ出さない / オフ：必ず出す
- **Lines**：データを選ばないときに出す文（上から順に。2行以上で掛け合い）
  - **話すキャラ**
  - **Text**：吹き出しに出す文。短めに（1〜2行）
  - **出している秒数**：0 なら文の長さで決める（一言の設定の「1文字あたりの秒数」）
  - **次の行までの間（秒）**：この行が消えてから次の行が出るまで
  - **SE**：この行を出すときに鳴らす（空なら鳴らさない）
- **終わるまで待つ**：オン：順番に実行のとき、一言が終わってから次の部品へ進む
- **優先度**：文を直接書いたときの優先度（自動の一言が割り込めないように、大きめにしておく）

#### 会話
イベントでダイアログを表示するアクションのクラス

- **会話データ**：出す会話（Assets/Data/Dialogue/ の DialogueData）。ここに入れれば、下の Dialogue（子の「会話」オブジェクト）は要りません
- **Dialogue**：（前の作り方）会話を持つ Dialogue。上の「会話データ」が空のときだけ使う
- **Wait Until Closed**：順番に実行するとき、会話を閉じるまで次の部品を待たせる
- **Close Key**：旧方式（DialogueManagerがないシーン）で閉じるキー

#### 効果音
イベント (EventZone → EventSequence) でSEを鳴らすアクション
- EventSequence の actions リストに追加して使う

- **Se On Enter**：イベント発動時に鳴らすSE
- **Se On Exit**：エリアから出たときに鳴らすSE (任意)
- **Stop Loop On Exit**：エリアから出たとき、seOnEnter がループSEなら止める
- **Play At This Position**：このオブジェクトの位置で鳴らす (3D寄りのSEのとき有効)

#### 暗さ・視界を変える
イベントの部品「暗さ・視界を変える」
- ランタンを拾ったら部屋が少し明るくなり、プレイヤーの周りが照らされる、など
- シーンの StageDarkness の値を変える（StageDarkness がないシーンでは何もしない）
- セーブから戻ったとき（完了したイベント）は、変えたあとの値にすぐ戻す

- **暗さを変える**
- **暗さ**：0 で普段の明るさ、1 で真っ暗（StageDarkness の Darkness と同じ）
- **視界を変える**
- **プレイヤーの明かりの半径**：プレイヤーの周りの明るい範囲（マス。StageDarkness の Radius と同じ）
- **かける時間（秒）**：0 ならすぐに変わる
- **終わるまで待つ**：順番に実行するとき、変わり終わってから次の部品へ進む

#### 画面の暗転
イベントの部品「画面の暗転」
- 画面を暗くする／明るくする。暗いままでも会話の枠と文字は見える（会話の画面より奥に出す）
- OP のモノローグ、回想、時間が飛ぶ場面などに使う
- 暗くしたままシーンを移ると、黒い画面はシーンと一緒に消える
- シーン遷移の暗転（SceneFader）とは別物（あちらは会話の画面も隠す）

- **種類**：暗転する：画面を暗くする／明転する：暗くした画面を戻す
- **かける時間（秒）**：0 ならすぐに切り替わる
- **色**：暗転の色（ふつうは黒。白くすると「白い光」の演出になる）
- **終わるまで待つ**：順番に実行するとき、暗転・明転が終わってから次の部品へ進む

#### 画面を揺らす
イベントの部品「画面を揺らす」（地響き・衝撃・頭痛など）
- マップの画面だけが揺れる（会話・HP などの UI は揺れない）
- 音と一緒に使うときは、この部品の前に SeEventAction を置く

- **揺れの大きさ（マス）**：0.1 で小さく、0.3 くらいで大きく揺れる
- **揺れる時間（秒）**：だんだん弱くなって止まる
- **揺れの速さ**：大きいほど細かく速く揺れる（ふつうは 25）
- **終わるまで待つ**：順番に実行するとき、揺れが止まってから次の部品へ進む

### 物・キャラ

#### 2人の状態
イベント（EventSequence）で2人の状態を変える
- 例：会話のあとで「別行動」にする（離れ離れになる）／合流の範囲に入ったら「一緒」に戻す
- 一緒：相棒がついてくる。切り替えると位置が入れ替わる。体力は共有（シグルの体力から減る）
- 待機・別行動：相棒はその場にいる。切り替えても位置はそのまま（カメラが移る）。体力は別々
- 今はセーブされない（シーンを読み込むと「一緒」に戻る）。離れ離れのステージの段階で、セーブするようにする

- **2人の状態を変える**：オフにすると、状態は変えずに、下の「操作するキャラ」「待て／ついてこいのキー」だけを変える
- **2人の状態**
- **操作するキャラも変える**：オン：下で選んだキャラに操作を切り替える
- **操作するキャラ**
- **待て／ついてこいのキー**：変えない／使えなくする（追跡中・離れ離れの場面など）／使えるようにする

#### キャラの向き
イベントの部品「キャラの向きを変える」（ノアが右を向く、など）
- 止まっている間はその向きのまま。歩き出すと、歩く向きに戻る
- プレイヤー以外（SpriteAnimator の付いた物）も「ほかの物」で向きを変えられる

- **だれ**
- **ほかの物**：「ほかの物」のとき、向きを変える物（SpriteAnimator が付いている物）
- **向き**

#### キャラを移す
キャラを移す
- 例：崩れた床で離れ離れになる → シグルを別のエリアへ移す ／ 扉の向こうへ移す演出 ／ 合流の場面で 2人を並べる
- 「暗転する」なら、暗転している間に移す（「順番に実行」では明転し終わるまで次を待つ）
- 一緒のときに 1 人だけ移すと、相棒がついてきて戻ってしまうので、先に「2人の状態を変える」で待機・別行動にしておく

- **移すキャラ**
- **移す場所**：空のオブジェクトを置いて入れる
- **暗転する**

#### 物を動かす
イベントの部品「物を動かす」
- 「ずらした位置から今の位置へ」：シーンに置いた位置へ、ずらした所から動いてくる（敵が上から降ってくる、など）
- 「今の位置からずらした位置へ」：置いた位置から、ずらした所へ動いていく（扉が開く・岩がどく、など）
- 敵を動かすときは、先に「敵に命令」で止めておく（止めないと自分で歩き出す）

- **動かすもの**：ノア・シグルは再生中に出てくるので、ここで選ぶ（歩くアニメになる。待機・別行動のときに使う）
- **動かす物**
- **動き方**
- **ずらす量（マス）**：上から降ってくるなら Y = 8 など。「目的の物へ」のときは、着く位置のずらし
- **目的**：「今の位置から目的の物へ」のとき、向かう先：下で選んだ物／ノア／シグル（ずらす量で、その横に止まる）
- **目的の物**：「今の位置から目的の物へ」のとき、向かう先（敵など。動いていても追う）
- **かける時間（秒）**
- **速さの変わり方**
- **終わるまで待つ**：順番に実行するとき、動き終わってから次の部品へ進む

#### 絵を差し替える
イベントでスプライトを差し替えるアクション
- （宝箱が開く、像が光る、スイッチが切り替わる、など）
- EventSequence の actions リストに追加して使う セーブから復元するときも同じ見た目にする（ItemInteraction の完了状態の保存）

- **Target**：見た目を変える SpriteRenderer
- **Sprite**：差し替える画像
- **Revert On Exit**：エリアから出たときに元の画像に戻す

#### 表示・非表示
イベントでオブジェクトを表示・非表示にするアクション
- （扉が消える、隠し通路が出る、など）
- EventSequence の actions リストに追加して使う セーブから復元するときも同じ状態にする（ItemInteraction の完了状態の保存）

- **Show**：表示するオブジェクト
- **Hide**：非表示にするオブジェクト
- **Revert On Exit**：エリアから出たときに元に戻す

### 進行

#### アイテムを取る
イベントでアイテムを消費する（取り上げる）アクション
- EventSequence の actions リストに追加して使う ItemInteraction のルールの「条件のアイテムを消費する」とは別に、 条件にないアイテムを取り上げたいときに使う

- **Item**：消費するアイテム
- **Count**：消費する個数
- **Take Available**：足りないときは、持っている分だけ消費する

#### アイテムを渡す
イベントでアイテムを渡すアクション
- EventSequence の actions リストに追加して使う

- **Item**：渡すアイテム
- **Count**：渡す個数
- **Se**：渡したときに鳴らすSE（任意）

#### オートセーブ
イベントの部品「オートセーブ」
- オートセーブ枠に、今の進み具合と「再開する位置」を書き込む（手動の枠は変えない）
- **入口に戻れなくなるなど、マップの通り道が変わるイベントの直後には必ず置く** （置かないと、ロードしたときにシーンに着いた位置＝通れなくなった所から始まってしまう）
- 話の区切り（仲間になった・ボスを倒した など）にも置くと、戻される距離が短くなる
- 会話などの途中ではなく、イベントの最後（プレイヤーが動けるようになる直前）に置く

- **再開する位置**：ロードしたときに出てくる位置
- **指定した場所**：「指定した場所」のとき。空のオブジェクトを置いて入れる

#### シーンを移る
イベントの部品「シーンを移る」（会話のあとで次のマップへ、など）
- 出口（SceneChange）にぶつかる代わりに、イベントの最後でシーンを移る
- 暗転・セーブの確定は、出口と同じ（シーンの SceneChange を使う）
- この部品のあとの部品は実行されない（シーンが変わるため）。一番最後に置く

- **Scene Name**：移る先のシーン（Build Settings に入っているものから選ぶ）
- **Spawn Point Id**：移った先での出現位置（移る先のシーンの PlayerSpawnPoint から選ぶ）

#### フラグ
イベント（EventSequence）でフラグを ON / OFF するアクション
- 例：NPC と話したら「NPCと話した」を ON にする、ボス部屋に入ったら「ボス戦中」を ON にする

- **Flags**：設定するフラグの一覧
  - **Flag**：設定するフラグ
  - **Value**：チェックで ON、外すと OFF にする
- **Revert On Exit**：エリアから出たときに元に戻す（EventZone で使うとき用。ボス部屋の中だけ、など）

#### メモを渡す
メモを渡す
- 例：NPC から手紙をもらう ／ 宝箱からメモが出てくる ／ 本棚を調べると日記が読める
- 「順番に実行」の EventSequence では、読み終わる（閉じる）まで次の部品を待つ

- **メモ**
- **その場で読む**：オフ：持っていることにするだけ（メニューで読める）

#### 即死
即死
- 例：選択を間違えた会話のあと ／ 時計が 0 時になったら ／ 答え合わせを間違えたとき
- この部品の前に並べた演出（会話・SE）は、そのまま流れてから即死する

- **即死したあと**

#### 合図を出す
イベントの部品「合図を出す」
- 会話のあと・仕掛けを解いたときなどに、自分で決めた合図を出す。受けるのは「合図を受けたら」と相棒の一言
- 出した物（合図の送り元）は、この部品のオブジェクト（受ける側の「送り元の絞り込み」に使う）

- **出す合図**：出す合図（Assets/Data/Signals/ の合図）
- **数**：合図に付ける数（受ける側で使うときだけ。ふだんは 0）

#### 待つ
指定した秒数だけ待ってから次の部品へ進むアクション
- （扉が消えてから一拍おいて会話、など）
- EventSequence を「順番に実行」にしたときだけ効果がある

- **Seconds**：待つ秒数
- **Ignore Time Scale**：ゲームの一時停止（Time Scale = 0）中も時間を進める

## 3. コンポーネント（Inspector の項目）

Inspector に日本語の項目名がある部品（フォルダごと）。Add Component の検索にはクラス名（英語）を入れる。

### Camera

#### CameraArea
カメラの範囲
- Is Trigger の BoxCollider2D の四角。カメラが追っているキャラがこの中にいる間は、カメラはこの四角の中だけを映す （ふだんはマップ〔Tilemap〕全体が範囲）
- 離れ離れのステージで、同じシーンの中に2つのエリアを作るときに使う（相手のエリアが画面に映り込まないように）
- 部屋ごとに区切ったカメラ（ゼルダの部屋切り替え風）にも使える
- 重なっているときは「優先度」の大きい方

- **優先度**：範囲が重なっているときは、大きい方を使う

#### MapCameraAspect
マップを写すカメラの画面比率
- 昔のゲームを今のモニターで遊んだときのように、マップは画面の中央の 4:3 だけに写し、左右（上下）は帯にする
- UI（Screen Space - Overlay の Canvas）は画面全体を使える（帯の上にも出せる）
- FocusCamera が付いているカメラには、シーンが始まったときに自動で付く（シーンに置かなくてよい）
- 比率や帯の色を変えたいときだけ、カメラに付けて Inspector で変える
- カメラの写す範囲（cam.aspect）が 4:3 になるので、カメラが止まるマップの端・マウスの位置・画面の外の判定もそれに合う

- **横の比率**：マップを写す範囲の横の比率（4:3 なら 4）
- **縦の比率**：マップを写す範囲の縦の比率（4:3 なら 3）
- **帯の色**：マップの外（左右の帯）の色

### Damage

#### DamageReceiver
攻撃を受ける部品
- Collider2D と同じオブジェクトに付ける。攻撃が当たると、指定した Health（空なら自分か親の Health）にダメージを渡す
- 敵の子オブジェクト（腕・弱点など）に付ければ、そこに当たった攻撃が本体の体力を減らす
- Health がなくても「当たった」ことは OnHit で分かる（ギミックの反応に使う）
- 範囲攻撃・弾は DamageUtility.Apply を通して当てるので、これがあればそちらが優先される

- **ダメージを渡す先**：この当たり判定に攻撃が当たったとき、体力を減らす相手。空なら自分か親の Health
- **ダメージの倍率**：ここに当たったときのダメージの倍率（弱点なら 2、硬い所なら 0.5、効かないなら 0）

### Enemy

#### AttackEmitter
攻撃の発生源（見えない敵）
- シーンに置いて、行動パターンを入れる。体がないので、行動のうち「待つ」「攻撃する」「仲間を呼ぶ」だけを使う（移動は飛ばす）
- 攻撃の起点が「敵の位置」なら、このオブジェクトの位置から出る。「プレイヤーの位置」なら、プレイヤーを狙って出る （例：プレイヤーの足元から腕が突き出る ＝ 起点：プレイヤー、発動：下から突き出る、突き出る物：腕のプレハブ）
- 「動く条件」を満たしている間だけ動く（エリアにいる間・フラグが立つまで、など）
- ギミックの「敵に命令」で、止める・動かす・段階を変える（攻撃を弱める）ことができる
- 会話中などは止まる（EnemyBlock）

- **行動パターン**：「待つ」「攻撃する」「仲間を呼ぶ」の並び。段階を使えば、ギミックを解くたびに弱くする（段階を変える）こともできる
- **最初から動く**：オフにすると、ギミックの「敵に命令（動かす）」まで止まっている
- **動く条件**：満たしている間だけ動く（空なら常に）。「プレイヤーがいる範囲」に Is Trigger の Collider2D を入れると、その中にいる間だけ攻撃してくる
  - **Flags**：フラグの条件。すべて満たすとき（空なら判定しない）
  - **Items**：アイテムの条件。すべて満たすとき（空なら判定しない）
  - **操作中のキャラ**：今操作しているキャラで判定する
  - **プレイヤーの体力**：2人で共有している体力の割合（最大を 1 とする）で判定する
  - **体力の割合**：0.3 なら最大の 30%
  - **プレイヤーがいる範囲**：操作中のキャラがこの Collider2D の範囲の中にいるとき（空なら判定しない。シーンに置いた物だけ指定できる）
  - **Gimmicks**：仕掛けの状態の条件。すべて満たすとき（空なら判定しない。シーンに置いた物だけ指定できる）。 / 例：「スイッチA が ON」「ダイヤルが 3」
  - **2人の状態**：ノアとシグルが一緒にいるか、離れているかで判定する
  - **2人がそろっている距離**：ノアとシグルがこの距離（マス）以内にいるとき（2人で押す扉・2人で回すレバーなど）。0 なら判定しない

#### Enemy
敵の本体
- 共通プレハブ Enemy_Base に付いている。「敵のデータ」（EnemyData）を入れてシーンに置くだけで動く （スポナーがなくても、狙う相手は操作中のキャラを自分で探す）
- 移動は Rigidbody2D（Dynamic）で行う。壁で止まり、マップ（PlayerSceneContext の Tilemap）の外には出ない
- MoveTo で目的地を渡すと、NavMesh2D で経路を探して壁を回り込む
- 会話・イベント中など（EnemyBlock）と、Paused の間は止まる 行動パターン（いつ・どこへ動くか、いつ攻撃するか）は次の段階で足す。今は MoveTo / Stop を外から呼ぶ

- **敵のデータ**：体力・速さ・見た目などをまとめたデータ（Assets/Data/Enemies/ の EnemyData）
- **倒したときのイベント**：倒した瞬間に実行する（扉が開く・会話 など）。セーブから戻ったときは、見た目だけ実行後の状態にする
- **倒したら ON にするフラグ**
- **倒した後に調べたとき**：敵のデータの「倒されたあと」が「残る」「おとなしくなる」のとき、E で調べると実行する（会話・アイテムをもらう など）
- **倒したことをセーブする**：オン：倒したことを覚えておき、シーンに戻ったときに「戻ったときの姿」にする（ボス・1 回だけの敵）
- **戻ったときの姿**：倒したことをセーブしたとき、シーンに戻ったらどうするか
- **セーブ用の ID**：空なら階層のパスで記録する（名前や親を変えると記録がリセットされる）

### Enemy/Battle

#### BattleArea
戦闘エリア
- 追いかけられるイベント・逃げるだけの戦闘・○秒生き残る戦闘・全滅させる戦闘を、勝ち方と負け方の組み合わせで作る 例：追跡イベント ＝ 勝ち方「ゴールに着く」×負け方「捕まる」×負けたとき「やり直す」。参加する敵の行動パターンは「追いかける」
- 始まるまで、参加する敵・攻撃の発生源は止めておける（「始まるまで敵を止めておく」）
- 戦闘中は、セーブポイントでセーブできない。「戦闘中にオンにするフラグ」で BGM を変えられる（BgmConditionFlag）
- 時間は、会話中などは進まない
- 「1回だけ」なら勝ったことをセーブし、シーンに戻ったときは勝ったあとの状態にする

- **始まり方**：エリアに入ったら：このオブジェクトの Collider2D（Is Trigger）に入ったら始まる
- **Enemies**：参加する敵。始まるまで止めておける。「敵を全部倒す」「捕まる」で見る
- **Emitters**：参加する攻撃の発生源（見えない敵）。始まるまで止め、終わったら止める
- **始まるまで敵を止めておく**
- **Waves**：ウェーブ（順に出てくる敵の組）。前のウェーブを全部倒すと次が出る。ウェーブの敵は始まるまで隠れている。勝ち方「敵を全部倒す」は、全部のウェーブを倒したら勝ち
  - **Enemies**：このウェーブで出てくる、シーンに置いた敵（始まるまで隠れている）
  - **Spawns**：このウェーブで新しく出す敵（敵のデータ・出る場所・数）
  - **出てくるまでの秒数**：前のウェーブを倒してから（最初のウェーブは戦闘が始まってから）出てくるまで
  - **メッセージ**：出てくるときに画面の真ん中に出す（例：第2波！）。空なら出さない
- **勝ち方**
- **生き残る秒数**
- **ゴール**：「ゴールに着く」のとき。操作中のキャラがこの Collider2D（Is Trigger）の中に入ったら勝ち
- **フラグ**：「フラグが立つ」のとき。このフラグが ON になったら勝ち（ギミックを解いたら ON にする、など）
- **負け方**
- **捕まる距離**：参加する敵が、操作中のキャラにこの距離まで近づいたら「捕まった」
- **制限時間（秒）**：「時間切れ」のとき
- **負けたとき**
- **負けたときのダメージ**：「ダメージを受けて続ける」のとき
- **やり直す位置**：「やり直す」で戻る位置（空のオブジェクトを置いて入れる）。空なら、始まったときにプレイヤーがいた位置
- **やり直したあと敵が止まる時間**：やり直し・ダメージのあと、敵が動き出すまでの秒数（すぐまた捕まらないように）。やり直しは、暗転してシーンを読み込み直し、戦闘が始まったときの状態（拾った物・フラグ・所持品・扉など）に戻す
- **始まったとき**：始まったときに実行するイベント（扉を閉める・会話・SE など）
- **勝ったとき**
- **負けたとき**：負けたときに実行するイベント（「捕まった！」の会話など。やり直しの前に実行）
- **戦闘中にオンにするフラグ**：戦闘中だけ ON（セーブしない一時的なフラグがおすすめ）。BgmConditionFlag で追跡中の曲に変えられる
- **目的と残り時間を画面に出す**：戦闘中、画面の上に目的・残り時間・残りの敵を出す
- **目的の文**：画面の上に出す目的。空なら勝ち方から自動で決める（ゴールまで逃げろ／生き残れ／敵を全部倒せ）
- **始まったときのメッセージ**：画面の真ん中に少しの間出す（例：逃げろ！）。空なら出さない
- **勝ったときのメッセージ**：例：逃げ切った！。空なら出さない
- **負けたときのメッセージ**：例：捕まった！。やり直すときは、これを出してから暗転する。空なら出さない
- **メッセージを出す時間（秒）**
- **勝ったあとの敵**
- **1回だけ**：オン：勝ったら二度と始まらない（セーブもする）
- **セーブ用の ID**：空なら階層のパスで記録する

#### BattleHud
戦闘の画面表示
- 戦闘エリア（BattleArea）が使う。シーンに置かなくてよい（Resources/UI/BattleHud.prefab から自動で作られ、シーンをまたいで残る）
- 上の帯：目的と残り時間・残りの敵。戦闘中だけ出る
- 真ん中：「逃げろ！」「逃げ切った！」「捕まった！」などのメッセージ（少しの間だけ出る）
- 見た目はプレハブで調整できる（Tools > 敵 > 戦闘の画面表示のプレハブを作る で作り直せる）

- **上の帯**：目的と残り時間を出す帯（背景ごと出し入れする）
- **上の帯の文字**
- **メッセージ**
- **ふつうの文字の色**
- **残りわずかの色**：残り時間が「残りわずか」の秒数を切ったときの色
- **残りわずか（秒）**

#### EnemyGroup
敵のグループ
- シーンに置いて、グループの敵を「メンバー」に入れる（Hierarchy 右クリック > 敵 > グループ）
- 全部（または○体）倒したら、イベントを実行・フラグを ON。「1回だけ」ならセーブする
- 「撃破の順番」をオンにすると、メンバーを上から順にしか倒せない。順番でない敵は、無敵（バリア）／倒しても復活／攻撃したら全員回復
- 次に倒す敵の頭の上に目印（下向きの三角）を出せる

- **Members**：グループの敵（シーンに置いた敵）。「撃破の順番」がオンなら、上から順に倒す
- **きっかけ**
- **倒す数**：「○体倒したら」のときの数
- **実行するイベント**
- **ON にするフラグ**
- **1回だけ（セーブする）**
- **セーブ用の ID**：空なら階層のパスで記録する
- **順番に倒す**：オン：メンバーを上から順にしか倒せない
- **順番でない敵は**
- **復活までの秒数**：「倒しても○秒で復活する」のとき。体力 1 で止まって動けなくなり、この秒数で全回復する
- **次に倒す敵に目印を出す**
- **目印の色**
- **バリアの色**
- **全員回復したときのエフェクト**：「攻撃したら全員回復する」で、順番を間違えたときに、それぞれの敵に出す

### Enemy/Gimmick

#### AttackSwitch
攻撃が当たると作動するスイッチ
- Collider2D と一緒に付ける（攻撃を受ける部品 DamageReceiver も自動で付く）
- ノアの範囲攻撃・シグルの弾・敵の攻撃や弾など、当たった攻撃を条件で絞って、EventSequence を実行する 例：シグルの弾でしか作動しない的 ／ 敵の突進を当てると壊れる柱 ／ ゲージ攻撃のパーフェクトで割れる岩
- 「1回だけ」なら作動したことをセーブし、シーンに戻ったときは作動後の見た目にする（EventSequence の復元）

- **攻撃の種類**
- **攻撃したキャラ**：「プレイヤー以外」にすると、敵の攻撃・ギミックだけで作動する
- **ゲージの判定**：ゲージ攻撃のとき、判定の結果で絞る（「なし」なら問わない）
- **作動までの回数**：条件に合う攻撃がこの回数当たったら作動する
- **実行するイベント**
- **仕掛けの状態**：作動したときに変える仕掛けの状態（GimmickState）。扉などの「条件」に入れて使う。空なら使わない
- **仕掛けの状態をどうするか**
- **1回だけ**：オン：1回作動したら、もう反応しない（セーブもする）／オフ：何度でも作動する
- **セーブ用の ID**：空なら階層のパスで記録する（名前や親を変えると記録がリセットされる）
- **当たったときのエフェクト**：条件に合う攻撃が当たるたびに出す
- **当たったときの SE**
- **効かない攻撃のエフェクト**：条件に合わない攻撃が当たったときに出す（「これでは駄目」と分かるように）。空なら何もしない

### Enemy/Navigation

#### EnemyNavArea
敵の通行設定エリア
- Collider2D（Is Trigger をオン）と一緒に付ける。プレイヤーは普通に通れる
- 入れない：敵はこの範囲に入る経路を選ばない（入口の外へは追ってこない、など）。形はコライダーのとおり
- 通りにくい：敵はできるだけ避けて回り込む（毒の床など）。形はコライダーの外枠の四角で効く 表示を切り替える（SetActive）と、0.5 秒以内に敵の経路に反映される

- **敵にとってこの場所は**：入れない：敵はこの範囲を通らない ／ 通りにくい：遠回りになっても避ける（どうしても必要なら通る）

### Enemy/Parts

#### EnemyPart
敵の部位
- 敵（Enemy）の子オブジェクトに、Collider2D（Is Trigger）と一緒に付ける（Hierarchy で敵を選んで右クリック > 敵 > 部位を追加）
- ここに当たった攻撃は、倍率をかけて本体の体力を減らす（弱点なら 2 倍、装甲なら 0 倍＝効かない、など）
- 部位の体力を決めると「壊せる部位」になる。壊れたとき：消える・絵を変える・段階を変える・攻撃を使えなくする・イベント・ 「独立する」（別の敵として動き出す。外れた腕が飛びかかってくる、など）
- 弱点は「見える条件」を決められる（シグルを操作しているときだけ光る、など）
- 本体と部位に同時に攻撃が当たったときは、部位で受ける（弱点 → 装甲 → ふつうの部位 → 本体 の順）

- **部位の名前**：見た目の変化（「この部位が壊れたら」）・デバッグ表示で使う名前（例：盾、右腕、コア）
- **種類**
- **本体へのダメージの倍率**：ここに当たったとき、本体の体力を減らす倍率。弱点 2、装甲 0（効かない）〜 0.5、ふつう 1 が目安
- **ひるみやすさ**：ここに当たったときのひるみの倍率（敵のデータの「ひるむまでのダメージ」にたまる量）。弱点は 2 など
- **Rules**：この部位だけの効き方（攻撃の種類・キャラ・ゲージ判定ごとの倍率）。例：この装甲はゲージ攻撃でしか削れない
  - **攻撃の種類**
  - **攻撃したキャラ**
  - **倍率**：2 なら2倍、0.5 なら半分、0 なら効かない
  - **ゲージの判定**：ゲージ攻撃のとき、判定の結果で絞る（「なし」なら問わない）
- **部位の体力**：0 なら壊れない。この回数分（効き方をかけたダメージで）当てると壊れる
- **壊れたら消える**：オン：壊れたらこの部位は見えなくなり、当たらなくなる（装甲なら本体がむき出しになる）／オフ：残る（絵を変えるなど）
- **壊れたあとの絵**：消えない設定のとき、壊れたらこの絵にする（空ならそのまま）
- **壊れたら段階を変える**：本体の行動パターンの段階の番号（1 から）。0 なら変えない（例：盾を壊されたら「怒り」へ）
- **Disable Attacks**：壊れたら本体が使えなくなる攻撃（例：右腕を壊したら、なぎ払いをしなくなる）
- **独立する**：壊れたら、この敵のデータの敵として、部位の位置から動き出す（空なら独立しない）。例：外れた腕が飛びかかってくる
- **壊れたときのイベント**
- **壊れたときのエフェクト**
- **壊れたときの SE**
- **当たったときのエフェクト**：部位に攻撃が当たるたびに出す（装甲の「カキン」など）
- **見える条件**：満たしている間だけ「目印」を出す（空ならいつも出す）。例：シグルを操作しているとき
  - **Flags**：フラグの条件。すべて満たすとき（空なら判定しない）
  - **Items**：アイテムの条件。すべて満たすとき（空なら判定しない）
  - **操作中のキャラ**：今操作しているキャラで判定する
  - **プレイヤーの体力**：2人で共有している体力の割合（最大を 1 とする）で判定する
  - **体力の割合**：0.3 なら最大の 30%
  - **プレイヤーがいる範囲**：操作中のキャラがこの Collider2D の範囲の中にいるとき（空なら判定しない。シーンに置いた物だけ指定できる）
  - **Gimmicks**：仕掛けの状態の条件。すべて満たすとき（空なら判定しない。シーンに置いた物だけ指定できる）。 / 例：「スイッチA が ON」「ダイヤルが 3」
  - **2人の状態**：ノアとシグルが一緒にいるか、離れているかで判定する
  - **2人がそろっている距離**：ノアとシグルがこの距離（マス）以内にいるとき（2人で押す扉・2人で回すレバーなど）。0 なら判定しない
- **目印**：見える条件を満たしている間だけ表示するオブジェクト（光る輪など。子オブジェクトに置く）
- **見えている間だけ効く**：オン：見える条件を満たしていない間は、本体へのダメージの倍率とひるみやすさが 1（ふつう）になる

### Enemy/Pattern

#### EnemyBrain
敵の行動パターンを実行する
- 共通プレハブ Enemy_Base に付いている。行動パターンは敵のデータ（EnemyData）のものを使う（ここで差し替えもできる）
- 巡回ポイントはシーンごとに違うので、ここ（シーンに置いた敵）に持たせる
- 段階の切り替え・行動の選択・待ち時間などは PatternRunner（見えない敵 AttackEmitter と共通）

- **行動パターンを差し替える**：空なら、敵のデータに入っている行動パターンを使う。この敵だけ違う動きにしたいときに入れる
- **Patrol Points**：巡回ポイント（「巡回する」行動で、上から順に回る）。空のオブジェクトを置いて入れる
- **動き出す距離**：プレイヤーがこの距離まで近づいたら動き出す。0 なら最初から動く

### Event

#### SceneStartEvent
シーンが始まったときに、条件を満たしていれば EventSequence を実行する
- OP（はじめから のときだけ）、ステージに初めて来たときの会話などに使う

- **実行するイベント**：実行する EventSequence（空なら同じオブジェクトのもの）
- **条件**：すべて満たしたときだけ実行する（空ならいつも）。例：フラグ「OP を見た」が OFF
  - **Flags**：フラグの条件。すべて満たすとき（空なら判定しない）
  - **Items**：アイテムの条件。すべて満たすとき（空なら判定しない）
  - **操作中のキャラ**：今操作しているキャラで判定する
  - **プレイヤーの体力**：2人で共有している体力の割合（最大を 1 とする）で判定する
  - **体力の割合**：0.3 なら最大の 30%
  - **プレイヤーがいる範囲**：操作中のキャラがこの Collider2D の範囲の中にいるとき（空なら判定しない。シーンに置いた物だけ指定できる）
  - **Gimmicks**：仕掛けの状態の条件。すべて満たすとき（空なら判定しない。シーンに置いた物だけ指定できる）。 / 例：「スイッチA が ON」「ダイヤルが 3」
  - **2人の状態**：ノアとシグルが一緒にいるか、離れているかで判定する
  - **2人がそろっている距離**：ノアとシグルがこの距離（マス）以内にいるとき（2人で押す扉・2人で回すレバーなど）。0 なら判定しない
- **始めるまでの時間（秒）**：シーンに着いてから、イベントを始めるまで待つ時間
- **最初から暗転しておく**：条件を満たしたとき、シーンの最初から画面を真っ暗にしておく（イベントの部品「画面の暗転」の明転で明るくする）

### Gimmick

#### CodeLock
番号錠
- 調べると入力の画面（←→ で桁、↑↓ で変える）。答えと同じなら正解で、仕掛けの状態が ON（固定・セーブ）
- 例：金庫の 4 桁の番号（バイオハザード）／ 色の並び（使える文字を「赤青黄緑」に）／ 曜日のダイヤル
- ヒントはメモ（NotePickup）や会話で渡す
- 扉などは、ほかの仕掛けと同じく「条件」でこの番号錠が ON かを見る

- **画面の見出し**：入力の画面の上に出す文（例：「金庫の番号」）
- **使える文字**：1 文字ずつ順に回る。数字なら 0123456789、色なら 赤青黄緑 など
- **答え**：使える文字で書いた答え（桁の数は答えの文字数）。例：0314
- **前の入力を覚えておく**：オン：もう一度調べたとき、前に入れた並びから始まる（シーンの中だけ）／オフ：毎回はじめの文字から
- **使えるキャラ**
- **正解の SE**
- **正解したときのイベント**：「カチッ」の会話など。扉を開けるのは、扉の「条件」にこの番号錠を入れる
- **間違いの SE**
- **間違えたときのイベント**：「開かない……」の会話・罠など。空なら音だけ
- **開いたあとに調べたとき**：もう開いているときに調べた（「もう開いている」など）。空なら何もしない
- **使えないキャラで調べたとき**

#### ExamineSequence
調べるたびに変わる
- 調べるたびに、イベントの並びの次を実行する（Ib・魔女の家の「2 回目に調べると……」）
- 例：絵を調べる 1 回目「きれいな絵」→ 2 回目「……目が動いた？」→ 3 回目 絵から手が出てくる
- 最後まで行ったら：最後をくり返す／最初に戻る／もう何もしない
- 何回調べたかはセーブする（Examine/<シーン>/<ID か階層パス>）。仕掛けの状態にも出せる（条件で使う）

- **Sequences**：1 回目・2 回目・3 回目… に実行する EventSequence（上から順に）
- **最後まで行ったら**
- **使えるキャラ**
- **使えないキャラで調べたとき**
- **回数を出す仕掛けの状態**：調べた回数（0, 1, 2 …）を入れる仕掛けの状態（なくてもよい）。扉などの条件で「3 回調べたら」に使う
- **セーブ用の ID**：空なら階層のパスで記録する

#### FloorSwitch
床スイッチ
- Is Trigger の Collider2D の上に、決めた物（ノア・シグル・押せる箱・敵）が乗ると、仕掛けの状態（GimmickState）が変わる 例：箱を乗せている間だけ開く扉 ／ 相棒を待たせて乗せておき、もう片方で先へ進む（同時押し）／ シグルの重さでだけ沈む床
- 「乗っている」は、乗った物の中心が範囲の中にあるとき（かすっただけでは反応しない）
- 操作していない相棒（ついてくる・待たせている）も、乗っていれば数える

- **動き**
- **ノア**
- **シグル**
- **押せる箱**
- **敵**
- **必要な数**：この数以上乗っているときに押される（2 なら、2人とも乗る・箱と1人 など）
- **押されたときの SE**
- **離れたときの SE**

#### GimmickHole
穴
- 当たり判定（Is Trigger オフの Collider2D）で通れない。押せる箱を押し込むと埋まり、当たり判定が消えて通れるようになる
- 埋まったかは仕掛けの状態（GimmickState）の ON。セーブされ、扉などの条件にも使える

- **穴の当たり判定**：埋まるまで通れなくする Collider2D（Is Trigger オフ）。空なら同じオブジェクトのもの
- **埋まった絵**：埋まったあとの絵。空なら色だけ変える
- **埋まったときの色**

#### GimmickReaction
条件で動く物
- 条件（スイッチが ON・答え合わせが済んだ・フラグ・アイテムなど）を満たしたら、表示を切り替え・イベントを実行する 例：スイッチ A と B が ON の間だけ開く扉 ／ 燭台を全部つけたら出てくる橋 ／ 一度開いたらずっと開いている扉
- 表示の切り替えは、満たしているかでいつも決まる（セーブから戻ったときも、仕掛けの状態から自然に戻る）
- 「一度満たしたらずっと」にすると、満たしたことをセーブする（Reaction/<シーン>/<ID か階層パス>）

- **条件**：「仕掛け」に、スイッチや答え合わせの GimmickState をドラッグする。ほかの条件（フラグ・アイテム・2人の状態など）も使える。すべて満たすとき
  - **Flags**：フラグの条件。すべて満たすとき（空なら判定しない）
  - **Items**：アイテムの条件。すべて満たすとき（空なら判定しない）
  - **操作中のキャラ**：今操作しているキャラで判定する
  - **プレイヤーの体力**：2人で共有している体力の割合（最大を 1 とする）で判定する
  - **体力の割合**：0.3 なら最大の 30%
  - **プレイヤーがいる範囲**：操作中のキャラがこの Collider2D の範囲の中にいるとき（空なら判定しない。シーンに置いた物だけ指定できる）
  - **Gimmicks**：仕掛けの状態の条件。すべて満たすとき（空なら判定しない。シーンに置いた物だけ指定できる）。 / 例：「スイッチA が ON」「ダイヤルが 3」
  - **2人の状態**：ノアとシグルが一緒にいるか、離れているかで判定する
  - **2人がそろっている距離**：ノアとシグルがこの距離（マス）以内にいるとき（2人で押す扉・2人で回すレバーなど）。0 なら判定しない
- **一度満たしたらずっと**：オン：一度条件を満たしたら、あとで条件を満たさなくなっても戻らない（セーブする）／オフ：満たしている間だけ
- **Show When Met**：満たしているときに表示する物（満たしていないときは隠す）。例：出てくる橋
- **Hide When Met**：満たしているときに隠す物（満たしていないときは表示する）。例：閉じた扉
- **Moves**：満たしているときに動かす物（扉が横にずれて開く・橋が伸びる）。満たさなくなったら戻る。当たり判定ごと動くので、敵の通り道も自動で変わる
  - **動かす物**
  - **動かす距離**：満たしたときに、置いた位置からどれだけずらすか（マス）。満たさなくなったら戻る
  - **動く時間（秒）**：0 なら一瞬で動く
- **動き始めの SE**
- **満たしたときのイベント**：満たした瞬間に実行する（扉が開く音・会話など）。セーブから戻ったときは、見た目だけ実行後の状態にする
- **満たさなくなったときのイベント**：満たさなくなった瞬間に実行する（扉が閉じる音など）。「一度満たしたらずっと」のときは使わない
- **セーブ用の ID**：「一度満たしたらずっと」のときに使う。空なら階層のパスで記録する

#### GimmickState
仕掛けの状態
- 謎解きの「入力」（スイッチ・レバー・燭台・ダイヤルなど）が持つ状態。ON / OFF（段階の数 2）か、0〜n の段階
- 扉などの「出力」は、条件（GameCondition の「仕掛けの状態」）でこの状態を見て動く
- 状態はセーブする（Gimmick/<シーン>/<ID か階層パス>）。セーブはほかの物と同じく「仮置き → 確定」
- 答え合わせが済んだら「固定」して、もう変えられないようにできる

- **表示名**：デバッグウィンドウや配線の表示で出る名前。空ならオブジェクトの名前
- **段階の数**：2 なら OFF（0）/ ON（1）。3 以上にすると 0, 1, 2 … の段階（ダイヤル・像の向きなど）
- **最初の状態**：0 = OFF。セーブがなければこの状態から始まる
- **最後の次は最初に戻る**：オン：「次の段階へ」で最後の次は 0 に戻る（ダイヤル）／オフ：最後で止まる
- **変わったときのイベント**：状態が変わるたびに実行する（音・見た目の切り替えなど）。空でもよい
- **戻るまでの秒数**：最初の状態から変わったら、この秒数で最初の状態に戻る（時間制限のあるスイッチ）。0 なら戻らない。 / 会話中などは時間が進まない。時間で戻る仕掛けは、シーンに入り直すと最初の状態から
- **残り時間の音**：戻るまでの間、1 秒ごとに鳴らす（カチカチ）。空なら鳴らさない
- **戻ったときの音**
- **セーブする**：オフにすると、シーンを読み込むたびに最初の状態に戻る（その場限りの仕掛け）
- **セーブ用の ID**：空なら階層のパスで記録する（名前や親を変えると記録がリセットされる）

#### GimmickSwitch
調べるスイッチ
- 範囲（Is Trigger の Collider2D）に入って E で調べると、仕掛けの状態（GimmickState）を変える
- 使えるキャラ（両方・ノアだけ・シグルだけ）と、使える条件（電源が入っている など）を決められる
- 使えないキャラ・条件を満たさないときは、それぞれのイベント（会話など）を実行する（空なら「できない」音だけ）
- 調べられるのは、範囲の中にいる「操作しているキャラ」だけ（ついてくる相棒・待たせている相棒では反応しない）

- **調べたとき**
- **使えるキャラ**：ノアだけ：ノアの装置・魔法陣 など ／ シグルだけ：重いレバー など
- **使える条件**：満たしているときだけ使える（空なら いつでも）。例：電源のスイッチが ON のとき
  - **Flags**：フラグの条件。すべて満たすとき（空なら判定しない）
  - **Items**：アイテムの条件。すべて満たすとき（空なら判定しない）
  - **操作中のキャラ**：今操作しているキャラで判定する
  - **プレイヤーの体力**：2人で共有している体力の割合（最大を 1 とする）で判定する
  - **体力の割合**：0.3 なら最大の 30%
  - **プレイヤーがいる範囲**：操作中のキャラがこの Collider2D の範囲の中にいるとき（空なら判定しない。シーンに置いた物だけ指定できる）
  - **Gimmicks**：仕掛けの状態の条件。すべて満たすとき（空なら判定しない。シーンに置いた物だけ指定できる）。 / 例：「スイッチA が ON」「ダイヤルが 3」
  - **2人の状態**：ノアとシグルが一緒にいるか、離れているかで判定する
  - **2人がそろっている距離**：ノアとシグルがこの距離（マス）以内にいるとき（2人で押す扉・2人で回すレバーなど）。0 なら判定しない
- **調べたときの SE**
- **使えないキャラで調べたとき**：例：ノアで調べたら「重くて動かない……シグルなら」。空なら「できない」音だけ

  - **状態の値**：0 = OFF、1 = ON、ダイヤルなら 0, 1, 2 …
  - **絵**：この状態のときの絵（空なら変えない）
  - **色を変える**
  - **色**

#### PushBlock

- **押せるキャラ**：重い箱はシグルだけ、など

- **押したときの SE**
- **穴に落ちたときの SE**

#### PuzzleCheck
答え合わせ
- 入力の仕掛け（スイッチ・燭台・ダイヤルなど）の状態を見て、正解なら自分の状態（GimmickState）を ON にする → 扉などは「条件」でこの答え合わせが ON かを見る（ほかの仕掛けと同じつなぎ方）
- 全部 ON ／ 決めた順番に ON（間違えたら全部戻す。燭台に順番に火をつける）／ 決めた組み合わせ（ダイヤル・像の向き）
- 正解したら入力を固定できる（もう動かせない）。正解したことはセーブする

- **Inputs**：答え合わせに使う仕掛け（GimmickState）。「決めた順番」なら、ON にする順番に上から並べる
- **答え合わせのしかた**
- **Answer**：「決めた組み合わせ」の答え。入力と同じ順番に、それぞれの値を並べる（0 = OFF、1 = ON、ダイヤルなら 0, 1, 2 …）
- **答え合わせをするとき**
- **正解したら入力を固定する**：オン：正解したら、入力のスイッチなどをもう動かせなくする
- **正解したときのイベント**：正解した瞬間に実行する（正解の音・会話など）。扉を開けるのは、扉の「条件」にこの答え合わせを入れる方法がおすすめ
- **正解の SE**
- **間違えたら入力を全部戻す**：「決めた順番」で順番を間違えたとき・「確かめたとき」に違っていたとき、入力を最初の状態に戻す
- **間違えたときのイベント**：ダメージ・敵が出る・会話など。空なら何もしない
- **間違えたときの SE**

#### WalkArea
歩ける範囲（円・四角・多角形の組み合わせ）
- このオブジェクトの子に Collider2D（Circle / Box / Polygon）を付けた物を置くと、その形を合わせた範囲だけ歩ける （ティンパニの上と、それをつなぐ通路だけ歩ける、など）
- 子に WalkAreaExclude（歩けない形）を付けると、その形は範囲から抜ける（柱・穴）
- 多角形に輪郭が2つ以上あるときは、内側の輪郭は穴になる（マスク画像から作ったとき）
- 形はシーンビューで Collider2D を編集して決める。数・位置・大きさは自由
- 子を非表示にすると、その形は範囲から外れる（イベントで表示すれば、通路が開く）
- Collider2D は形を読むためだけに使い、再生中は無効にする（弾や敵にはぶつからない）
- 1つのシーンに何個置いてもよい（部屋ごとなど）。全部を合わせた範囲になる
- プレイヤー・敵の移動・敵と相棒の道（NavMesh2D）・アイテムや落石の出る場所が、この範囲を使う（MapArea）
- シーンに置かなければ、今までどおりマップ全体（MapBounds）を歩ける

- **シーンビューに範囲を表示**：選んでいなくても、歩ける範囲を緑の線（歩けない形は赤い線）で表示する
- **マスク画像**：マップの絵と同じ大きさの画像。白く塗った所が歩ける所（透明・黒は歩けない）。下の「マスク画像から作る」で形を作る
- **合わせるマップの絵**：マスク画像を重ねる絵（この絵と同じ位置・大きさとして読む）。空ならシーンの MapBounds の絵
- **線の細かさ（マス）**：輪郭の点を間引く細かさ。小さいほど絵に忠実だが点が増える（0.1 くらいがおすすめ）
- **白とみなす明るさ**：この明るさ（白さ×不透明さ）より明るい所を歩ける所にする

### Item/Interaction

#### ItemInteraction
アイテムの所持状況で結果が変わるオブジェクト
- 「きっかけ」（調べた／エリアに入った）で、上から順にルールの条件（アイテム・フラグ）を調べる
- 条件を満たした最初のルールの EventSequence を実行する。どれも満たさなければ「それ以外」を実行する
- ルールに「完了にする」を付けると、以後は「完了後」の EventSequence だけを実行する 完了したことは Save に記録し、シーンを読み込み直すと見た目だけを完了後の状態にする 例：扉 ルール1：鍵 ×1 を持っている → 鍵を消費 → 扉を非表示にする（完了にする）
- それ以外：「鍵がかかっている」と会話 Collider2D（Is Trigger）を付けたオブジェクトに付けて使う

- **Rules**
  - **Label**：メモ（Inspector で見分けるための名前。動作には影響しない）
  - **Conditions**：すべて満たしたときにこのルールを実行する（空なら常に満たす）
  - **Flag Conditions**：フラグの条件。アイテムの条件と合わせて、すべて満たしたときにこのルールを実行する（空なら常に満たす）
  - **Consume Items**：実行するときに、条件のアイテムを消費する（「持っていないとき」の条件は消費しない）
  - **Sequence**：実行する内容
  - **Mark Completed**：実行したら完了にする（以後このルールは実行されず、完了状態を保存する）
- **After Completed**：完了したあとにもう一度調べた・入ったときに実行する（例：「もう開いている」）
- **キーの案内の文**：近づいたときに物の上に「[E] ○○」と出す文。空なら案内を出さない。実行できるルール（か「満たさないとき」「完了後」）がないときは出さない
- **Save Id**：完了したことを記録するためのID。空ならヒエラルキー上の名前を使う（同じシーンで重複しないようにする）
- **Save Completed**：完了状態を保存して、シーンを読み込み直しても完了後の状態にする

### Manager

#### PlayerSwitchManager
プレイヤー切り替え管理クラス
- 2人の状態（PartyMode）で、切り替えたときの動きと体力の扱いが変わる - 一緒：切り替えると位置が入れ替わり、操作していない方がついてくる。体力は共有（シグルがノアを守っている＝シグルの体力から減る）
- - 待機・別行動：切り替えても位置はそのまま（カメラが相手へ移る）。操作していない方はその場にいる。体力は別々

- **Switch Se**：キャラクターを切り替えたとき

- **切り替えの演出**：待機・別行動のときに C で切り替えたときのカメラ：すぐ／スライド（なめらかに移る）／暗転（別のエリアにいるとき向き）
- **敵が狙う相手**：待機・別行動のときに敵が狙う相手：操作しているキャラだけ（待っている相棒は狙われない）／近い方（待っている相棒も狙われる）
- **待て／ついてこいのキー**：押すと、相棒をその場で待たせる（待機）／呼び戻す（一緒）。別行動のときは使えない
- **待たせたときの SE**
- **呼び戻したときの SE**
- **相棒が来られないときの SE**：呼んでも道がない（狭い通路の向こう・壁の向こう）・使えないときに鳴らす
- **相棒が来られないときのイベント**：例：「そっちには行けない……」の会話。空なら音だけ
- **シグルが仲間になったフラグ**：このフラグが立つまで、シグルは出てこない（ノア1人で進む。体力はノアの分だけ、C・F キーは使えない）。イベントでフラグを立てると、その場でノアの位置に出てきて一緒になる（出る場所はイベントの部品「キャラを移す」で変えられる）。空なら最初から2人

キャラによって通れる壁
- 当たり判定（Is Trigger オフの Collider2D）を、決めたキャラだけ通り抜けられるようにする 例：ノアだけ通れる狭い通路（シグルにとっては壁）／ シグルだけ通れる重い扉の隙間
- 「一緒」のときに通れるキャラが入ると、相棒（通れない方）は入口で自動で待つ（待機になる）
- 敵・押せる箱にとっては、ふつうの壁

- **通れるキャラ**：ノアだけ：狭い通路 ／ シグルだけ：シグルにしか抜けられない所
- **入ったら相棒を待たせる**：オン：一緒のときに通れるキャラが入ると、相棒はその場で待つ（呼び戻すには 待て／ついてこい のキー。通路を出てから）
- **相棒を待たせたときの SE**

#### ConditionalVisible
条件で見える物
- 条件（初期値：ノアを操作しているとき）を満たしている間だけ、絵（SpriteRenderer・Tilemap）を表示する。切り替わるときはふわっと 例：ノアにだけ見える壁の文字（ヒント）／ シグルにだけ見える足場（見えている間だけ渡れる）
- 当たり判定も、見えている間だけ・見えていない間だけ有効にできる
- 条件は GameCondition なので、フラグ・仕掛けの状態・2人の状態なども使える

- **見える条件**：満たしている間だけ見える。初期値は「ノアを操作しているとき」
  - **Flags**：フラグの条件。すべて満たすとき（空なら判定しない）
  - **Items**：アイテムの条件。すべて満たすとき（空なら判定しない）
  - **操作中のキャラ**：今操作しているキャラで判定する
  - **プレイヤーの体力**：2人で共有している体力の割合（最大を 1 とする）で判定する
  - **体力の割合**：0.3 なら最大の 30%
  - **プレイヤーがいる範囲**：操作中のキャラがこの Collider2D の範囲の中にいるとき（空なら判定しない。シーンに置いた物だけ指定できる）
  - **Gimmicks**：仕掛けの状態の条件。すべて満たすとき（空なら判定しない。シーンに置いた物だけ指定できる）。 / 例：「スイッチA が ON」「ダイヤルが 3」
  - **2人の状態**：ノアとシグルが一緒にいるか、離れているかで判定する
  - **2人がそろっている距離**：ノアとシグルがこの距離（マス）以内にいるとき（2人で押す扉・2人で回すレバーなど）。0 なら判定しない
- **切り替わる時間（秒）**：ふわっと出る・消える時間。0 なら一瞬
- **見えていないときの濃さ**：0 なら完全に消える。0.15 などにすると、うっすら見える
- **当たり判定**

#### GuardGauge
守り（弾消し・Q キー）のゲージ
- 弾消しを出している間はゲージが減り、出していない間はたまる（リチャージ）
- ゲージが空になると、決めた量までたまるまで弾消しを出せない
- シーンに置いたときだけ制限がかかる（置いていないシーンは今までどおり、いつでも出せる）
- 画面の左上（HP の下）にゲージを出す。名前の表示は「シグルの守り」（シグルが守っている、という演出）
- アイテムなどから、ゲージをためる（Refill）・しばらくリチャージを速くする（BoostRecharge）

- **出していられる時間（秒）**：ゲージが満タンのとき、弾消しを出し続けられる時間
- **空から満タンまでの時間（秒）**：リチャージにかかる時間。アイテムで短くできる
- **たまり始めるまでの間（秒）**：弾消しをやめてから、たまり始めるまでの間
- **空になったら出せるようになる量**：空になったあと、ゲージがこの割合までたまるまで出せない（1 なら満タンまで）
- **名前**
- **ゲージの色**
- **リチャージ中の色**：空になって出せない間の色
- **速くたまっている間の色**：アイテムでリチャージが速くなっている間の色
- **画面の位置（左上から）**
- **空になったときの音**
- **また出せるようになったときの音**

#### LiftPoint
持ち上げる場所（踏み台）
- 調べると、決めたキャラ（初期値：ノア）が「行き先」へ跳んで移る（段差の上・高い棚・向こう岸）
- 「相棒の手伝いが要る」なら、2人がそろっているときだけ（シグルがノアを持ち上げる）。手伝った相棒はその場で待つ
- 戻るときは、行き先側にもう1つ置き、行き先をこちらにして「相棒の手伝いが要る」をオフにする（一人で降りる）
- 移ったあとは、移ったキャラを操作する

- **移るキャラ**：行き先へ移るキャラ。シグルがノアを持ち上げるなら ノア
- **行き先**：移る先の位置（空のオブジェクト）
- **相棒の手伝いが要る**：オン：もう1人がこの場所の近くにいるときだけ使える（持ち上げてもらう）。オフ：一人で使える（降りる・飛び降りる）
- **手伝う相棒の距離**：もう1人がこの場所からこの距離（マス）以内にいるとき
- **移る時間（秒）**
- **跳ぶ高さ**：移るときに弧を描く高さ（見た目だけ）
- **移るときの SE**
- **移ったあとのイベント**
- **手伝いがいないとき**：例：「一人じゃ届かない……シグル、手伝って」。空なら「できない」音だけ

#### PartyRejoinArea
合流の範囲
- Is Trigger の Collider2D の中に、ノアとシグルの2人がそろうと、2人の状態を「一緒」に戻し、イベントを実行する 例：離れ離れのステージの出口で再会する（再会の会話）／ 同時押しの部屋を抜けたところ
- 「1回だけ」ならセーブする（Rejoin/<シーン>/<ID か階層パス>）
- 「待て／ついてこい」を使えなくしていたら、使えるように戻すこともできる

- **合流したときのイベント**：例：再会の会話・SE
- **待て／ついてこいを使えるようにする**：オン：合流したら、イベントで使えなくしていた「待て／ついてこい」のキーを使えるように戻す
- **1回だけ（セーブする）**
- **セーブ用の ID**：空なら階層のパスで記録する

  - **Flags**：フラグの条件。すべて満たすとき（空なら判定しない）

  - **プレイヤーの体力**：2人で共有している体力の割合（最大を 1 とする）で判定する
  - **体力の割合**：0.3 なら最大の 30%
  - **プレイヤーがいる範囲**：操作中のキャラがこの Collider2D の範囲の中にいるとき（空なら判定しない。シーンに置いた物だけ指定できる）
  - **Gimmicks**：仕掛けの状態の条件。すべて満たすとき（空なら判定しない。シーンに置いた物だけ指定できる）。 / 例：「スイッチA が ON」「ダイヤルが 3」
  - **2人の状態**：ノアとシグルが一緒にいるか、離れているかで判定する
  - **2人がそろっている距離**：ノアとシグルがこの距離（マス）以内にいるとき（2人で押す扉・2人で回すレバーなど）。0 なら判定しない
- **条件を満たさなくなったら敵を消す**：オン：範囲から出たら、このスポナーから出た敵を消す（数は戻らない）
- **予告の時間（秒）**：出る場所に丸を見せてから出す。0 ならすぐ出る

### Talk

### Timpani

#### TimpaniPeg
ティンパニのペグ
- 調べる（E）とリズムゲームが始まる：外側の輪が縮み、中心の輪に重なる瞬間にもう一度 E を押すと「成功」
- 決めた回数だけ成功すると締まる（同じオブジェクトの GimmickState が ON になる）
- ゲームは止まらない（敵の攻撃は続く）。ペグから離れる・キャラを切り替えると中断する（進んだ分は残る）
- 使えるキャラ（初期値：ノアだけ）。使えないキャラで近づくと、使えるキャラの目印が出る
- 締まったかどうかは、ペグの色・上に出る印（◆◇）でわかる
- 1台のティンパニのペグが全部締まったかは、答え合わせ（PuzzleCheck「全部 ON」）でペグの GimmickState を見る

- **使えるキャラ**：ペグを締められるキャラ。使えないキャラで近づくと、使えるキャラの目印が出る
- **使えないキャラで調べたとき**：例：「俺には無理だ。ノアに任せる」の会話。空なら「できない」音だけ
- **成功する回数**：この回数だけタイミングよく押すと締まる
- **輪が縮む時間（秒）**：外側の輪が縮みきるまでの時間。短いほど難しい
- **成功するたびに速くなる割合**：0.1 なら、成功するたびに 10% ずつ速くなる。0 なら変わらない
- **判定の甘さ（マス）**：縮む輪と中心の輪の大きさの差が、これ以内のときに押すと成功。大きいほど簡単
- **失敗で戻る回数**：タイミングを外したとき、成功の回数をいくつ減らすか。0 なら減らない
- **失敗のあと押せない時間（秒）**：連打で成功しないように、外したあと少しの間は押せない
- **ペグの絵**：色を変える SpriteRenderer（空なら自分か子から探す）
- **ゆるんでいる色**
- **締まった色**
- **外側の輪の大きさ（マス）**：縮み始めの輪の半径
- **中心の輪の大きさ（マス）**：ここに重なる瞬間に押す
- **輪の色**
- **重なっているときの色**：今押せば成功、というときの輪の色
- **始めたときの音**
- **成功の音**
- **失敗の音**
- **締まったときの音**
- **成功のエフェクト**
- **締まったときのエフェクト**
- **締まったときのイベント**：このペグが締まったときに実行する（空でよい）

#### TimpaniRoom
ティンパニの部屋全体
- 子のティンパニ（TimpaniUnit）を自動で見つける
- 調律できた数に合わせてフラグを立てる（1台目 → 1つ目のフラグ、2台目 → 2つ目…）
- 敵の行動パターンの「段階」が、このフラグで進む（残りの敵が激しくなる）
- 全部調律できたら、クリアのフラグを立て、残っている弾を消し、イベントを実行する
- シーンが始まったとき、激しさのフラグは OFF に戻す（やり直し・読み直しで最初から）

- **Units**：部屋のティンパニ（空なら子のティンパニを全部）
- **Escalation Flags**：調律できた数ごとに立てるフラグ（1台目で1つ目、2台目で2つ目…）。敵の行動の段階を進める。セーブしないフラグにする
- **全部調律できたら立てるフラグ**：クリアしたことを覚えるフラグ（セーブするフラグにすると、戻ってきても戦闘は始まらない）
- **全部調律できたときのイベント**：クリアしたときに実行する（会話・扉を開けるなど）
- **全部調律できたら残りの弾を消す**
- **Show When Cleared**：全部調律できたら表示する物（出口への通路の「歩ける範囲」など）。クリアしたあとに戻ってきたときも表示する
- **ヒントの合図を出すまでの時間（秒）**：戦闘中、ペグがこの時間進まなかったら標準の合図「しばらくペグが進まない」を出す（0 なら出さない）。一言のヒントのきっかけ

#### TimpaniUnit
ティンパニ1台
- 子のペグ（TimpaniPeg）と、子の敵（Enemy＝音楽生物）を自動で見つける（Inspector で入れてもよい）
- ペグが1つ締まるたびに、周りの敵の攻撃を一度消す（弾を消し、攻撃をやめさせて少し止める）
- ペグが全部締まると、真ん中の敵がおとなしくなる（敵のデータの「倒されたあと：おとなしくなる」）
- → 調律できた印（♪）・エフェクト・回復アイテムを1つ出す → 部屋（TimpaniRoom）に知らせる

- **真ん中の敵**
- **Pegs**：このティンパニのペグ（空なら子のペグを全部）
- **攻撃を消す範囲（マス）**：締まったペグからこの距離の中の敵の弾を消し、敵の攻撃をやめさせる。0 なら消さない
- **敵を止める時間（秒）**：攻撃をやめさせた敵が、また動き出すまでの時間
- **攻撃を消したときのエフェクト**：締まったペグの位置に出す（空でもよい）
- **出す回復アイテム**：InstantPickup のプレハブ（空なら出さない）
- **アイテムを出す位置（敵から）**
- **調律できたあとの絵**：おとなしくなった敵の絵に差し替える（空なら差し替えない）
- **調律できたときのエフェクト**
- **調律できたときの音**
- **調律できた印の色**
- **調律できたときのイベント**：このティンパニを調律できたときに実行する（空でよい）

## 4. データ（Project の Create）

#### SpriteAnimData (空)（SpriteAnimData。Create > Animation > SpriteAnimData (空)）
キャラクター・オブジェクト1体分のアニメーション設定 (ScriptableObject)
- 作り方:
- 連番画像 / スプライトシートをまとめて選択して右クリック → Create → Animation → SpriteAnimData (選択した画像から作成)
- または 右クリック → Create → Animation → SpriteAnimData (空) で作って、Inspector に画像をドラッグする 使い方:
- 動かしたいオブジェクト (SpriteRenderer があるもの) に SpriteAnimator を付けて、このデータを指定する
- キャラクターは CharacterAnimLink も付けると、移動に合わせて Idle / Walk が自動で切り替わる

- **Default Clip**：最初に流す動き (空なら一番上の動き)
- **Clips**：動きの一覧
  - **Name**：動きの名前 (Idle / Walk / Damage / Dead / Open など)
  - **Direction Mode**：向きの持ち方
  - **Down**：下向き (正面) の画像。「向きなし」のときはここだけ使う
  - **Up**：上向き (背中) の画像
  - **Left**：左向きの画像 (空なら右を反転して使う)
  - **Right**：右向きの画像 (空なら左を反転して使う)
  - **Fps**：1秒に何コマ進めるか (大きいほど速い)
  - **Play Mode**：再生のしかた
  - **Next Clip**：「1回 → 次の動きへ」のとき、次に流す動きの名前
  - **Frame Lengths**：コマごとの長さの倍率 (空ならすべて 1。2 にするとそのコマだけ2倍長く表示)
  - **Events**：決まったコマで鳴らす音・出すエフェクト

#### BGM Effect Profile（BgmEffectProfile。Create > Audio > BGM Effect Profile）
進行度 (0〜1) ごとのエフェクト設定をまとめたアセット
- キーとキーの間の進行度では、前後のキーの設定を補間する 作り方 : Projectウィンドウで右クリック → Create → Audio → BGM Effect Profile

- **Keys**：進行度ごとの設定 (並び順は自由)
  - **Label**：メモ用の名前 (例: 序盤)

#### 相棒の一言（BarkData。Create > 仕掛け > 相棒の一言）
相棒の一言のデータ
- Resources/Barks/ に置くと、きっかけが起きたときに自動で選ばれる（シーンに置く物はない）
- 同じきっかけのデータが複数あれば、条件を満たすものから「優先度」の高いものを選ぶ（同じなら重みでランダム）
- 吹き出しはゲームを止めない。会話・メニューの間は出ない

- **使う**：オフにすると、この一言は出ない（消さずに止めておきたいとき）
- **きっかけ**：いつ出すか。「イベント・範囲からだけ」は、イベントの部品「一言」と一言の範囲から出す
- **合図**：きっかけが「合図が来た」のとき：この合図で出す（標準の合図は Assets/Data/Signals/標準/）。戦闘中だけにしたいときは、条件に戦闘中のフラグなどを入れる
- **秒数**：「長く待たせている」：待たせてからこの秒数で出す / 「しばらく止まっている」：止まってからこの秒数で出す / 「体力が少なくなった」では使わない
- **体力の割合**：「体力が少なくなった」：受けたあとの体力（最大を 1）がこの割合以下になったら出す
- **倒した敵**：「敵を倒した」：この敵のときだけ出す（空ならどの敵でも）
- **Condition**：出す条件（フラグ・アイテム・操作中のキャラ・2人の状態など）。すべて満たすとき。空なら判定しない
  - **Flags**：フラグの条件。すべて満たすとき（空なら判定しない）
  - **Items**：アイテムの条件。すべて満たすとき（空なら判定しない）
  - **操作中のキャラ**：今操作しているキャラで判定する
  - **プレイヤーの体力**：2人で共有している体力の割合（最大を 1 とする）で判定する
  - **体力の割合**：0.3 なら最大の 30%
  - **プレイヤーがいる範囲**：操作中のキャラがこの Collider2D の範囲の中にいるとき（空なら判定しない。シーンに置いた物だけ指定できる）
  - **Gimmicks**：仕掛けの状態の条件。すべて満たすとき（空なら判定しない。シーンに置いた物だけ指定できる）。 / 例：「スイッチA が ON」「ダイヤルが 3」
  - **2人の状態**：ノアとシグルが一緒にいるか、離れているかで判定する
  - **2人がそろっている距離**：ノアとシグルがこの距離（マス）以内にいるとき（2人で押す扉・2人で回すレバーなど）。0 なら判定しない
- **優先度**：同じきっかけで複数出せるとき、大きい方を出す。出している一言より大きければ割り込む
- **出る確率**：1 ならいつも。0.3 なら 3 回に 1 回くらい（毎回出るとうるさい一言に）
- **何回出すか**
- **次に出せるまで（秒）**：一度出したら、この秒数は同じ一言を出さない
- **一言どうしの間を待たない**：オンにすると、前の一言のすぐあとでも出す（一言の設定の「一言どうしの間」を待たない）。大事な一言（戦闘の始まり・体力が少ない・ヒントなど）に
- **出すまでの間（秒）**：きっかけから少し間をおいて出す（間に会話などが始まったら出さない）
- **Variants**：候補。どれか1つを選んで出す（同じことを毎回言わないように、言い方を変えて並べる）
  - **Lines**：上から順に出す。2行以上で掛け合いになる（例：シグル「大丈夫か」→ ノア「平気」）
  - **選ばれやすさ**：候補の中からこの重みで選ぶ（同じなら同じ確率）
- **Memo**：メモ（ゲームには出ない）

#### 攻撃（AttackData。Create > 敵 > 攻撃）
敵の攻撃のデータ
- 攻撃は「予告（範囲を見せる）→ 発動（当たり判定が出る）→ 後隙（反撃できる時間）」の順に進む
- 同じ攻撃を、いろいろな敵の行動パターンで使い回せる
- 組み合わせの例：ビーム＝敵の位置×長方形×出し続ける、突進＝敵の位置×長方形×一瞬×突進、 足元の爆発＝プレイヤーの位置（予告時）×円×一瞬、なぎ払い＝敵の位置×扇形×一瞬
- 上から落ちる＝予告が影になり、最後に物が落ちてくる ／ 下から突き出る＝発動で地面から物が出る（残せる）
- ／ 設置して起爆＝その場に物を置き、時間・触れる・攻撃されるで爆発（置いたあと、敵は次の行動に移る）

- **予告の時間（秒）**：範囲を見せてから発動するまでの時間。0 なら予告なしですぐ発動
- **範囲を表示する**：オフにすると、時間は待つが範囲は見せない（見えない攻撃）
- **描き方**
- **色**：予告の色。透明度（A）で薄さを調整する
- **満ちていく表示**：発動までの残り時間に合わせて、内側から色が満ちていく（そろそろ来る、が分かる）
- **点滅させる**：発動の直前（最後の 30%）に点滅させる
- **描く順番**：大きいほど手前に描かれる。地面 0、建物 1〜2、弾 2、物 5、キャラ 99〜100。既定の 3 は「床の上・物やキャラの下」
- **暗い所でも見える**：オン：暗いステージでも明るさが変わらない（おすすめ）／オフ：周りと同じように暗くなる
- **予告の SE**
- **予告中の敵のアニメ**：SpriteAnimData の動きの名前（構えるなど）。なければ何もしない
- **起点**：攻撃の範囲を置く場所
- **向き**
- **決まった角度**：向きが「決まった角度」のときの角度（度）
- **予告の間は向きを合わせ続ける**：オン：予告の間はプレイヤーの方へ向き直し続け、発動の瞬間に向きが決まる ／ オフ：予告を出した時点の向きのまま（避けやすい）
- **前にずらす距離**：起点を向きの方向へずらす（マス）。敵の体の外から出したいときなど
- **範囲の形**：当たり判定と予告の形（どちらも同じ形）
  - **形**
  - **半径**：円・扇形・リングの外側の半径（マス）
  - **内側の半径**：リングの穴の半径。この内側は安全
  - **長さ**：長方形の、起点から前への長さ（マス）
  - **幅**：長方形の幅（マス）
  - **角度**：扇形の開き具合（度）。90 なら前の 90 度
- **長方形の長さを壁で止める**：ビーム・突進で、途中に壁があればそこまでにする（予告も短くなる）
- **発動のしかた**
- **ダメージ**
- **当たる相手**
- **ノアには効かない**：オンなら、この攻撃はノアをすり抜ける（キャラを切り替えて避ける遊びに）
- **シグルには効かない**
- **攻撃の種類**：当たった相手から見た攻撃の種類（敵どうしで当たるときの効き方などに使う）
- **ひるみでキャンセルできる**：敵がひるんだとき、この攻撃を途中でやめるか（後隙ではいつでもひるむ）。できないときは、攻撃が終わってからひるむ
- **出し続ける時間（秒）**：「出し続ける」のときの長さ
- **当たる間隔（秒）**：「出し続ける」のとき、同じ相手に何秒ごとに当たるか
- **回る速さ（度/秒）**：「出し続ける」の間、範囲を回転させる（ビームのなぎ払い）。0 なら回らない。マイナスで逆回り
- **弾の撃ち方**
- **撃つ弾の数**：1回に同時に撃つ数（狙い撃ち：扇状 ／ 全方位・うず巻き：一周に並べる ／ ばらまき：ランダム）
- **弾の広がり（度）**：狙い撃ち・ばらまきのときの、端から端までの角度
- **撃つたびに回す角度（度）**：うず巻きのとき、1回撃つごとに向きを回す角度
- **連射の回数**：上の弾を何回撃つか
- **連射の間隔（秒）**
- **弾の速さ**：1秒に進む距離。0 なら弾のプレハブのまま
- **弾消しで消せる**：オフにすると、ノアの弾消し（Q）で消えない弾になる
- **落ちてくる物（プレハブ）**：「上から落ちる」のとき、上から降ってくる見た目（岩など）。空なら予告（影）と着地のエフェクトだけ
- **落ちる高さ**：どれだけ上から落ちてくるか（マス）
- **落ちる時間（秒）**：予告の最後のこの時間で落ちてくる
- **落とす数**：「上から落ちる」で、1回の攻撃で落とす数。2 以上にすると、下の「ばらまく場所」に間をあけて次々に落とす（1 なら今までどおり起点に1つ）
- **次を落とすまで（秒）**：落とす数が 2 以上のとき、1つ落としてから次の影を出すまでの時間
- **ばらまく場所**：落とす数が 2 以上のとき、どこに落とすか
- **ばらまく半径（マス）**：ばらまく場所が「敵の周り」「プレイヤーの周り」のときの広さ。「歩ける範囲全体」で歩ける範囲がないシーンでも、敵の周りのこの広さにする
- **プレイヤーを狙う割合**：ばらまくうち、この割合はプレイヤーの近く（下の「狙うときのずれ」の中）に落とす。0 なら狙わない
- **狙うときのずれ（マス）**：プレイヤーを狙うとき、プレイヤーの位置からこの距離までずらす（ちょうど足元には落ちにくい）
- **影どうしの最低の間（マス）**：同じ攻撃で落とす影どうしを、この距離より近くに置かない（同じ場所に重ならない）
- **突き出る物（プレハブ）**：「下から突き出る」のとき、地面から出てくる見た目（とげ・腕など）。当たり判定（Collider2D）が付いていれば、残っている間は壁になる
- **残る時間（秒）**：突き出た物が残る時間。0 ならすぐ引っ込む
- **残っている間も当たる**：オン：残っている間、範囲に入ると「当たる間隔」ごとに当たる
- **置く物（プレハブ）**：「設置して起爆」のとき、置かれる見た目（爆弾など）。空なら小さな丸
- **起爆までの時間（秒）**：置いてから爆発するまで。0 なら時間では爆発しない（触れる・攻撃されるで爆発）
- **プレイヤーが触れたら爆発**
- **攻撃されたら爆発**：ノアやシグルの攻撃が当たったら爆発する（敵を巻き込む使い方も）
- **起爆まで範囲を見せる**：置いてから爆発するまで、爆発の範囲を表示する
- **敵自身の動き**
- **突進の速さ**：1秒に進む距離（マス）。プレイヤーは 5
- **壁にぶつかったら気絶（秒）**：突進が壁で止まったとき、この秒数だけ動けなくなる（反撃のチャンス）。0 なら気絶しない
- **発動のエフェクト**：範囲の真ん中に出す（右向きの絵なら攻撃の向きに回る）
- **発動の SE**
- **発動したときの画面の揺れ（マス）**：地響き・落石などで画面を揺らす大きさ（0.1 で小さく、0.3 で大きく）。0 なら揺らさない
- **発動したときに出す物**：範囲の真ん中に出す物（落石と一緒に落ちてくるアイテムなど。InstantPickup のプレハブ）。空なら出さない。弾を撃つ攻撃では出さない
- **出す確率**：発動するたびに、この確率で出す（1 なら毎回）
- **発動中の敵のアニメ**
- **後隙（秒）**：攻撃が終わってから次の行動までの時間。長いほど反撃しやすい
- **Memo**：プランナー用のメモ（ゲームには影響しない）

#### 敵のデータ（EnemyData。Create > 敵 > 敵のデータ）
敵のデータ
- 敵を増やすときは、既存の EnemyData を複製（Ctrl + D）して数値と絵を変える
- シーンに置いた敵（共通プレハブ Enemy_Base）の Enemy の「敵のデータ」に入れて使う 行動パターン・攻撃・弱点・倒した後の処理は、これからの段階で足していく

- **名前**：一覧やデバッグで表示する名前
- **最大の体力**：この回数分ダメージを受けると倒れる（ノアの範囲攻撃は1回で1ダメージ）
- **移動の速さ**：1秒に進む距離（マス）。プレイヤーは 5
- **大きさ**：通れる道の幅が変わる。大きい敵は細い通路を通れない
- **押されにくい**：オン：プレイヤーがぶつかっても押されない ／ オフ：押される
- **行動パターン**：EnemyPattern（いつ・どこへ動き、いつ攻撃するか）。空ならその場に立っているだけ
- **倒されたら呼んだ仲間も消す**：「仲間を呼ぶ」で出した敵を、この敵が倒されたときに一緒に倒す
- **Damage Rules**：攻撃の種類・攻撃したキャラごとの倍率。当てはまるものを全部かける。0 なら効かない（空ならすべて等倍）。 / 例：「ノアのゲージ攻撃 ×2」「シグルの弾 ×0（効かない）」
  - **攻撃の種類**
  - **攻撃したキャラ**
  - **倍率**：2 なら2倍、0.5 なら半分、0 なら効かない
  - **ゲージの判定**：ゲージ攻撃のとき、判定の結果で絞る（「なし」なら問わない）
- **ひるむまでのダメージ**：受けたダメージ（弱点などの倍率をかけたもの）がこれだけたまるとひるむ。今の行動（攻撃の予告など）をやめて、少しの間動けなくなる。0 ならひるまない
- **ひるむ時間（秒）**
- **ひるみが減る速さ（1 秒あたり）**：たまったひるみが、攻撃を受けない間に減っていく量。0 なら減らない
- **Stagger Rules**：攻撃の種類・キャラ・ゲージ判定ごとの「ひるみやすさ」の倍率。0 ならその攻撃ではひるまない（空ならすべて等倍）。 / 例：「ゲージ攻撃・パーフェクト ×3」「シグルの弾 ×0」
  - **攻撃の種類**
  - **攻撃したキャラ**
  - **倍率**：2 なら2倍、0.5 なら半分、0 なら効かない
  - **ゲージの判定**：ゲージ攻撃のとき、判定の結果で絞る（「なし」なら問わない）
- **ひるんだときのアニメ**
- **ひるんだときのエフェクト**
- **ひるんだときの SE**
- **Look Rules**：条件を満たしている間（攻撃を受けたときは決めた秒数）、見た目を変える。下の行ほど優先される。 / 例：体力 50% 以下で赤く／ゲージ攻撃で凍る（青く 2 秒）／盾が壊れたら別のアニメ
  - **きっかけ**
  - **体力の割合**
  - **攻撃の種類**
  - **攻撃したキャラ**
  - **ゲージの判定**
  - **続く時間（秒）**：「この攻撃を受けたとき」に、見た目が変わっている時間
  - **部位の名前**：EnemyPart の「部位の名前」
  - **段階の番号**：行動パターンの段階の番号（1 から）
  - **条件**
  - **アニメーション**：この間だけ使う SpriteAnimData（空ならそのまま）
  - **色を変える**
  - **色**：絵にかける色（白ならそのまま）
  - **点滅させる**
  - **変わったときのエフェクト**：この見た目になった瞬間に出す
  - **変わったときの SE**
- **ぶつかったときのダメージ**：プレイヤーに触れたときのダメージ。0 なら触れても何もない
- **ダメージの間隔（秒）**：触れ続けているとき、何秒ごとにダメージを与えるか
- **アニメーション**：SpriteAnimData。Idle（待機）・Walk（移動）・Damage（ダメージ）・Dead（倒れる）の名前の動きを自動で使う。空なら下の絵のまま
- **絵（アニメがないとき）**：アニメーションが空のときに表示する絵。空ならプレハブの絵のまま
- **エフェクト**：消える瞬間に出す（死亡アニメがあれば流し終わってから）
- **SE**：倒された瞬間に鳴らす
- **死亡アニメの名前**：アニメーションにこの名前の動きがあれば、流し終わってから消える
- **倒されたあと**：消える／倒れた姿で残る（調べられる）／おとなしくなる（攻撃しなくなり、その場に立つ。調べられる）
- **残った姿の色**：「倒れた姿で残る」のときにかける色
- **Drops**：倒されたときに落とすアイテム（確率つき）。シーンに置いた敵の「倒したとき」の設定とは別に、この種類の敵ならいつも落とす
  - **アイテム**
  - **個数**
  - **確率**：1 なら必ず、0.3 なら 30%
  - **すぐ持ち物に入れる**：オン：倒した瞬間に持ち物に入る／オフ：その場に落ちて、触れると拾える（拾わずにシーンを出ると消える）
- **Memo**：プランナー用のメモ（ゲームには影響しない）

#### 行動パターン（EnemyPattern。Create > 敵 > 行動パターン）
敵の行動パターン
- 段階のリスト。最初の段階から始まり、「次の段階へ進む条件」を満たすと次へ進む（戻らない）
- 各段階では、行動の部品（待つ・近づく・離れる・巡回・ランダムに歩く・攻撃する）を、選び方に従って繰り返す
- 同じパターンをいろいろな敵で使い回せる。巡回ポイントはシーンの敵（EnemyBrain）に持たせる

- **Phases**：段階のリスト（上から順に進む）
  - **段階の名前**：デバッグ表示に出る名前（例：通常、怒り）
  - **行動の選び方**
  - **Actions**：この段階でする行動。「＋行動を追加」から選ぶ
  - **次の段階へ進む条件**
  - **体力の割合**：0.5 なら体力が半分以下で次へ
  - **秒数**
  - **条件**：満たしたら次の段階へ（範囲の条件はシーンの物を指定できないので使えない）
  - **進むとき今の行動をやめる**：オン：条件を満たした瞬間に、攻撃の途中でもやめて次の段階へ ／ オフ：今の行動が終わってから次へ
  - **エフェクト**
  - **SE**
  - **アニメ**：SpriteAnimData の動きの名前（1回流す）
  - **止まる時間（秒）**：段階が変わった直後に、何もしない時間（変身の演出など）
- **Memo**：プランナー用のメモ（ゲームには影響しない）

## 5. 標準の合図

ゲームが自動で出す合図。アセットは `Assets/Data/Signals/標準/`（Tools > 合図 > 標準の合図を作る）。使い方は `Docs/合図の使い方.md`。

| 合図 | ID | いつ出るか |
|---|---|---|
| ペグでタイミングよく押せた | `timpani/peg_hit` | まだ締まっていないとき。送り元＝ペグ。数＝成功した回数 |
| ペグでタイミングを外した | `timpani/peg_miss` | 送り元＝ペグ |
| ペグが締まった | `timpani/peg_tightened` | 周りの攻撃が消えたとき。そのティンパニの最後のペグ（＝調律できた）は除く。送り元＝ティンパニ。数＝締まった数 |
| ティンパニを調律できた | `timpani/calmed` | 最後の1台（＝全部調律できた）は除く。送り元＝ティンパニ。数＝調律できた数 |
| ティンパニを全部調律できた | `timpani/all_calmed` | 送り元＝ティンパニの部屋 |
| しばらくペグが進まない | `timpani/stalled` | 戦闘中、ティンパニの部屋の「ヒントの合図を出すまでの時間」ペグが進まなかったとき。送り元＝ティンパニの部屋 |
| 守りのゲージが切れた | `guard/empty` | 送り元＝守りのゲージ |
| 守りのゲージが戻った | `guard/ready` | 空になったあと、また出せるようになったとき。送り元＝守りのゲージ |
| 守りのアイテムが出てきた | `item/appeared_guard` | すぐ効くアイテム（守りのゲージ）が出たとき。送り元＝アイテム |
| 回復のアイテムが出てきた | `item/appeared_heal` | すぐ効くアイテム（体力の回復）が出たとき。送り元＝アイテム |
| すぐ効くアイテムを拾った | `item/picked` | 送り元＝拾ったキャラ |
| 敵を倒した | `enemy/defeated` | 送り元＝敵 |
| 戦闘が始まった | `battle/started` | 送り元＝戦闘エリア |
| 戦闘に勝った | `battle/won` | 送り元＝戦闘エリア |
| 戦闘に負けた | `battle/lost` | 戦闘エリアの負け方を満たしたとき（体力が 0 のゲームオーバーは含まない）。送り元＝戦闘エリア |
| ダメージを受けた | `player/damaged` | ノア・シグル。送り元＝受けたキャラ（一緒のときは体力を分けているシグルになることがある）。数＝残りの体力 |
| 体力が少ない | `player/low_health` | ダメージを受けて、体力が最大の 1/3 以下のとき（受けるたびに出る。「ダメージを受けた」より先に出る）。送り元＝受けたキャラ。数＝残りの体力 |
| オートセーブした | `game/autosaved` | 送り元なし |
