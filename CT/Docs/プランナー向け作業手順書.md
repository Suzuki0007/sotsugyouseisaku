# プランナー向け作業手順書（イベント・アイテム・フラグ・音・明かり・マップ遷移・ツール）

この手順書を上から順に見ながら操作すれば、**コードを書かずに、Unity だけで**次の作業が一人でできるようになります。

- アイテム・フラグ・会話・効果音・エフェクト・アニメのデータを作る
- 「調べたら○○」「持っていたら○○」「フラグが立ったら○○」のイベントをマップに置く
- 演出の順番や待ち時間を決める
- セーブポイント・シーンの出入口（マップ遷移）を置く
- 効果音（SE）・BGM を鳴らし、条件や進み具合で BGM を切り替える
- ステージを暗くして、プレイヤーやたいまつの周りだけ明るくする
- 敵を置いて強さ・攻撃を調整し、全滅したら扉が開く・範囲に入ると敵が出てくる・倒すと話せる、などを作る（くわしくは `Docs/敵の作り方.md`）
- 設定ミスを見つけ、再生して確かめる

各機能のくわしい説明は、最後の「付録 C. くわしい資料」の手順書にあります。迷ったときはそちらも見てください。

## 0. Unity の基本操作（はじめての人向け）

### 画面の名前
| 名前 | 場所（初期配置） | 何をするところ |
|---|---|---|
| **Hierarchy**（ヒエラルキー） | 左 | 今開いているシーンに置いてあるオブジェクトの一覧 |
| **Scene ビュー** | 中央 | マップを見ながらオブジェクトを動かす |
| **Game ビュー** | 中央のタブ | 再生したときのゲーム画面 |
| **Inspector**（インスペクター） | 右 | 選んだオブジェクト・データの設定を変える |
| **Project**（プロジェクト） | 下 | ファイル（画像・データ・シーン）の一覧 |
| **Console**（コンソール） | 下のタブ | エラーやメッセージが出る |

### よく使う操作
| やりたいこと | 操作 |
|---|---|
| シーンを開く | Project で `Assets/Scenes/` のシーンをダブルクリック |
| オブジェクトを選ぶ | Hierarchy か Scene ビューでクリック |
| オブジェクトを動かす | 選んで **W** キー → 矢印をドラッグ（または Inspector の Transform の Position に数字を入れる） |
| ひな形を作る | **Hierarchy の何もないところを右クリック** → メニューから選ぶ |
| 部品（コンポーネント）を付ける | オブジェクトを選ぶ → Inspector の一番下の **Add Component** → 名前を入力して選ぶ |
| データを欄に入れる | Project のファイルを、Inspector の欄へ**ドラッグ＆ドロップ**（欄の右の ◉ を押して選んでもよい） |
| オブジェクトを欄に入れる | Hierarchy のオブジェクトを、Inspector の欄へドラッグ＆ドロップ |
| リストに行を足す | リストの右下の **＋**（消すのは **−**） |
| 名前を変える | 選んで **F2** |
| 元に戻す | **Ctrl + Z** |
| シーンを保存する | **Ctrl + S**（タブの名前の横に `*` が出ていたら未保存） |
| 再生／停止 | 画面上の **▶** ボタン（もう一度押すと止まる） |

> ⚠ **再生中に変えた設定は、止めると元に戻ります。** 設定を変えるのは、再生を止めてからにしてください（再生中は画面の色が少し変わります）。

### Inspector の項目の説明を見る
項目の名前にマウスを乗せると、**日本語の説明（ツールチップ）**が出ます。迷ったらまず乗せてみてください。

## 1. 作業を始める前に

### 1-1. どのシーンで作業するか
ゲームで使うシーンは次の4つです（`Assets/Scenes/`）。

| シーン | 内容 |
|---|---|
| `Title` | タイトル画面（ゲームはここから始まる） |
| `Stage1_1` / `Stage1_2` | ステージ（行き来できる） |
| `SceneGameOver` | ゲームオーバー画面 |

`Stage1`・`Stage2`・`SampleScene`・`kari` フォルダのシーンは古いもので、ゲームには入っていません。**作業しないでください。**

### 1-2. 再生のしかた
| 再生のしかた | 使うとき | セーブ |
|---|---|---|
| **Title を開いて ▶** | 本番と同じ流れで確かめたいとき | 選んだスロット（1〜3）に保存される |
| **ステージを開いて ▶**（直接再生） | 作ったイベントをすぐ確かめたいとき | 初期設定では**保存しない** |

ふだんの確認は **ステージから直接再生**が速くておすすめです。

### 1-3. 最初に一度だけ：デバッグの準備
**Tools > デバッグ** を開いて、ウィンドウを Inspector の横などに置いておきます。

- 再生中に **「無敵」** をオンにすると、敵にやられずに確認できます（シーンが変わっても続きます）。
- 「**再生開始時に、下のアイテムとフラグを与える**」をオンにすると、毎回その状態から始められます（8 章）。

### 1-4. 作業の基本の流れ
```
① データを作る（2章）
② マップに置く・イベントを組み立てる・音や明かりを付ける（3〜6章）
③ Tools > シーンチェック で設定ミスがないか見る（8章）
④ 再生して確かめる（デバッグウィンドウを使う）
⑤ Ctrl + S でシーンを保存する
```

## 2. データを作る

ゲームの「もの」は、**データ（アセット）**として Project に作ってから使います。

### 2-1. アイテム（ItemData）
1. Project で **`Assets/Resources/Items/`** を開く
   > ⚠ **必ずこのフォルダ（の中）に作ってください。** 外に置くと、セーブから復元できません。
2. 何もないところを右クリック → **Create > Item > ItemData**
3. ファイル名を付ける（例：`Item_Gem`）
4. Inspector で設定する

| 項目 | 入れるもの |
|---|---|
| **Id** | セーブ用の名前。半角英数字（例：`gem`）。**他のアイテムと重ならないように**。カンマ「,」とコロン「:」は使わない。空ならファイル名 |
| **Display Name** | アイテム画面に出る名前（例：青い宝石） |
| **Description** | アイテム画面に出る説明 |
| **Icon** | アイコン画像（なくてもよい） |
| **Is Key** | 鍵として使う（古い宝箱 `Treasure` で使える）ときだけオン |

> 同じアイテムは何個でも持てます（アイテム画面に「×2」のように出ます）。

### 2-2. フラグ（GameFlag）
フラグは「○○した」を覚えておく **ON / OFF のスイッチ**です（最初はすべて OFF）。

1. **Tools > フラグ > 新しいフラグを作成**（`Assets/Data/Flags/` にできる）
2. ファイル名を「何が起きたか」が分かる名前にする（例：`TalkedToElder`、`BossDefeated`）
3. Inspector で設定する

| 項目 | 入れるもの |
|---|---|
| **Id** | セーブ用の名前。空ならファイル名。**重ならないように** |
| **Memo** | どこで ON になるか、何に使うかのメモ |
| **Saved** | オン：セーブされる（基本はこれ）／オフ：ゲームを起動し直すと OFF に戻る（ボス戦中だけ、など） |

### 2-3. 会話（DialogueData）

**方法 A：Inspector で作る（少ないとき）**
1. Project で `Assets/Data/Dialogue/` などを開き、右クリック → **Create > Talk > DialogueData**
2. **Lines** の **＋** で文を足し、各文に入れる
   - **Character**：話すキャラ（`Assets/Data/Characters/` の CharacterProfile をドラッグ）。空なら立ち絵なし（看板・ナレーション）
   - **Expression**：表情
   - **Speaker Name**：名前欄を変えたいときだけ（例：？？？）
   - **Text**：本文

**方法 B：CSV で作る（多いとき・台本で管理したいとき）**
1. **Tools > 会話 > CSVのひな形を作成** → Excel やスプレッドシートで編集する

| 会話ID | キャラ | 表情 | 名前 | 本文 |
|---|---|---|---|---|
| Elder_First | Elder | 通常 | | よく来たな。 |
| | Elder | 笑顔 | | 北の森へ行ってみるといい。 |
| Sign_Village | | | | ここは はじまりの村 |

   - **会話ID が空の行は、上の行の続き**（同じ会話の次の文）になります。
   - 表情：通常・笑顔・怒り・悲しみ・驚き・困り
2. 「CSV UTF-8」で保存して、`Assets` の中（例：`Assets/Data/Dialogues/`）に置く
3. CSV を右クリック → **会話CSVを取り込む**
4. CSV と同じ場所に、会話IDごとの DialogueData ができる

> 台本を直したら、**もう一度取り込むだけ**で反映されます（シーンに設定済みのものはそのまま）。CSV で管理する会話は、Inspector で直接直さないでください（取り込むと上書きされます）。

**新しいキャラを足すとき**：右クリック → **Create > Talk > CharacterProfile**（名前・名前の色・立ち絵・表情ごとの画像）。

### 2-4. 効果音（SeData）
1. 音声ファイル（wav / mp3 / ogg）を `Assets/SE/` に入れる
2. 音声ファイルを選んで右クリック → **Create > Audio > SeData (音声ファイルごとに作成)**
   - 何パターンかある音（足音など）は、まとめて選んで **(選択した音声をまとめて1つに)** → 鳴らすたびにランダムで選ばれる
3. 音量・ピッチなどは SeData の Inspector で調整する（項目と、鳴らす場所の設定は **5 章**）

### 2-5. エフェクト（EffectData）
1. 画像を `Assets/Images/Effect/` に入れ、Inspector で **Texture Type = Sprite (2D and UI)** にする
2. 画像（連番ならまとめて）を選んで右クリック → **Create > Effect > EffectData (選択した画像をまとめて1つのアニメに)**
3. Inspector でプレビューを見ながら、速さ・消え方・表示順・一緒に鳴らす SE を決める

くわしくは `Assets/Script/Effect/README_エフェクトの使い方.md`。

### 2-6. アニメーション（SpriteAnimData）
1. 画像の名前を **`キャラ名_動き_向き`**（例：`Noah_Walk_Down`）にして入れる
2. 1キャラ分の画像をまとめて選んで右クリック → **Create > Animation > SpriteAnimData (選択した画像から作成)**
3. Inspector で動きごとの速さ・再生のしかた（ループ／1回）を決める

くわしくは `Assets/Script/SpriteAnimation/README_アニメーションの使い方.md`。

## 3. マップに置く

### 3-1. 拾えるアイテム（ItemPickup）
1. マップに置く見た目のオブジェクトを用意する（画像を Hierarchy にドラッグすると作れる）
2. Add Component → **Box Collider 2D** を付けて、**Is Trigger をオン**（拾える範囲になる）
3. Add Component → **ItemPickup** を付ける
4. **Item** に 2-1 で作った ItemData をドラッグ
5. **Pickup Id** に、そのシーンで重ならない名前を入れる（例：`Gem_Room1`）

再生して近づき、**E キー**で拾えます。一度拾ったものは、シーンに戻っても出てきません。

### 3-2. 調べると何かが起きるもの（ItemInteraction）
「持っていたら扉が開く」「話しかけると会話が出る」など、**ほとんどのイベントはこれで作ります。**

**① ひな形を作る**
Hierarchy の何もないところを右クリック → **アイテム連動 > 調べるオブジェクト**
```
ItemInteraction     ← 調べる範囲（Box Collider 2D）と設定（ItemInteraction）
├─ 成功時          ← 条件を満たしたときの中身（表示切り替え＋会話）
└─ それ以外        ← 条件を満たさないときの中身（会話）
```
名前を分かりやすく変え（例：`扉_倉庫`）、置きたい場所に動かします。調べる範囲の大きさは **Box Collider 2D の Size** で変えます（Scene ビューに緑の四角で出ます）。

**② ルールを決める（ItemInteraction の Inspector）**

| 項目 | 説明 |
|---|---|
| **Trigger** | 「調べたとき（E キー）」か「エリアに入ったとき」 |
| **Rules** | 条件と結果の組。**上から順に調べて、最初に条件を満たした1つだけ**を実行する |
| └ **Label** | メモ（例：鍵を持っている） |
| └ **Conditions** | アイテムの条件。Item・Count（何個以上）・Not Have（持っていないとき） |
| └ **Flag Conditions** | フラグの条件。Flag・State（ON のとき／OFF のとき） |
| └ **Consume Items** | 実行するとき、条件のアイテムを消費する |
| └ **Sequence** | 実行する中身（「成功時」が入っている） |
| └ **Mark Completed** | 実行したら「完了」にする（以後このルールは実行されない） |
| **Otherwise** | どのルールも満たさないときの中身（「それ以外」が入っている） |
| **After Completed** | 完了したあとに調べたときの中身（例：「もう開いている」）。なくてもよい |
| **Save Id** | 完了を記録する名前。**シーンで重ならない名前を入れておく**のがおすすめ |
| **Save Completed** | 完了状態をセーブする（シーンに戻っても開いたまま、など） |

- Conditions と Flag Conditions は、**すべて満たしたとき**に実行されます。条件が空のルールは「いつでも実行」です。
- 「A **か** B」にしたいときは、ルールを2つ並べます。
- 条件のアイテムは **Project からドラッグ**して入れます。

**③ 中身を作る**：「成功時」「それ以外」を選んで、4 章の部品を付けたり設定したりします。

### 3-3. エリアに入ると起きるイベント
| 作り方 | 使うとき |
|---|---|
| ItemInteraction の **Trigger** を「エリアに入ったとき」にする | 条件で中身を変えたいとき（「地図を持っていたらヒント」など） |
| Hierarchy 右クリック → **フラグ > 入るとフラグを設定するエリア** | 入ったらフラグを ON にしたいだけのとき |
| `EventZone`（Box Collider 2D〈Is Trigger オン〉＋ EventZone ＋ EventSequence） | 条件のない、昔ながらのイベント |

> `EventZone` の「Once Only（1回だけ）」は**セーブされません**（シーンに戻るともう一度起きます）。セーブしたいときは ItemInteraction（Mark Completed）を使ってください。

### 3-4. 持っている間・フラグで見た目を切り替える
| 作り方 | 何が起きるか |
|---|---|
| Hierarchy 右クリック → **アイテム連動 > 持っている間だけ切り替え**（ItemPossessionSwitch） | アイテムを持っている間だけ表示・非表示（ランタンで明るくなる、など） |
| Hierarchy 右クリック → **フラグ > フラグで切り替え**（FlagSwitch） | フラグが ON の間だけ表示・非表示（話したら岩が消える、など） |

| 項目 | 説明 |
|---|---|
| **Conditions**（FlagSwitch は Flag Conditions・Item Conditions） | 条件（すべて満たしたとき） |
| **Active When Met** | 条件を満たしている間だけ**表示する**もの |
| **Active When Not Met** | 条件を満たしていない間だけ**表示する**もの（＝満たすと消える） |

> ⚠ 切り替えの部品を付けたオブジェクト**自身**は、リストに入れないでください（消えると切り替えが止まります）。消したいものは別のオブジェクトにして、リストに入れます。

### 3-5. セーブポイント
1. Hierarchy 右クリック → **セーブポイント**（仮の青い丸・調べる範囲・SavePoint ができる）
2. 置きたい場所に動かす
3. Inspector で設定する

| 項目 | 説明 |
|---|---|
| **Question** | 最初に出す確認の文（例：セーブしますか？） |
| **Resume Offset** | 「つづきから」で再開する位置（Scene ビューに水色の丸で出る）。**セーブポイントに重ならない、歩ける場所**にする |
| **Save Se** | セーブしたときの音（空なら共通の音） |

見た目は SpriteRenderer の Sprite を差し替えます。

> 戦闘エリア（追跡イベント・逃げる戦闘など）の戦闘中は、セーブポイントでセーブできません（`Docs/敵の作り方.md` 11 章）。

### 3-6. マップ遷移（出口 SceneChange と 出現位置 PlayerSpawnPoint）
出入口は2つの部品の組み合わせでできています。

| 部品 | 置く場所 | 役割 |
|---|---|---|
| **SceneChange**（遷移ポイント） | **移動元**のシーンの出口 | プレイヤーがぶつかると、行き先のシーンへ移動する |
| **PlayerSpawnPoint**（出現位置） | **移動先**のシーンの入口 | 移動してきたプレイヤーが出てくる場所 |

2つは **出現位置 ID**（文字列）で結びつきます。移動するときは自動で暗転 → 切り替え → 明転します（暗転 0.3 秒・真っ暗のまま 0.1 秒・明転 0.3 秒）。その間プレイヤーは操作できません。暗転の設定は不要です。

**① 移動先に出現位置を置く（PlayerSpawnPoint）**
1. 移動先のシーンを開き、Hierarchy 右クリック → **Create Empty** で空のオブジェクトを作る
2. 名前を「どこから来たときの位置か」が分かるものにする（例：`Spawn_FromStage1_1`）
3. プレイヤー（ノア）を出したい位置に動かす（Scene ビューに**水色の丸**で出る）
4. Add Component → **PlayerSpawnPoint** を付けて設定する

| 項目 | 入れるもの | 例 |
|---|---|---|
| **Spawn Point Id** | 出現位置 ID。**このシーンで重ならない名前** | `FromStage1_1` |
| **Sigle Spawn Point** | シグルを出す位置（任意）。空ならノアと同じ位置 | 子オブジェクト `Sigle` |

- シグルの位置を分けたいときは、出現位置の子に空のオブジェクトを作って、それを **Sigle Spawn Point** に入れます（**ピンクの丸**で出る）。シグルはそこに出て、ノアが動き出すと、ノアの後ろへ歩いて付いてきます。
- 出現位置は、出口の **少し内側** に置いてください。出口に重なると、押し出されて位置がずれたり、少し動いただけで元のシーンに戻ったりします。
- 出入口が複数あるときは、出入口ごとに1つずつ置きます。
- **Ctrl + S** で保存します（保存していないと、移動元のドロップダウンに出てきません）。

**② 移動元に出口を置く（SceneChange）**
既存の出口を複製（**Ctrl + D**）して使うのが確実です。新しく作るときは：
1. 出口の場所にオブジェクトを作り、Add Component → **Box Collider 2D**（**Is Trigger はオフのまま**。プレイヤーが「ぶつかったとき」に反応する）
2. Add Component → **SceneChange** を付けて設定する

| 項目 | 入れるもの |
|---|---|
| **Scene Name** | 行き先のシーンを**ドロップダウンから選ぶ**（Build Settings に入っているシーンだけが出る） |
| **Spawn Point Id** | 行き先の出現位置を**ドロップダウンから選ぶ**。「デフォルトの位置」なら、行き先の PlayerPartySpawner の既定の位置に出る |
| **Leave Se** / **Arrive Se** | 暗転を始めたとき（ドアを開ける音など）／行き先で明るくなるとき（ドアを閉める音など）の SE（任意） |

- ドロップダウンに**オレンジ色の「⚠」**が出たら、行き先のシーンが Build Settings にないか、その ID の出現位置が行き先にありません。
- 一番下の「**手入力に切り替え**」で文字を直接打つこともできます（ふだんは使わない）。

**ID の付け方のおすすめ**：「`From` + 移動元のシーン名」（例：`FromStage1_1`）。同じシーンへの出入口が2つ以上あるときは `FromStage1_1_North` のように区別します。

**例：Stage1_1 と Stage1_2 を行き来する**（説明用の例です）
| 移動元 | 出口の場所 | Scene Name | Spawn Point Id | 移動先に置く出現位置 |
|---|---|---|---|---|
| Stage1_1 | 右端 | `Stage1_2` | `FromStage1_1` | Stage1_2 の左端（ID `FromStage1_1`） |
| Stage1_2 | 左端 | `Stage1_1` | `FromStage1_2` | Stage1_1 の右端（ID `FromStage1_2`） |

**知っておくこと**
- 移動先に着くと、そこが**自動でセーブ**されます（「つづきから」はその出現位置から始まる）。
- 「はじめから」の位置はタイトルの TitleMenu、ゲームオーバーの「リトライ」は倒れたステージの既定の位置から始まります。
- 新しいシーンを作ったら、**File > Build Profiles**（Build Settings）に追加しないと、ドロップダウンに出ず、移動もできません。追加はプログラマーに相談してください。
- 遷移先・出現位置 ID のミスは **Tools > シーンチェック** で見つかります。

| うまくいかないとき | 確認すること |
|---|---|
| ぶつかっても移動しない | 出口の Collider 2D の **Is Trigger がオフ**か／Scene Name が空でないか |
| 移動先の違う場所に出る | Spawn Point Id が移動先の出現位置と同じか（⚠ が出ていないか）／移動先のシーンを保存したか |
| 着いてすぐ元のシーンに戻る | 出現位置が出口に重なっている → 少し内側へ |
| シグルが変な場所に出る | Sigle Spawn Point が壁の中・マップの外になっていないか |

### 3-7. エフェクト・アニメをオブジェクトに付ける
| やりたいこと | 付ける部品 |
|---|---|
| 「出現したとき」「ダメージを受けたとき」「触れたとき」などにエフェクト | Add Component → **Effect > Effect Trigger**（「＋」で行を足し、いつ・どれを選ぶ） |
| 弾・敵・攻撃のエフェクト | Prefab の Inspector に最初からある「エフェクト」欄に EffectData を入れる |
| オブジェクトをアニメさせる | Add Component → **Animation > Sprite Animator**（Animation Data に SpriteAnimData） |
| キャラの歩き・待機を自動で切り替える | 上に加えて **Animation > Character Anim Link** |

> ⚠ Sprite Animator は、Unity の **Animator** と一緒に付けないでください（画像が上書きされます）。

## 4. イベントの中身を組み立てる（EventSequence と部品）

「成功時」「それ以外」などの中身は、**EventSequence**（部品を並べる箱）と、**部品（〜EventAction）**でできています。

### 4-1. 部品を付ける手順
1. 「成功時」などのオブジェクトを選ぶ
2. Add Component → 部品の名前（例：`SeEventAction`）
3. 部品の設定をする
4. EventSequence の **Actions** に登録する
   - 登録し忘れると、EventSequence に**黄色い警告**と「**入っていない部品を Actions の最後に追加**」ボタンが出るので、押せば登録されます。
   - Actions が空のままなら、付いている部品を上から順に使います。

### 4-2. 部品の一覧
| 部品 | できること | 主な設定 |
|---|---|---|
| **DialogueEventAction** | 会話を出す | **Dialogue**（同じオブジェクトの Dialogue）。Dialogue の **Dialogue Data** に会話を入れる（1文だけなら **Dialogue Text** に直接書いてもよい）。**Wait Until Closed**：閉じるまで次を待つ（初期値オン） |
| **SeEventAction** | 効果音を鳴らす | Se On Enter に SeData |
| **SetActiveEventAction** | オブジェクトを表示・非表示 | **Show**：表示するもの／**Hide**：消すもの |
| **SpriteChangeEventAction** | 画像を差し替える | Target（SpriteRenderer）・Sprite |
| **AnimEventAction** | アニメを流す | Wait Until Finished：終わるまで待つ |
| **EffectEventAction** | エフェクトを出す | EffectData |
| **WaitEventAction** | 指定した秒数待つ | Seconds |
| **ItemGiveEventAction** | アイテムを渡す | Item・Count |
| **ItemTakeEventAction** | アイテムを取り上げる | Item・Count |
| **SetFlagEventAction** | フラグを ON / OFF | Flags（Value にチェックで ON） |
| **BgmFlagEventAction** など | BGM を切り替える | — |

### 4-3. 順番と待ち時間（EventSequence の設定）
| 項目 | 説明 |
|---|---|
| **Play Mode** | **順番に実行**（初期値・おすすめ）：Actions を上から順に、前の部品が終わってから次へ／**すべて同時に実行**：全部を一度に |
| **Lock Player** | 実行中はプレイヤーを動けなくする。演出の間に歩き回らせたくないときにオン |
| **Actions** | 実行する部品。ドラッグで並べ替えられる |

- 会話は**閉じるまで**、WaitEventAction は**指定秒数**、アニメは（設定すれば）**終わるまで**次を待ちます。ほかの部品は一瞬で終わります。

> ⚠ **中身（EventSequence）が付いているオブジェクトや、その親を Hide に入れないでください。** 途中で止まって、後ろの部品が動かなくなります。扉を消したいときは、扉を別のオブジェクトにします（ひな形はそうなっています）。

### 4-4. セーブから戻ったときの見た目
Mark Completed で完了したイベントは、シーンに戻ったときに**見た目だけ**が完了後の状態になります（表示切り替え・画像の差し替え・アニメの最後の形）。会話や音は出ません。

## 5. 音を付ける（SE・BGM）

### 5-1. SE の流れ
```
① 音声ファイルを Assets/SE/ に入れる
② SeData を作る（2-4）
③ 鳴らしたい場所の「SE」欄に SeData をドラッグする
④ 再生を止めた状態で設定 → 保存（シーンは Ctrl + S、プレハブは開いて保存）→ 再生して聞く
```
音声ファイルを直接 SE 欄に入れることはできません。必ず **SeData** をはさみます（同じ SeData を何か所でも使えます）。

**音声ファイルのルール**
| 項目 | ルール |
|---|---|
| 形式・置き場所 | wav / mp3 / ogg を `Assets/SE/` に（エクスプローラーからドラッグで取り込める） |
| 名前 | `SE_内容`（例：`SE_KeyOP`、`SE_Door_OP`）。SeData は `Se_内容` の名前で同じフォルダにできる |
| 長さ | 鳴り切りの音は**頭の無音を削る**（無音があると操作より遅れて聞こえる） |
| 足音 | **1歩分ずつ**に切り分ける。数パターン用意して「まとめて1つに」で作ると、毎回ランダムで単調にならない |

### 5-2. SeData の項目
迷ったら初期値のままで大丈夫です。

| 項目 | 初期値 | 意味と目安 |
|---|---|---|
| **Clips** | — | 鳴らす音。複数入れるとランダム（同じ音の連続はなるべく避ける）。ドラッグで追加できる |
| **Volume** | 1 | 音量（0〜1）。足音など何度も鳴る音は 0.3〜0.6 |
| **Pitch Min / Max** | 1 / 1 | 鳴らすたびに音の高さをこの範囲で揺らす。足音・攻撃音は 0.9〜1.1 |
| **Loop** | オフ | オンで止めるまで鳴り続ける（環境音、弾消しエリアの持続音などだけ） |
| **Spatial Blend** | 0 | 0 はどこでも同じ音量。このゲームでは 0 のまま |
| **Min Interval** | 0.03 | 同じ SE を次に鳴らせるまでの最短秒数。連打でうるさいときは大きく |
| **Max Concurrent** | 4 | 同じ SE を同時に鳴らせる数（超えると古い音が止まる）。0 は制限なし |
| **Output Group** | 空 | ミキサーの出力先。通常は空 |

> **同じ音でも、キャラごとに SeData を分けてください。** ノアとシグルの足音に同じ SeData を使うと、Min Interval に引っかかって片方が鳴らないことがあります。

### 5-3. SE を鳴らす場所
**A. すでに「SE」欄がある場所**（ドラッグするだけ）

| 鳴らしたいとき | 設定する場所 | 欄の名前 |
|---|---|---|
| 歩く | プレイヤーのプレハブ（`Assets/Prefab/Players/`）の **FootstepSe** | Footstep Se（操作中）／Follower Footstep Se（付いてくるとき。空なら無音）／Step Distance（1歩の距離。初期値 0.8） |
| 弾を撃つ | シグルの **SigleShooter** | Shot Se |
| 攻撃を始める | ノアの **AreaAttackController** / **TimingGaugeAttackController** | Attack Se |
| 弾消しエリア | ノアの **NoahBulletDeleteAreaController** | Area Start Se ／ Area Loop Se（Loop オンの SeData）／ Area End Se |
| キャラ切り替え | シーンの **PlayerSwitchManager** | Switch Se |
| ダメージ・回復・死亡 | Health の付いたオブジェクトに **HealthSe** を追加（敵にも使える） | Damage Se ／ Heal Se ／ Death Se |
| ゲームオーバー | ノアの **NoahDead** | Game Over Leave Se ／ Game Over Arrive Se |
| アイテムを拾う | **ItemPickup**（古い鍵は KeyItem） | Pickup Se |
| アイテムを渡す（イベント） | **ItemGiveEventAction** | Se |
| 宝箱（古い仕組み） | **Treasure** | Open Se ／ Locked Se |
| シーンを移動する | **SceneChange** | Leave Se ／ Arrive Se |
| セーブポイント | **SavePoint** | Save Se（空なら共通の音） |
| エフェクトと一緒に | **EffectData** | 一緒に鳴らす SE |
| アニメの特定のコマ | **SpriteAnimData** の「コマごとのイベント」 | SE |
| メニュー・タイトルなどの UI | `Assets/Resources/UISounds.asset`（9 章） | Select / Decide / Cancel など |

> ⚠ **プレイヤー（ノア・シグル）の設定は、シーンではなくプレハブに**してください。2人はゲーム開始時にプレハブから作られるので、シーン上のものに設定しても反映されません。プレハブは `Assets/Prefab/Players/` をダブルクリックで開き、設定したら保存します。
>
> ⚠ **2026-11-08 時点で、ノア・シグルのプレハブに FootstepSe が付いていません**（足音が鳴らない状態です）。足音を付けるときは、プレハブを開いて一番上のオブジェクトに **Add Component → FootstepSe** を追加してから設定してください。HealthSe も同じように追加します。
> シグルの射撃（左クリック）は 11-08 に直りました。**SigleShooter の Shot Se はまだ空**なので、射撃の音を決めたら、シグルのプレハブの SigleShooter に入れてください。

**B. イベントで鳴らす**：EventSequence の部品 **SeEventAction**（4 章）。Se On Enter に Loop オンの SeData を入れると、エリアにいる間だけ鳴り続けます（Stop Loop On Exit がオンなら出たときに止まる）。

**C. 出現したとき・ボタン・Unity のアニメに合わせて**：鳴らしたいオブジェクトに **SePlayer** を追加し、Se に SeData を入れる
| タイミング | 設定 |
|---|---|
| オブジェクトが出たとき（表示されたとき） | **Play On Enable** をオン |
| オブジェクトが消えたとき | **Se On Disable** に SeData |
| ボタンを押したとき | ボタンの On Click に SePlayer を登録し `SePlayer.Play`（UI のボタンなら **UIButtonSound** でもよい） |
| Animation ウィンドウのアニメの特定のコマ | アニメーションイベントの関数に `PlaySe` を選び、Object 欄に SeData |

**D. どれにも当てはまらないとき**：プログラマーに「SE 欄の追加」を頼みます（数行の作業）。伝えること：**何が起きたときに鳴らすか**（例：敵が弾を撃ったとき）／**鳴り切りか、鳴らし続けるか**（続けるならいつ止めるか）／**SeData の名前**（あとで入れる、でも可）。欄は空でもエラーにならないので、先に欄だけ作ってもらって大丈夫です。

### 5-4. BGM の基本（SceneBgm）
BGM は、各シーンに1つ置いた **SceneBgm** で決めます（実際に鳴らす BgmManager は自動で作られる）。
`Title`・`Stage1_1`・`Stage1_2` には置いてあります。Hierarchy の検索欄に `t:SceneBgm` と入れると見つかります。

**新しいシーンに置くとき**：Create Empty → 名前を `SceneBgm` → Add Component → **SceneBgm** → **Default Clip** に曲をドラッグ。

| 項目 | 初期値 | 内容 |
|---|---|---|
| **Default Clip** | なし | このシーンで流す曲（空なら無音） |
| **Default Volume** | 1 | 音量（0〜1） |
| **Default Fade Time** | 1 秒 | 条件付きの曲から基本の曲に戻るときの切り替え時間 |
| **Resume Default** | オン | 基本の曲に戻ったとき、止めた位置の続きから流す |
| **Effect Profile** | なし | このシーンの音のエフェクト（5-6） |
| **Start Fade In Time** | 2 秒 | シーン開始時のフェードイン |
| **Fade Out Previous** | オン | オン：前の曲が消えてから新しい曲／オフ：重ねながら切り替え |
| **Previous Fade Out Time** | 0.5 秒 | 前のシーンの曲を消す時間 |
| **Clear Flags On Start** | オフ | オンでシーン開始時に**一時フラグ（Saved オフの GameFlag と、BGM 用の文字のフラグ）をすべて OFF** にする |

- 次のシーンに**同じ曲**を設定すると、曲は途切れずに流れ続けます。違う曲なら、前の曲を 0.5 秒で消して新しい曲を 2 秒でフェードインします。
- SceneBgm を置かないシーンでは、前のシーンの曲がそのまま流れます。

### 5-5. 条件で BGM を切り替える（ルール）
毎フレーム、成り立っている**ルール**のうち **Priority（優先度）が一番大きいもの**の曲が流れます。どれも成り立たなければ基本の曲に戻ります。

1. 条件の部品（下の表）を付けたオブジェクトを用意する
2. SceneBgm の **Rules** の ＋ でルールを足す
3. **Condition** にそのオブジェクトをドラッグし、**Clip** に曲を入れ、**Priority** を決める

| 条件の部品 | 成り立つとき | 主な設定 | 例 |
|---|---|---|---|
| **BgmConditionArea** | 操作中のキャラが範囲内にいる | Box Collider 2D（**Is Trigger オン**）を一緒に付ける | 洞窟・店の中だけ別の曲 |
| **BgmConditionHealth** | HP の割合が Threshold 以下 | Threshold（0.3 = 30%）、Target（空なら操作中のキャラ） | ピンチの曲 |
| **BgmConditionFlag** | フラグが ON | **Flag** に GameFlag をドラッグ（おすすめ）。古い Flag Name（文字）も使える | ボス戦 |

- どの条件にも **Invert** があり、オンにすると「〜でないとき」になります。

| ルールの項目 | 内容 |
|---|---|
| Label | メモ（例：ボス戦） |
| Condition / Clip / Volume | 条件・流す曲（空なら無音）・音量 |
| Priority | 大きいほど優先（目安：ボス戦 100、ピンチ 50、エリア 10） |
| Fade Time | 切り替えの時間（秒） |
| Effect Profile | この曲の間だけ使うエフェクト（空ならシーンの設定） |
| Latch | オンにすると、一度成り立ったら条件が外れてもその曲のまま |

**例：ボス部屋に入ったらボスの曲**
1. **Tools > フラグ > 新しいフラグを作成** → `BossBattle`、**Saved はオフ**（一時的なフラグ）
2. Hierarchy 右クリック → **フラグ > 入るとフラグを設定するエリア** → ボス部屋の入口に置き、Flags に `BossBattle`（Value にチェック）
3. 別のオブジェクトに **BgmConditionFlag** を付け、Flag に `BossBattle`
4. SceneBgm に Rule を足し、Condition = 3、Clip = ボスの曲、Priority = 100
5. ボスを倒したら通常の曲に戻すには、倒したときに **SetFlagEventAction** で `BossBattle` を OFF にします（Latch はオフのまま）。「ボスを倒したとき」にイベントを起こす仕組みや、Latch の解除（`SceneBgm.ResetLatches`）が必要なときはプログラマーに頼んでください。

> 以前の手順書の「BgmFlagEventAction の Flag Name に `Boss` と打つ」方法も、そのまま動きます。新しく作るときは、打ち間違いのない GameFlag を使うのがおすすめです。

### 5-6. 進み具合で音を変える（エフェクトと進行度）
「序盤は崩れた音、進むほど整った音」を、**BGM Effect Profile** 1つで作れます。

1. Project で右クリック → **Create > Audio > BGM Effect Profile**
2. **Keys** の ＋ で状態を足し、**Progress**（0〜1）と各エフェクトの値を入れる（間の進行度は自動でなめらかにつながる）
3. SceneBgm の **Effect Profile**（またはルールの Effect Profile）に入れる

| エフェクト | 効果 | 範囲 | 効かない値 |
|---|---|---|---|
| Lowpass Cutoff | こもり（壁の向こうで鳴っているよう） | 10〜22000 Hz | 22000 |
| Highpass Cutoff | 薄さ（ラジオのような音） | 10〜22000 Hz | 10 |
| Resonance（2つ） | 上の2つの境目にクセを出す | 1〜10 | 1 |
| Distortion | ゆがみ・音割れ | 0〜1 | 0 |
| Wobble（Rate / Depth） | 揺れ・不安定さ | 0〜1 | 0 |
| Echo（Delay / Decay） | やまびこ | 0〜1 | 0 |
| Reverb | 響き・広がり（終盤の豪華さ） | 0〜1 | 0 |
| Volume | 音量の倍率 | 0〜1 | 1 |

設定例（3段階）：
| 状態 | Progress | Lowpass | Highpass | Distortion | Wobble | Reverb |
|---|---|---|---|---|---|---|
| 序盤（崩れた音） | 0 | 800 | 300 | 0.5 | 0.6 | 0 |
| 中盤 | 0.5 | 5000 | 10 | 0.15 | 0.2 | 0 |
| 終盤（整った音） | 1 | 22000 | 10 | 0 | 0 | 0.3 |

**進行度を上げる**：EventSequence の部品 **BgmProgressEventAction** を使います。
| Mode | 動き |
|---|---|
| **SetAtLeast**（初期値・おすすめ） | Value より低いときだけ Value にする（戻ってきても下がらない） |
| Set | Value にする |
| Add | Value だけ足す |

例：ステージ1のボスを倒したら SetAtLeast 0.25、ステージ2クリアで 0.5。値が変わると約 1.5 秒かけて音が移り変わります。

**試聴する**：適当なオブジェクトに **BgmProgressDebug** を付け、再生中に **Override Progress** をオンにして **Progress** を動かすと、その進行度の音をすぐ聞けます（確認が終わったら外す）。

> ⚠ 2026-11-08 時点では、**進行度はセーブされません**（ゲームを起動し直すと 0 に戻る）。また、エディタでは再生を止めても前の値が残ることがあります（プログラマーに報告済み）。

### 5-7. 音が鳴らないとき
| 症状 | よくある原因 | 対処 |
|---|---|---|
| まったく鳴らない | シーン・プレハブを保存していない／再生中に設定した | 止めてから設定し直し、保存する |
| プレイヤーの音だけ鳴らない | シーン上のノア・シグルに設定した／プレハブに FootstepSe がない | プレハブに設定・追加する（5-3） |
| あるステージでだけ鳴らない | そのステージのオブジェクトに設定していない | ステージごとに設定する |
| Console に「SeData '○○' に音声ファイルが設定されていません」 | SeData の Clips が空 | Clips に音声ファイルを入れる |
| 2人の足音の片方が消える | 2人で同じ SeData を使っている | キャラごとに分ける |
| 連打で途切れる／うるさい | Min Interval・Max Concurrent | 途切れるなら Min Interval を小さく・Max Concurrent を大きく、うるさいなら逆 |
| 操作より遅れて聞こえる | 音声の頭に無音 | 音声編集ソフト（Audacity など）で削る |
| 音が止まらない | Loop オンの SeData を鳴り切りの場所に使った | Loop をオフに |
| BGM が変わらない | Priority が低い／条件の Collider の Is Trigger がオフ／フラグが違う | Priority、Is Trigger、**Tools > フラグ > フラグ一覧**で ON になっているか |
| BGM が戻らない | ルールの Latch がオン | Latch をオフにするか、プログラマーに解除を頼む |

## 6. 暗いステージと明かり（StageDarkness・LightSource）

ステージを暗くして、プレイヤーの周りやたいまつ・ランプの周りだけを明るくできます。今は `Stage1_2` で使っています。

### 6-1. 始める前に確認すること
- **暗くなるのは「Lit」マテリアルの画像だけ**です。Sprite Renderer（タイルマップなら Tilemap Renderer）の **Material** が `Sprite-Lit-Default` のものが暗くなり、`Sprites-Default` などの Unlit は明るいままです。わざと Unlit にしておくと、暗い中でもくっきり見える看板などにできます。
- Canvas の UI（ライフ・メニューなど）は暗くなりません。
- **シーンビューでは暗くなりません**（暗くなるのは再生中だけ）。マップは明るいまま作れます。
- 再生中に値を変えるとすぐ確かめられますが、**止めると元に戻ります**。決まった値は、止める前にコンポーネント右上の **⋮ → Copy Component**、止めたあとに **⋮ → Paste Component Values** で残せます。

### 6-2. ステージを暗くする（StageDarkness）
1. 暗くしたいステージを開き、Create Empty → 名前を `StageDarkness`
2. Add Component → **StageDarkness**
3. 再生して暗さと明かりの範囲を調整 → 値を残して保存（Ctrl + S）

置かなかったステージは、今まで通り明るいままです。

| 項目 | 初期値 | 内容 |
|---|---|---|
| **Darkness** | 0.9 | 0 で普段の明るさ、1 で真っ暗。0.85〜0.95 が「地形がうっすら見える」目安 |
| **Ambient Color** | 白 | 暗い部分の色味（少し青で夜、少し緑で地下・毒の沼） |
| **Global Light** | 空 | 空のままでよい（シーンの Global Light 2D を自動で使う） |
| **Target** | 空 | 照らす相手。空なら Player タグのものを自動で探す |
| **Offset** | 0, 0 | 明かりの中心をずらす（体の中心なら Y = 0.5 など） |
| **Radius** | 4 | 明るい範囲の半径（視界の広さ。1 = タイル1枚分） |
| **Inner Radius** | 1 | 完全に明るい中心の半径（Radius より大きくできない） |
| **Light Intensity** | 1 | 明かりの強さ |
| **Light Color** | 白 | 明かりの色（オレンジ寄りでランタン風） |
| **Falloff** | 0.5 | 境目のぼかし方（0 に近いほどなめらか、1 に近いほどくっきり） |
| **Flicker Amount / Speed** | 0 / 3 | 明かりの揺れ幅と速さ（0.05〜0.1 でランタン風） |

明かりの範囲：中心から Inner Radius までは完全に明るく、Radius までだんだん暗くなり、その外は Darkness の暗さになります。

> ⚠ **既知の問題**：Target が空のとき、最初に見つけた Player タグのキャラだけを照らすため、**キャラを切り替えると明かりが操作キャラに付いてこない**ことがあります。プレイヤーはゲーム開始時に作られるので、Target に直接入れることもできません（プログラマーが対応予定）。

### 6-3. 光源を置く（LightSource）
たいまつ・ランプ・光るキノコ・窓から差す光など。
1. 光らせたいオブジェクト（画像付きでも空でもよい）を選ぶ
2. Add Component → **LightSource**
3. 再生して範囲・色・揺れを調整する

明かりはオブジェクトに付いていくので、動くものにも使えます。たいまつをプレハブにしておくと、置くだけで明かり付きになります。

| 項目 | 初期値 | 内容 |
|---|---|---|
| **Shape** | Circle | **Circle**：円形（たいまつ・ランプ）／**Sprite**：画像の形で照らす（窓の光・魔法陣） |
| **Light Sprite** | 空 | Sprite のときの光の形。空ならオブジェクト自身の画像 |
| **Sprite Scale** | 1 | Sprite のときの大きさ |
| **Offset** | 0, 0 | 明かりの中心（たいまつの火の位置に合わせる） |
| **Radius / Inner Radius** | 3 / 0.5 | Circle のときの範囲（見方は StageDarkness と同じ） |
| **Intensity** | 1 | 強さ |
| **Color** | 暖色 | 明かりの色 |
| **Falloff** | 0.5 | 境目のぼかし方 |
| **Flicker Amount / Speed** | 0 / 3 | 揺れ（何本置いても、それぞれ違うタイミングで揺れる） |
| **Only In Dark Stage** | オン | オンなら、StageDarkness のあるステージでだけ点く |
| **Self Illuminate** | オフ | オンで、その画像自体が暗闇でもくっきり見える（炎・光るキノコ） |
| **Unlit Material** | 空 | ふだんは空。ビルドしたゲームで Self Illuminate が効かないときだけ `Sprite-Unlit-Default` |

**おすすめの初期値**（ここから遊びながら調整する）
| 用途 | 部品 | 主な値 |
|---|---|---|
| 洞窟 | StageDarkness | Darkness 0.92、Ambient #D8D4CC、Radius 4 / Inner 1、Light Color #FFE2B8、Flicker 0.06 |
| 夜の森 | StageDarkness | Darkness 0.8、Ambient #9FB2E6、Radius 5 / Inner 1.5、Flicker 0 |
| 真っ暗な遺跡 | StageDarkness | Darkness 1.0、Radius 2.5 / Inner 0.5、Falloff 0.8、Flicker 0.1 |
| たいまつ | LightSource（Circle） | Radius 3 / Inner 0.5、Intensity 1.2、Color #FFB35C、Flicker 0.12 / 4、Self Illuminate オン |
| 光るキノコ | LightSource（Circle） | Radius 1.5 / Inner 0.2、Intensity 0.7、Color #7FE0D0、Flicker 0.05 / 1、Self Illuminate オン |
| 窓から差す月光 | LightSource（Sprite） | Light Sprite = 窓形の画像、Sprite Scale 3、Intensity 0.8、Color #C9D6FF |

### 6-4. イベントや持ち物で明かりを変える
| やりたいこと | 作り方 |
|---|---|
| スイッチを調べるとたいまつが点く | たいまつ（LightSource 付き）を非表示にしておき、ItemInteraction の成功時に **SetActiveEventAction** の Show で表示（練習 5） |
| ランタンを持っている間だけ部屋が明るい | **ItemPossessionSwitch** の Active When Met に、LightSource 付きのオブジェクトを入れる |
| フラグが ON になったら明かりが消える | **FlagSwitch** の Active When Not Met に、LightSource 付きのオブジェクトを入れる |
| 視界をだんだん広げる・部屋をだんだん明るくする・明かりの色を変える | プログラマーに頼む（`SetRadius`・`SetDarkness`・`SetLightColor` などの仕組みはある） |

### 6-5. 明かりがおかしいとき
| 症状 | 確認すること |
|---|---|
| 暗くならない | StageDarkness のチェック（名前の左）がオンか／Darkness が 0 でないか |
| 一部の画像・タイルだけ明るい | その Material が Unlit → `Sprite-Lit-Default` に |
| 明かりが付いてこない・変な所が明るい | キャラを切り替えた（既知の問題）／Player タグのものが他にもある |
| たいまつが光らない | Only In Dark Stage がオンで、StageDarkness がないステージ／Shape が Sprite で画像がない |
| ビルドで Self Illuminate が効かない | Unlit Material に `Sprite-Unlit-Default` |
| 重い | 画面に数十個までの想定。それ以上はプログラマーに相談 |

## 7. 通しで作ってみる（練習問題）

まずは `Stage1_1` を開き、**プレイヤーの出てくる場所の近く**で練習してください。終わったら作ったものを消すか、シーンを保存せずに閉じても構いません。

> **お手本を見たいとき**：**Tools > アイテム連動 > サンプルを配置（開いているシーン）** で、鍵の扉・宝石の像・ランタンの明かりの完成品が置かれます（`ItemInteractionSample` の下にまとまっているので、消すときはそれを消す）。

### 練習 1：鍵で開く扉（アイテム条件・消費・完了）
**ゴール**：鍵がないと「鍵がかかっている」、鍵を持って調べると鍵が1本減って扉が消える。

1. **扉の見た目を作る**：画像を Hierarchy にドラッグして `扉` と名前を付け、Add Component → **Box Collider 2D**（Is Trigger は**オフ** = 通れない）
2. **ひな形を作る**：右クリック → アイテム連動 > 調べるオブジェクト → 名前を `扉_練習` にして、扉に重なる位置へ。Box Collider 2D の Size を扉より少し大きくする
3. **ルール**：`扉_練習` の ItemInteraction の Rules の1つ目が「鍵を持っている」になっているのを確認する
   - Conditions の Item に鍵（`Assets/Resources/Items/Item_Key`）が入っている／Count = 1
   - Consume Items = オン、Mark Completed = オン
   - Save Id に `Door_Practice` と入れる
4. **成功時**：`成功時` を選び、SetActiveEventAction の **Hide** の ＋ で欄を作り、Hierarchy の `扉` をドラッグ。Dialogue の **Dialogue Text** に「鍵を使って扉を開けた。」
5. **それ以外**：`それ以外` の Dialogue Text に「鍵がかかっている。」
6. **鍵を置く**：3-1 の手順で、鍵の ItemPickup を近くに置く（Pickup Id = `Key_Practice`）
7. **確かめる**：Tools > シーンチェック → 再生 → 鍵を拾わずに扉を調べる → 鍵を拾って Tab（メニュー）> アイテムで鍵を確認 → 扉を調べる → 扉が消え、鍵が減っていれば成功

### 練習 2：長老と話すと岩が消える（フラグ）
**ゴール**：長老と話すとフラグ `TalkedToElder` が ON になり、出口をふさぐ岩が消える。2回目は別のセリフ。

1. **フラグを作る**：Tools > フラグ > 新しいフラグを作成 → `TalkedToElder`（Saved = オン）
2. **長老**：右クリック → アイテム連動 > 調べるオブジェクト → 名前を `長老`
   - Rules の1つ目：**Conditions の行を − で消して空にする**（＝いつでも実行）、Label を「初めて話す」、Mark Completed = オン
   - 成功時：SetActiveEventAction は外す（Remove Component）。Dialogue Text「北の森へ行きなさい」。Add Component → **SetFlagEventAction** → Flags の ＋ → `TalkedToElder` を入れて **Value にチェック** → EventSequence の警告ボタンで登録
   - Hierarchy 右クリックで `長老` の子に空のオブジェクト（Create Empty）を作り `完了後` と名前を付け、**EventSequence** と **DialogueEventAction**・**Dialogue** を付けて Dialogue Text「気をつけてな」。DialogueEventAction の Dialogue に同じオブジェクトの Dialogue をドラッグ。ItemInteraction の **After Completed** にこの `完了後` をドラッグ
   - Otherwise は使わないので、`それ以外` は消してよい
3. **岩**：岩のオブジェクト（Is Trigger オフの Box Collider 2D 付き）を出口に置く
4. **切り替え**：右クリック → フラグ > フラグで切り替え → Flag Conditions に `TalkedToElder`（ON のとき）、**Active When Not Met** に岩
5. **確かめる**：再生 → 岩で通れない → 長老と話す → 岩が消える → もう一度話すと「気をつけてな」
   - **Tools > フラグ > フラグ一覧** で、再生中に `TalkedToElder` を直接 ON / OFF して動きを確かめることもできます

### 練習 3：宝石をはめると、少し待ってから通路が出る（順番・待ち時間）
**ゴール**：像を調べると、音 → 像の画像が変わる → 0.5 秒待つ → 通路が出る → 会話、の順に起きる。その間プレイヤーは動けない。

1. 宝石の ItemData を作り（2-1）、ItemPickup で置く（3-1）
2. 像（SpriteRenderer）と、非表示にした通路のオブジェクトを置く（通路は Inspector の名前の左のチェックを外すと非表示）
3. 右クリック → アイテム連動 > 調べるオブジェクト → `像`。ルールの Item を宝石に変える
4. `成功時` の EventSequence：**Play Mode = 順番に実行**、**Lock Player = オン**。部品を次の順に並べる
   1. SeEventAction（はめ込む音）
   2. SpriteChangeEventAction（Target = 像、Sprite = 光った画像）
   3. WaitEventAction（Seconds = 0.5）
   4. SetActiveEventAction（**Show** に通路。Hide は空）
   5. DialogueEventAction（「どこかで扉が開く音がした……」）
5. **確かめる**：順番どおりに起き、その間動けなければ成功。チェックポイントやシーン移動のあとで戻ってきても、像の画像と通路がそのままなら保存もできています

### 練習 4：手紙を届けるとお礼をもらえる（消費・アイテムを渡す・別の会話）
**ゴール**：手紙を持って NPC に話すと、手紙が減ってお礼の品がもらえる。持っていないと普段の会話。届けたあとは別のセリフ。

1. 手紙とお礼の品の ItemData を作る
2. NPC：調べるオブジェクトのひな形 → ルールの Item を手紙、Consume Items = オン、Mark Completed = オン
3. 成功時：SetActiveEventAction は外す → 会話「ありがとう！」→ **ItemGiveEventAction**（Item = お礼の品）
4. それ以外：普段の会話
5. After Completed：練習 2 と同じ作り方で「手紙、届けてくれてありがとう」
6. **確かめる**：**Tools > デバッグ** の再生中のアイテム欄で、手紙を ＋ してから話しかけると速く確かめられます

### 練習 5：暗い部屋でスイッチを入れると、たいまつが点いて曲が変わる（明かり・SE・BGM）
**ゴール**：暗い部屋でスイッチを調べると、音が鳴ってたいまつが点き、部屋の BGM が変わる。シーンに戻ってきても点いたまま。

1. **部屋を暗くする**：練習用のシーン（`Stage1_2` など、StageDarkness がすでにあるならそれを使う）。なければ 6-2 の手順で StageDarkness を置く
2. **たいまつを置く**：たいまつの画像を置き、Add Component → **LightSource**（6-3 の「たいまつ」の値）。名前を `たいまつ_練習` にして、**Inspector の名前の左のチェックを外して非表示**にする
3. **フラグを作る**：**Tools > フラグ > 新しいフラグを作成** → `TorchLit`（Saved = オン）
4. **スイッチ**：右クリック → アイテム連動 > 調べるオブジェクト → `スイッチ_練習`
   - Rules の1つ目：Conditions を − で空にする、Mark Completed = オン、Save Id = `Torch_Practice`
   - 成功時：SetActiveEventAction の **Show** に `たいまつ_練習`、**SeEventAction**（点火の音）、**SetFlagEventAction**（`TorchLit` を ON）、Dialogue Text「たいまつに火がついた。」。EventSequence の警告ボタンで部品を登録
   - `それ以外` は使わないので消してよい
5. **BGM**：別のオブジェクトに **BgmConditionFlag**（Flag = `TorchLit`）を付け、シーンの SceneBgm の Rules に ＋ → Condition = そのオブジェクト、Clip = 明るい曲、Priority = 10
6. **確かめる**：再生 → 部屋は暗い → スイッチを調べる → 音・明かり・曲が変わる → 出口から別のシーンへ行って戻る → たいまつが点いたまま・曲もそのまま（`TorchLit` がセーブされている）なら成功

> **練習 6〜9 は敵の練習です。** 先に **Tools > 敵 > 共通プレハブとサンプルを作る** を一度押しておいてください。くわしい説明は `Docs/敵の作り方.md` にあります（カッコ内は章の番号）。

### 練習 6：敵を置いて、強さと攻撃を調整する（敵のデータ・敵の一覧・デバッグ）
**ゴール**：自分の敵のデータを作って置き、速さを変え、攻撃の範囲を見ながら直し、再生中に攻撃を出させて確かめる。

1. **データを作る**：**Tools > 敵 > 敵の一覧** →「新しく作る」→ `EnemyData_練習` で保存（サンプルの敵が写される）
2. **置く**：Hierarchy 右クリック > **敵 > 敵を置く** → Enemy の **敵のデータ** に `EnemyData_練習` を入れる（2・3 章）
3. **一覧で調整**：敵の一覧の `EnemyData_練習` の行で、体力を 5、速さを 3 にする
4. **範囲を見る**：置いた敵を選ぶ → Scene ビューにオレンジの円（なぎ払いをする距離）が出る。そのまま Project で `Attack_Sample_なぎ払い` を選ぶ → 敵の位置に赤い扇形が出る。Inspector の **半径** を 3 にして、扇形が広がるのを見る（5 章）
   - サンプルを直したくないときは、攻撃を Ctrl + D で複製してから直し、行動パターンも複製して差し替える
5. **確かめる**：**Tools > デバッグ** の「無敵」をオン → 再生 →「敵」の欄で攻撃の候補から `Attack_Sample_なぎ払い` を選び **攻撃** を押す → 予告のあとに扇形の攻撃が出れば成功（14 章）

### 練習 7：部屋の敵を全部倒すと扉が開く（グループ・倒したことのセーブ）
**ゴール**：3 体の敵を全部倒すと扉が消える。シーンに戻っても扉は開いたまま、敵もいない。

1. **扉**：扉の画像を置き、Box Collider 2D（Is Trigger オフ）を付ける
2. **敵**：練習 6 と同じように 3 体置き、名前を `敵A`・`敵B`・`敵C` にする。3 体とも Enemy の **倒したことをセーブする** をオン
3. **グループ**：Hierarchy で `敵A`→`敵B`→`敵C` の順に Ctrl を押しながら選び、右クリック > **敵 > グループ（全滅・撃破の順番）**（12 章）
4. **扉を開ける**：グループの子の `倒したとき` に **SetActiveEventAction** を付け、**Hide** に扉を入れる。EventSequence の警告ボタンで部品を登録。グループの **1回だけ（セーブする）** がオンになっているのを確かめる
5. **（やってみよう）順番に倒す**：グループの **順番に倒す** をオンにすると、`敵A`→`敵B`→`敵C` の順にしか倒せなくなる（順番でない敵にはバリアが出る）
6. **確かめる**：シーンチェック → 再生 → 3 体倒す → 扉が消える → セーブポイントでセーブするか、出口から別のシーンへ行って戻る → 扉も敵もないなら成功（倒したことは、セーブポイントかシーンの移動で確定します）

### 練習 8：範囲に入ると敵が出てきて、全部倒すとアイテムがもらえる（スポナー）
**ゴール**：広間に入ると敵が 2 体ずつ、合計 4 体出てくる。全部倒すと宝石がもらえる。

1. **スポナー**：Project で `EnemyData_練習`（なければ `EnemyData_Sample`）を選んでから、Hierarchy 右クリック > **敵 > スポナー（敵のデータから出す）**（3-1）
2. 子の **出し始める範囲** の四角を広間の大きさに、**出る場所** を広間の奥に動かす
3. **同時にいる数** = 2、**合計で出す数** = 4、**次を出すまで（秒）** = 2、**ばらつき（半径）** = 1.5、**プレイヤーから離す距離** = 3
4. **ごほうび**：スポナーの子に空のオブジェクト `全部倒したとき` を作り、**EventSequence** と **ItemGiveEventAction**（Item = 宝石）と会話（「宝石を手に入れた」）を付ける。スポナーの **全部出して全部倒したら > 実行するイベント** にドラッグ
5. **確かめる**：再生 → 広間に入ると予告の丸のあとに敵が出る → 倒すと 2 秒後に次が出る → 4 体倒すと宝石がもらえる。デバッグの「敵」でスポナーの出した数が見られます

### 練習 9：倒すとおとなしくなって話せる敵（倒されたあと・倒した後に調べたとき）
**ゴール**：敵を倒すと攻撃しなくなってその場に立ち、調べると話せる。シーンに戻っても立ったまま。

1. **置く**：敵を置き、敵のデータに `EnemyData_Sample_おとなしくなる` を入れる（倒されたあと＝おとなしくなる。7 章）
2. **会話**：敵の子に空のオブジェクト `倒した後の会話` を作り、**EventSequence**・**DialogueEventAction**・**Dialogue**（「……参った。もう戦わない」）を付ける
3. 敵の Enemy の **倒した後に調べたとき** に `倒した後の会話` を、**倒したことをセーブする** をオン、**戻ったときの姿** は「倒されたあとと同じ」のまま
4. **（やってみよう）**：**倒したときのイベント** に会話を入れると、倒した瞬間にしゃべる。**倒したら ON にするフラグ** に GameFlag を入れると、ほかのイベントの条件に使える
5. **確かめる**：再生 → 倒す → 敵が立ったまま攻撃してこない → 近づいて E で会話が出る → シーンを移動して戻っても立っていて、話せれば成功

## 8. 確かめる

### 8-1. シーンチェック（Tools > シーンチェック）
開くとすぐ、今のシーンの設定ミスを一覧にします。**シーンを作り終えたら必ず一度見てください。**

- **エラー**（赤）：直さないと正しく動かない（行き先のシーンがない、ID が重なっている、調べる範囲の Is Trigger がない、自分を非表示にして止まる、など）
- **注意**（黄）：たぶん設定し忘れ（部品が Actions に入っていない、ルールの Sequence が空、など）
- **参考**：問題ないこともある
- 各行の **選択** ボタンで、そのオブジェクトが選ばれます
- **Build Settings の全シーンをチェック** で、ゲームの全シーンをまとめて調べられます

### 8-2. デバッグウィンドウ（Tools > デバッグ）
| 再生中にできること | 使い方 |
|---|---|
| アイテムを増やす・減らす | アイテムの ＋ ／ − |
| フラグを切り替える | チェックを付ける・外す |
| ワープ | 出現位置へ／Scene ビューの中心へ／別のシーンの出現位置へ |
| 全回復・1ダメージ・**無敵** | 無敵はシーンが変わっても続く |
| 今の状態をセーブ | チェックポイントと同じ |
| **2人の状態**（一緒・待機・別行動）・今の体力（ノア／シグル） | 離れ離れの確認に（`Docs/謎解きと2人の仕掛けの作り方.md`） |
| **敵**：敵を止める・歩ける範囲と経路を表示・倒す・**攻撃を出させる**・スポナー／グループ／戦闘エリアの状態 | 新しい作りの敵（`Docs/敵の作り方.md` 14 章） |

**再生開始時の状態**：「再生開始時に、下のアイテムとフラグを与える」をオンにして、個数とフラグを決めておくと、毎回その状態から始まります。**この設定は自分の PC だけ**です。確認が終わったら**オフに戻してください**。

**セーブ**：「ステージから再生するとき」でスロットを選ぶと、ステージから直接再生したときにそのデータを読み、そのデータに保存します（初期値は「使わない」＝保存しない）。各スロットの中身の確認と削除もここでできます。

### 8-3. フラグ一覧（Tools > フラグ > フラグ一覧）
すべてのフラグとメモが一覧になります。再生中は ON / OFF を直接切り替えられます。ID が重なっていると警告が出ます。

### 8-4. 確認のチェックリスト
- [ ] シーンチェックでエラーが出ていない
- [ ] 条件を**満たさないとき**の動きも確かめた
- [ ] 2回目に調べたときの動き（After Completed、または何も起きない）を確かめた
- [ ] 完了したあと、**シーンを出て戻ってきても**見た目が正しい
- [ ] 演出の途中で動き回れてしまわない（必要なら Lock Player）
- [ ] 音（SE・BGM）を付けたなら、実際に鳴るのを聞いた（プレイヤーの音はプレハブを保存した）
- [ ] 出入口を作ったなら、行き・帰りの両方を通って、正しい場所に出ることを確かめた
- [ ] デバッグの「再生開始時の状態」をオフに戻した
- [ ] **Ctrl + S** でシーンを保存した

## 10. 困ったとき

| 困っていること | まず見るところ |
|---|---|
| 調べても何も起きない | 調べる範囲（Box Collider 2D）の **Is Trigger** がオンか／範囲がプレイヤーに届くか／**E キー**を押したか／会話中・メニュー中ではないか |
| 条件を満たしているのに「それ以外」になる | Conditions の Item・Count、Flag Conditions の State／Rules の順番（上のルールが先に実行される）／もう完了していないか（After Completed になる） |
| 会話が出ない | DialogueEventAction の **Dialogue** が空でないか／Dialogue に会話（Dialogue Data か Dialogue Text）が入っているか／シーンに **DialogueSystem.prefab** があるか |
| 途中の部品が動かない | 部品が **Actions に登録**されているか（黄色い警告）／Hide に自分や親を入れていないか（シーンチェックで分かる）／Play Mode |
| 会話の後ろの部品が、会話の前に動いてしまう（または逆） | Play Mode が「順番に実行」か／DialogueEventAction の Wait Until Closed |
| 拾ったものがシーンに戻ると復活する／完了が消える | Pickup Id・Save Id が空で、**オブジェクトの名前や親を変えた**（名前で記録しているため） → ID を入れる |
| 2つの同じものが、片方を拾うと両方消える | Pickup Id（Save Id）が重なっている → シーンチェックで分かる |
| アイテムがアイテム画面に出ない／セーブから戻らない | ItemData が `Assets/Resources/Items/` の外にある |
| 再生を止めたら設定が戻った | 再生中に変えた設定は戻る。止めてから設定し直す |
| 音が鳴らない・BGM が変わらない | 5-7 の表 |
| 暗くならない・明かりがおかしい | 6-5 の表 |
| 出入口で移動しない・違う場所に出る | 3-6 の最後の表 |
| エラーが出た | Console の赤い行をダブルクリックすると、関係する場所が開く。分からなければ、**赤い行の文章をそのまま**プログラマーに送る |

## 11. やってはいけないこと・注意

- **ItemData は `Assets/Resources/Items/` の外に置かない。**
- **Id（アイテム・フラグ）を後から変えない。** 古いセーブのそのアイテム・フラグが消えます。
- **Pickup Id / Save Id を入れずに、名前や親を変えない。** 拾った・完了した記録がリセットされます。
- **中身（EventSequence）のオブジェクトやその親を Hide に入れない。**
- **切り替えの部品を付けたオブジェクト自身を、切り替えのリストに入れない。**
- **Sprite Animator と Animator を一緒に付けない。**
- **Tools の「〜を作成」で、タイトル・メニュー・アイテム画面を勝手に作り直さない。**
- **古いシーン（Stage1・Stage2・SampleScene・kari）で作業しない。**
- **プレイヤー（ノア・シグル）の設定はシーンではなくプレハブに。** 設定したらプレハブを保存する。
- **出現位置を出口に重ねない。**（着いてすぐ元のシーンに戻る）
- 作業の最後に **シーンチェック → 保存（Ctrl + S）**。
- セーブが確定するのは、**シーンに着いたとき・シーンを出るとき・セーブポイント・チェックポイント**です。その前にタイトルに戻ると、拾ったものは失われます（不具合ではありません）。
