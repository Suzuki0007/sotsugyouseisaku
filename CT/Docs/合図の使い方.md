# 合図の使い方

「ペグが締まった」「スイッチを押した」「戦闘が始まった」のような**出来事**に名前（合図）を付けて、
それを受けた側が「イベントを動かす」「フラグを立てる」「相棒の一言を出す」ようにする仕組みです。
**コードを書かずに、出来事どうしをつなげられます。**

- **合図**：Project ウィンドウで右クリック → **Create > 合図 > 合図**（置き場所は `Assets/Data/Signals/`）。フラグと同じように、アセットをドラッグして使う（名前の打ち間違いが起きない）。
- 合図は「その瞬間に起きたこと」を伝えるだけで、**セーブはしない**。状態を残したいときは、受けた側でフラグを立てる。

## 合図を出す
| 出し方 | 使うとき |
|---|---|
| イベントの部品 **合図を出す**（EventSequence の「＋ 部品を追加」→ 進行 → 合図を出す） | 会話のあと・仕掛けを解いたときなど、自分で決めた出来事を知らせる。「数」は受ける側で使うときだけ |
| **標準の合図**（ゲームが自動で出す） | ペグ・調律・守り・アイテム・敵・戦闘・ダメージなど。`Assets/Data/Signals/標準/` にある合図を受ける側に入れるだけ（一覧は「合図を受けたら」と同じフォルダの説明、または早見表） |

## 合図を受ける：「合図を受けたら」
Hierarchy で右クリック → **合図 > 合図を受けたら**。子に「反応したとき」（EventSequence）ができる。

「反応」を並べる（上から順に見て、合う物は全部反応する）。

| 項目 | 説明 |
|---|---|
| メモ | 見分けるための名前 |
| 合図 | この合図が来たら反応する |
| 送り元 | どこから来ても／このオブジェクトか、その子から来たときだけ／決めた物（とその子）から来たときだけ。**部屋ごとに分けたいとき**（この部屋のペグが締まったときだけ、など）に使う |
| 条件 | この条件を満たしているときだけ（フラグ・アイテム・操作キャラ・2人の状態など。空ならいつも） |
| 何回まで | シーンに来てから反応する回数（0＝何度でも）。ゲームの中で1回だけにしたいときは、反応でフラグを立てて条件に入れる |
| 次に反応できるまで | 一度反応したら、この秒数は反応しない |
| 遅らせる | 合図が来てから、この秒数たってから反応する |
| 実行するイベント | 反応したときに動かす EventSequence |
| 立てるフラグ・フラグを ON にする | 反応したときにフラグを設定する |
| 相棒の一言 | 反応したときに出す一言（BarkData） |

- 「合図を受けたら」のオブジェクトが**表示されている間だけ**受ける。部屋ごと非表示にすれば止まる。
- 合図を受けて合図を出す、が続きすぎると止まる（同じ合図を出し直す間違いに気づけるように、コンソールに出る）。

## 確かめる
- **Tools > デバッグ > 合図（記録・試しに送る）**（再生中）：最近の合図（時刻・合図・出した物・反応した数）と、合図を試しに送るボタン。
- 反応しないときは：合図が同じアセットか／送り元の絞り込み／条件／何回まで・次に反応できるまで／「合図を受けたら」が表示されているか、を見る。

## 例
**ペグが3つ締まったら扉を開ける**（標準の合図を使う）：「合図を受けたら」→ 合図 `ペグが締まった`、送り元 `決めた物`＝その部屋のティンパニ、何回まで 0 → 実行するイベントで「数を数える」代わりに、仕掛けの状態（GimmickState）を1つ進める部品を入れ、扉の GimmickReaction の条件を「3以上」にする。

**会話のあとに BGM を変える**：会話のイベントの最後に部品「合図を出す」（`会話が終わった`）→「合図を受けたら」でフラグを立て、BGM のルールの条件にそのフラグを入れる。
