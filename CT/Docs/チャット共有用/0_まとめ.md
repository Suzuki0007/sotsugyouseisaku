時点：2026-11-21。実装は Claude Code（Code タブ）が担当。**この資料は自動では新しくならない**ので、大きく進んだら作り直して入れ直す。

## 1. どんなゲームか

- 2D トップダウンのアクション／探索ゲーム。Unity 6.5（6000.5.4f1）・URP 2D。
- 主人公は **ノア（Noah）** と **シグル（Sigle）**。C キーで操作を切り替え、F キーで相棒を待たせる・呼び戻す（シグルが仲間になってから）。
- **ノアは音が聞こえない**。演出は「光・揺れ・震え・吹き出し（音名など）」で見せる（音はプレイヤー向けに鳴らしてよい）。
- 舞台は音楽・楽器の仕掛けのある塔。師匠カイロスの手紙をきっかけにノアが島へ渡る。
- 開発の目標：**プランナーがコードを書かずに Inspector だけで制作を進められる**こと。

## 2. キャラと会話の方針（決まっていること）

- **ノア**：一人称「ボク」。最初はシグルに好意的だが、ムッとしたり不審に思ったりもする。
- **シグル**：一人称「俺」、ていねい語なし、ぶっきらぼう。お面をかぶっている（「顔色」ではなく「肩で息してる」など、表情・顔色の表現は使わない）。ノアを助けたときに力を使って、実は調子が悪いのを隠している。裏ではやさしい（ヒントをくれる・「気をつけろよ」）。
- 2人の関係は **バディものの、まだ仲良くなっていない最初の段階**。これからお互いを知り、認め合っていく。今の時点で「認める」場面はまだ入れない。
- カイロス＝ノアの**師匠**。
- 間は「、、」で書く。
- 世界観・物語の流れ・キャラの詳しい設定は `1_シナリオと設定.md`、会話の全文は `2_会話の全文.md`（どちらもこのフォルダ）。

## 4. まだないもの・決めていないこと

- T字通路の**西の部屋・東の部屋**（中身・成果の条件）。
- ランプが 2 つとも点いたあとの、**扉を開ける大なぞ**。
- **合流**（シグルが仲間になる）をどこで起こすか。合流のあとはシグルを操作でき、ボス戦は 2 人の前提。
- ボス戦へのつながり。ボスの先（台本 F1_13・二層）のシーン。
- 本番の素材（絵・音）。素材の一覧は `Docs/素材チェックリスト.xlsx`。シグルの後ろ向きの絵、立ち絵の表情差分もまだない。

## 6. 気をつけていること（既知の問題・高い物）

- T字通路の先がないので、ボス戦へ進めない。合流のフラグ `Flag_Sigle_Joined` を立てる場面もない。
- ゲームオーバーのリトライは「シーンに着いた位置」から。入口に戻れなくなる場面のあとで倒れる場面を作ると進めなくなるおそれ。
- 提出前に消すファイルがある（使っていない敵の行動のクラス。名前が不適切）。

## 7. チームと作業の約束

- 作業はすべて日本語。
- ほかのメンバー（成田さん・鈴木さん）が書いたコードは勝手に直さない。直したときはコミットメッセージに説明を書く。
- コミット・push は本人が Fork で行う（Claude からはしない）。
- 外部の AI（MUSE.AI）が指示書を書き、Claude Code が実装する流れ。指示書の決まりは `Docs/MUSE向け/1_指示書を書くときの決まり.md`。
