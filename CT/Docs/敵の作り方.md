# 敵の作り方（プランナー向け）

最終更新：2026-11-08（段階4：追跡と逃げる戦闘 まで）

敵の仕組みは段階ごとに作っています。**今できるのは「敵の種類を作る・置く・動き方と攻撃（落下・突き出る・爆弾・弾幕を含む）を決める・仲間を呼ぶ・見つけたら追いかける・効く攻撃を決める・見えない敵を置く・ギミックと連動させる・追跡イベントや逃げる戦闘を作る・確かめる」まで**です。
部位・ひるみ・見た目の変化、倒した後の処理、グループ・撃破の順番などは、これからの段階で書き足していきます。

> 今までの敵（`Assets/Prefab/Enemies/Enemy.prefab`、スポナーで出るもの）は、そのまま動きます。
> 同じ動きの新しい敵（壁を回り込む）は、サンプルの「撃つ敵」です（7 章）。

**まず触ってみる**：Tools > 敵 > **サンプルを作る** → Hierarchy 右クリック > 敵 > **敵を置く** → 置いた敵の「敵のデータ」に `Assets/Data/Enemies/Sample/` の EnemyData を入れて再生。

---

## 1. 全体の考え方

| もの | 何か | 置き場所 |
|---|---|---|
| **敵のデータ（EnemyData）** | 敵1種類分の設定（体力・速さ・見た目・**行動パターン**・**効き方**・倒されたときの演出） | `Assets/Data/Enemies/` |
| **行動パターン（EnemyPattern）** | いつ・どこへ動き、いつ攻撃するか。段階（第1形態・第2形態）に分けられる | `Assets/Data/Enemies/`（Patterns など） |
| **攻撃（AttackData）** | 攻撃1つ分。予告（範囲を見せる）→ 発動 → 後隙 | `Assets/Data/Enemies/`（Attacks など） |
| **共通プレハブ（Enemy_Base）** | すべての敵の元になる入れ物。データを入れると、その敵になる | `Assets/Resources/Enemies/Enemy_Base.prefab` |
| **シーンに置いた敵** | 共通プレハブを置いて、データを入れたもの。巡回ポイントはここに入れる | 各シーン |

```
敵のデータ ──→ 行動パターン ──→ 段階 ──→ 行動（待つ・近づく・離れる・巡回・ランダムに歩く・攻撃する）
                                                                              └──→ 攻撃（AttackData）
```

**敵を増やす = データを1つ作る**です。プレハブを複製する必要はありません。行動パターンと攻撃は、いろいろな敵で使い回せます。

## 2. 敵の種類を作る（EnemyData）

1. Project で `Assets/Data/Enemies/Sample/EnemyData_Sample` を選び、**Ctrl + D** で複製します。
   （新しく作るときは、Project の右クリック > **Create > 敵 > 敵のデータ**）
2. 名前を変えて、`Assets/Data/Enemies/` に移します（例：`EnemyData_コウモリ`）。
3. Inspector で項目を決めます。

| 項目 | 意味 | 目安 |
|---|---|---|
| **名前** | 一覧やデバッグで出る名前 | |
| **最大の体力** | この回数分ダメージを受けると倒れる | ノアの範囲攻撃 1 回 = 1 ダメージ |
| **移動の速さ** | 1 秒に進む距離（マス） | プレイヤーは 5 |
| **大きさ** | 小・中・大。**大きい敵は細い通路を通れない** | ボスは「大」にすると広間から出てこない |
| **押されにくい** | オンならプレイヤーがぶつかっても動かない | |
| **行動パターン** | 4 章で作る EnemyPattern。空ならその場に立っているだけ | |
| **受けるダメージの効き方** | 6 章 | 空なら全部等倍 |
| **ぶつかったときのダメージ** | プレイヤーに触れたときのダメージ。0 なら何もない | |
| **ダメージの間隔（秒）** | 触れ続けたとき、何秒ごとにダメージか | 1 |
| **アニメーション** | SpriteAnimData。`Idle`（待機）・`Walk`（移動）・`Damage`（ダメージ）・`Dead`（倒れる）の名前の動きを自動で使う | なければ空でよい |
| **絵（アニメがないとき）** | アニメが空のときの絵 | |
| **エフェクト / SE**（倒されたとき） | 消える瞬間のエフェクト、倒された瞬間の音 | |
| **死亡アニメの名前** | この名前の動きを流し終わってから消える | `Dead` |
| **メモ** | 自分用のメモ（ゲームには影響しない） | |

> 体力・2人の体力について：敵の攻撃がシグルに当たると、**ノアの体力（2人で共有）**が減ります。

## 3. 敵を置く

1. Hierarchy で右クリック > **敵 > 敵を置く**（Scene ビューの真ん中に置かれます）。
   または `Assets/Resources/Enemies/Enemy_Base` を Scene にドラッグします。
2. 置いた敵を選び、Inspector の **Enemy > 敵のデータ** に、2 で作った EnemyData を入れます。
3. 位置を動かして、**シーンを保存**します。

- **スポナーは要りません。** 置くだけで、操作中のキャラを自分で見つけます。
- 置いた敵の **EnemyBrain** で、その敵だけの設定ができます。

| 項目 | 意味 |
|---|---|
| **行動パターンを差し替える** | 空なら敵のデータの行動パターン。この敵だけ違う動きにしたいときに入れる |
| **Patrol Points（巡回ポイント）** | 「巡回する」で上から順に回る場所。空のオブジェクトを置いてドラッグで入れる（選ぶと緑の線で見える） |
| **動き出す距離** | プレイヤーがこの距離まで近づいたら動き出す（黄色の円）。0 なら最初から |

- スポナー（`EnemySpawner`）から出したいときは、スポナーの **Spawn Object** に Enemy_Base（またはそれを元にしたプレハブ）を入れます。
- 敵は壁で止まり、マップ（地面の Tilemap）の外には出ません。

## 4. 動き方を決める（行動パターン）

1. Project の右クリック > **Create > 敵 > 行動パターン**（またはサンプルを Ctrl + D で複製）。
2. Inspector で、段階の中に**行動**を並べます。「**＋**」を押すと行動の種類を選べます。つまんで並べ替えられます。
3. 敵のデータの「行動パターン」に入れます。

### 4-1. 行動の種類

| 行動 | すること | 主な項目 |
|---|---|---|
| **待つ** | その場で止まる | 最短・最長（秒）。違う値ならランダム |
| **移動 > 近づく** | プレイヤーに近づく（壁は回り込む） | ここまで近づく・最長の時間・速さの倍率 |
| **移動 > 離れる** | プレイヤーから離れる（行き止まりには逃げない） | ここまで離れる・最長の時間 |
| **移動 > 巡回する** | 巡回ポイント（3 章）を順に回る | 全部のポイントを回る・ポイントで待つ |
| **移動 > ランダムに歩く** | 最初にいた場所のまわりを歩く | 範囲（半径）・回数 |
| **移動 > 追いかける（見失ったら探す）** | 見えている間は追いかけ、見失ったら最後に見た場所へ行って探す。見つからなければあきらめて次の行動へ | 追いかけ中に見える距離・探す時間・ここまで近づいたら終わる・近いとき／遠いときの速さ・見つけたときのエフェクトと SE |
| **攻撃する** | 攻撃（5 章）を出す | 攻撃・回数・間隔 |
| **仲間を呼ぶ** | 敵を呼び出す（4-3） | 呼ぶ敵・数・同時にいられる数・出る場所 |

どの行動にも、次の項目があります。

| 項目 | 意味 |
|---|---|
| **この行動をする距離** | 「プレイヤーがこの距離より近いとき／遠いとき」だけする。満たさないときは飛ばして次の行動へ |
| **この行動をする見え方・見える距離** | 「プレイヤーが見えているとき／見えていないとき」だけする。**間に壁があると見えない**（隠れてやり過ごせる） |
| **重み** | 選び方が「重みつきランダム」のときの選ばれやすさ |

> 例：「近づく」→「攻撃する（近いときだけ）」→「待つ」。遠いと攻撃を飛ばすので、近づいてから殴る敵になります。
> 例（見張り）：「追いかける（見えているとき）」→「攻撃する（近いとき）」→「巡回する（見えていないとき）」。壁の陰に隠れると、探したあと巡回に戻ります。

### 4-3. 仲間を呼ぶ

| 項目 | 意味 |
|---|---|
| **呼ぶ敵** | 出てくる敵のデータ |
| **1回に呼ぶ数・同時にいられる数** | 呼んだ仲間が「同時にいられる数」以上いるときは、この行動を飛ばす |
| **出る場所** | 自分のまわり／プレイヤーのまわり／**自分のまわりに卵を置く**（時間でかえる。かえる前に攻撃すれば壊せる） |
| **距離** | 出る場所の中心からの距離 |
| **予告の時間・色** | 出る場所に丸を見せてから出す |
| **卵がかえるまで・卵の体力・卵の絵** | 卵のとき |
| **出たときのエフェクト・SE・呼ぶときのアニメ** | |

- 敵のデータの「**倒されたら呼んだ仲間も消す**」（初期値オン）で、呼んだ敵を倒すと仲間も一緒に倒れます。

### 4-2. 段階（第1形態・第2形態）

| 項目 | 意味 |
|---|---|
| **段階の名前** | デバッグに出る名前 |
| **行動の選び方** | 上から順番に／ランダム／重みつきランダム |
| **次の段階へ進む条件** | 進まない／体力がこの割合以下／○秒経ったら／条件（フラグ・アイテム・操作中のキャラ・体力）を満たしたら |
| **進むとき今の行動をやめる** | オン：攻撃の途中でもやめて次へ（予告も消える）。オフ：今の行動が終わってから |
| **この段階に入ったとき** | エフェクト・SE・アニメ・止まる時間（変身の演出） |

- 段階は**上から順に進み、戻りません**。「＋段階を追加」で足し、▲で並べ替えます。
- 例：段階1「通常」（体力 50% 以下で次へ）→ 段階2「怒り」（攻撃を増やしてランダムに）。

## 5. 攻撃を作る（AttackData）

1. Project の右クリック > **Create > 敵 > 攻撃**（またはサンプルを複製）。
2. Inspector で決めます。**選んだ設定で使わない項目は隠れます**。
3. 行動パターンの「攻撃する」に入れます。

攻撃は **予告（範囲を見せる）→ 発動（当たる）→ 後隙（攻撃のあとの、反撃できる時間）** の順に進みます。

### 5-1. 予告

| 項目 | 意味 |
|---|---|
| **予告の時間** | 範囲を見せてから発動するまで。0 なら予告なしですぐ |
| **範囲を表示する** | オフにすると、時間は待つが範囲は見せない（見えない攻撃） |
| **描き方・色** | 塗りと枠／塗りだけ／枠だけ。色の A（透明度）で薄さ |
| **満ちていく表示** | 発動までの時間に合わせて内側から色が満ちる |
| **点滅させる** | 発動の直前に点滅 |
| **描く順番** | 3 なら「床の上・物やキャラの下」。大きいほど手前 |
| **暗い所でも見える** | オンなら暗いステージでも明るさが変わらない（おすすめ） |
| **予告の SE・予告中の敵のアニメ** | 構えの音・動き（アニメの名前。なければ何もしない） |

### 5-2. 出る場所と形

| 項目 | 選べるもの |
|---|---|
| **起点** | 敵の位置／プレイヤーの位置（予告を出した時点で決める＝動けば避けられる）／プレイヤーの位置（予告の間は追いかける） |
| **向き** | プレイヤーの方向／敵の向いている方向／決まった角度 |
| **予告の間は向きを合わせ続ける** | オン：発動の瞬間まで狙い続ける（ビーム向き）。オフ：最初の向きのまま（避けやすい） |
| **前にずらす距離** | 敵の体の外から出したいとき |
| **範囲の形** | 円（半径）／長方形（長さ・幅。ビーム・突進）／扇形（半径・角度）／リング（外側と内側の半径。内側は安全） |
| **長方形の長さを壁で止める** | ビーム・突進が壁を突き抜けない（予告も短くなる） |

**予告の形と当たる範囲は同じ**です（見た目どおりに当たります）。

### 5-3. 発動

| 発動のしかた | 動き | 主な項目 |
|---|---|---|
| **一瞬** | その瞬間に範囲の中に当たる | 敵自身の動き（下） |
| **出し続ける** | 範囲が残り、入っていると当たり続ける（ビーム） | 出し続ける時間・当たる間隔・回る速さ（なぎ払い） |
| **弾を撃つ** | 弾を撃つ（5-6） | 撃ち方・弾の数・連射・速さ・弾消しで消せるか |
| **上から落ちる** | 予告（影）の最後に上から物が落ちてきて、着地で当たる | 落ちてくる物（プレハブ）・落ちる高さ・落ちる時間 |
| **下から突き出る** | 発動の瞬間に地面から物が出て当たる。残せる | 突き出る物（プレハブ）・残る時間・残っている間も当たる |
| **設置して起爆** | その場に爆弾・罠を置き、置いたら敵は次の行動へ | 置く物・起爆までの時間・触れたら爆発・攻撃されたら爆発・範囲を見せる |

| 敵自身の動き（一瞬のとき） | 動き |
|---|---|
| **その場で止まる** | 動かない |
| **突進する** | 予告の長方形を走る（プレイヤーはすり抜けて当たる）。**壁にぶつかったら気絶（秒）** で反撃のチャンスを作れる。形は長方形にする |

| 共通の項目 | 意味 |
|---|---|
| **ダメージ** | 当たったときのダメージ |
| **当たる相手** | プレイヤー／敵（ほかの敵にも当たる）／両方 |
| **ノアには効かない・シグルには効かない** | オンならそのキャラをすり抜ける（キャラを切り替えて避ける遊びに） |
| **発動のエフェクト・SE・敵のアニメ** | 範囲の真ん中にエフェクト |

- **突き出る物に当たり判定（Collider2D）を付ける**と、残っている間は壁になります（敵の通り道も自動で変わる）。とげの壁で道をふさぐ、などに使えます。
- **爆弾**は「当たる相手：両方」にすると敵も巻き込みます。「攻撃されたら爆発」をオンにすると、ノア・シグルの攻撃で遠くから起爆できます（爆弾で敵を倒す遊びに）。
- 落ちてくる物・突き出る物・置く物のプレハブが空でも動きます（予告と、発動のエフェクトだけになる）。

### 5-6. 弾の撃ち方

| 撃ち方 | 動き | 主な項目 |
|---|---|---|
| **狙い撃ち** | 向き（プレイヤーなど）に撃つ。数を増やすと扇状 | 弾の数・広がり |
| **全方位** | ぐるっと一周に並べて撃つ | 弾の数 |
| **うず巻き** | 一周に並べ、撃つたびに回す | 弾の数・撃つたびに回す角度（向きは「決まった角度」がおすすめ） |
| **ばらまき** | 広がりの中のランダムな方向 | 弾の数・広がり |

- **連射の回数と間隔**で、何回撃つかを決めます。
- **弾の速さ**（0 なら弾のまま）・**ダメージ**・**ノア／シグルには効かない**・**弾消しで消せる**（オフでノアの Q で消えない弾）は、攻撃ごとに変えられます。弾の見た目はシーンの「敵の弾のプール」の弾です。

### 5-4. 後隙
- **後隙（秒）**：攻撃が終わってから次の行動までの時間。長いほど反撃しやすい。

### 5-5. 組み合わせの例（サンプルにあります）

| 攻撃 | 起点 | 形 | 発動 | 動き |
|---|---|---|---|---|
| なぎ払い | 敵 | 扇形 120° | 一瞬 | その場 |
| 突進 | 敵 | 長方形 7×1.2 | 一瞬 | 突進（壁で気絶 1 秒） |
| ビーム | 敵 | 長方形 10×0.8 | 出し続ける 1.5 秒 | その場（予告中は狙い続ける） |
| 足元の爆発 | プレイヤー（予告時） | 円 | 一瞬 | その場（点滅） |
| リング | 敵 | リング | 一瞬 | その場（敵の近くが安全） |
| 狙い撃ち | 敵 | － | 弾 6 連射 | その場（今までの敵と同じ） |
| 落石 | プレイヤー（予告時） | 円 | 上から落ちる | 影を見て避ける |
| とげ（下から） | プレイヤー（予告時） | 円 | 下から突き出る（1 秒残る） | |
| 腕（下から伸びる） | プレイヤー（予告時） | 縦の長方形 | 下から突き出る（残っている間も当たる） | 見えない敵用 |
| 爆弾 | 敵 | 円 | 設置して起爆（3 秒・触れる・攻撃される） | 敵も巻き込む |
| 全方位弾 | 敵 | － | 弾 12 方向 × 3 回 | |
| うず巻き弾 | 敵 | － | 弾 4 方向 × 24 回、回る（弾消しで消えない） | |
| 電気の床（敵に当たる） | 敵（＝出す場所） | 円 | 出し続ける 3 秒 | ギミックの「ダメージエリアを出す」用 |

## 6. 効く攻撃を決める（受けるダメージの効き方）

敵のデータの「**受けるダメージの効き方**」に行を足します。当てはまる行の倍率を**全部かけます**。

| 項目 | 意味 |
|---|---|
| **攻撃の種類** | すべて／ノアの範囲攻撃／ノアのゲージ攻撃／シグルの弾／体当たり／爆発／ギミック など |
| **攻撃したキャラ** | 問わない／ノア／シグル／プレイヤー以外（敵・ギミック） |
| **倍率** | 2 なら2倍、0.5 なら半分、**0 なら効かない** |
| **ゲージの判定** | ゲージ攻撃のとき、パーフェクト／グッド／ミスで絞る |

例：
- 「シグルの弾 ×0.5」＋「ゲージ攻撃・パーフェクト ×2」（サンプルの砲台）
- 「すべての攻撃 ×0」＋「ギミック ×1」＝ギミックでしか倒せない敵
- 「攻撃したキャラ：ノア ×0」＝シグルでしか倒せない敵

> 倍率をかけた結果が小数のときは四捨五入します（0 より大きければ最低 1）。

## 7. サンプル（Tools > 敵 > サンプルを作る）

`Assets/Data/Enemies/Sample/` に作られます（すでにあるものは上書きしません）。

| 敵のデータ | 動き |
|---|---|
| EnemyData_Sample（サンプルの敵） | 近づいて、近ければなぎ払う |
| EnemyData_Sample_突進 | 少し待って、プレイヤーに向かって突進。壁にぶつかると気絶 |
| EnemyData_Sample_砲台 | 動かない大きな敵。ビーム → 体力が半分で「怒り」（ビーム・リング・足元の爆発をランダムに）。シグルの弾は半分、ゲージのパーフェクトは2倍 |
| EnemyData_Sample_撃つ | **今までの敵と同じ動き**（6 発撃ってから 3 秒近づく）。壁は回り込む |
| EnemyData_Sample_巡回 | 遠いときは巡回、5 マス以内なら近づいてなぎ払う（敵の EnemyBrain に巡回ポイントを入れる） |
| EnemyData_Sample_爆弾魔 | 近づいて爆弾を置き、離れる |
| EnemyData_Sample_弾幕 | 動かない。全方位弾 → うず巻き弾 |
| EnemyData_Sample_呼ぶ | 仲間（サンプルの敵）を2体 → 卵を1つ。同時に 3 体まで。倒すと仲間も倒れる |
| EnemyData_Sample_追跡者 | 見えている間は追いかけ、見失ったら 3 秒探す（近いと少し遅く、遠いと速い）。倒せない前提。**戦闘エリア（10 章）と組み合わせて追跡イベントにする** |
| EnemyData_Sample_見張り | 見えないときは巡回、見つけたら追いかけてなぎ払う（EnemyBrain に巡回ポイントを入れる） |
| （行動パターン）Pattern_Sample_見えない敵（足元から腕） | **攻撃の発生源**（8 章）に入れて使う。段階「強い」（腕ととげ）→ 命令で「弱い」（とげだけ、間隔が長い） |

## 8. 攻撃だけが襲ってくる（攻撃の発生源＝見えない敵）

体のない敵です。腕だけ・攻撃だけが襲ってくる場面、避けながら進む・避けながらギミックを解く場面に使います。

1. Hierarchy で右クリック > **敵 > 攻撃の発生源（見えない敵）**。子に「動く範囲」（Is Trigger の四角）が付いてきます。
2. **行動パターン**を入れます（例：`Pattern_Sample_見えない敵（足元から腕）`）。体がないので、行動は「待つ」「攻撃する」「仲間を呼ぶ」だけが動きます（移動は飛ばす）。
3. 「動く範囲」の四角の大きさを合わせます。**プレイヤーがこの中にいる間だけ**攻撃してきます。

| 項目 | 意味 |
|---|---|
| **行動パターン** | 攻撃の並び。段階を使うと、ギミックを解くたびに弱くできる |
| **最初から動く** | オフにすると、ギミックの「敵に命令：動かす」まで止まっている |
| **動く条件** | 満たしている間だけ動く（フラグ・アイテム・操作中のキャラ・体力・**プレイヤーがいる範囲**） |

- 攻撃の起点が「敵の位置」なら発生源の位置から、「プレイヤーの位置」ならプレイヤーの足元に出ます。向き「敵の向いている方向」は、発生源の右向き（回転で変えられる）。
- 例：**腕が襲ってくる** ＝ 起点：プレイヤー（予告時）、発動：下から突き出る、突き出る物：腕の絵のプレハブ。
- Scene ビューではピンクの丸と、動く範囲の色付きの四角で見えます。

## 9. ギミックと連動させる

### 9-1. ギミック → 敵（イベントの部品）

ItemInteraction（調べる）・EventZone（エリアに入る）などの EventSequence に、ほかの部品と同じように **Add Component** で付けます。

| 部品 | できること | 主な項目 |
|---|---|---|
| **EnemyCommandEventAction（敵に命令）** | 敵・攻撃の発生源に命令する | 相手（敵・攻撃の発生源のリスト）、命令（止める／○秒だけ止める／動かす／今の行動をやめさせる／段階を変える／倒す／消す）、秒数、段階の番号（1 から）、止まっている間の色、エフェクト・SE |
| **EnemyDamageEventAction（敵にダメージ）** | 敵（または敵の一部分）にダメージ | 相手、ダメージ、攻撃の種類（初期値「ギミック」）、エフェクト・SE |
| **DamageAreaEventAction（ダメージエリアを出す）** | 攻撃のデータを、指定した場所から出す | 攻撃、出す場所、回数・間隔、終わるまで次の部品を待たせる |

- **止める**と、敵は動き・攻撃・体当たりが止まり、色が変わります（止まっている間の色）。
- **段階を変える**で、攻撃の発生源を「弱い」段階に切り替えれば、ギミックを解くたびに攻撃が弱くなります。
- 「ダメージエリアを出す」で、攻撃の「当たる相手」を**敵**にすると、敵にだけ効くエリアになります（例：仕掛けを動かすと床に電気、そこに敵を誘い込む）。ずっと出しておきたいときは、攻撃の発生源を置いて「敵に命令：動かす／止める」で切り替えます。
- セーブから戻ったとき（ItemInteraction の完了の復元）は、ずっと続く命令（止める・動かす・段階・倒す・消す）だけがやり直されます。

### 9-2. 敵・プレイヤーの攻撃 → ギミック（攻撃で作動するスイッチ）

1. Hierarchy で右クリック > **敵 > 攻撃で作動するスイッチ**（当たり判定・EventSequence 付き）。
2. 絵を付け、**反応する攻撃**を決め、EventSequence に部品（扉が開く・敵に命令 など）を付けます。

| 項目 | 意味 |
|---|---|
| **攻撃の種類・攻撃したキャラ・ゲージの判定** | 反応する攻撃。例：シグルの弾だけ／プレイヤー以外（敵の攻撃だけ）／ゲージのパーフェクトだけ |
| **作動までの回数** | 条件に合う攻撃がこの回数当たったら作動 |
| **実行するイベント** | 作動したときの EventSequence |
| **1回だけ・セーブ用の ID** | 1回だけなら作動したことをセーブ（シーンに戻ると作動後の見た目） |
| **当たったときのエフェクト・SE／効かない攻撃のエフェクト** | 条件に合わない攻撃が当たったときの「これでは駄目」の合図 |

- ノアの範囲攻撃・シグルの弾・敵の攻撃・敵の弾・爆弾など、**どの攻撃も当たります**（反応するかは条件で決まる）。
- 例：**シグルの弾でしか作動しない的**／**敵の突進を当てると壊れる柱**（攻撃したキャラ：プレイヤー以外）／**爆弾で壊れる岩**（攻撃の種類：爆発）。

## 10. 追いかけられるイベント・逃げる戦闘（戦闘エリア）

戦闘の「始まり方」「勝ち方」「負け方」を組み合わせて作ります。

1. Hierarchy で右クリック > **敵 > 戦闘エリア（追跡・逃げる戦闘）**。次が一緒にできます：入ると始まる四角（Is Trigger）、**ゴール**（緑）、**やり直す位置**（青の丸）、イベントの「始まったとき」「勝ったとき」「負けたとき」。
2. **参加する敵**に、追いかけてくる敵（例：敵のデータ＝追跡者）を入れます。攻撃の発生源も入れられます。
3. 勝ち方・負け方を決め、ゴールとやり直す位置を動かします。

| 項目 | 選べるもの |
|---|---|
| **始まり方** | エリアに入ったら／イベントの部品から（会話のあとなど）／シーンが始まったら |
| **始まるまで敵を止めておく** | オンなら、参加する敵・攻撃の発生源は始まるまで動かない |
| **勝ち方** | なし（イベントの部品で終える）／**敵を全部倒す**／**○秒生き残る**／**ゴールに着く**／**フラグが立つ**（ギミックを解く） |
| **負け方** | なし（体力がなくなったらいつものゲームオーバー）／**捕まる**（参加する敵が「捕まる距離」まで近づく）／**時間切れ** |
| **負けたとき** | **やり直す**（暗転して、戦闘が始まったときの状態に戻り、やり直す位置から始め直す）／ダメージを受けて続ける／ゲームオーバー／戦闘を終えて「負けたとき」のイベントだけ |
| **やり直したあと敵が止まる時間** | やり直し・ダメージのあと、すぐまた捕まらないように |
| **始まったとき・勝ったとき・負けたとき** | それぞれのイベント（扉を閉める・会話・SE など） |
| **戦闘中にオンにするフラグ** | 戦闘中だけ ON。BGM の BgmConditionFlag で**追跡中の曲**に変えられる（セーブしない一時的なフラグがおすすめ） |
| **目的と残り時間を画面に出す** | 戦闘中、画面の上の帯に「目的・残り時間・残りの敵」を出す（残り 10 秒を切ると赤くなる） |
| **目的の文** | 帯に出す目的。空なら勝ち方から自動（ゴールまで逃げろ／生き残れ／敵を全部倒せ） |
| **始まったとき・勝ったとき・負けたときのメッセージ** | 画面の真ん中に少しの間出す（例：逃げろ！／逃げ切った！／捕まった！）。空なら出さない。やり直すときは、負けたときのメッセージを出してから暗転する |
| **メッセージを出す時間** | 秒数 |
| **勝ったあとの敵** | そのまま／止める／消す |
| **1回だけ・セーブ用の ID** | 勝ったら二度と始まらない（セーブする） |

組み合わせの例：

| 作りたいもの | 始まり方 | 勝ち方 | 負け方 | 負けたとき | 参加する敵の行動 |
|---|---|---|---|---|---|
| 追いかけられるイベント | エリアに入ったら／会話のあと | ゴールに着く | 捕まる | やり直す | 追いかける（追跡者） |
| 逃げるだけの戦闘（30 秒耐える） | エリアに入ったら | ○秒生き残る | なし | － | 攻撃してくる敵・攻撃の発生源 |
| ギミックを解くまで耐える | エリアに入ったら | フラグが立つ | なし | － | 見えない敵（攻撃の発生源） |
| 部屋の敵を全滅させる | エリアに入ったら | 敵を全部倒す | なし | － | ふつうの敵（「始まったとき」で扉を閉め、「勝ったとき」で開ける） |
| 時間内にゴール | エリアに入ったら | ゴールに着く | 時間切れ | やり直す | － |

- 画面の表示の見た目（文字の大きさ・色・位置・帯の色）は `Assets/Resources/UI/BattleHud.prefab` で変えられます（Tools > 敵 > 戦闘の画面表示のプレハブを作る で作り直すと、変えた見た目は消えます）。
- **戦闘中はセーブポイントでセーブできません**（調べると「できない」音が鳴る）。
- **時間は、会話中などは進みません。**
- **やり直すと、戦闘中に起きたことはすべて元に戻ります**：拾った物（拾える物はまた置かれる）、所持品、立てたフラグ（セーブする／しない両方）、調べて開けた扉など、置かれた爆弾、敵の位置。シーンを暗転して読み込み直すためで、**体力は満タン**になります。「負けたとき」のイベント（「捕まった！」の会話など）が終わってから暗転します。
- 会話のあとで始めたいときは、始まり方を「イベントの部品から」にし、会話の EventSequence に **BattleControlEventAction（戦闘エリアを操作）**の「始める」を付けます。ギミックを解いたら勝ち、は「勝ったことにする」でもできます。

## 11. 敵が通れない・通りにくい場所を決める（敵の通行設定エリア）

敵は、壁（当たり判定のあるオブジェクト）を自動でよけて道を探します。**プレイヤーは通れるが、敵だけ入れない場所**を作りたいときに使います。

1. Hierarchy で右クリック > **敵 > 敵の通行設定エリア**。
2. 四角の大きさ（BoxCollider2D の Size）と位置を合わせます。**Is Trigger はオンのまま**にしてください（オフにするとプレイヤーも通れなくなります）。
3. **敵にとってこの場所は** を選びます。

| 選択 | 動き | 使いどころ |
|---|---|---|
| **入れない** | 敵はこの範囲を通らない | 部屋の入口の外までは追ってこない、安全地帯 |
| **通りにくい（できれば避ける）** | 遠回りになっても避ける。どうしても必要なら通る | 毒の床、ぬかるみ |

- Scene ビューでは、入れない = **赤**、通りにくい = **オレンジ**の四角で見えます。
- 扉などの表示を切り替える（SetActive）と、0.5 秒以内に敵の道の探し方に反映されます。何もしなくて大丈夫です。

## 12. 確かめる

**デバッグウィンドウ（Tools > デバッグ）の「敵」**（再生中）：

| 項目 | 使い方 |
|---|---|
| **敵を止める** | 動き・攻撃・体当たりを止める（ゆっくり確認したいとき） |
| **歩ける範囲と敵の経路を表示** | 敵が歩ける範囲を**水色の線**、敵が向かっている道を**黄色の線**で、ゲーム画面に表示 |
| 今いる敵 | 名前・体力・**今の段階と行動**（例「怒り：攻撃する（ビーム）」）。名前を押すと選択、「倒す」「全部倒す」（効き方に関係なく倒せる） |
| 攻撃の発生源 | 名前・今の状態（止まっている理由も）。「止める／動かす」 |
| 戦闘エリア | 戦闘中か（セーブポイント不可）・経過時間・残り時間・残りの敵。「始める」「勝ち」「やめる」（追跡を飛ばして先を確かめるときに） |

**シーンチェック（Tools > シーンチェック）**で見つかるもの：
- 敵のデータが入っていない／行動パターンがない（参考）
- 敵のタグ・レイヤーが Enemies でない（攻撃が当たらない）
- 「巡回する」があるのに巡回ポイントが空
- 行動パターンの「攻撃する」に攻撃が入っていない、行動のない段階、中身が消えた行動
- 突進なのに形が長方形でない
- 「仲間を呼ぶ」に呼ぶ敵が入っていない
- 攻撃の発生源に行動パターンがない／動く範囲の Is Trigger がオフ
- 攻撃で作動するスイッチに「実行するイベント」がない／セーブ用の名前が重なっている
- 「敵に命令」「敵にダメージ」の相手が空、「ダメージエリアを出す」に攻撃がない
- 戦闘エリア：入る四角・ゴールの Is Trigger がオフ、ゴール・フラグ・参加する敵が足りない、セーブ用の名前が重なっている、「戦闘エリアを操作」に戦闘エリアがない
- 敵の通行設定エリアの Is Trigger がオフ

**会話中・イベント中（プレイヤーが動けない間）・メニューを開いている間は、敵も止まります。**

## 13. 困ったとき

| こんなとき | 確かめること |
|---|---|
| 攻撃が当たらない | 敵のタグとレイヤーが **Enemies** か（シーンチェック） |
| 敵がいつまでも倒れない | 敵のデータの「最大の体力」 |
| 触れてもダメージがない | 「ぶつかったときのダメージ」が 0 になっていないか／デバッグの「無敵」がオンになっていないか |
| 敵が変な所を通る・通らない | デバッグの「歩ける範囲を表示」で水色の線を見る。壁に当たり判定（Collider2D）が付いているか |
| 大きい敵が通路に入れない | 「大きさ」が大になっている（細い通路は通れない） |
| 敵が動かない | 敵のデータに行動パターンが入っているか／EnemyBrain の「動き出す距離」／会話中やメニューを開いていないか／デバッグの「敵を止める」 |
| 攻撃が出ない | 「この行動をする距離」の条件を満たしているか（デバッグで今の行動を見る）／「攻撃する」に攻撃が入っているか |
| 攻撃が当たらない（敵の攻撃） | 「当たる相手」がプレイヤーか／「ノアには効かない」などがオンになっていないか／デバッグの「無敵」 |
| 予告が見えない | 「範囲を表示する」・予告の時間・色の A（透明度）・描く順番（大きくすると手前に出る） |
| 弾が出てすぐ消える | 敵が壁のすぐそばにいる（弾は壁に当たると消える） |
| 効かないはずの攻撃が効く／効くはずが効かない | 効き方の行の「攻撃の種類」「攻撃したキャラ」「ゲージの判定」。当てはまる行は全部かけ算 |
| 見えない敵が攻撃してこない | 動く範囲にプレイヤーが入っているか／「最初から動く」／命令で止まっていないか（デバッグで状態を見る）／行動が移動だけになっていないか |
| 仲間が出てこない | 「同時にいられる数」に達している／出る場所が壁の中（歩ける場所がない） |
| 爆弾がすぐ爆発する | 「プレイヤーが触れたら爆発」で、ついてくるシグルが触れている |
| スイッチが反応しない | 反応する攻撃の条件（種類・キャラ・判定）／「1回だけ」で作動済み（セーブ済み） |
| 追いかけてこない | 間に壁があって見えていない（探したあとあきらめる）／「追いかけ中に見える距離」／戦闘エリアの「始まるまで敵を止めておく」で、まだ始まっていない |
| すぐ捕まる・捕まらない | 戦闘エリアの「捕まる距離」と、追いかける行動の「近いとき／遠いときの速さ」（プレイヤーは 5） |
| 追跡が始まらない | 始まり方と、入る四角の Is Trigger／「1回だけ」で勝ち済み（セーブ済み） |
| セーブポイントで何も出ない | 戦闘中（追跡中）はセーブできない |
