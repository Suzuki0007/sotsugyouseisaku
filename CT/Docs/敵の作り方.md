# 敵の作り方（プランナー向け）

最終更新：2026-11-08（段階1：土台まで）

敵の仕組みは段階ごとに作っています。**今できるのは「敵の種類を作る・置く・敵が通れない場所を決める・確かめる」まで**です。
敵の動き方（行動パターン）・攻撃・弱点・倒した後の処理などは、これからの段階で、この手順書に書き足していきます。

> いま置いた敵は、**その場に立っていて、触れるとダメージを与え、攻撃されると倒れる**だけです（動き出すのは次の段階から）。
> 今までの敵（`Assets/Prefab/Enemies/Enemy.prefab`、スポナーで出るもの）は、そのまま動きます。

---

## 1. 全体の考え方

| もの | 何か | 置き場所 |
|---|---|---|
| **敵のデータ（EnemyData）** | 敵1種類分の設定（体力・速さ・見た目・倒されたときの演出） | `Assets/Data/Enemies/` |
| **共通プレハブ（Enemy_Base）** | すべての敵の元になる入れ物。データを入れると、その敵になる | `Assets/Prefab/Enemies/Enemy_Base.prefab` |
| **シーンに置いた敵** | 共通プレハブを置いて、データを入れたもの | 各シーン |

**敵を増やす = データを1つ作る**です。プレハブを複製する必要はありません。

---

## 2. 敵の種類を作る（EnemyData）

1. Project で `Assets/Data/Enemies/Sample/EnemyData_Sample` を選び、**Ctrl + D** で複製します。
   （新しく作るときは、Project の右クリック > **Create > 敵 > 敵のデータ**）
2. 名前を変えて、`Assets/Data/Enemies/` に移します（例：`EnemyData_コウモリ`）。
3. Inspector で項目を決めます。

| 項目 | 意味 | 目安 |
|---|---|---|
| **名前** | 一覧やデバッグで出る名前 | |
| **最大の体力** | この回数分ダメージを受けると倒れる | ノアの範囲攻撃 1 回 = 1 ダメージ |
| **移動の速さ** | 1 秒に進む距離（マス） | プレイヤーは 5 |
| **大きさ** | 小・中・大。**大きい敵は細い通路を通れない** | ボスは「大」にすると広間から出てこない |
| **押されにくい** | オンならプレイヤーがぶつかっても動かない | |
| **ぶつかったときのダメージ** | プレイヤーに触れたときのダメージ。0 なら何もない | |
| **ダメージの間隔（秒）** | 触れ続けたとき、何秒ごとにダメージか | 1 |
| **アニメーション** | SpriteAnimData。`Idle`（待機）・`Walk`（移動）・`Damage`（ダメージ）・`Dead`（倒れる）の名前の動きを自動で使う | なければ空でよい |
| **絵（アニメがないとき）** | アニメが空のときの絵 | |
| **エフェクト / SE**（倒されたとき） | 消える瞬間のエフェクト、倒された瞬間の音 | |
| **死亡アニメの名前** | この名前の動きを流し終わってから消える | `Dead` |
| **メモ** | 自分用のメモ（ゲームには影響しない） | |

> 体力・2人の体力について：敵の攻撃がシグルに当たると、**ノアの体力（2人で共有）**が減ります。

---

## 3. 敵を置く

1. Hierarchy で右クリック > **敵 > 敵を置く**（Scene ビューの真ん中に置かれます）。
   または `Assets/Prefab/Enemies/Enemy_Base` を Scene にドラッグします。
2. 置いた敵を選び、Inspector の **Enemy > 敵のデータ** に、2 で作った EnemyData を入れます。
3. 位置を動かして、**シーンを保存**します。

- **スポナーは要りません。** 置くだけで、操作中のキャラを自分で見つけます。
- スポナー（`EnemySpawner`）から出したいときは、スポナーの **Spawn Object** に Enemy_Base（またはそれを元にしたプレハブ）を入れます。
- 敵は壁で止まり、マップ（地面の Tilemap）の外には出ません。

---

## 4. 敵が通れない・通りにくい場所を決める（敵の通行設定エリア）

敵は、壁（当たり判定のあるオブジェクト）を自動でよけて道を探します。**プレイヤーは通れるが、敵だけ入れない場所**を作りたいときに使います。

1. Hierarchy で右クリック > **敵 > 敵の通行設定エリア**。
2. 四角の大きさ（BoxCollider2D の Size）と位置を合わせます。**Is Trigger はオンのまま**にしてください（オフにするとプレイヤーも通れなくなります）。
3. **敵にとってこの場所は** を選びます。

| 選択 | 動き | 使いどころ |
|---|---|---|
| **入れない** | 敵はこの範囲を通らない | 部屋の入口の外までは追ってこない、安全地帯 |
| **通りにくい（できれば避ける）** | 遠回りになっても避ける。どうしても必要なら通る | 毒の床、ぬかるみ |

- Scene ビューでは、入れない = **赤**、通りにくい = **オレンジ**の四角で見えます。
- 扉などの表示を切り替える（SetActive）と、0.5 秒以内に敵の道の探し方に反映されます。何もしなくて大丈夫です。

---

## 5. 確かめる

**デバッグウィンドウ（Tools > デバッグ）の「敵」**（再生中）：

| 項目 | 使い方 |
|---|---|
| **敵を止める** | 動き・攻撃・体当たりを止める（ゆっくり確認したいとき） |
| **歩ける範囲と敵の経路を表示** | 敵が歩ける範囲を**水色の線**、敵が向かっている道を**黄色の線**で、ゲーム画面に表示 |
| 今いる敵 | 名前・体力。名前を押すと選択、「倒す」「全部倒す」 |

**シーンチェック（Tools > シーンチェック）**で見つかるもの：
- 敵のデータが入っていない
- 敵のタグ・レイヤーが Enemies でない（攻撃が当たらない）
- 敵の通行設定エリアの Is Trigger がオフ

**会話中・イベント中（プレイヤーが動けない間）・メニューを開いている間は、敵も止まります。**

---

## 6. 困ったとき

| こんなとき | 確かめること |
|---|---|
| 攻撃が当たらない | 敵のタグとレイヤーが **Enemies** か（シーンチェック） |
| 敵がいつまでも倒れない | 敵のデータの「最大の体力」 |
| 触れてもダメージがない | 「ぶつかったときのダメージ」が 0 になっていないか／デバッグの「無敵」がオンになっていないか |
| 敵が変な所を通る・通らない | デバッグの「歩ける範囲を表示」で水色の線を見る。壁に当たり判定（Collider2D）が付いているか |
| 大きい敵が通路に入れない | 「大きさ」が大になっている（細い通路は通れない） |
