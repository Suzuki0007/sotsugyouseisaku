# 敵の作り方（プランナー向け）

最終更新：2026-11-08（段階2：行動パターンと攻撃の基本まで）

敵の仕組みは段階ごとに作っています。**今できるのは「敵の種類を作る・置く・動き方（行動パターン）と攻撃を決める・効く攻撃を決める・確かめる」まで**です。
落下・突き出る・設置する攻撃、ギミックとの連動、追跡、部位、倒した後の処理などは、これからの段階で書き足していきます。

> 今までの敵（`Assets/Prefab/Enemies/Enemy.prefab`、スポナーで出るもの）は、そのまま動きます。
> 同じ動きの新しい敵（壁を回り込む）は、サンプルの「撃つ敵」です（7 章）。

**まず触ってみる**：Tools > 敵 > **サンプルを作る** → Hierarchy 右クリック > 敵 > **敵を置く** → 置いた敵の「敵のデータ」に `Assets/Data/Enemies/Sample/` の EnemyData を入れて再生。

---

## 1. 全体の考え方

| もの | 何か | 置き場所 |
|---|---|---|
| **敵のデータ（EnemyData）** | 敵1種類分の設定（体力・速さ・見た目・**行動パターン**・**効き方**・倒されたときの演出） | `Assets/Data/Enemies/` |
| **行動パターン（EnemyPattern）** | いつ・どこへ動き、いつ攻撃するか。段階（第1形態・第2形態）に分けられる | `Assets/Data/Enemies/`（Patterns など） |
| **攻撃（AttackData）** | 攻撃1つ分。予告（範囲を見せる）→ 発動 → 後隙 | `Assets/Data/Enemies/`（Attacks など） |
| **共通プレハブ（Enemy_Base）** | すべての敵の元になる入れ物。データを入れると、その敵になる | `Assets/Prefab/Enemies/Enemy_Base.prefab` |
| **シーンに置いた敵** | 共通プレハブを置いて、データを入れたもの。巡回ポイントはここに入れる | 各シーン |

```
敵のデータ ──→ 行動パターン ──→ 段階 ──→ 行動（待つ・近づく・離れる・巡回・ランダムに歩く・攻撃する）
                                                                              └──→ 攻撃（AttackData）
```

**敵を増やす = データを1つ作る**です。プレハブを複製する必要はありません。行動パターンと攻撃は、いろいろな敵で使い回せます。

---

## 2. 敵の種類を作る（EnemyData）

1. Project で `Assets/Data/Enemies/Sample/EnemyData_Sample` を選び、**Ctrl + D** で複製します。
   （新しく作るときは、Project の右クリック > **Create > 敵 > 敵のデータ**）
2. 名前を変えて、`Assets/Data/Enemies/` に移します（例：`EnemyData_コウモリ`）。
3. Inspector で項目を決めます。

| 項目 | 意味 | 目安 |
|---|---|---|
| **名前** | 一覧やデバッグで出る名前 | |
| **最大の体力** | この回数分ダメージを受けると倒れる | ノアの範囲攻撃 1 回 = 1 ダメージ |
| **移動の速さ** | 1 秒に進む距離（マス） | プレイヤーは 5 |
| **大きさ** | 小・中・大。**大きい敵は細い通路を通れない** | ボスは「大」にすると広間から出てこない |
| **押されにくい** | オンならプレイヤーがぶつかっても動かない | |
| **行動パターン** | 4 章で作る EnemyPattern。空ならその場に立っているだけ | |
| **受けるダメージの効き方** | 6 章 | 空なら全部等倍 |
| **ぶつかったときのダメージ** | プレイヤーに触れたときのダメージ。0 なら何もない | |
| **ダメージの間隔（秒）** | 触れ続けたとき、何秒ごとにダメージか | 1 |
| **アニメーション** | SpriteAnimData。`Idle`（待機）・`Walk`（移動）・`Damage`（ダメージ）・`Dead`（倒れる）の名前の動きを自動で使う | なければ空でよい |
| **絵（アニメがないとき）** | アニメが空のときの絵 | |
| **エフェクト / SE**（倒されたとき） | 消える瞬間のエフェクト、倒された瞬間の音 | |
| **死亡アニメの名前** | この名前の動きを流し終わってから消える | `Dead` |
| **メモ** | 自分用のメモ（ゲームには影響しない） | |

> 体力・2人の体力について：敵の攻撃がシグルに当たると、**ノアの体力（2人で共有）**が減ります。

---

## 3. 敵を置く

1. Hierarchy で右クリック > **敵 > 敵を置く**（Scene ビューの真ん中に置かれます）。
   または `Assets/Prefab/Enemies/Enemy_Base` を Scene にドラッグします。
2. 置いた敵を選び、Inspector の **Enemy > 敵のデータ** に、2 で作った EnemyData を入れます。
3. 位置を動かして、**シーンを保存**します。

- **スポナーは要りません。** 置くだけで、操作中のキャラを自分で見つけます。
- 置いた敵の **EnemyBrain** で、その敵だけの設定ができます。

| 項目 | 意味 |
|---|---|
| **行動パターンを差し替える** | 空なら敵のデータの行動パターン。この敵だけ違う動きにしたいときに入れる |
| **Patrol Points（巡回ポイント）** | 「巡回する」で上から順に回る場所。空のオブジェクトを置いてドラッグで入れる（選ぶと緑の線で見える） |
| **動き出す距離** | プレイヤーがこの距離まで近づいたら動き出す（黄色の円）。0 なら最初から |

- スポナー（`EnemySpawner`）から出したいときは、スポナーの **Spawn Object** に Enemy_Base（またはそれを元にしたプレハブ）を入れます。
- 敵は壁で止まり、マップ（地面の Tilemap）の外には出ません。

## 4. 動き方を決める（行動パターン）

1. Project の右クリック > **Create > 敵 > 行動パターン**（またはサンプルを Ctrl + D で複製）。
2. Inspector で、段階の中に**行動**を並べます。「**＋**」を押すと行動の種類を選べます。つまんで並べ替えられます。
3. 敵のデータの「行動パターン」に入れます。

### 4-1. 行動の種類

| 行動 | すること | 主な項目 |
|---|---|---|
| **待つ** | その場で止まる | 最短・最長（秒）。違う値ならランダム |
| **移動 > 近づく** | プレイヤーに近づく（壁は回り込む） | ここまで近づく・最長の時間・速さの倍率 |
| **移動 > 離れる** | プレイヤーから離れる（行き止まりには逃げない） | ここまで離れる・最長の時間 |
| **移動 > 巡回する** | 巡回ポイント（3 章）を順に回る | 全部のポイントを回る・ポイントで待つ |
| **移動 > ランダムに歩く** | 最初にいた場所のまわりを歩く | 範囲（半径）・回数 |
| **攻撃する** | 攻撃（5 章）を出す | 攻撃・回数・間隔 |

どの行動にも、次の項目があります。

| 項目 | 意味 |
|---|---|
| **この行動をする距離** | 「プレイヤーがこの距離より近いとき／遠いとき」だけする。満たさないときは飛ばして次の行動へ |
| **重み** | 選び方が「重みつきランダム」のときの選ばれやすさ |

> 例：「近づく」→「攻撃する（近いときだけ）」→「待つ」。遠いと攻撃を飛ばすので、近づいてから殴る敵になります。

### 4-2. 段階（第1形態・第2形態）

| 項目 | 意味 |
|---|---|
| **段階の名前** | デバッグに出る名前 |
| **行動の選び方** | 上から順番に／ランダム／重みつきランダム |
| **次の段階へ進む条件** | 進まない／体力がこの割合以下／○秒経ったら／条件（フラグ・アイテム・操作中のキャラ・体力）を満たしたら |
| **進むとき今の行動をやめる** | オン：攻撃の途中でもやめて次へ（予告も消える）。オフ：今の行動が終わってから |
| **この段階に入ったとき** | エフェクト・SE・アニメ・止まる時間（変身の演出） |

- 段階は**上から順に進み、戻りません**。「＋段階を追加」で足し、▲で並べ替えます。
- 例：段階1「通常」（体力 50% 以下で次へ）→ 段階2「怒り」（攻撃を増やしてランダムに）。

## 5. 攻撃を作る（AttackData）

1. Project の右クリック > **Create > 敵 > 攻撃**（またはサンプルを複製）。
2. Inspector で決めます。**選んだ設定で使わない項目は隠れます**。
3. 行動パターンの「攻撃する」に入れます。

攻撃は **予告（範囲を見せる）→ 発動（当たる）→ 後隙（攻撃のあとの、反撃できる時間）** の順に進みます。

### 5-1. 予告

| 項目 | 意味 |
|---|---|
| **予告の時間** | 範囲を見せてから発動するまで。0 なら予告なしですぐ |
| **範囲を表示する** | オフにすると、時間は待つが範囲は見せない（見えない攻撃） |
| **描き方・色** | 塗りと枠／塗りだけ／枠だけ。色の A（透明度）で薄さ |
| **満ちていく表示** | 発動までの時間に合わせて内側から色が満ちる |
| **点滅させる** | 発動の直前に点滅 |
| **描く順番** | 3 なら「床の上・物やキャラの下」。大きいほど手前 |
| **暗い所でも見える** | オンなら暗いステージでも明るさが変わらない（おすすめ） |
| **予告の SE・予告中の敵のアニメ** | 構えの音・動き（アニメの名前。なければ何もしない） |

### 5-2. 出る場所と形

| 項目 | 選べるもの |
|---|---|
| **起点** | 敵の位置／プレイヤーの位置（予告を出した時点で決める＝動けば避けられる）／プレイヤーの位置（予告の間は追いかける） |
| **向き** | プレイヤーの方向／敵の向いている方向／決まった角度 |
| **予告の間は向きを合わせ続ける** | オン：発動の瞬間まで狙い続ける（ビーム向き）。オフ：最初の向きのまま（避けやすい） |
| **前にずらす距離** | 敵の体の外から出したいとき |
| **範囲の形** | 円（半径）／長方形（長さ・幅。ビーム・突進）／扇形（半径・角度）／リング（外側と内側の半径。内側は安全） |
| **長方形の長さを壁で止める** | ビーム・突進が壁を突き抜けない（予告も短くなる） |

**予告の形と当たる範囲は同じ**です（見た目どおりに当たります）。

### 5-3. 発動

| 発動のしかた | 動き | 主な項目 |
|---|---|---|
| **一瞬** | その瞬間に範囲の中に当たる | 敵自身の動き（下） |
| **出し続ける** | 範囲が残り、入っていると当たり続ける（ビーム） | 出し続ける時間・当たる間隔・回る速さ（なぎ払い） |
| **弾を撃つ** | 今までの弾をプレイヤーに向けて撃つ | 弾の数（扇状）・広がり・連射の回数と間隔 |

| 敵自身の動き（一瞬のとき） | 動き |
|---|---|
| **その場で止まる** | 動かない |
| **突進する** | 予告の長方形を走る（プレイヤーはすり抜けて当たる）。**壁にぶつかったら気絶（秒）** で反撃のチャンスを作れる。形は長方形にする |

| 共通の項目 | 意味 |
|---|---|
| **ダメージ** | 当たったときのダメージ |
| **当たる相手** | プレイヤー／敵（ほかの敵にも当たる）／両方 |
| **ノアには効かない・シグルには効かない** | オンならそのキャラをすり抜ける（キャラを切り替えて避ける遊びに） |
| **発動のエフェクト・SE・敵のアニメ** | 範囲の真ん中にエフェクト |

> **弾を撃つ**ときの弾のダメージ・速さ・見た目は、シーンの「敵の弾のプール」の弾で決まります。「当たる相手」「効かないキャラ」は弾には使えません。

### 5-4. 後隙
- **後隙（秒）**：攻撃が終わってから次の行動までの時間。長いほど反撃しやすい。

### 5-5. 組み合わせの例（サンプルにあります）

| 攻撃 | 起点 | 形 | 発動 | 動き |
|---|---|---|---|---|
| なぎ払い | 敵 | 扇形 120° | 一瞬 | その場 |
| 突進 | 敵 | 長方形 7×1.2 | 一瞬 | 突進（壁で気絶 1 秒） |
| ビーム | 敵 | 長方形 10×0.8 | 出し続ける 1.5 秒 | その場（予告中は狙い続ける） |
| 足元の爆発 | プレイヤー（予告時） | 円 | 一瞬 | その場（点滅） |
| リング | 敵 | リング | 一瞬 | その場（敵の近くが安全） |
| 狙い撃ち | 敵 | － | 弾 6 連射 | その場（今までの敵と同じ） |

## 6. 効く攻撃を決める（受けるダメージの効き方）

敵のデータの「**受けるダメージの効き方**」に行を足します。当てはまる行の倍率を**全部かけます**。

| 項目 | 意味 |
|---|---|
| **攻撃の種類** | すべて／ノアの範囲攻撃／ノアのゲージ攻撃／シグルの弾／体当たり／爆発／ギミック など |
| **攻撃したキャラ** | 問わない／ノア／シグル／プレイヤー以外（敵・ギミック） |
| **倍率** | 2 なら2倍、0.5 なら半分、**0 なら効かない** |
| **ゲージの判定** | ゲージ攻撃のとき、パーフェクト／グッド／ミスで絞る |

例：
- 「シグルの弾 ×0.5」＋「ゲージ攻撃・パーフェクト ×2」（サンプルの砲台）
- 「すべての攻撃 ×0」＋「ギミック ×1」＝ギミックでしか倒せない敵
- 「攻撃したキャラ：ノア ×0」＝シグルでしか倒せない敵

> 倍率をかけた結果が小数のときは四捨五入します（0 より大きければ最低 1）。

## 7. サンプル（Tools > 敵 > サンプルを作る）

`Assets/Data/Enemies/Sample/` に作られます（すでにあるものは上書きしません）。

| 敵のデータ | 動き |
|---|---|
| EnemyData_Sample（サンプルの敵） | 近づいて、近ければなぎ払う |
| EnemyData_Sample_突進 | 少し待って、プレイヤーに向かって突進。壁にぶつかると気絶 |
| EnemyData_Sample_砲台 | 動かない大きな敵。ビーム → 体力が半分で「怒り」（ビーム・リング・足元の爆発をランダムに）。シグルの弾は半分、ゲージのパーフェクトは2倍 |
| EnemyData_Sample_撃つ | **今までの敵と同じ動き**（6 発撃ってから 3 秒近づく）。壁は回り込む |
| EnemyData_Sample_巡回 | 遠いときは巡回、5 マス以内なら近づいてなぎ払う（敵の EnemyBrain に巡回ポイントを入れる） |

> 今までの敵（Enemy.prefab）を新しい作りにしたいときは、スポナーの **Spawn Object** を Enemy_Base に変え、Enemy_Base を元にしたプレハブ（敵のデータ＝撃つ）を作って入れます（シーンの変更なので、作業する人が行ってください）。

## 8. 敵が通れない・通りにくい場所を決める（敵の通行設定エリア）

敵は、壁（当たり判定のあるオブジェクト）を自動でよけて道を探します。**プレイヤーは通れるが、敵だけ入れない場所**を作りたいときに使います。

1. Hierarchy で右クリック > **敵 > 敵の通行設定エリア**。
2. 四角の大きさ（BoxCollider2D の Size）と位置を合わせます。**Is Trigger はオンのまま**にしてください（オフにするとプレイヤーも通れなくなります）。
3. **敵にとってこの場所は** を選びます。

| 選択 | 動き | 使いどころ |
|---|---|---|
| **入れない** | 敵はこの範囲を通らない | 部屋の入口の外までは追ってこない、安全地帯 |
| **通りにくい（できれば避ける）** | 遠回りになっても避ける。どうしても必要なら通る | 毒の床、ぬかるみ |

- Scene ビューでは、入れない = **赤**、通りにくい = **オレンジ**の四角で見えます。
- 扉などの表示を切り替える（SetActive）と、0.5 秒以内に敵の道の探し方に反映されます。何もしなくて大丈夫です。

## 9. 確かめる

**デバッグウィンドウ（Tools > デバッグ）の「敵」**（再生中）：

| 項目 | 使い方 |
|---|---|
| **敵を止める** | 動き・攻撃・体当たりを止める（ゆっくり確認したいとき） |
| **歩ける範囲と敵の経路を表示** | 敵が歩ける範囲を**水色の線**、敵が向かっている道を**黄色の線**で、ゲーム画面に表示 |
| 今いる敵 | 名前・体力・**今の段階と行動**（例「怒り：攻撃する（ビーム）」）。名前を押すと選択、「倒す」「全部倒す」（効き方に関係なく倒せる） |

**シーンチェック（Tools > シーンチェック）**で見つかるもの：
- 敵のデータが入っていない／行動パターンがない（参考）
- 敵のタグ・レイヤーが Enemies でない（攻撃が当たらない）
- 「巡回する」があるのに巡回ポイントが空
- 行動パターンの「攻撃する」に攻撃が入っていない、行動のない段階、中身が消えた行動
- 突進なのに形が長方形でない
- 敵の通行設定エリアの Is Trigger がオフ

**会話中・イベント中（プレイヤーが動けない間）・メニューを開いている間は、敵も止まります。**

## 10. 困ったとき

| こんなとき | 確かめること |
|---|---|
| 攻撃が当たらない | 敵のタグとレイヤーが **Enemies** か（シーンチェック） |
| 敵がいつまでも倒れない | 敵のデータの「最大の体力」 |
| 触れてもダメージがない | 「ぶつかったときのダメージ」が 0 になっていないか／デバッグの「無敵」がオンになっていないか |
| 敵が変な所を通る・通らない | デバッグの「歩ける範囲を表示」で水色の線を見る。壁に当たり判定（Collider2D）が付いているか |
| 大きい敵が通路に入れない | 「大きさ」が大になっている（細い通路は通れない） |
| 敵が動かない | 敵のデータに行動パターンが入っているか／EnemyBrain の「動き出す距離」／会話中やメニューを開いていないか／デバッグの「敵を止める」 |
| 攻撃が出ない | 「この行動をする距離」の条件を満たしているか（デバッグで今の行動を見る）／「攻撃する」に攻撃が入っているか |
| 攻撃が当たらない（敵の攻撃） | 「当たる相手」がプレイヤーか／「ノアには効かない」などがオンになっていないか／デバッグの「無敵」 |
| 予告が見えない | 「範囲を表示する」・予告の時間・色の A（透明度）・描く順番（大きくすると手前に出る） |
| 弾が出てすぐ消える | 敵が壁のすぐそばにいる（弾は壁に当たると消える） |
| 効かないはずの攻撃が効く／効くはずが効かない | 効き方の行の「攻撃の種類」「攻撃したキャラ」「ゲージの判定」。当てはまる行は全部かけ算 |
