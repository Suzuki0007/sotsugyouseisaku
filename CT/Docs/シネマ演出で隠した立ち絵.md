# シネマ演出で隠した立ち絵（2026-11-25 時点の記録）

> **2026-11-25 追記：立ち絵をもう一度出すようにした**（ユーザーの指示）。「シネマ演出でも立ち絵を出す」の初期値をオンにし、シネマ演出のときは小さめ（0.75 倍）にして下の帯の上に立たせ、短いフェードイン（0.2 秒）で出る。下の一覧は、立ち絵が出る会話の一覧としてそのまま使える。

会話をシネマ演出（上下の黒い帯・下の帯の字幕）で出すようにしたので、**今まで立ち絵が出ていた会話でも、立ち絵が出なくなっています**。
あとで立ち絵を出すときのために、2026-11-25 の時点で「立ち絵が出ていた会話」をここに残します（会話データとシーンのファイルから機械的に集めた一覧）。

## 立ち絵をもう一度出すには
- **全部の会話で出す**：各シーンの DialogueManager（DialogueSystem プレハブ。Stage1_2 はシーンの Canvas の物）の **「シネマ演出でも立ち絵を出す」をオン**にする。プレハブを直せば、プレハブを使っているシーンは全部変わる。
- **今までの会話の枠に戻す**：同じ所の **「シネマ演出で出す」をオフ**にする（そのシーンだけ元の見た目）。
- Claude に「立ち絵も出して」と頼めば、この一覧をもとに切り替えと見た目の調整（帯と立ち絵の重なり）を行う。

## 注意（立ち絵を出すとき）
- 立ち絵の並び順は、DialogueSystem プレハブでは 100（帯の 97 より手前）なので、帯の上に出る。
- **Stage1_2** は会話の画面がシーンの Canvas に直接組んであり、その Canvas の並び順によっては立ち絵の下の方が下の帯に隠れる。出すときに確かめる。
- 立ち絵は今「通常」の絵だけ（ノア Images/UI/UI_Noah・シグル Images/UI/UI_siguru）。
