# イベントの順番と待ち時間（プランナー向け）

「会話が終わってから扉が消える」「扉が消えて、1秒たってから会話」のように、
**イベントの部品を順番に、間をあけて実行する**ための説明です。

---

## 1. EventSequence の設定

| 項目 | 説明 |
|---|---|
| **実行のしかた** | **順番に実行**（おすすめ・初期値）：流れの上から順に実行し、会話などは終わってから次へ進む<br>**すべて同時に実行**：全部を一度に実行する（以前の動き） |
| **プレイヤーを止める** | 実行中はプレイヤーを動けなくする（移動・攻撃・キャラ切り替え・アイテム画面・調べる、を止める）。演出の待ち時間に歩き回らせたくないときにオン |
| **流れ** | 実行する部品の一覧（番号・部品の名前・中身の一言）。**▶** で開くとその場で設定を直せる。**↑↓** で順番、**×** で外す、**＋ 部品を追加** で分類ごとのメニューから足す |
| **詳しい設定** | Actions の欄を直接編集する（ふだんは「流れ」で足りる） |

- **Actions が空**のときは、同じオブジェクトに付いている部品を上から順に実行します（流れの ↑↓ は部品そのものの並びを入れ替えます）。
- 付いているのに Actions に入っていない部品があると、Inspector に**警告**と「**入っていない部品を流れの最後に追加**」ボタンが出ます。
- 再生中は「実行中 / 待機中」が出て、今実行している部品が**緑色**になります。**「▶ 今すぐ実行（操作中のキャラで）」**で、きっかけなしにその場で試せます（Tools > デバッグ の「イベント（その場で試す）」からも）。

---

## 2. 「終わるまで待つ」部品

順番に実行するとき、次の部品は **前の部品が終わるまで**待ちます。
多くの部品（SE・表示切り替え・フラグなど）は一瞬で終わるので、すぐに次へ進みます。

| 部品 | 待つ時間 | 設定 |
|---|---|---|
| **DialogueEventAction**（会話） | 会話を閉じるまで | **会話データ**に DialogueData を入れるだけ（子の Dialogue は要らない）。**Wait Until Closed**（初期値オン）。オフにすると会話を出したまま次へ進む |
| **WaitEventAction** | 指定した秒数 | **Seconds**：待つ秒数／**Ignore Time Scale**：一時停止中も進める |
| **ScreenFadeEventAction**（画面の暗転） | 暗転・明転が終わるまで | **終わるまで待つ**（初期値オン）。暗いままでも会話の枠と文字は見える（OP・回想向け） |
| **AnimEventAction** | アニメが終わるまで | **Wait Until Finished**（初期値オフ）。ループするアニメは1周で次へ進む |
| **シネマ演出（上下の帯）** | 帯が出きる・引っ込みきるまで | **終わるまで待つ**（初期値オン）。**動く時間** の秒数 |
| **字幕** | キーで送るまで／秒数 | **送り方**：キーで送る（E・Space・Enter）／秒数で次へ（**出しておく秒数**）。会話データなら文の数だけ待つ |

---

## シネマ演出（映画のような上下の帯と字幕）

イベントの場面で、**上下から黒い帯が出て、カメラがキャラへ寄り、下の帯に字幕が出る**演出です（シネマティック・レターボックス）。ゲームの絵のまま、ムービーに切り替えずに行います。

### 並べ方（EventSequence：順番に実行、Lock Player オン）
1. **シネマ演出**：する事＝**始める**、寄る先＝シグルなど
2. **字幕**：会話データ（CSV で作った DialogueData）か、話し手＋字幕の文
3. （ほかの部品：キャラの向き・物を動かす・効果音など）
4. **シネマ演出**：する事＝**終える**（帯が引っ込み、カメラが元に戻り、字幕も消える）

### シネマ演出の項目
| 項目 | 意味 |
|---|---|
| する事 | 始める（帯を出してカメラを寄せる）／終える（帯を引っ込めてカメラを戻す） |
| 帯の太さ | 上下それぞれの帯の太さ（マップの映る範囲の高さに対する割合）。0.12 くらいが映画らしい。字幕を出すなら 0.1 以上 |
| 寄る強さ | 1 で寄らない。1.3 で 1.3 倍に大きく映る（寄りすぎると絵が粗い。1.5 くらいまで） |
| 寄る先 | 今のまま／操作中のキャラ／ノア／シグル／物（動いても追いかける） |
| 寄る物 | 寄る先が「物」のときの相手（扉・敵・空のオブジェクト） |
| 動く時間 | 帯が出る・カメラが寄るまでの秒数 |
| 終わるまで待つ | オンなら、帯が出きってから次の部品へ |

### 字幕の項目
| 項目 | 意味 |
|---|---|
| 会話データ | 入れると、その文を上から順に字幕で出す（名前はキャラの色。立ち絵は出ない）。空なら下の「字幕の文」 |
| 話し手・名前の上書き | 「字幕の文」の話し手（名前が文の前に出る）。空ならナレーション |
| 字幕の文 | 出す文（2行まで。1行は約 35 文字。字の大きさはいつも同じで、3行目は帯からはみ出す） |
| 送り方・出しておく秒数 | キーで送る／秒数で次へ |
| 最後に消す | オフにすると、出したまま次の部品へ（「終える」で消える） |

### 注意
- **「始める」を置いたら、同じ流れの最後に必ず「終える」を置く**（ないとシーンチェックで注意が出ます）。
- 帯は画面の中央のマップの範囲（4:3）の上下に出ます。
- **ふつうの会話（DialogueEventAction・調べたときの会話）も、初めから同じ帯と字幕で出ます**（DialogueManager の「シネマ演出で出す」。オフにするとそのシーンは今までの会話の枠）。会話の部品だけでも映画のような見た目になるので、「シネマ演出」の部品は、寄る先を決めたいとき・会話のない場面で帯を出したいときに使います。
- 今は立ち絵は出ません（DialogueManager の「シネマ演出でも立ち絵を出す」で出せます。前に立ち絵が出ていた会話の一覧は `Docs/シネマ演出で隠した立ち絵.md`）。
- 字幕をキーで送っている間は、プレイヤーは動けません（調べる・攻撃も出ない）。
- ロードしても帯・字幕は戻りません（演出の途中でセーブしない）。

## 例

### 宝石をはめると、像が光って、少し待ってから通路が出る
EventSequence（順番に実行、Lock Player オン）の Actions：
1. SeEventAction（はめ込む音）
2. AnimEventAction（像が光る。Wait Until Finished オン）
3. WaitEventAction（0.5 秒）
4. SetActiveEventAction（Show に通路）
5. DialogueEventAction「どこかで扉が開く音がした……」

### 会話のあとでアイテムをもらう
1. DialogueEventAction「これを持っていきなさい」
2. ItemGiveEventAction（お守り）
3. SeEventAction（入手音）

### 会話を2つ続ける（別の人が話す）
1. DialogueEventAction（長老の会話）
2. DialogueEventAction（主人公の返事）

> 1つの DialogueData の中で話者を変えることもできます。続けて出したいだけなら、そちらのほうが簡単です。

---

## 注意

- **すべて同時に実行**にすると、待ち時間（WaitEventAction）は効きません。
- 実行中に EventSequence のオブジェクトを**非表示にすると途中で止まります**。
  SetActiveEventAction の Hide に、EventSequence が付いているオブジェクト（やその親）を入れないでください。
  扉を消したいときは、扉と EventSequence を別のオブジェクトにします（ひな形はそうなっています）。
- 実行中に同じイベントをもう一度起こしても、最後まで終わるまでは無視されます。
- セーブからの復元（完了状態の再現）では待ち時間はなく、見た目だけが一瞬で切り替わります。
