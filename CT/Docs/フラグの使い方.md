# フラグの使い方（プランナー向け）

「NPC と話したら扉が開く」「ボスを倒したら会話が変わる」など、
**アイテム以外の進行状態**を、コードを書かずに Inspector だけで扱うための手順です。

フラグは **ON / OFF の2つだけ**を持つスイッチです。最初はすべて OFF です。

| やりたいこと | 使う部品 |
|---|---|
| フラグを用意する | **GameFlag**（アセット） |
| フラグを ON / OFF する | **SetFlagEventAction** |
| フラグで結果を変える | **ItemInteraction** の Flag Conditions |
| フラグで表示を切り替える | **FlagSwitch** |
| フラグで BGM を変える | **BgmConditionFlag** |

---

## 1. フラグを作る

- メニューの **Tools > フラグ > 新しいフラグを作成**（`Assets/Data/Flags/` に作られます）
- または Project ウィンドウで右クリック → **Create > Flag > GameFlag**（どのフォルダでも可）

| 項目 | 説明 |
|---|---|
| **Id** | セーブ用の名前。空ならファイル名。**他のフラグと重ならないように** |
| **Memo** | どこで立つか、何に使うかのメモ（動作には関係なし） |
| **Saved** | オン：セーブされる（基本はこれ）／オフ：起動し直すと OFF に戻る（ボス戦中だけ BGM を変える、など） |

ファイル名は「何が起きたか」が分かる名前がおすすめです。例：`TalkedToElder`、`BossDefeated`、`SwitchA_On`

> フラグ名を手で打つ必要はありません。使う場所にはアセットを**ドラッグ**して入れます。

---

## 2. フラグを ON / OFF する（SetFlagEventAction）

EventSequence の Actions に **SetFlagEventAction** を追加します（会話・SE などと同じ部品です）。

| 項目 | 説明 |
|---|---|
| **Flags** | 設定するフラグの一覧。**Value** にチェックで ON、外すと OFF |
| **Revert On Exit** | エリアから出たら元に戻す（EventZone で「部屋の中にいる間だけ」にしたいとき） |

### よく使う置き方
- **調べたら ON**：ItemInteraction の「成功時」に SetFlagEventAction を入れる
- **エリアに入ったら ON**：Hierarchy で右クリック → **フラグ > 入るとフラグを設定するエリア**
  （範囲・EventZone・SetFlagEventAction がまとめて作られます。Flags にフラグを入れるだけ）

---

## 3. フラグで結果を変える（ItemInteraction）

ItemInteraction の各ルールに **Flag Conditions** が増えました。
アイテムの Conditions と **両方すべて**満たしたときに、そのルールが実行されます。

| 項目 | 説明 |
|---|---|
| **Flag** | 判定するフラグ |
| **State** | 「ON のとき」か「OFF のとき」 |

アイテムを使わないときは、Conditions（アイテム）を空のままにしてください。

---

## 4. フラグで表示を切り替える（FlagSwitch）

Hierarchy で右クリック → **フラグ > フラグで切り替え**

| 項目 | 説明 |
|---|---|
| **Flag Conditions** | フラグの条件（すべて満たしたとき） |
| **Item Conditions** | アイテムの条件も付けたいときだけ（任意） |
| **Active When Met** | 条件を満たしている間だけ表示する |
| **Active When Not Met** | 条件を満たしていない間だけ表示する |

フラグが変わった瞬間に切り替わります。シーンに戻ってきたときも、セーブされたフラグで正しく切り替わります。
FlagSwitch を付けたオブジェクト自身は、切り替え対象に入れないでください。

---

## 5. フラグで BGM を変える

- **BgmConditionFlag** の **Flag** にフラグを入れる
- 切り替えは SetFlagEventAction（または BgmFlagEventAction の **Flag**）で行う
- 一時的な BGM（ボス部屋の中だけ、など）は、フラグの **Saved をオフ**にすると、セーブに残りません

> 前からある Flag Name（文字で書く方式）もそのまま動きます。
> Saved をオフにした GameFlag の Id を同じ名前（例：`Boss`）にすると、同じフラグとして扱われます。

---

## 例

### 長老と話すと、村の出口が開く
1. フラグ `TalkedToElder` を作る
2. 長老：ItemInteraction（調べたとき）
   - ルール1：条件なし、Mark Completed = オン
     - 成功時：会話「北の森へ行きなさい」＋ **SetFlagEventAction**（TalkedToElder を ON）
   - After Completed：会話「気をつけてな」
3. 出口：**FlagSwitch**（TalkedToElder が ON のとき）
   - Active When Not Met = 出口をふさぐ岩

### ボスを倒したら、NPC のセリフが変わる
- NPC：ItemInteraction
  - ルール1：Flag Conditions = `BossDefeated` が ON、Mark Completed = オフ → 会話「ありがとう、英雄よ！」
  - ルール2：条件なし、Mark Completed = オフ → 普段の会話

### スイッチを2つ押したら扉が開く
- スイッチA・B：それぞれ ItemInteraction で `SwitchA_On` / `SwitchB_On` を ON（＋SpriteChangeEventAction で見た目を変える）
- 扉：FlagSwitch（SwitchA_On が ON ＋ SwitchB_On が ON）→ Active When Not Met = 扉

### 鍵を持っていて、かつ番人と話したあとなら門が開く
- 門：ItemInteraction
  - ルール1：Conditions = 鍵 ×1、Flag Conditions = `TalkedToGuard` が ON、Consume Items = オン
- Otherwise：会話「まずは番人に話を聞こう」

---

## 動作確認

- **Tools > フラグ > フラグ一覧** で、すべてのフラグとメモを確認できます
- **再生中**はこの一覧（または GameFlag の Inspector）で ON / OFF を直接切り替えられます
  → 後半のイベントを、最初から遊ばずに確認できます
- Id が重なっていると、一覧の上に警告が出ます
- フラグが変わると Console に `[フラグ] 名前 = ON` と出ます

## 注意

- セーブの確定はチェックポイントとシーン遷移のときです（アイテムと同じ）。
- エディタで再生を止めると、フラグはリセットされます。
- フラグの Id を後から変えると、古いセーブのそのフラグは OFF に戻ります。
