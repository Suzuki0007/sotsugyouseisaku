# シーン分け：『願いの塔と壊れた調律師』（2026-11-27）

シナリオ（ストーリー進行・イベント構成案）を、11/27 の打ち合わせの方針（`Docs/打ち合わせ_2026-11-27_実装方針.md`）に沿って **絵になるイベントシーン 38** に分けたものです。

## この分け方の決まり
- **1 シーン＝1 つの見せ場**（短編のつもりで作る）。見せ場から逆算して、その前の匂わせ・入口と出口を決める。
- **言葉は最小限**。ノアに感想を言わせない。どう思ったかはプレイヤーに委ねる。表の「言葉」は、出してよい言葉の上限の目安。
- **敵・HP・攻撃はなし**。怖さ・緊張は演出（追ってくる・揺れ・暗さ）で。
- **ノアは耳が聞こえない**：プレイヤーには聞こえる音（シグルの関節の異音・怒鳴り声・秒針）に、ノアは反応しない。この「聞こえ方のずれ」を全体のモチーフにする。
- **対比のモチーフ**：歩く位置（前を歩くシグル → 歩幅を合わせるノア → 並んで歩く）、墓を作る（一人 → 二人）、小舟（来る → 去る）、手紙（「親愛なる調律師へ」→「あなたの一番の調律師より」）、懐中時計（止まっている → 動く）。同じ構図をくり返して使う。
- 種類：**見せ場**＝絵になるイベント／**つなぎ**＝次の見せ場までの間を見せる短い場面／**調べる**＝自由な順番で物を調べる場面。

表の「使える部品」は、今あるもの（`Docs/演出の作り方.md`）。**新しく要るもの**は最後にまとめました。

## 並べ方（ランダムを含む）の候補
- **最初のシーンを S16（カイロスが撃たれている）にする案**：「あの男はなぜ死んだのか」から始め、そのあと S01 の小舟へ戻る。
- **順番を入れ替えてもよいシーン**：S08・S09（第一章の中）、S22〜S24（地下の調べる順番は自由）。
- **入れ替えてはいけないシーン**：対比になっている組（S04 と S28 と S38、S25 と S33、S01 と S35）は、前の方を先に見せる。

## 新しく要るもの（今の仕組みにない物）
1. **映画の字幕の話者の見分け**（S22・S30）：話者ごとの色に加えて、色以外の見分け方（字の形・位置・字幕の前の印など）。シナリオの確認事項にもある。
2. **ノアに聞こえない音**（S14・S16・S34）：プレイヤーには鳴るが、ノアの向き・一言の反応が起きない効果音。今の効果音で鳴らせるので、「ノアは反応しない」の決まりを手順書に書くだけでよいかもしれない。
3. **歩く位置の入れ替え**（S04・S28・S38）：今は相棒（シグル）がノアの後ろをついてくる。シグルが前を歩く／並んで歩くには、ついてくる動きの設定を足す。
4. **ティンパニ部屋の戦いを外す**（S10）：打ち合わせの「敵・HP・攻撃なし」に合わせるか。
5. **出会いの場所**（S04）：今は第一層の追跡のあとに助けられて出会う。シナリオどおり入口で出会うか。
