# 謎解きと2人の仕掛けの作り方（プランナー向け）

最終更新：2026-11-09（段階5：ホラー・謎解きの演出 まで）

謎解き・ステージギミック・ノアとシグルの協力・離れ離れの展開を、コードを書かずに作るための手順書です。段階ごとに作っているので、できるようになったものから書き足していきます。

**今できること**
- 2人の状態（一緒・待機・別行動）をイベントで切り替える。一緒のときは体力を共有（シグルがノアを守っている）、離れているときは別々（1〜4 章）
- 攻撃は操作しているキャラだけが出す
- **ホラー・謎解きの演出**（19 章）：番号錠・何をはめるか選ぶ置き台・メモ（拾う・メニューで読み返す）・調べるたびに変わる・即死の罠とやり直す位置・見ていない間に動く像
- **離れ離れのステージ**（18 章）：エリアごとのカメラの範囲・離れているときの切り替えの演出（スライド・暗転）・敵が狙う相手・カメラを向ける・合流の範囲・2人の状態のセーブ
- **2人の能力**（15〜17 章）：**待て／ついてこい（F キー）**・ノアだけ通れる狭い通路・シグルだけ壊せる壁・キャラにだけ見える物・2人で押す箱・持ち上げる場所・「相棒の出番」の目印
- **仕掛け**（6〜14 章）
  - 調べるスイッチ（使えるキャラ：両方・ノアだけ・シグルだけ）
  - 条件で動く扉・橋（開く・ずれて開く・伸びる）
  - 床スイッチ・押せる箱と穴・置き台・燭台・状態で変わる見た目・時間で戻る仕掛け
  - 答え合わせ（全部 ON／決めた順番／決めた組み合わせ）
  - イベントや攻撃で仕掛けを動かす
  - 配線の表示

これから作るもの（予定）：
- 相棒の一言・ヒント・絆の段階（段階6）

---

## 1. 2人の状態

| 状態 | 相棒（操作していない方） | キャラを切り替えると | 体力 |
|---|---|---|---|
| **一緒**（はじめはこれ） | 後ろについてくる | 2人の位置が入れ替わる | **2人で共有**（シグルの体力から減る） |
| **待機** | その場で待つ | 位置はそのまま。カメラが相手へ移る | 別々 |
| **別行動**（離れ離れ） | その場にいる | 位置はそのまま。カメラが相手へ移る | 別々 |

- **一緒に戻すと、相棒が合流します。** 近ければ（10 マス以内）歩いて追いつき、遠ければ操作しているキャラの位置へ移ります。距離はシーンの PlayerSwitchManager の「相棒が歩いて合流する距離」で変えられます。
- **2人の状態はセーブされます**（同じシーンに戻ったとき・つづきから・やり直しで、離れ離れのまま戻る。違うシーンに移ると「一緒」に戻る。18-6）。

### 1-1. イベントで状態を変える（2人の状態を変える）

EventSequence に **PartyModeEventAction（2人の状態を変える）** を付けます。

| 項目 | 意味 |
|---|---|
| **2人の状態** | 一緒／待機／別行動 |
| **操作するキャラも変える** | オンにすると、下で選んだキャラに操作を切り替える |
| **操作するキャラ** | ノア／シグル |

例：
- 崩れた床で2人が分かれる → 会話のあとで「別行動」にする。操作するキャラは、先に進むほうにする
- 合流の場所に入ったら「一緒」に戻す（EventZone などで）

## 2. 体力

- **シグルは体力が多く（6）、ノアは少ない（3）**。値は `Assets/Prefab/Players/` の Player_Noah・Player_Sigle の **Health > Max Health** で変えられます。
- **一緒のとき**：シグルがノアを守っている、という作りです。ノアが攻撃を受けても、**シグルの体力から減ります**。画面のハートはシグルの体力で、白です。
- **離れているとき**：それぞれ自分の体力です。画面のハートは操作しているキャラの体力で、ノアはピンク、シグルは水色です。
  - ノアの体力は、離れたときの値から減っていきます（一緒の間は減りません）。
- **体力はセーブされます**（シーンを移っても減ったまま。つづきから・戦闘エリアのやり直しでは、セーブしたときの体力に戻る。ゲームオーバーからのリトライ・はじめからは満タン）。
- **どちらかの体力が 0 になるとゲームオーバー**です（一緒のときは共有している体力が 0 になったとき）。
- ハートは、最大の体力の数だけ自動で並びます（置いてあるハートより多いときは、同じ間隔で増やします）。色はシーンの LifeUIController の「一緒のとき（2人で共有）の色」「離れているときのノアの色／シグルの色」で変えられます。
- 回復は、今の体力（一緒ならシグルの体力）を回復します。

---

## 3. 攻撃

- 攻撃は**操作しているキャラだけ**が出します（シグルを操作しているときに Space / R を押しても、ノアの攻撃は出ません）。
  - ノア：Space（範囲攻撃）、R（ゲージ攻撃）、Q（弾消し）
  - シグル：左クリック（射撃）

## 5. 困ったとき（2人の状態・体力）

| こんなとき | 確かめること |
|---|---|
| 切り替えると相手と位置が入れ替わってしまう | 2人の状態が「一緒」になっている（入れ替わるのは一緒のときだけ） |
| 相棒がついてこない | 2人の状態が「待機」か「別行動」になっている |
| ハートの数が変わった | 離れていると、操作しているキャラの体力（ノアは少ない）が出る |
| シーンを移ったら一緒に戻った | 違うシーンに移ると「一緒」に戻る（作りどおり。離れ離れのステージは 1 つのシーンの中で作る。18-6） |

## 6. 仕掛けの考え方（入力 → 状態 → 条件 → 動く物）

謎解きの部品は、**「状態を持つ入力」と「条件で動く物」**の2つに分けて、**ドラッグでつなぐ**だけで作ります。

```
調べるスイッチ ─┐（ON / OFF）
攻撃で作動するスイッチ ─┤                ┌→ 条件で動く物（扉・橋が出る・壁が消える）
イベント（会話・アイテムをはめる）─┤→ 仕掛けの状態 →┤
                    │                └→ 答え合わせ（全部・順番・組み合わせ）→ その状態をまた扉の条件に
```

- **仕掛けの状態**（GimmickState）：ON / OFF（または 0, 1, 2 … の段階）。**セーブされます**（シーンに戻ってもスイッチは ON のまま）。
- **条件**：今までの「条件」（フラグ・アイテム・操作中のキャラ など）に、**仕掛け**と**2人の状態**の項目が増えました。敵の「動く条件」や戦闘エリアなど、条件を使うところならどこでも使えます。
  - **仕掛け**：「スイッチ A が ON のとき」「ダイヤルが 3 のとき」など。仕掛けの欄に、シーンに置いたスイッチ（GimmickState の付いた物）をドラッグする。
  - **2人の状態**：一緒のとき／離れているとき。
- 扉を開けるのは、**扉の「条件」にスイッチを入れる**のが基本です（スイッチ側に扉を入れるのではありません）。1つのスイッチを、いくつもの扉・橋が見られます。

## 7. 調べるスイッチ（レバー・ボタン・燭台・ダイヤル）

1. Hierarchy 右クリック > **仕掛け > 調べるスイッチ**。黄色い丸（見た目。差し替えてよい）と、調べる範囲（Is Trigger の円）ができます。
2. **GimmickState（仕掛けの状態）** と **GimmickSwitch（調べるスイッチ）** を設定します。

**GimmickState（仕掛けの状態）**

| 項目 | 意味 |
|---|---|
| **表示名** | デバッグや配線の表示に出る名前 |
| **段階の数** | 2 = OFF / ON。3 以上でダイヤル・像の向き（0, 1, 2 …） |
| **最初の状態** | 0 = OFF |
| **最後の次は最初に戻る** | ダイヤルなら オン（3 の次は 0）。オフなら最後で止まる |
| **変わったときのイベント** | 変わるたびに実行（音・見た目の差し替え。SpriteChange など） |
| **セーブする・セーブ用の ID** | オフにすると、シーンに入るたびに最初の状態に戻る |
| **戻るまでの秒数**（時間で戻る） | 最初の状態から変わったら、この秒数で戻る（**時間制限のあるスイッチ**。走って扉を抜ける）。0 なら戻らない。会話中などは時間が進まない。シーンに入り直すと最初の状態から |
| **残り時間の音・戻ったときの音** | 戻るまで 1 秒ごとに鳴る音（カチカチ）と、戻ったときの音 |

**GimmickSwitch（調べるスイッチ）**

| 項目 | 意味 |
|---|---|
| **調べたとき** | ON / OFF を切り替える（段階があれば次へ）／ON にする（戻らない）／OFF にする／次の段階へ |
| **使えるキャラ** | **両方／ノアだけ／シグルだけ** |
| **使える条件** | 満たしているときだけ使える（例：電源のスイッチが ON） |
| **調べたときの SE** | |
| **使えないキャラで調べたとき** | 例：ノアで調べたら「重くて動かない……シグルなら」の会話。空なら「できない」音だけ |
| **条件を満たさないとき** | 例：「電気が来ていない」 |
| **固定されているとき** | 答え合わせが済んで動かせないとき |

- 調べられるのは、**範囲の中にいる「操作しているキャラ」だけ**です（ついてくる相棒・待たせている相棒が範囲にいても反応しません）。
- ON / OFF で見た目を変えたいときは、「変わったときのイベント」に SpriteChange などを入れるか、下の「条件で動く物」で ON の絵と OFF の絵を出し分けます。

## 8. 条件で動く物（扉・橋・消える壁）

1. （先にスイッチを Hierarchy で選んでおくと、そのスイッチが条件に入ります。Ctrl を押しながら複数選べます）Hierarchy 右クリック > **仕掛け > 条件で動く物（扉）**。
2. 子の **閉じた扉**（当たり判定つきの四角。差し替えてよい）は、条件を満たすと隠れます。子の **開いたとき** に音などの部品を付けます。

| 項目 | 意味 |
|---|---|
| **条件** | 「仕掛け」の ＋ でスイッチをドラッグし、比べ方（ON のとき／OFF のとき／この値のとき など）を選ぶ。フラグ・アイテム・2人の状態なども使える。**すべて満たすとき** |
| **一度満たしたらずっと** | オン：一度開いたら、スイッチを戻しても開いたまま（セーブする）／オフ：満たしている間だけ（踏んでいる間だけ開く、など） |
| **Show When Met** | 満たしているときに表示する物（出てくる橋） |
| **Hide When Met** | 満たしているときに隠す物（閉じた扉） |
| **Moves（動かす物）** | 満たしているときに、置いた位置から「動かす距離」だけずらす物（**扉が横にずれて開く・橋が伸びる・床がせり上がる**）。「動く時間」をかけて動き、満たさなくなったら戻る。当たり判定ごと動くので、敵の通り道も自動で変わる |
| **動き始めの SE** | 動かす物が動き始めたときの音 |
| **満たしたときのイベント／満たさなくなったときのイベント** | 開く音・閉じる音・会話など |

- 表示の切り替えは、条件からいつも決まります。セーブから戻ったときも、スイッチの状態から自然に開いた／閉じた状態になります。
- **条件が空だと動きません**（設定し忘れで開きっぱなしにならないように）。
- **隠す物は子にしてください。** 自分（条件で動く物）を隠すと、条件を見られなくなります（シーンチェックでエラー）。

## 9. 答え合わせ（全部・順番・組み合わせ）

1. （入力にしたいスイッチを Hierarchy で選んでおくと、選んだ順に入力に入ります）Hierarchy 右クリック > **仕掛け > 答え合わせ**。
2. 答え合わせ自身も「仕掛けの状態」を持っていて、**正解すると ON** になります。扉の「条件」に、この答え合わせを入れます。

| 項目 | 意味 |
|---|---|
| **Inputs（入力）** | 答え合わせに使うスイッチなど。「決めた順番」なら、ON にする順番に上から並べる |
| **答え合わせのしかた** | **全部 ON にする**／**決めた順番に ON にする**（間違えたら全部戻る。燭台を順番に灯す）／**決めた組み合わせにする**（ダイヤル・像の向き） |
| **Answer（答え）** | 「決めた組み合わせ」の答え。入力と同じ順番に値を並べる（0 = OFF、1 = ON、ダイヤルなら 0, 1, 2 …） |
| **答え合わせをするとき** | 入力が変わるたびに（正解したらすぐ）／イベントの部品で確かめたとき（「決定」のレバーを引くと確かめる。違っていたら「間違えたとき」） |
| **正解したら入力を固定する** | 正解したら、入力のスイッチをもう動かせない |
| **正解したときのイベント・SE** | |
| **間違えたら入力を全部戻す・間違えたときのイベント・SE** | ダメージ・敵が出る・会話など |

- 正解したことはセーブされ、シーンに戻ったときも正解のまま（入力も固定されたまま）です。
- 「決めた順番」は、途中まで灯してシーンを出ると、戻ったときは最初からになります。

## 10. 床スイッチ・押せる箱・穴・置き台

### 10-1. 床スイッチ（乗ると押される）

Hierarchy 右クリック > **仕掛け > 床スイッチ**。灰色の四角（押されると緑。絵は「見た目」を差し替える）ができます。

| 項目 | 意味 |
|---|---|
| **動き** | 乗っている間だけ ON／一度乗ったら ON のまま／乗るたびに切り替え |
| **反応する物** | **ノア／シグル／押せる箱／敵** をそれぞれオン・オフ（シグルの重さでだけ沈む床＝シグルだけオン） |
| **必要な数** | この数以上乗っているときに押される（2 なら、2人とも乗る・箱と1人 など） |
| **押されたとき・離れたときの SE** | |

- 乗った物の**中心**が範囲の中にあるときに数えます（かすっただけでは反応しない）。
- **操作していない相棒も数えます。** 相棒を「待機」にして床スイッチの上に置き、もう片方で先へ進む、が作れます（2人の状態の切り替えは 1 章。「待て」のキーは段階3で足します）。

### 10-2. 押せる箱と穴

Hierarchy 右クリック > **仕掛け > 押せる箱** ／ **穴（箱で埋まる）**。どちらもマスの真ん中にそろえて置かれます。

**押せる箱（PushBlock）**

| 項目 | 意味 |
|---|---|
| **押せるキャラ** | 両方／ノアだけ／シグルだけ（重い箱はシグルだけ） |
| **マスの大きさ** | 1 回押したときに動く距離（1 マス） |
| **押し始めるまで（秒）** | 箱に向かってこの秒数歩き続けると動く（かすっただけで動かないように） |
| **動く時間（秒）** | |
| **押したとき・穴に落ちたときの SE** | |
| **押せないキャラで押したとき** | 例：ノアで押したら「重くて動かない……」の会話。空なら「できない」音 |
| **セーブする・セーブ用の ID** | 箱の位置と、穴に落ちたかをセーブする |

- 操作しているキャラが、箱に向かって**上下左右**に歩き続けると押せます。
- 行き先に壁・ほかの箱・キャラ・敵があると動きません。
- **埋まっていない穴に押し込むと、箱が落ちて穴が埋まり、通れるようになります。**
- 箱を床スイッチに乗せると押されます（10-1 で「押せる箱」をオン）。
- 箱が角に詰まって動かせなくなったときのために、イベントの部品 **押せる箱を元に戻す**（PushBlockResetEventAction）があります。「戻す」レバーを置き、その「変わったときのイベント」に付けるのがおすすめです。箱の欄が空ならシーンの全部の箱を戻します。穴に落ちた箱はそのままです。

**穴（GimmickHole）**

| 項目 | 意味 |
|---|---|
| **穴の当たり判定** | 埋まるまで通れなくする Collider2D（空なら同じオブジェクトのもの） |
| **埋まった絵／埋まったときの色** | 埋まったあとの見た目（絵が空なら色だけ変える） |

- 埋まったかは仕掛けの状態（ON）でセーブされ、扉などの条件にも使えます（「穴を全部埋めたら開く」など）。

### 10-3. 置き台（アイテムをはめる）

Hierarchy 右クリック > **仕掛け > 置き台（アイテムをはめる）**。

| 項目 | 意味 |
|---|---|
| **はめるアイテム・個数** | |
| **はめたら持ち物から減らす** | オフなら、持っているだけでよい（見せるだけ） |
| **取り外せる** | オンなら、もう一度調べると外して持ち物に戻す |
| **使えるキャラ** | |
| **はめた物の表示・はめた物の大きさ** | はめるとアイテムの絵を出す（子の「はめた物」） |
| **はめたとき・外したときの SE** | |
| **アイテムを持っていないとき** | 例：「何かをはめるくぼみがある」 |
| **使えないキャラで調べたとき** | |

- 4 つの台に宝石をそろえる → 答え合わせ（全部 ON）に 4 つの台を入れる。
- **何をはめるか選ぶ**ときは、**Choices（選べるアイテム）** にアイテムを並べます（19-2）。今までの ItemInteraction（アイテム条件で中身が変わる）に「仕掛けを操作」を付ける方法でも作れます。

## 11. 燭台・状態で変わる見た目（GimmickVisual）

**GimmickVisual（状態で見た目を変える）** を付けると、仕掛けの状態ごとに見た目を変えられます。

| 項目 | 意味 |
|---|---|
| **仕掛けの状態** | 見る仕掛け（空なら同じオブジェクトか親のもの） |
| **絵を変える SpriteRenderer** | 空なら同じオブジェクトのもの |
| **Looks（状態ごとの見た目）** | 状態の値ごとに、**絵**（空なら変えない）・**色**・**表示する物**・**有効にする部品**（LightSource など）。どの行にも出てくる物・部品は、今の状態の行にないときは隠す・無効にする |

- 例：
  - レバー：値 0 に上向きの絵、値 1 に下向きの絵。
  - 燭台：値 1 の「表示する物」に火、「有効にする部品」に明かり（LightSource）。
  - ダイヤル：値ごとに数字の絵。
- Hierarchy 右クリック > **仕掛け > 燭台（調べて灯す・明かりつき）** で、調べると灯る燭台（スイッチ＋火＋明かり＋GimmickVisual）ができます。
- **順番に灯す謎**は、燭台をいくつか置いて、答え合わせ（決めた順番に ON）の入力に入れます。
- **シグルの弾で灯す燭台**：調べるスイッチの代わりに、攻撃で作動するスイッチ（AttackSwitch）の「仕掛けの状態」に燭台を入れます（12 章）。

---

## 12. イベント・攻撃で仕掛けを動かす

**イベントの部品「仕掛けを操作」（GimmickEventAction）**：

| 項目 | 意味 |
|---|---|
| **仕掛け** | 仕掛けの状態（GimmickState）の付いた物 |
| **操作** | ON にする／OFF にする／切り替える／次の段階へ／値にする／最初の状態に戻す／固定する／固定を外す／**答え合わせをする**／入力を全部戻す（答え合わせの物に） |
| **値** | 「値にする」のとき |

- 例：ItemInteraction（アイテムをはめる）の「成功時」に付けて、宝石をはめたら仕掛けを ON。「決定」のレバー（調べるスイッチ）の「変わったときのイベント」に付けて、答え合わせをする。
- イベントからの操作は、固定されていても変えます。

**攻撃で作動するスイッチ（AttackSwitch）**：**仕掛けの状態**の欄に仕掛けを入れると、作動したときに ON（切り替え・次へ も選べる）にします。シグルの弾でしか作動しない的 → 扉、などが作れます（Hierarchy 右クリック > 敵 > 攻撃で作動するスイッチ。くわしくは `Docs/敵の作り方.md`）。

## 13. 配線を見る・確かめる

- **配線の表示**：スイッチ・扉・答え合わせを選ぶと、Scene ビューに**つながっている相手への矢印**と「スイッチA → 条件で動く：ON のとき」のような説明が出ます。再生中は ON の仕掛けからの線が黄色になります。**Tools > 仕掛け > 配線をいつも全部表示** で、選んでいなくても全部出ます。
- **デバッグウィンドウ（Tools > デバッグ）の「仕掛け」**（再生中）：シーンの仕掛けの状態の一覧。「切り替え／次へ」「戻す（固定も外す）」、答え合わせは「答え合わせ」「入力を戻す」と、今の状態（ON の数・順番の進み・今の値と答え）。
- **シーンチェック**で見つかるもの：
  - 仕掛けのセーブの名前が重なっている
  - どこからも使われていない仕掛け（参考）
  - 条件で動く物の条件が空、仕掛けの入っていない行、何も切り替えない、自分を隠す
  - 答え合わせの入力が空、答えの数が入力の数と合わない、順番の入力が 1 つ
  - 調べるスイッチに調べる範囲がない
  - 「仕掛けを操作」の仕掛けが空
  - 床スイッチ・置き台に範囲がない、置き台のアイテムが空
  - 穴に当たり判定がない
  - 押せる箱の当たり判定が Is Trigger・マスより大きい、セーブの名前が重なっている
  - 状態で見た目を変える部品に仕掛けの状態がない
- デバッグウィンドウの「仕掛け」には、時間で戻る仕掛けの残り時間と、**押せる箱の「全部元に戻す」**も出ます。

## 14. 困ったとき（仕掛け）

| こんなとき | 確かめること |
|---|---|
| スイッチを調べても反応しない | 範囲（Is Trigger の Collider2D）の中に、操作しているキャラがいるか／使えるキャラ／使える条件／固定されていないか（デバッグで「（固定）」） |
| 扉が開かない | 扉の条件の「仕掛け」にスイッチが入っているか／比べ方（ON のとき・OFF のとき）／ほかの条件も全部満たしているか。スイッチを選んで、扉への矢印が出るか見る |
| 扉が開いたままになる | 「一度満たしたらずっと」がオン |
| シーンに戻るとスイッチが戻っている | 仕掛けの状態の「セーブする」がオフ／セーブ（セーブポイント・シーンの移動）の前にタイトルに戻った |
| 同じ名前のスイッチの記録が混ざる | 同じ親の下に同じ名前の物がある（セーブ用の ID を付ける。シーンチェックで出る） |
| 順番の謎が最初に戻る | 途中でシーンを出ると、戻ったときは最初から（作りどおり） |
| 箱が押せない | 押せるキャラ／行き先に壁・箱・キャラ・敵がないか／箱に向かって上下左右に歩き続けているか（斜めは横か縦の強い方）／箱の当たり判定がマスより大きくないか（シーンチェック） |
| 箱が穴に落ちない | 穴に当たり判定（Is Trigger オフ）があるか／もう埋まっていないか |
| 床スイッチが押されない | 反応する物（ノア・シグル・箱・敵）／必要な数／乗った物の中心が範囲に入っているか／範囲の Is Trigger |
| 置き台にはめられない | アイテムの個数／使えるキャラ／もうはめてある（取り外せない） |
| 燭台が光らない | GimmickVisual の行の値（1 = ON）と、表示する物・有効にする部品／暗いステージの LightSource の設定 |
| 時間で戻らない | 「戻るまでの秒数」が 0／固定されている（答え合わせが済んだ） |
| 組み合わせが正解なのに開かない | 答えの値の並びが入力の並びと合っているか／「イベントの部品で確かめたとき」になっていて、確かめていない |

## 15. 待て／ついてこい（相棒に指示する）

**F キーで、相棒をその場で待たせる・呼び戻す**ことができます（キーはシーンの PlayerSwitchManager の「待て／ついてこいのキー」で変えられます）。

| 今の状態 | F を押すと |
|---|---|
| 一緒 | **待機**：相棒がその場で待つ（体力は別々になる） |
| 待機 | **一緒**：相棒が歩いて合流する。**道がないと来られない**（「来られない」音、または会話） |
| 別行動 | 使えない（イベントで一緒に戻す） |

- 待たせている間に C で切り替えると、位置は入れ替わらず、カメラが相手へ移ります。
- **同時押し**：相棒を床スイッチの上で待たせ（10-1）、もう片方で開いた扉の先へ進む。
- 呼び戻すと、相棒は道（まっすぐ・回り道）を探して歩いてきます。**狭い通路の向こう・壁の向こうなど、道がないときは来られません。** 先に道を作る（扉を開ける）か、通路を出てから呼びます。
- **F キーを使えなくする**：イベントの部品「2人の状態を変える」の **待て／ついてこいのキー** で「使えなくする」「使えるようにする」（追跡中・離れ離れの場面など）。状態は変えずにキーだけ変えるときは **2人の状態を変える** をオフにします。
- PlayerSwitchManager の **待たせたとき・呼び戻したとき・来られないときの SE**、**相棒が来られないときのイベント**（「そっちには行けない……」の会話など）で演出を付けられます。

> **当たり判定について**：シグルの体の当たり判定は、プレハブで無効になっています（ついてくるときにノアに引っかからないように）。**シグルを操作しているとき・待たせているとき・別行動のときは有効**になり、壁で止まり、調べる範囲・イベントの範囲・狭い通路などに反応します。

## 16. 2人の能力を使う仕掛け

Hierarchy 右クリック > **仕掛け > 2人 > …** で置けます。

### 16-1. 狭い通路（ノアだけ通れる）（CharacterBarrier）

| 項目 | 意味 |
|---|---|
| **通れるキャラ** | ノアだけ（狭い通路）／シグルだけ |
| **入ったら相棒を待たせる** | 一緒のときに通れるキャラが入ると、相棒は入口で自動で待つ（オンのままにしてください。オフだと、ついてくる相棒が通路をすり抜けます） |
| **相棒を待たせたときの SE** | |

- 当たり判定（Is Trigger オフの Collider2D）が、通れるキャラにとってだけ「ない」ことになります。通れないキャラ・敵・押せる箱にとってはふつうの壁です。
- 見た目は「見た目」の絵を差し替えます（低い穴・すき間など）。
- 例：ノアが狭い通路を抜けて、向こうのスイッチでシグル側の扉を開ける → シグルに切り替えて先へ → 合流したら F で呼ぶ。

### 16-2. 壊せる壁（シグルだけ壊せる）（BreakableWall）

| 項目 | 意味 |
|---|---|
| **壊せるキャラ** | 攻撃したキャラ（初期値：シグルだけ。シグルの弾で壊す） |
| **攻撃の種類・ゲージの判定** | さらに絞る（ノアのゲージ攻撃のパーフェクトだけ、など） |
| **壊れるまでの回数** | |
| **壊れた絵** | がれきの絵（空なら絵を消す） |
| **壊れたときのエフェクト・SE・イベント** | |
| **当たったときの／効かない攻撃のエフェクト・SE** | 壊せる攻撃が当たるたび／条件に合わない攻撃（ノアの攻撃など）が当たったとき |

- 壊れたことは仕掛けの状態（ON）でセーブされ、扉などの条件にも使えます。

### 16-3. キャラにだけ見える物（ConditionalVisible）

| 項目 | 意味 |
|---|---|
| **見える条件** | 初期値は「ノアを操作しているとき」。シグルにするなら「操作中のキャラ」をシグルに。フラグ・仕掛けの状態なども使える |
| **切り替わる時間・見えていないときの濃さ** | ふわっと出る・消える。濃さを 0.15 などにすると、うっすら見える |
| **当たり判定** | 変えない／**見えている間だけ当たる**（見える壁）／**見えていない間だけ当たる**（見えると消える壁＝見えている間だけ渡れる足場の下の穴） |

- 子の絵（SpriteRenderer・Tilemap）もまとめて出し消しします。
- 例：
  - ノアにだけ見える壁の文字（ヒント）。
  - シグルにだけ見える足場：穴の当たり判定を付けたオブジェクトに「見えていない間だけ当たる」を設定し、操作中のキャラをシグルにする。

### 16-4. 2人がそろってできること

- **条件の「2人がそろっている距離」**：ノアとシグルがこの距離以内にいるとき。調べるスイッチの「使える条件」に入れると、**2人で回すレバー**になります。
- **押せる箱の「2人で押す」**：相棒が箱のそば（2 マス以内）にいるときだけ押せる（とても重い扉・大きな岩）。一緒なら相棒はついてくるので、そのまま押せます。「1人で押したとき」に会話を入れられます。

### 16-5. 持ち上げる場所（踏み台と行き先）（LiftPoint）

Hierarchy 右クリック > **仕掛け > 2人 > 持ち上げる場所** で、次の 2 つができます。
- **踏み台（上がる）**：2人そろって調べると、ノアが行き先（上）へ跳ぶ。
- **降りる場所**：一人で調べると下へ戻る。

| 項目 | 意味 |
|---|---|
| **移るキャラ** | 行き先へ移るキャラ（初期値：ノア） |
| **行き先** | 移る先の位置（空のオブジェクト） |
| **相棒の手伝いが要る** | オン：2人ともこの場所の近く（手伝う相棒の距離）にいるときだけ使える。手伝った相棒はその場で待つ／オフ：移るキャラが一人で使える（降りる・飛び降りる） |
| **移る時間・跳ぶ高さ・SE** | |
| **移ったあとのイベント** | |
| **手伝いがいないとき** | 例：「一人じゃ届かない……シグル、手伝って」 |

- 移ったあとは、移ったキャラを操作します（手伝った相棒は待機）。降りたら F で呼んで合流します。

### 16-6. 「相棒の出番」の目印

使えるキャラが決まった仕掛け（調べるスイッチ・置き台・押せる箱・壊せる壁・狭い通路）に、使えないキャラで近づくと、仕掛けの上に **「シグル」「ノア」の札**が出ます（切り替えを促す）。

- 見た目（文字・色・背景・大きさ・出す距離）は `Assets/Resources/PartyHints.asset`（**Tools > 仕掛け > 相棒の目印の設定を作る** で選べる）で変えられます。「出す」をオフにすると出ません。

## 18. 離れ離れのステージ

### 18-1. 作り方の考え方

**同じシーンの中に、2人それぞれのエリアを離して作ります。**
- フラグ・仕掛けの状態・セーブ・敵が、そのまま両方のエリアで使えます。片方のスイッチでもう片方の扉が開く、は「スイッチと扉が別のエリアにある」だけです。
- **違うシーンに移ると、2人は「一緒」に戻ります**（相棒もついてくる）。離れ離れの間は、シーンの出口を使わないか、出口を合流の後に置きます。

**流れの例**
1. 2人で歩いてきて、崩れた床（イベント）で離れ離れになる。会話のあとで、イベントの部品 **2人の状態を変える**：別行動、操作するキャラ：ノア、**待て／ついてこいのキー：使えなくする**。続けて、イベントの部品 **キャラを移す**（移すキャラ：シグル、移す場所：シグル側のエリアに置いた空のオブジェクト、暗転する）でシグルを別のエリアへ送る。
2. それぞれのエリアを **カメラの範囲** で囲む（相手のエリアが映り込まない）。
3. C で切り替えながら、それぞれのエリアの仕掛けを解く。片方で何かが起きたら、**カメラを向ける** で相手側の変化を見せる。
4. 出口の **合流の範囲** に2人がそろったら、一緒に戻る（再会の会話）。

**キャラを移す（PartyWarpEventAction）**：移すキャラ（ノア・シグル・操作しているキャラ・相棒）を **移す場所** へ移します。**暗転する** なら暗転している間に移し、「順番に実行」では明転し終わるまで次を待ちます。**一緒のときに 1 人だけ移すと相棒がついてきてしまう**ので、先に「2人の状態を変える」で別行動にします。

2人が別々の道へ歩いていく作り（狭い通路で分かれる・持ち上げる場所で分かれる）でも離れ離れにできます。

### 18-2. カメラの範囲（CameraArea）

Hierarchy 右クリック > **仕掛け > 2人 > カメラの範囲（エリアごと）**。

- Is Trigger の四角の中にカメラが追うキャラがいる間は、**カメラはその四角の外を映しません**（ふだんはマップ全体）。
- 四角の大きさ（BoxCollider2D の Size）をエリアに合わせます。**画面より小さいと、中ではカメラが動かず真ん中に固定**されます（シーンチェックで「参考」）。
- 重なっているときは **優先度** の大きい方を使います。
- 別の範囲に入った（部屋を移った）ときは、カメラがなめらかに移ります（部屋ごとに区切ったカメラにも使えます）。

### 18-3. 離れているときの設定（シーンの PlayerSwitchManager）

| 項目 | 意味 |
|---|---|
| **切り替えの演出** | 待機・別行動のときに C で切り替えたときのカメラ：**すぐ／スライド**（なめらかに移る。初期値）／**暗転**（別のエリアにいるとき向き） |
| **敵が狙う相手** | 待機・別行動のとき：**操作しているキャラだけ**（初期値。待っている相棒は狙われない）／**近い方**（待っている相棒も狙われる。緊張感が出るが、相棒の体力が 0 になってもゲームオーバー） |

### 18-4. カメラを向ける（CameraLookEventAction）

イベントの部品。**見せる場所** へカメラを向けて、**見せる時間** だけ見せてから戻します。

| 項目 | 意味 |
|---|---|
| **見せる場所** | 扉など（空のオブジェクトでもよい） |
| **動く時間・見せる時間** | |
| **戻す** | オフにすると向けたまま（次の「カメラを向ける」で戻す） |

- 「順番に実行」の EventSequence では、戻すまで次の部品を待ちます。見せている間プレイヤーを止めたいときは **Lock Player** をオン。
- 例：ノアがスイッチを入れる → 仕掛けを ON → **カメラを向ける**（シグル側の扉）→ 扉が開くのを見せて戻る。

### 18-5. 合流の範囲（PartyRejoinArea）

Hierarchy 右クリック > **仕掛け > 2人 > 合流の範囲**。

| 項目 | 意味 |
|---|---|
| **合流したときのイベント** | 子の「合流したとき」に再会の会話・SE |
| **待て／ついてこいを使えるようにする** | 離れ離れの間に使えなくしていたキーを戻す |
| **1回だけ（セーブする）・セーブ用の ID** | |

- 範囲の中に **2人がそろうと**、「一緒」に戻ってイベントを実行します。

### 18-6. セーブ

- **セーブするたびに**（セーブポイント・シーンに着いたとき・シーンを出るとき など）、2人の状態・操作しているキャラ・相棒の位置・「待て／ついてこい」を使えなくしているかを記録します。
- **同じシーンに戻ったとき**（つづきから・戦闘エリアのやり直し・同じシーンの読み直し）は、離れ離れのまま戻ります。
  - 操作していたキャラは再開する位置（セーブポイントなど）に出ます。
  - 相棒は記録した位置に出ます。
- 違うシーンに移ったときは「一緒」に戻ります。
- **体力もセーブします**（ノア・シグルそれぞれ。シーンを移っても、つづきから・やり直しでも、セーブしたときの体力に戻る）。倒れてゲームオーバーになったとき・はじめからは、2人とも満タン。

### 18-7. 困ったとき（離れ離れ）

| こんなとき | 確かめること |
|---|---|
| 相手のエリアが画面に映る | カメラの範囲で囲んでいるか／四角がエリアより大きくないか |
| カメラが動かない | カメラの範囲が画面より小さい（真ん中に固定）。シーンチェックで「参考」が出る |
| 切り替えるとカメラがパッと飛ぶ | PlayerSwitchManager の「切り替えの演出」 |
| 待っている相棒が敵にやられる | 「敵が狙う相手」が「近い方」になっている |
| 合流しない | 2人とも合流の範囲の中にいるか／Is Trigger／「1回だけ」で合流済み |
| つづきからで2人が一緒に戻った | セーブしたシーンと違うシーンで再開している／セーブより後に離れ離れになった |

## 19. ホラー・謎解きの演出

Hierarchy 右クリック > **仕掛け > 謎解き > …** で置けます。

### 19-0. 謎解きの画面（共通）

番号錠・何をはめるか選ぶ・メモを読む は、同じ「謎解きの画面」に出ます。開いている間は、プレイヤー・敵は止まります。

| 操作 | キー |
|---|---|
| 選ぶ・変える | ↑↓←→（W A S D） |
| 決定 | Space / Enter / E |
| やめる・とじる | Esc / Tab / Backspace |

- 見た目（フォント・色）は `Assets/Resources/PuzzleUI.asset`（**Tools > 仕掛け > 謎解きの画面の設定を作る** で選べる）で変えられます。

### 19-1. 番号錠（CodeLock）

| 項目 | 意味 |
|---|---|
| **画面の見出し** | 例：「金庫の番号」 |
| **使える文字** | 1 文字ずつ順に回る。数字なら `0123456789`、色なら `赤青黄緑`、曜日なら `月火水木金土日` |
| **答え** | 使える文字で書いた答え（桁の数は答えの文字数）。例：`0314` |
| **前の入力を覚えておく** | もう一度調べたとき、前に入れた並びから始まる |
| **使えるキャラ** | |
| **正解・間違いの SE とイベント** | 正解すると仕掛けの状態が ON（固定・セーブ）。扉は、扉の「条件」にこの番号錠を入れる |
| **開いたあとに調べたとき** | 「もう開いている」など |

- ヒントは、メモ（19-3）や会話で渡します。

### 19-2. 何をはめるか選ぶ置き台（ItemSocket の Choices）

置き台（10-3）の **Choices（選べるアイテム）** にアイテムを並べると、調べたときに、**持っている物の中から選ぶ画面**が出ます。

- 仕掛けの状態は「**選んだアイテムが Choices の何番目か（1 から）**」になります（0 ＝何もはめていない）。
- 例：4 つの台に「どの像に何を」持たせる謎（バイオハザード）。
  1. 4 つの台の Choices を同じ並び（例：剣・盾・冠・杖）にする。
  2. 答え合わせ（決めた組み合わせ）の入力に 4 つの台を入れ、Answer に正しい番号（例：2, 4, 1, 3）を並べる。
- 「取り外せる」をオンにすると、間違えたときに外してはめ直せます。

### 19-3. メモ（NoteData・NotePickup・メニューの「メモ」）

1. Project の `Assets/Resources/Notes/` で右クリック > **Create > 仕掛け > メモ**。**見出し・本文**（長いとページに分かれる）・**絵**・**並び順**を書く。**必ず `Resources/Notes/` に置く**（メニューの一覧に出すため）。
2. Hierarchy 右クリック > **仕掛け > 謎解き > メモ（調べると読む）** を置き、**メモ** に 1 で作った NoteData を入れる。

| 項目（NotePickup） | 意味 |
|---|---|
| **拾ったら消す** | オン：読み終わったら見た目を消す（シーンに戻っても消えたまま）／オフ：何度でも読める（壁の落書き・掲示板） |
| **拾ったときの SE・読み終わったときのイベント** | 例：「……これは、金庫の番号？」の会話 |

- 読んだメモは、**メニュー（Tab）> メモ** でいつでも読み返せます。持っているかはセーブされます。
- イベントで渡すときは、イベントの部品 **メモを渡す（NoteEventAction）**（その場で読む／持っていることにするだけ）。「順番に実行」では読み終わるまで次を待ちます。
- 今あるメニュー画面のプレハブには「メモ」のボタンを足してあります（**Tools > メニュー画面 > メニューに「メモ」を足す**。作り直しは **Tools > メニュー画面 > メニューのプレハブを作成**）。

### 19-4. 調べるたびに変わる（ExamineSequence）

Hierarchy 右クリック > **仕掛け > 謎解き > 調べるたびに変わる** で、子に「1回目」「2回目」「3回目」の EventSequence ができます。

| 項目 | 意味 |
|---|---|
| **Sequences** | 1 回目・2 回目・3 回目… に実行するイベント（上から順に） |
| **最後まで行ったら** | 最後をくり返す／最初に戻る／もう何もしない |
| **使えるキャラ・使えないキャラで調べたとき** | |
| **回数を出す仕掛けの状態** | 調べた回数を入れる GimmickState（段階の数を多めに）。扉の条件で「3 回調べたら」に使う |
| **セーブ用の ID** | 何回調べたかはセーブされる |

- 例：絵を調べる 1 回目「きれいな絵」→ 2 回目「……目が動いた？」→ 3 回目 絵から手が出てくる（Ib・魔女の家）。

### 19-5. 即死の罠とやり直す位置（DeathTrap・RetryPoint・即死）

- **やり直す位置**（Hierarchy 右クリック > 仕掛け > 謎解き > やり直す位置）：部屋の入口に置く。範囲に入ると「やり直す位置」と、そのときまでの進行を記録します（ファイルには書かない）。子の **出る位置** がやり直したときに出る場所です。
- **即死の罠**（仕掛け > 謎解き > 即死の罠）：範囲に入ると即死。

| 項目（DeathTrap） | 意味 |
|---|---|
| **即死したあと** | **やり直す**（やり直す位置から。記録したあとに拾った物・立てたフラグ・開けた扉などは元に戻る）／**ゲームオーバー** |
| **作動する条件** | 例：仕掛けが OFF のとき（スイッチで罠を止められる） |
| **即死の演出** | 叫び声・画面を赤く・会話など。終わってから暗転する |

- イベントで即死させるときは、イベントの部品 **即死（DeathEventAction）**。その前に並べた会話・SE が流れてから暗転します（選択を間違えた会話のあと、など）。
- やり直す位置がないシーンでは、セーブの「再開する位置」（シーンの入口・セーブポイント）からやり直します（シーンチェックで「参考」）。
- 反応するのは操作しているキャラだけです（ついてくる相棒・待たせている相棒は引っかからない）。

### 19-6. 見ていない間に動く物（像・人形）

敵の行動の部品 **移動 > 見ていない間に近づく（像・人形）** を使います（`Docs/敵の作り方.md` 4 章）。サンプルの敵 **EnemyData_Sample_像** は、攻撃が効かず、見られていない間だけ近づいて、触れるとダメージを与えます。

- **見られている判定**：プレイヤーがこちらを向いている（初期値。視野の角度・見える距離・壁の向こうは見えない）／画面に映っている／どちらか／両方。
- 止めたい・消したいときは、イベントの部品「敵に命令」（止める・消す）を使います。

### 19-7. 困ったとき（演出）

| こんなとき | 確かめること |
|---|---|
| 番号錠が正解にならない | 答えの文字が「使える文字」に入っているか（シーンチェック）／桁の数（答えの文字数） |
| 置き台で選ぶ画面が出ない | Choices にアイテムが入っているか／選べるアイテムを持っているか（持っていなければ「持っていないとき」） |
| メモがメニューに出ない | NoteData が `Assets/Resources/Notes/` にあるか（シーンチェック）／拾ったあと、セーブ（確定）の前にタイトルに戻っていないか |
| メニューに「メモ」がない | Tools > メニュー画面 > メニューに「メモ」を足す |
| 即死してもやり直さない | 即死したあとが「ゲームオーバー」になっていないか／罠の範囲の Is Trigger |
| 思ったより前からやり直しになる | やり直す位置の範囲に入っていない（シーンの入口からになる） |
| 像が動かない・止まらない | 見られている判定（向き／画面）・視野の角度・見える距離。デバッグウィンドウの「敵」で今の行動を見る |
| 謎解きの画面でキーが効かない | ゲームの画面をクリックしてから操作する（エディタではゲームビューにフォーカスが必要） |

## 20. 練習

### 練習 1：2つのスイッチで開く扉（1つはシグルだけ）

**ゴール**：左のレバーはシグルにしか動かせない。両方のレバーを ON にすると扉が開く。

1. Hierarchy 右クリック > **仕掛け > 調べるスイッチ** を 2 つ。名前を `レバー左`・`レバー右` にする
2. `レバー左` の GimmickSwitch の **使えるキャラ** を **シグルだけ**。**使えないキャラで調べたとき** に、子に作った EventSequence + Dialogue（「重くて動かない……シグルなら」）を入れる
3. `レバー左` → `レバー右` の順に Ctrl を押しながら選び、右クリック > **仕掛け > 条件で動く物（扉）**。扉を通路に置く
4. **確かめる**：
   1. 再生してノアで `レバー左` を調べると、会話が出る。
   2. C でシグルに切り替えて `レバー左` を ON、`レバー右` も ON にすると扉が消える。
   3. スイッチを選ぶと、Scene ビューに扉への矢印が出る。

### 練習 2：箱で床スイッチを押さえ、穴を埋めて進む（押せる箱・床スイッチ・穴・ずれて開く扉）
**ゴール**：箱を床スイッチに乗せると扉が横にずれて開く。その先の穴は、もう1つの箱を押し込んで埋める。

1. Hierarchy 右クリック > **仕掛け > 床スイッチ**、**押せる箱** を 2 つ、**穴（箱で埋まる）** を置く。箱 1 は床スイッチから 2 マス離れた所、穴は扉の先の通路、箱 2 は穴の手前に
2. 床スイッチを選んで、右クリック > **仕掛け > 条件で動く物（扉）**。扉の **Hide When Met** の「閉じた扉」を − で外し、**Moves** の ＋ で **動かす物** に「閉じた扉」、**動かす距離** を (2, 0)、**動く時間** 0.6 に（横にずれて開く）
3. 床スイッチの **動き** が「乗っている間だけ ON」、**反応する物** の「押せる箱」がオンなのを確かめる
4. 戻すレバー：**仕掛け > 調べるスイッチ** を置いて `戻すレバー` に。子に EventSequence + **PushBlockResetEventAction**（箱は空＝全部）を作り、GimmickState の **変わったときのイベント** に入れる
5. **確かめる**：
   1. 再生して、箱 1 を床スイッチに押していくと、扉が横にずれて開く。
   2. ノアが床スイッチから降りても、箱が乗っていれば開いたまま。
   3. 箱 2 を穴に押し込むと穴が埋まって通れる。
   4. 箱を角に詰まらせてから `戻すレバー` を調べると、箱が戻る。

### 練習 3：狭い通路を抜けて、相棒のために扉を開ける（狭い通路・待て／ついてこい・同時押し）
**ゴール**：
- ノアだけが狭い通路を抜けられる。
- 向こうの床スイッチをノアが踏んでいる間だけ、シグル側の扉が開く。
- シグルが扉を抜けたら、2人で合流する。

1. 通路の壁の切れ目に、Hierarchy 右クリック > **仕掛け > 2人 > 狭い通路（ノアだけ通れる）** を置き、すき間をふさぐ大きさにする（BoxCollider2D の Size と「見た目」の大きさ）
2. 通路の向こうに **仕掛け > 床スイッチ**（反応する物：ノアだけオン）
3. 床スイッチを選んで **仕掛け > 条件で動く物（扉）** を作り、シグル側の別の道をふさぐ位置に置く
4. **確かめる**：
   1. 再生してノアで通路に入ると、シグルが入口で止まる（待機）。
   2. 抜けて床スイッチに乗り、C でシグルに切り替える（ノアは乗ったまま待つ）。
   3. 扉が開いているのでシグルで抜け、ノアのそばまで歩いて F を押すと 2人が合流する。
   4. 通路の手前で F を押すと「来られない」音が鳴る。

### 練習 4：離れたエリアで、お互いの扉を開け合う（カメラの範囲・カメラを向ける・合流）
**ゴール**：
- ノアのエリアとシグルのエリアが離れている。
- ノアがスイッチを入れるとシグル側の扉が開き（カメラで見せる）、シグルが床スイッチに乗るとノア側の扉が開く。
- 出口で 2人がそろうと再会の会話。

1. 同じシーンの離れた場所に、エリアを 2 つ作る（壁で区切る）。それぞれを **仕掛け > 2人 > カメラの範囲** で囲む
2. ノア側に **調べるスイッチ**、シグル側に **条件で動く物（扉）**（条件：ノア側のスイッチが ON）
3. ノア側のスイッチの GimmickState の **変わったときのイベント** に、EventSequence（Lock Player オン）+ **CameraLookEventAction**（見せる場所：シグル側の扉）
4. シグル側に **床スイッチ**（シグルだけオン）、ノア側に **条件で動く物（扉）**（条件：その床スイッチが ON）
5. 2つのエリアの先がつながる出口に **仕掛け > 2人 > 合流の範囲**。子の「合流したとき」に再会の会話
6. **確かめる**：
   1. 離れ離れにする：ノア側の入口に EventZone を置き、EventSequence に **2人の状態を変える**（別行動）→ **キャラを移す**（シグル → シグル側のエリアの空のオブジェクト）を並べる。再生して入る（デバッグウィンドウの「プレイヤー」で別行動にし、ワープで移してもよい）。
   2. ノアでスイッチを入れると、カメラがシグル側の扉へ移って開くのを見せ、戻ってくる。
   3. C で切り替えると、カメラがなめらかにシグルへ移る（相手のエリアは映らない）。
   4. シグルで床スイッチに乗り、ノアに切り替えて扉を抜ける（シグルは乗ったまま待つ）。
   5. 出口で 2人がそろうと、会話が出て一緒に戻る。

### 練習 5：日記を読んで金庫を開け、像から逃げる（メモ・番号錠・即死の罠・像）
**ゴール**：
- 日記に書かれた番号で金庫を開けると鍵が手に入る。
- 鍵で扉を開けた先で、像が背後から近づいてくる。
- 床の罠に引っかかると、部屋の入口からやり直し。

1. `Assets/Resources/Notes/` に **Create > 仕掛け > メモ** で `Note_日記` を作る（本文に「金庫の番号は 0314」）
2. **仕掛け > 謎解き > メモ（調べると読む）** を机の上に置き、メモに `Note_日記`
3. **仕掛け > 謎解き > 番号錠** を金庫の位置に置き、答え `0314`、正解したときのイベントに **ItemGiveEventAction**（鍵）
4. 鍵の扉は **仕掛け > 置き台**（はめるアイテム：鍵）＋ **条件で動く物（扉）**（条件：置き台が ON）
5. 扉の先の部屋の入口に **仕掛け > 謎解き > やり直す位置**、部屋の床に **即死の罠**（即死したあと：やり直す）
6. Hierarchy 右クリック > **敵 > 敵を置く** で部屋の奥に像を置き、敵のデータに **EnemyData_Sample_像**
7. **確かめる**：
   1. 日記を読み、Tab > メモ で読み返せる。
   2. 金庫に 0314 を入れると鍵がもらえ、扉が開く。
   3. 部屋で像に背を向けると近づいてくる（向くと止まる）。
   4. 罠を踏むと、部屋の入口からやり直しになる（扉は開いたまま、鍵も使ったまま＝やり直す位置に入る前のことは戻らない）。
