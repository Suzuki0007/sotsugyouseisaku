# 謎解きと2人の仕掛けの作り方（プランナー向け）

最終更新：2026-11-08（段階1：仕掛けの土台 まで）

謎解き・ステージギミック・ノアとシグルの協力・離れ離れの展開を、コードを書かずに作るための手順書です。段階ごとに作っているので、できるようになったものから書き足していきます。

**今できること**
- 2人の状態（一緒・待機・別行動）をイベントで切り替える。一緒のときは体力を共有（シグルがノアを守っている）、離れているときは別々（1〜4 章）
- 攻撃は操作しているキャラだけが出す
- **仕掛け**（6〜12 章）
  - 調べるスイッチ（使えるキャラ：両方・ノアだけ・シグルだけ）
  - 条件で動く扉・橋
  - 答え合わせ（全部 ON／決めた順番／決めた組み合わせ）
  - イベントや攻撃で仕掛けを動かす
  - 配線の表示

これから作るもの（予定）：
- 床スイッチ・押せる箱・時間制限・燭台などの部品
- 「待て／ついてこい」・狭い通路・重い物・壊せる壁
- 離れ離れのステージ（エリアごとのカメラ・合流・セーブ）
- ホラー・謎解きの演出、相棒の一言

---

## 1. 2人の状態

| 状態 | 相棒（操作していない方） | キャラを切り替えると | 体力 |
|---|---|---|---|
| **一緒**（はじめはこれ） | 後ろについてくる | 2人の位置が入れ替わる | **2人で共有**（シグルの体力から減る） |
| **待機** | その場で待つ | 位置はそのまま。カメラが相手へ移る | 別々 |
| **別行動**（離れ離れ） | その場にいる | 位置はそのまま。カメラが相手へ移る | 別々 |

- **一緒に戻すと、相棒が合流します。** 近ければ（10 マス以内）歩いて追いつき、遠ければ操作しているキャラの位置へ移ります。距離はシーンの PlayerSwitchManager の「相棒が歩いて合流する距離」で変えられます。
- **今は2人の状態をセーブしません**（シーンを読み込むと「一緒」に戻ります）。離れ離れのステージの段階で、セーブするようにします。

### 1-1. イベントで状態を変える（2人の状態を変える）

EventSequence に **PartyModeEventAction（2人の状態を変える）** を付けます。

| 項目 | 意味 |
|---|---|
| **2人の状態** | 一緒／待機／別行動 |
| **操作するキャラも変える** | オンにすると、下で選んだキャラに操作を切り替える |
| **操作するキャラ** | ノア／シグル |

例：
- 崩れた床で2人が分かれる → 会話のあとで「別行動」にする。操作するキャラは、先に進むほうにする
- 合流の場所に入ったら「一緒」に戻す（EventZone などで）

---

## 2. 体力

- **シグルは体力が多く（6）、ノアは少ない（3）**。値は `Assets/Prefab/Players/` の Player_Noah・Player_Sigle の **Health > Max Health** で変えられます。
- **一緒のとき**：シグルがノアを守っている、という作りです。ノアが攻撃を受けても、**シグルの体力から減ります**。画面のハートはシグルの体力で、白です。
- **離れているとき**：それぞれ自分の体力です。画面のハートは操作しているキャラの体力で、ノアはピンク、シグルは水色です。
  - ノアの体力は、離れたときの値から減っていきます（一緒の間は減りません）。
- **どちらかの体力が 0 になるとゲームオーバー**です（一緒のときは共有している体力が 0 になったとき）。
- ハートは、最大の体力の数だけ自動で並びます（置いてあるハートより多いときは、同じ間隔で増やします）。色はシーンの LifeUIController の「一緒のとき（2人で共有）の色」「離れているときのノアの色／シグルの色」で変えられます。
- 回復は、今の体力（一緒ならシグルの体力）を回復します。

---

## 3. 攻撃

- 攻撃は**操作しているキャラだけ**が出します（シグルを操作しているときに Space / R を押しても、ノアの攻撃は出ません）。
  - ノア：Space（範囲攻撃）、R（ゲージ攻撃）、Q（弾消し）
  - シグル：左クリック（射撃）

## 4. 確かめる

**デバッグウィンドウ（Tools > デバッグ）の「プレイヤー」**（再生中）：

| 項目 | 使い方 |
|---|---|
| **2人の状態** | 一緒／待機／別行動を直接切り替える |
| **今の体力** | 今の体力と、だれの体力か（2人で共有・ノア・シグル）。その下にノアとシグルそれぞれの値 |
| **全回復（2人とも）／1 ダメージ（今の体力）** | 体力の確認に |
| **無敵** | ダメージを受けない（シーンが変わっても続く） |

## 5. 困ったとき（2人の状態・体力）

| こんなとき | 確かめること |
|---|---|
| 切り替えると相手と位置が入れ替わってしまう | 2人の状態が「一緒」になっている（入れ替わるのは一緒のときだけ） |
| 相棒がついてこない | 2人の状態が「待機」か「別行動」になっている |
| ハートの数が変わった | 離れていると、操作しているキャラの体力（ノアは少ない）が出る |
| シーンを移ったら一緒に戻った | 2人の状態はまだセーブされない（これからの段階で対応） |

---

## 6. 仕掛けの考え方（入力 → 状態 → 条件 → 動く物）

謎解きの部品は、**「状態を持つ入力」と「条件で動く物」**の2つに分けて、**ドラッグでつなぐ**だけで作ります。

```
調べるスイッチ ─┐（ON / OFF）
攻撃で作動するスイッチ ─┤                ┌→ 条件で動く物（扉・橋が出る・壁が消える）
イベント（会話・アイテムをはめる）─┤→ 仕掛けの状態 →┤
                    │                └→ 答え合わせ（全部・順番・組み合わせ）→ その状態をまた扉の条件に
```

- **仕掛けの状態**（GimmickState）：ON / OFF（または 0, 1, 2 … の段階）。**セーブされます**（シーンに戻ってもスイッチは ON のまま）。
- **条件**：今までの「条件」（フラグ・アイテム・操作中のキャラ など）に、**仕掛け**と**2人の状態**の項目が増えました。敵の「動く条件」や戦闘エリアなど、条件を使うところならどこでも使えます。
  - **仕掛け**：「スイッチ A が ON のとき」「ダイヤルが 3 のとき」など。仕掛けの欄に、シーンに置いたスイッチ（GimmickState の付いた物）をドラッグする。
  - **2人の状態**：一緒のとき／離れているとき。
- 扉を開けるのは、**扉の「条件」にスイッチを入れる**のが基本です（スイッチ側に扉を入れるのではありません）。1つのスイッチを、いくつもの扉・橋が見られます。

---

## 7. 調べるスイッチ（レバー・ボタン・燭台・ダイヤル）

1. Hierarchy 右クリック > **仕掛け > 調べるスイッチ**。黄色い丸（見た目。差し替えてよい）と、調べる範囲（Is Trigger の円）ができます。
2. **GimmickState（仕掛けの状態）** と **GimmickSwitch（調べるスイッチ）** を設定します。

**GimmickState（仕掛けの状態）**

| 項目 | 意味 |
|---|---|
| **表示名** | デバッグや配線の表示に出る名前 |
| **段階の数** | 2 = OFF / ON。3 以上でダイヤル・像の向き（0, 1, 2 …） |
| **最初の状態** | 0 = OFF |
| **最後の次は最初に戻る** | ダイヤルなら オン（3 の次は 0）。オフなら最後で止まる |
| **変わったときのイベント** | 変わるたびに実行（音・見た目の差し替え。SpriteChange など） |
| **セーブする・セーブ用の ID** | オフにすると、シーンに入るたびに最初の状態に戻る |

**GimmickSwitch（調べるスイッチ）**

| 項目 | 意味 |
|---|---|
| **調べたとき** | ON / OFF を切り替える（段階があれば次へ）／ON にする（戻らない）／OFF にする／次の段階へ |
| **使えるキャラ** | **両方／ノアだけ／シグルだけ** |
| **使える条件** | 満たしているときだけ使える（例：電源のスイッチが ON） |
| **調べたときの SE** | |
| **使えないキャラで調べたとき** | 例：ノアで調べたら「重くて動かない……シグルなら」の会話。空なら「できない」音だけ |
| **条件を満たさないとき** | 例：「電気が来ていない」 |
| **固定されているとき** | 答え合わせが済んで動かせないとき |

- 調べられるのは、**範囲の中にいる「操作しているキャラ」だけ**です（ついてくる相棒・待たせている相棒が範囲にいても反応しません）。
- ON / OFF で見た目を変えたいときは、「変わったときのイベント」に SpriteChange などを入れるか、下の「条件で動く物」で ON の絵と OFF の絵を出し分けます。

---

## 8. 条件で動く物（扉・橋・消える壁）

1. （先にスイッチを Hierarchy で選んでおくと、そのスイッチが条件に入ります。Ctrl を押しながら複数選べます）Hierarchy 右クリック > **仕掛け > 条件で動く物（扉）**。
2. 子の **閉じた扉**（当たり判定つきの四角。差し替えてよい）は、条件を満たすと隠れます。子の **開いたとき** に音などの部品を付けます。

| 項目 | 意味 |
|---|---|
| **条件** | 「仕掛け」の ＋ でスイッチをドラッグし、比べ方（ON のとき／OFF のとき／この値のとき など）を選ぶ。フラグ・アイテム・2人の状態なども使える。**すべて満たすとき** |
| **一度満たしたらずっと** | オン：一度開いたら、スイッチを戻しても開いたまま（セーブする）／オフ：満たしている間だけ（踏んでいる間だけ開く、など） |
| **Show When Met** | 満たしているときに表示する物（出てくる橋） |
| **Hide When Met** | 満たしているときに隠す物（閉じた扉） |
| **満たしたときのイベント／満たさなくなったときのイベント** | 開く音・閉じる音・会話など |

- 表示の切り替えは、条件からいつも決まります。セーブから戻ったときも、スイッチの状態から自然に開いた／閉じた状態になります。
- **条件が空だと動きません**（設定し忘れで開きっぱなしにならないように）。
- **隠す物は子にしてください。** 自分（条件で動く物）を隠すと、条件を見られなくなります（シーンチェックでエラー）。

---

## 9. 答え合わせ（全部・順番・組み合わせ）

1. （入力にしたいスイッチを Hierarchy で選んでおくと、選んだ順に入力に入ります）Hierarchy 右クリック > **仕掛け > 答え合わせ**。
2. 答え合わせ自身も「仕掛けの状態」を持っていて、**正解すると ON** になります。扉の「条件」に、この答え合わせを入れます。

| 項目 | 意味 |
|---|---|
| **Inputs（入力）** | 答え合わせに使うスイッチなど。「決めた順番」なら、ON にする順番に上から並べる |
| **答え合わせのしかた** | **全部 ON にする**／**決めた順番に ON にする**（間違えたら全部戻る。燭台を順番に灯す）／**決めた組み合わせにする**（ダイヤル・像の向き） |
| **Answer（答え）** | 「決めた組み合わせ」の答え。入力と同じ順番に値を並べる（0 = OFF、1 = ON、ダイヤルなら 0, 1, 2 …） |
| **答え合わせをするとき** | 入力が変わるたびに（正解したらすぐ）／イベントの部品で確かめたとき（「決定」のレバーを引くと確かめる。違っていたら「間違えたとき」） |
| **正解したら入力を固定する** | 正解したら、入力のスイッチをもう動かせない |
| **正解したときのイベント・SE** | |
| **間違えたら入力を全部戻す・間違えたときのイベント・SE** | ダメージ・敵が出る・会話など |

- 正解したことはセーブされ、シーンに戻ったときも正解のまま（入力も固定されたまま）です。
- 「決めた順番」は、途中まで灯してシーンを出ると、戻ったときは最初からになります。

## 10. イベント・攻撃で仕掛けを動かす

**イベントの部品「仕掛けを操作」（GimmickEventAction）**：

| 項目 | 意味 |
|---|---|
| **仕掛け** | 仕掛けの状態（GimmickState）の付いた物 |
| **操作** | ON にする／OFF にする／切り替える／次の段階へ／値にする／最初の状態に戻す／固定する／固定を外す／**答え合わせをする**／入力を全部戻す（答え合わせの物に） |
| **値** | 「値にする」のとき |

- 例：ItemInteraction（アイテムをはめる）の「成功時」に付けて、宝石をはめたら仕掛けを ON。「決定」のレバー（調べるスイッチ）の「変わったときのイベント」に付けて、答え合わせをする。
- イベントからの操作は、固定されていても変えます。

**攻撃で作動するスイッチ（AttackSwitch）**：**仕掛けの状態**の欄に仕掛けを入れると、作動したときに ON（切り替え・次へ も選べる）にします。シグルの弾でしか作動しない的 → 扉、などが作れます（Hierarchy 右クリック > 敵 > 攻撃で作動するスイッチ。くわしくは `Docs/敵の作り方.md`）。

## 11. 配線を見る・確かめる

- **配線の表示**：スイッチ・扉・答え合わせを選ぶと、Scene ビューに**つながっている相手への矢印**と「スイッチA → 条件で動く：ON のとき」のような説明が出ます。再生中は ON の仕掛けからの線が黄色になります。**Tools > 仕掛け > 配線をいつも全部表示** で、選んでいなくても全部出ます。
- **デバッグウィンドウ（Tools > デバッグ）の「仕掛け」**（再生中）：シーンの仕掛けの状態の一覧。「切り替え／次へ」「戻す（固定も外す）」、答え合わせは「答え合わせ」「入力を戻す」と、今の状態（ON の数・順番の進み・今の値と答え）。
- **シーンチェック**で見つかるもの：
  - 仕掛けのセーブの名前が重なっている
  - どこからも使われていない仕掛け（参考）
  - 条件で動く物の条件が空、仕掛けの入っていない行、何も切り替えない、自分を隠す
  - 答え合わせの入力が空、答えの数が入力の数と合わない、順番の入力が 1 つ
  - 調べるスイッチに調べる範囲がない
  - 「仕掛けを操作」の仕掛けが空

## 12. 困ったとき（仕掛け）

| こんなとき | 確かめること |
|---|---|
| スイッチを調べても反応しない | 範囲（Is Trigger の Collider2D）の中に、操作しているキャラがいるか／使えるキャラ／使える条件／固定されていないか（デバッグで「（固定）」） |
| 扉が開かない | 扉の条件の「仕掛け」にスイッチが入っているか／比べ方（ON のとき・OFF のとき）／ほかの条件も全部満たしているか。スイッチを選んで、扉への矢印が出るか見る |
| 扉が開いたままになる | 「一度満たしたらずっと」がオン |
| シーンに戻るとスイッチが戻っている | 仕掛けの状態の「セーブする」がオフ／セーブ（セーブポイント・シーンの移動）の前にタイトルに戻った |
| 同じ名前のスイッチの記録が混ざる | 同じ親の下に同じ名前の物がある（セーブ用の ID を付ける。シーンチェックで出る） |
| 順番の謎が最初に戻る | 途中でシーンを出ると、戻ったときは最初から（作りどおり） |
| 組み合わせが正解なのに開かない | 答えの値の並びが入力の並びと合っているか／「イベントの部品で確かめたとき」になっていて、確かめていない |

## 13. 練習：2つのスイッチで開く扉（1つはシグルだけ）

**ゴール**：左のレバーはシグルにしか動かせない。両方のレバーを ON にすると扉が開く。

1. Hierarchy 右クリック > **仕掛け > 調べるスイッチ** を 2 つ。名前を `レバー左`・`レバー右` にする
2. `レバー左` の GimmickSwitch の **使えるキャラ** を **シグルだけ**。**使えないキャラで調べたとき** に、子に作った EventSequence + Dialogue（「重くて動かない……シグルなら」）を入れる
3. `レバー左` → `レバー右` の順に Ctrl を押しながら選び、右クリック > **仕掛け > 条件で動く物（扉）**。扉を通路に置く
4. **確かめる**：
   1. 再生してノアで `レバー左` を調べると、会話が出る。
   2. C でシグルに切り替えて `レバー左` を ON、`レバー右` も ON にすると扉が消える。
   3. スイッチを選ぶと、Scene ビューに扉への矢印が出る。
