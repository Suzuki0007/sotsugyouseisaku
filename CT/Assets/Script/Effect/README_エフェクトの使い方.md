# エフェクトの使い方（プランナー向け）

コードを書かずに、**素材を入れる → EffectData を作る → EffectTrigger を付ける** の3ステップでエフェクトを出せます。

---

## 1. 素材を入れる

- 画像は `Assets/Images/Effect/` に入れてください。
- 入れた画像を選び、Inspector の **Texture Type** を **Sprite (2D and UI)** にします。
  - 1枚の画像にコマが並んでいる（スプライトシート）場合は、**Sprite Mode: Multiple** にして **Sprite Editor** で切り分けてください。
  - `hit_01.png, hit_02.png …` のように1コマずつ分かれた画像でもOKです。
- パーティクルで作る場合は、Prefab を用意してください。

## 2. EffectData を作る

Project ウィンドウで素材を選んで **右クリック → Create → Effect** から作ります。

| メニュー | 使うとき |
|---|---|
| EffectData (選択した画像をまとめて1つのアニメに) | 連番画像をまとめて選んだとき／切り分けたスプライトを選んだとき |
| EffectData (画像ファイルごとに作成) | スプライトシートを何枚か選び、1枚につき1つ作りたいとき |
| EffectData (選択したPrefabから作成) | パーティクルなどの Prefab から作るとき |
| EffectData (空) | 中身を後から入れたいとき |

`Fx_hit` のような名前で、素材と同じフォルダにできます。画像は名前順（01, 02, … 10 の順）に並びます。

### Inspector で調整する

作った EffectData を選ぶと、Inspector の中で**アニメーションのプレビュー**が動きます。

```
┌ 見た目 ───────────────────────┐
│ 表示方法   スプライト連番          │
│ 画像       [hit_01][hit_02]…    │
│ 速さ       12   ← 大きいほど速い  │
│ 色         □ 白 = そのまま       │
│ ┌──────────────┐          │
│ │   (プレビュー)  │ ← ここで動く │
│ └──────────────┘          │
├ 消え方 ───────────────────────┤
│ いつ消えるか  自動 / 秒数 / ループ │
├ 位置・大きさ・向き ─────────────┤
├ 表示順 ───────────────────────┤
│ Order in Layer 200 ← キャラ(99〜101)より手前 │
├ 音 ─────────────────────────┤
│ 一緒に鳴らすSE  Se_Hit          │
└──────────────────────────┘
```

| 項目 | 説明 |
|---|---|
| いつ消えるか | **自動**：1回再生したら消える ／ **秒数を指定**：指定した秒数で消える ／ **ループ**：止めるまで出続ける（オーラ、炎など） |
| 位置のずらし | Y を `0.5` にすると少し上に出ます |
| 大きさのばらつき | `0.2` で ±20% の範囲で毎回ランダム |
| 向き・左右反転をランダムに | 同じエフェクトが続いても単調に見えにくくなります |
| 表示順 | キャラクターの前に出すなら Order in Layer を大きく（200 など） |
| 一緒に鳴らすSE | SeData を入れると、エフェクトと同時に鳴ります |
| 詳細設定 | ポーズ中も動かす／連打対策／事前に作っておく数 |

設定が足りないと、黄色の警告が出ます。

**Play モード中**は、Inspector 下の **「▶ 試し再生」** でゲーム画面の中央に出して確認できます。

## 3. EffectTrigger を付ける

エフェクトを出したいオブジェクト（敵、宝箱、プレイヤーなど）を選び、
**Add Component → Effect → Effect Trigger** を追加します。

「＋」で行を増やし、それぞれ **いつ** と **エフェクト** を選びます。

| いつ | 例 | 必要なもの |
|---|---|---|
| 出現したとき (最初の1回) | 敵の登場エフェクト | — |
| 表示されたとき (毎回) | 出し入れするオブジェクト | — |
| 消えたとき・非表示になったとき | 消滅の煙 | — |
| ダメージを受けたとき | ヒット | Health |
| 回復したとき | 回復のキラキラ | Health |
| 死亡したとき | 爆発 | Health |
| 何かが入ってきたとき | 踏んだら光る床 | Collider2D (Is Trigger オン) |
| 何かが出ていったとき | — | Collider2D (Is Trigger オン) |
| 何かにぶつかったとき | 壁に当たった火花 | Collider2D (Is Trigger オフ) |
| 手動 | アニメーションに合わせた土煙 | 下の「手動で出す」を参照 |

選んだタイミングに関係する項目だけが表示されます。

| 項目 | 説明 |
|---|---|
| 名前・メモ | 何のエフェクトかのメモ。手動で出すときの呼び名にもなります |
| どこに | （触れたとき）このオブジェクト／触れた相手／触れた場所 |
| 相手のタグ | （触れたとき）`Player` を選ぶとプレイヤーのときだけ出ます |
| くっついて動く | 出した後もキャラについていきます（オーラなど） |
| 出ていったら止める | 入っている間だけループエフェクトを出します |
| 1回だけ出す | 2回目以降は出しません |

シーンビューでは、オブジェクトを選ぶと**エフェクトが出る位置がオレンジの丸**で表示されます。

Play モード中は、Inspector 下の **「▶ ○○」ボタン**で各行を試し再生できます。

### 手動で出す（アニメーションイベント・UnityEvent）

- **アニメーションイベント**：Animation ウィンドウでイベントを置き、Function に `Play`（String）を選び、String に行の「名前」を入力します。
  - 例：名前「足煙」→ String に `足煙`
- **UnityEvent**（ボタンなど）：EffectTrigger の `Play()`（手動の行をすべて）または `Play(string)` を指定します。

### イベントで出す

EventZone のイベントで出したいときは、**EffectEventAction** を付けて EventSequence の actions に登録します。

## 4. すでに用意されているエフェクト欄（弾・敵・攻撃）

次のスクリプトには、Inspector に **「エフェクト」欄** が最初からあります。EffectData を入れるだけで出ます（空なら何も出ません）。

| 設定する場所 | 欄 | 出るタイミング・場所 |
|---|---|---|
| `Prefab/Bullet/PlayerBullet` / `EnemyBullet` | Hit Effect | 狙った相手に当たったとき（当たった表面） |
| 〃 | Obstacle Hit Effect | 壁など、相手以外に当たったとき |
| 〃 | Vanish Effect | 寿命が切れたとき・弾消しエリアで消されたとき |
| 〃 | Rotate Effect To Direction | オンにすると、弾の進行方向にエフェクトを回転させる |
| `EnemyShooter`（敵） | Shot Effect | 敵が弾を撃ったとき（撃った方向に回転） |
| `SigleShooter`（シグル） | Shot Effect | シグルが弾を撃ったとき（撃った方向に回転） |
| `EnemyDead`（敵） | Death Effect | 敵が死亡したとき |
| `AreaAttack`（範囲攻撃） | Attack Effect / Hit Effect | 攻撃したとき／当たった相手ごと |

> 向きが付くエフェクトは、**右向き**に描いておくと進行方向・撃った方向に合わせて回転します。

敵の「ダメージを受けたとき」など、ここにないタイミングは **EffectTrigger** を敵の Prefab に付けて設定してください。

## よくある質問

**Q. エフェクトが出ない**
- EffectData に画像が入っているか（黄色い警告が出ていないか）確認してください。
- EffectTrigger の Inspector に警告が出ていないか確認してください（Health や Collider2D が足りない など）。
- キャラの後ろに隠れていないか、**表示順**を確認してください。

**Q. エフェクトが消えない**
- 「いつ消えるか」が **ループ** になっていませんか？
- パーティクルの **Looping** がオンだと「自動」では消えません（Inspector に警告が出ます）。

**Q. 連打すると重い／うるさい**
- EffectData の **詳細設定 → 連打の最短間隔／同時に出せる最大数** を設定してください。

## プログラマー向け

```csharp
[SerializeField] private EffectData hitFx;

EffectManager.Play(hitFx, transform.position);           // その場に出す
EffectManager.Play(hitFx, transform.position, 90.0f);    // 向きを指定
EffectHandle h = EffectManager.Play(auraFx, transform);  // 追従
EffectManager.Stop(h);                                   // 止める (パーティクルは自然に消える)
EffectManager.Stop(h, true);                             // すぐ消す
EffectManager.StopAll();                                 // すべて消す
EffectManager.Preload(hitFx, 10);                        // 事前に10個作っておく
```

- `EffectManager` はシーンに置かなくても自動で作られ、シーンをまたいで残ります（SeManager と同じ）。シーン切り替え時には出ているエフェクトをすべて消します。
- エフェクトはプールで使い回すので、`Instantiate` / `Destroy` は発生しません。
- Prefab の終わりは ParticleSystem / Animator から自動で判定します。独自の終わり方にしたい場合は、Prefab のスクリプトに `IEffectFinishable` を実装してください。
