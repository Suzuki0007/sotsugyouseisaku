## 使い方のメモ

- ランプの中心は西 (1020, 72)、東 (1140, 72)。スプライトの左上は中心から32ずらした位置
- E3のランプ明滅は、`lamp_on_64x64.png` の表示を短く切り替えることで表現する（専用素材は作っていない）
- 管は背景に描き込み済み。震えの重ね絵は管の経路（西：(990,40)→(270,40)→(270,270)、東：(1170,40)→(1890,40)→(1890,270)）に合わせた位置で作ってある
- 人物（ノア・シグル）はプレビュー内だけの仮。実装では既存の立ち絵・スプライトを使う
- 並び順（描画順）：背景 → 扉 → 管の震え → 音符の光 → ランプ → 人物
