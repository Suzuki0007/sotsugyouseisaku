## 仮組みの順序（レイヤー）

1. 背景 `bg_shosai_placeholder.png`
2. `floor_marks.png`（絨毯の上）
3. オブジェクト（ティンパニ・机・本棚・マレット台・扉・ランプ・楽譜・断片・傷）
4. キャラクター（ノアのスポーンは扉Aの内側 (1280, 630) 付近、西向き。シグルは (270, 400)）
5. エフェクト（波紋など。仮素材なし）

## 注意

- 当たり判定は仕様書のオブジェクト一覧に合わせて矩形・円で置く（ティンパニは円形、家具は矩形、壁の内側が歩ける範囲）
- ティンパニの大きさは直径の目安（T1約200px／T2約180px／T3約160px／T4約140px）に余白を足した画像サイズになっている
- 扉の開閉は画像の差し替えで表現する。仕掛け扉はシグルが殴ったタイミングでロックされ、扉Aも閉まる
